# 함수 설명 템플릿

manual/<언어>/<함수명>.md 는 아래 구조를 그대로 따른다. IntelliSense 툴팁의
함수명 링크가 이 페이지로 연결되므로, 파일명은 **bare 함수명**(EG./x 접두 제외,
대문자, 예: `GROUPBY.md`, `CEILING.MATH.md`)이어야 한다.

언어 폴더: `kr`(한국어, 기준) → 완성 후 `en`/`ja`/`es`/`zh-CN`/`zh-TW`로 번역 확대.

---

```markdown
# 함수명

한 줄 요약(카탈로그 desc와 동일하거나 더 풍부하게).

## 구문

    함수명(인수1, [인수2], …)

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 인수1 | 필수 | … |
| 인수2 | 선택 | … 기본값 포함 |

## 반환

반환 형태(스칼라/배열·스필 여부)와 값의 의미. 오류가 나는 조건(#VALUE!, #N/A 등).

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=함수명(…)` | … | … |

## 참고

- 네이티브/Google 원본과의 차이(있다면 — 예: 집계자는 텍스트 "SUM").
- 관련 함수 링크: [다른함수](다른함수.md)
- 지원: Excel 2010+ (구버전에서는 bare 이름, 최신에서는 EG. 접두)
```
