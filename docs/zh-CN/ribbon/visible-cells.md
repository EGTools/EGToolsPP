# 可见单元格

**位置**：功能区 `EGTools` 选项卡 → `可见单元格` 组

处理已应用筛选·行/列隐藏的区域的复制·粘贴的功能组。
由 2 个拆分按钮组成 — **复制**（默认动作 = 仅复制可见单元格）和
**粘贴**（默认动作 = 仅粘贴值）。

## 仅复制可见单元格

在所选区域中仅挑出**可见单元格**记为复制源并复制到剪贴板。

1. 选择要复制的范围并按下按钮。若所选不是单元格（区域），
   则不做任何动作静默结束。
2. 从所选区域中排除被筛选/隐藏遮住的单元格，仅挑出**可见单元格**，
   将工作簿·工作表名和区域地址记为复制源。
3. 同一区域也会复制到 Excel 剪贴板（显示流动边框），
   可直接用于普通粘贴。

## 全部复制

将所选区域**全部（含隐藏单元格）** 仅**记为**复制源。
不复制到剪贴板，因此屏幕上没有任何变化。

## 仅粘贴值 / 粘贴公式 / 全部粘贴

将记住的复制源按顺序仅粘贴到当前所选区域的**可见单元格**。
3 个菜单只是粘贴的内容不同 — **仅粘贴值**（计算结果值，拆分按钮的
默认动作）、**粘贴公式**、**全部粘贴**（值·公式·格式整体）。

### 操作流程

1. 先执行[仅复制可见单元格](#仅复制可见单元格)或[全部复制](#全部复制)，
   让其记住复制源。
2. 选择要粘贴的目标区域并按菜单。目标中被筛选/隐藏遮住的单元格
   会被跳过，仅**可见单元格**按源顺序填充。
   目标只选择一个单元格时，从该单元格起向下·向右粘贴。
3. 源为多个单元格时，内部会创建**临时工作簿**，按目标的隐藏行/列
   位置调整形状后再粘贴。临时工作簿不保存并自动关闭
   （无需担心清理失败）。
4. 此过程中源工作表的**自动筛选会暂时解除，随后按原条件恢复**。
   源只有一个单元格时无此中间步骤，直接填充目标的全部可见单元格。

### 无法执行的情况

| 情况 | 提示 |
|---|---|
| 尚未记住复制源 | “请先执行[仅复制可见单元格]。” |
| 源工作簿/工作表已关闭或改名 | “找不到复制源工作簿/工作表。请重新复制。” |

## 备注

- 源以工作簿·工作表名和地址记忆。关闭源工作簿或更改工作表名后
  需要重新复制。
- 在筛选状态下复制的可见区域若碎片化得非常厉害（区域地址超过
  255 个字符），可能导致源重新解析失败。此时也会提示重新复制。
