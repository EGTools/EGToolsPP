# 开始选项卡的对齐方式组（跨列居中）

**位置**：Excel `开始`选项卡 → `对齐方式`组（由 EGTools++ 替换） → 合并按钮下方的`跨列居中`

加载 EGTools++ 后，Excel `开始`选项卡中默认的**对齐方式**组会被隐藏，并在原位置重新生成一个
布局相同的**对齐方式**组。加载项无法向 Office 默认组内部插入控件，因此采用整组重建的方式；
唯一的差别是在合并按钮下方新增的**跨列居中**按钮。该按钮不合并单元格，只把水平对齐改为
"跨列居中"，从而在让标题跨多列居中显示的同时，排序、筛选和公式引用照常工作。

**仅当** Excel 合并下拉菜单中尚无原生"跨列居中"项（idMso `CenterAcrossSelection`）时才会替换。
在已有原生项的 Excel 中，默认的`对齐方式`组保持不变，EGTools++ 按钮不会出现（请使用 Excel 自带的项）。

## 组布局

| 位置 | 控件 | 来源 |
|---|---|---|
| 左侧第 1 行 | 顶端对齐 · 垂直居中 · 底端对齐 · 方向 | Excel 内置 |
| 左侧第 2 行 | 左对齐 · 居中 · 右对齐 · 减少缩进量 · 增加缩进量 | Excel 内置 |
| 右侧第 1 行 | 自动换行 | Excel 内置 |
| 右侧第 2 行 | 合并后居中（下拉） | Excel 内置 |
| 右侧第 3 行 | **跨列居中** | EGTools++ 新增 |
| 对话框启动器 | 设置单元格格式：对齐 | Excel 内置 |

Excel 内置控件是把被隐藏的默认组中的控件原样重新放置，因此其行为、标签和快捷键与 Excel 一致。

## 操作步骤 — 跨列居中

1. 以含有内容的单元格为最左端，在同一行中选择要横向铺开的列范围（例如 `A1:F1`）。
   同时选择多行时会逐行应用。
2. 点击`开始`选项卡 → `对齐方式`组中的**跨列居中**。
3. 所选区域的水平对齐被设为**跨列居中**（`xlHAlignCenterAcrossSelection`）：每一行中，内容显示在
   其右侧连续空单元格范围的中央。单元格不会被合并。
4. 在同一区域再次点击，水平对齐恢复为**常规**（`xlHAlignGeneral`）——该按钮是切换式的。

## 规则

| 情形 | 行为 |
|---|---|
| 所选区域已全部为"跨列居中" | 恢复为**常规**对齐 |
| 混合状态（仅部分已应用）或未应用 | 对整个所选区域应用**跨列居中** |
| 选中的是非单元格对象（形状、图表、图片等） | 不执行任何操作 |
| 垂直方向 | 只更改水平对齐，不做垂直居中（这是 Excel "跨列居中"的定义）。垂直位置请用顶端/垂直居中/底端对齐按钮另行设置 |
| 撤消 | 这是加载项命令，不会记录到 Excel 的撤消（`Ctrl+Z`）中。要恢复，请再次点击按钮或在"设置单元格格式"中更改水平对齐 |

## 说明

- Microsoft 正从 Microsoft 365 Insider 渠道开始，逐步推送合并下拉菜单中的"跨列居中"项（2026 年 9 月
  What's New）。EGTools++ 在`开始`选项卡提供此功能，使其在 Excel 2010~2024 以及尚未收到推送的
  Microsoft 365 中也可用。在已有原生项的 Excel 中，EGTools++ 会在加载时检测到它并且不替换`对齐方式`组，
  因此两者不会同时出现，请使用 Excel 自带的项。该判定仅在 EGTools++ 加载时进行一次，若渠道或版本变更
  导致原生项新增或消失，需重新启动 Excel 后才会生效。
- 通过`设置单元格格式`对话框（`Ctrl+1`）→ `对齐`选项卡 → 水平对齐`跨列居中`也能得到同样的效果。
  此按钮是一键应用/取消该设置的快捷方式。
- 若要让多个含值的单元格仅在外观上像已合并，请参阅[保留值的合并](merge-split.md#保留值的合并)；
  该命令应用的是合并格式，而此按钮只更改水平对齐。
- 卸载 EGTools++ 后，替换组消失，Excel 默认的`对齐方式`组重新显示。
