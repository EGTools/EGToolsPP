# 单元格右键菜单

**位置**：右键单击单元格区域 → 上下文菜单

加载 EGTools++ 后，单元格右键菜单中会新增项目。
在普通单元格·表格（列表）区域、页面布局视图中都出现在相同位置。

## 日期选择

在右键单击的单元格旁弹出日历，选取日期填入。无需手动输入日期，
点击两次即可录入。

1. 右键单击单元格并按**日期选择**，活动单元格右侧会出现日历
   （超出屏幕边界时移到左侧）。当前单元格值为日期时以**该日期
   所在月份**开始，否则以今天开始。
2. 用顶部 `◀◀`/`◀`/`▶`/`▶▶` 移动年/月。**点击日期即把该日期填入
   单元格**并关闭日历（灰色显示的上/下月日期也可点击）。
3. 点击底部**“今天: yyyy-mm-dd”行可跳转到今天**。
   按 `Esc` 或关闭窗口(X)取消时单元格不变。

- 周日·**节假日为红色**，周六为蓝色，今天以边框标示。
  鼠标悬停在节假日格上时，底部显示节假日名称。
- 节假日以内置计算为准，若已注册 data.go.kr 密钥，**临时节假日**
  也会反映 — 参见[日历/日程表 — 节假日说明](calendar.md#节假日说明)。

## 打开链接

在所选单元格内容中查找以 `http://` 或 `https://` 开头的 URL，
用默认浏览器打开。

- 即使单元格文本中 URL 与其他文字混在一起，也会找到第一个 URL 打开。
- 选择了多个单元格时，以**第一个单元格（左上）** 为准。
- 单元格中没有 URL 时不做任何动作。

没有超链接格式的普通文本 URL 也能点击两次即打开，
无需进入单元格编辑模式或创建超链接。
