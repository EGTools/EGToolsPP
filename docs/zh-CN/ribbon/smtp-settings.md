# SMTP 设置

**位置**：功能区 `EGTools` 选项卡 → `EGTools` 组 → 拆分按钮下拉菜单

用于登记[邮件合并](mailmerge.md)的**发送邮件**（选项 4·5·6·7）所用
SMTP 服务器信息的对话框。

## 设置项目

| 项目 | 说明 |
|---|---|
| 发件人姓名 | 显示给收件人的发件人名称（可省略 — 省略时仅显示邮箱地址） |
| 发件人邮箱 | 发件人地址，同时是 **SMTP 登录账户** |
| 发送邮件服务器 | SMTP 服务器地址（例：`smtp.gmail.com`） |
| 服务器端口 | 默认 **465** |
| SSL | 是否使用 SSL（默认开启） |

## 规则

- 设置保存在用户账户（注册表）中，**不会留在工作簿里**。
- **密码绝不保存。** 每次发送邮件时输入，仅在内存中使用。
- 在邮件合并中选择了发送选项但设置为空时（邮箱·服务器·端口任一
  缺失），此对话框会**自动打开**。仍未填写完整则中止发送。

## 重要限制 — 仅支持隐式 SSL

发送引擎（Windows CDO）**仅支持隐式 SSL（implicit SSL）**。通常
**端口 465** 属于此类。**不支持端口 587 的 STARTTLS**，
输入 587 会导致发送失败。

- Gmail：服务器 `smtp.gmail.com`，端口 `465`，SSL 开启 —
  请申领**应用专用密码**代替账户密码输入。
- 其他服务也请使用“SSL(465)”方式的端口；启用两步验证的账户
  可能需要应用专用密码。

## 备注

- 中文等非 ASCII 主题/正文以 UTF-8 编码发送。
- 发送失败时，服务器返回的错误说明会原样显示在
  [邮件合并](mailmerge.md)完成汇总的失败列表中。
