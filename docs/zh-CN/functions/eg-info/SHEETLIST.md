# SHEETLIST

**类别**：EGTools 专用函数

返回调用工作簿中可见工作表名列表。

## 语法

```
=SHEETLIST([开始], [结束], [仅中间], [排除当前表])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 开始 | 可选 | 起始表编号/名称(默认: 第一个) |
| 结束 | 可选 | 结束表编号/名称(默认: 最后) |
| 仅中间 | 可选 | TRUE 排除起止表 |
| 排除当前表 | 可选 | TRUE 排除当前表(默认) |

## 返回

以 1 列数组（溢出）返回可见工作表名。调用位置·工作簿确认失败、COM 连接失败、开始·结束指定无效时返回 #VALUE!；筛选后没有剩余工作表时返回 #N/A。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=SHEETLIST()` |  | 结果取决于工作簿构成 |

## 备注

- 宏类函数，通过 COM 读取工作表信息（非线程安全）。
- 隐藏工作表始终排除，默认还排除发起调用的工作表（排除当前表默认 TRUE）。
- 开始·结束可用工作表编号或名称指定。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `SHEETLIST` 名称注册。
