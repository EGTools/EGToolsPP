# TOTALPAGES

**类别**：EGTools 专用函数

按当前打印设置的总页数(打印前请重新计算)。

## 语法

```
=TOTALPAGES([忽略起始号])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 忽略起始号 | 可选 | TRUE 忽略起始页码设置从 1 起 |

## 返回

以数字标量返回总页数，并反映打印设置中的起始页码（忽略起始号 TRUE 时从 1 起）。查询页数失败时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=TOTALPAGES()` |  | 结果取决于打印设置 |

## 备注

- 宏类函数，使用 XLM GET.DOCUMENT（非线程安全）。
- 更改打印设置后需重算才会更新值。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `TOTALPAGES` 名称注册。
