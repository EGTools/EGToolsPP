# EVAL

**类别**：EGTools 专用函数

计算文本形式的公式并返回结果。

## 语法

```
=EVAL(公式)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 公式 | 必需 | 公式文本，如 "SUM(A1:A3)*2" |

## 返回

原样返回计算结果 — 标量为单一值，数组以溢出输出。公式为空或计算失败（含无法连接 COM）时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=EVAL("SUM(A1:A3)*2")` |  | 结果取决于工作表的值 |

## 备注

- 宏类函数，使用 COM Application.Evaluate（非线程安全）。
- 公式开头的 "=" 会自动补上。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `EVAL` 名称注册。
