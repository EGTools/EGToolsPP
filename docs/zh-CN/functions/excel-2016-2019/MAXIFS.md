# MAXIFS

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2016/2019

返回满足所有条件的单元格的最大值。

## 语法

```
=MAXIFS(最大值范围, 条件区域1, 条件1, ...)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 最大值范围 | 必需 | 求最大值的单元格 |
| 条件区域1 | 必需 | 要检验的区域 |
| 条件1 | 必需 | 条件，如 ">5" |
| … | 可选 | 以上参数可重复指定 |

## 返回

以数字标量返回满足所有条件的单元格数值中的最大值。条件区域与目标区域大小不同时返回 #VALUE!，没有满足条件的值时返回 0。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=MAXIFS({1;5;3},{1;2;3},">1")` | 5 | 满足条件的最大值 |
| `=MAXIFS({10;20},{1;2},">5")` | 0 | 无匹配时为 0 |

## 备注

- 条件支持数字、比较运算符（如 ">5"）和通配符（*、?），文本比较不区分大小写。
- 条件值指定为数组时按元素计算，以相同形状的数组溢出返回。错误的条件值按不匹配处理；通过条件的行的值为错误时返回该错误。
- 相关函数：MINIFS。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `MAXIFS` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.MAXIFS`。
