# UNPIVOT

**类别**：EGTools 专用函数

将交叉表(透视表)转换为规范化数据表。

## 语法

```
=UNPIVOT(数组, [固定列], [固定行], [排序], [列名], [有子集])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组 | 必需 | 源表(含标题) |
| 固定列 | 可选 | 左侧行标题列数(默认 1) |
| 固定行 | 可选 | 顶部列标题行数(默认 1) |
| 排序 | 可选 | 结果排序: 列号，负数为降序，如 {1,-3} |
| 列名 | 可选 | 结果表的标题 |
| 有子集 | 可选 | 值列按集合重复时为 TRUE |

## 返回

以二维数组（溢出）返回包含标题行的规范化数据表。输入不是数组、固定列·固定行为负或超出范围或两者均为 0、排序为 0 或超出结果列范围时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=UNPIVOT({"Item","Jan","Feb";"A",10,20;"B",30,40},1,1,,{"Item","Month","Qty"})` | {"Item","Month","Qty";"A","Jan",10;"A","Feb",20;"B","Jan",30;"B","Feb",40} | 解除交叉表透视 |
| `=UNPIVOT({"Item","Jan","Feb";"A",10,20;"B",30,40},1,1,-3,{"Item","Month","Qty"})` | {"Item","Month","Qty";"B","Feb",40;"B","Jan",30;"A","Feb",20;"A","Jan",10} | 按第 3 列降序排序 |

## 备注

- 仅基于值工作，不支持合并单元格填充。
- 值全部为空的条目（单元格）从结果中排除。
- 省略列名时，默认标题随 UI 语言（韩语/英语）而变化。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `UNPIVOT` 名称注册。
