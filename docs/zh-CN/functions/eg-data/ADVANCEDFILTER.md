# ADVANCEDFILTER

**类别**：EGTools 专用函数

用高级筛选式条件网格(行=或，列=与)筛选表格。

## 语法

```
=ADVANCEDFILTER(数据, 筛选, [去重])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数据 | 必需 | 含标题行的数据 |
| 筛选 | 必需 | 含标题行的条件网格 — 支持 =, <>, >, <, >=, <=, *, ? |
| 去重 | 可选 | TRUE 删除重复行 |

## 返回

以二维数组（溢出）返回包含标题行的筛选结果。数据·筛选不是数组或少于 2 行、或筛选标题不在数据标题中时返回 #VALUE!；没有任何匹配的数据行时返回 #N/A。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=ADVANCEDFILTER({"Name","Qty";"A",10;"B",5;"A",7},{"Qty";">6"})` | {"Name","Qty";"A",10;"A",7} | 仅提取 Qty>6 的行 |
| `=ADVANCEDFILTER({"Name","Qty";"Apple",10;"Banana",5;"Avocado",7},{"Name";"A*"})` | {"Name","Qty";"Apple",10;"Avocado",7} | 通配符 A* 筛选 |

## 备注

- 不带运算符的文本条件与 Excel 高级筛选相同，按“开头字符串”匹配。
- 通配符 *、? 在 = 及 <> 条件中受支持。
- 结果始终包含数据的标题行。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `ADVANCEDFILTER` 名称注册。
