# DIRFOLDER

**类别**：EGTools 专用函数

列出指定文件夹的文件(可含文件夹)。

## 语法

```
=DIRFOLDER(路径, [筛选], [含文件夹], [子文件夹], [含隐藏])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 路径 | 必需 | 文件夹路径 |
| 筛选 | 可选 | 如 "*.xlsx;*.csv"(默认 *.*) |
| 含文件夹 | 可选 | TRUE 包含文件夹名 |
| 子文件夹 | 可选 | TRUE 递归子文件夹 |
| 含隐藏 | 可选 | TRUE 包含隐藏项 |

## 返回

以数组（溢出）返回项目名称，包含子文件夹时按深度分列（阶梯式）。路径缺失或为空时返回 #VALUE!；没有匹配项时返回 #N/A。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=DIRFOLDER("C:\Data","*.xlsx;*.csv",FALSE,TRUE)` |  | 结果取决于文件夹内容 |

## 备注

- 非宏函数，直接使用 Win32 API 读取文件夹。
- 筛选可用 ";" 指定多个，支持 *·? 通配符。
- 隐藏项默认排除，可用含隐藏 TRUE 包含。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `DIRFOLDER` 名称注册。
