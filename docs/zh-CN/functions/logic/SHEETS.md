# SHEETS

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

返回工作簿（或引用）中的工作表数。

## 语法

```
=SHEETS([引用])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 引用 | 可选 | 引用（可选） |

## 返回

省略引用时以数字返回工作簿中的工作表数，指定引用时始终返回 1。查询工作表数失败时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=SHEETS()` |  | 文档的工作表数（取决于文档） |

## 备注

- 指定引用时始终返回 1（不支持计算 3-D 引用的工作表数）。
- 注册为宏表函数。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `SHEETS` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.SHEETS`。
