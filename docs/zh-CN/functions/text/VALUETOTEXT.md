# VALUETOTEXT

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2024

返回值的文本表示。

## 语法

```
=VALUETOTEXT(值, [格式])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 值 | 必需 | 值 |
| 格式 | 可选 | 0 简明(默认)，1 严格(文本加引号) |

## 返回

返回值的文本表示形式的单一文本（标量）。实现本身不返回额外的错误值。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=VALUETOTEXT(1.5)` | 1.5 | 数字原样 |
| `=VALUETOTEXT("abc",1)` | "abc" | 严格：文本加引号 |
| `=VALUETOTEXT(TRUE)` | TRUE | 逻辑值 |

## 备注

- 严格（1）格式中，文本内的双引号写成两个（""）。
- value指定为数组时按元素计算，以相同形状的数组溢出返回（错误元素原样返回该错误）。
- 相关函数：ARRAYTOTEXT
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `VALUETOTEXT` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.VALUETOTEXT`。
