# STREXT

**类别**：EGTools 专用函数

按字符类型(数字/拉丁/韩文/日文/汉字)或正则表达式提取·删除。

## 语法

```
=STREXT(文本, 选项, [分隔符])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 源文本 |
| 选项 | 必需 | S=空白 A=拉丁 N=数字 K=韩文 J=日文 H=汉字；以 "-" 开头则删除；其他视为正则 |
| 分隔符 | 可选 | 提取片段间的连接符(默认无) |

## 返回

返回提取（或删除）结果的单一文本（标量）。缺少文本·选项、选项为空、没有有效的字符类别或正则表达式无效时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=STREXT("abc123한글45","N")` | 12345 | 仅提取数字 |
| `=STREXT("abc123한글45","K")` | 한글 | 仅提取韩文 |
| `=STREXT("a1b2","N","-")` | 1-2 | 用分隔符连接 |

## 备注

- N 类别也包含小数点 '.'。
- 选项不是 -SANKJH 的组合时，整体按 ECMAScript 正则表达式（std::wregex）解释。
- 选项以 '-' 开头时删除而非提取这些字符。
- 文本指定为数组时按元素处理，以相同形状的数组溢出返回（错误元素原样返回该错误）；选项·分隔符指定为数组时返回 #VALUE!。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `STREXT` 名称注册。
