# ARRAYTOTEXT

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2024

返回数组的文本表示。

## 语法

```
=ARRAYTOTEXT(数组, [格式])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组 | 必需 | 数组 |
| 格式 | 可选 | 0 简明(默认)，1 严格 |

## 返回

返回将整个数组连接为一体的单一文本（标量）。实现本身不返回额外的错误值。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=ARRAYTOTEXT({1,2;3,4})` | 1, 2, 3, 4 | 简明格式连接 |
| `=ARRAYTOTEXT({"a",1;"b",2},1)` | {"a",1;"b",2} | 严格格式 |

## 备注

- 简明（0）格式不区分行列，用 ", " 连接所有元素。
- 严格（1）格式形如 {a,b;c,d}，仅文本加双引号，内部的引号写成两个（""）。
- 相关函数：VALUETOTEXT
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `ARRAYTOTEXT` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.ARRAYTOTEXT`。
