# TRIMENDS

**类别**：EGTools 专用函数

仅删除首尾空白(保留中间空白)。

## 语法

```
=TRIMENDS(文本, [选项])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 文本或区域 |
| 选项 | 可选 | 额外删除: +1 控制字符，+2 nbsp，+4 不可见 Unicode(默认 0) |

## 返回

返回首尾清理后的文本（标量）；文本参数为数组/区域时按元素处理并溢出。选项超出 0~7 范围时返回 #VALUE!；空单元格变为空字符串。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=TRIMENDS("  a  b  ")` | a  b | 仅去除首尾空白 |
| `=TRIMENDS("a",8)` | #VALUE! | 选项超出范围 |

## 备注

- 选项为 0 时也始终去除首尾的空格·制表符·CR·LF。
- 与 TRIM 不同，字符串中间的空白保持不变。
- 选项可累加：+1 控制字符，+2 NBSP，+4 不可见 Unicode 空白（ZWSP·全角空格等）。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `TRIMENDS` 名称注册。
