# SAMPLINGAC

**类别**：EGTools 专用函数

按 ISO 2859-1 返回接收数(Ac)。

## 语法

```
=SAMPLINGAC(批量, AQL, [检验水平], [严格度], [方案], [次数])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 批量 | 必需 | 批/批次数量 |
| AQL | 必需 | 接收质量限 |
| 检验水平 | 可选 | 默认 G2 |
| 严格度 | 可选 | 0 正常，1 加严，-1 放宽 |
| 方案 | 可选 | 1 一次，2 二次，3~5 多次 |
| 次数 | 可选 | 抽样次数 |

## 返回

返回 ISO 2859-1 接收数 Ac（标量数字）。AQL 超出 0~1000 或检验水平·方案·次数无效时返回 #VALUE!；批量小于 2 或 AQL 小于 0.01 时返回 #NUM!；在表中找不到对应值时返回 #N/A 错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=SAMPLINGAC(1000,1)` | 2 | G2·正常·一次，AQL 1.0 |
| `=SAMPLINGAC(1000,1,"G2",1)` | 1 | 加严检验 |
| `=SAMPLINGAC(500,2.5)` | 3 | 批量 500，AQL 2.5 |

## 备注

- 批量为 1 时返回 0。
- 所有参数都可指定数组，可一次计算 LOT 列表或 AQL 表 — 按元素计算并以相同形状的数组溢出返回；标量重复使用，列向量×行向量按外积扩展，大小不匹配的元素为 #N/A。
- 相关函数：SAMPLINGSIZE、SAMPLINGRE、SAMPLINGLABEL
- 支持：Excel 2010+。在所有 Excel 版本中均按 `SAMPLINGAC` 名称注册。
