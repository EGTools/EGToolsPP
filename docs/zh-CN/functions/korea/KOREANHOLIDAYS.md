# KOREANHOLIDAYS

**类别**：EGTools 专用函数

返回韩国法定节假日列表(含替代休日规则)。

## 语法

```
=KOREANHOLIDAYS([年份], [含名称], [劳动节], [api_key])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 年份 | 可选 | 年份(默认: 今年) |
| 含名称 | 可选 | TRUE 包含名称(默认) |
| 劳动节 | 可选 | TRUE 包含劳动节(默认) |
| api_key | 可选 | 用于查询临时节假日的 data.go.kr 密钥。输入一次即保存，以后可省略。指定 0 则不调用 API，仅用内置计算 |

## 返回

以每行为 [日期序列值, 节假日名称] 的两列数组溢出返回（含名称=FALSE 时仅日期 1 列）。年份超出 919~2050 范围时返回 #VALUE! 错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=ROWS(KOREANHOLIDAYS(2025,,,0))` | 18 | 2025 年节假日行数 — 最后一个参数 0 表示不调用 API，仅用内置计算 |
| `=INDEX(KOREANHOLIDAYS(2025,FALSE,,0),1,1)` | 45658 | 第一个节假日（1 月 1 日）的序列值，仅日期（不含名称） |
| `=KOREANHOLIDAYS(2026)` |  | 默认行为 — 用已保存的 data.go.kr 密钥合并临时节假日（如 2026-06-03 全国同时地方选举日）。结果行数取决于密钥注册和网络状况 |

## 备注

- 替代公休日规则按各自的施行年度应用（儿童节 2014+，三一节·光复节·开天节 2022+，佛诞日·圣诞节 2023+）。
- 节假日名称遵循加载项的语言设置（韩语/英语）；同一天重叠的节假日名称用逗号合并。
- 农历节假日（春节·佛诞日·中秋）用内置农历表（918~2050 年）计算。
- api_key 参数有三种用法。**省略**（默认行为）时，用已保存的 data.go.kr 密钥查询特日信息 API，自动合并临时节假日·选举日等内置计算中没有的项目；没有密钥或查询失败时仅返回内置计算结果（公式不会因错误而中断）。**指定密钥字符串**时保存并使用该密钥，此时若查询失败，单元格中会以 `ERROR: 节假日 API - <原因>` 形式显示原因（无密钥 / 密钥被拒 + 服务器消息 / 服务器连接失败 / 响应中无条目）。**指定 0** 时不调用 API，仅使用内置计算（无网络访问）。
- data.go.kr（韩国公共数据门户）认证密钥每个账户只有一个，KOREANHOLIDAYS·功能区日历/日程表·BRNSTATUS 共用同一密钥。作为最后一个参数传入一次，或在功能区 [EGTools] → [管理 API 密钥] 中注册后即保存到用户账户，此后可省略；旧版本中为营业执照查询单独注册的密钥会在首次使用时自动迁移到统一槽位。
- 查询结果按年度缓存，重算时同一年度只查询一次。失败不缓存，因此修正密钥后下次计算立即生效。
- api_key 指定为数组时在保存前返回 #VALUE!（防止保存错误的密钥）。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `KOREANHOLIDAYS` 名称注册。
