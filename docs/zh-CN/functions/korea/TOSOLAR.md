# TOSOLAR

**类别**：EGTools 专用函数

将韩国农历转换为公历(919~2050年)。

## 语法

```
=TOSOLAR(农历日期)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 农历日期 | 必需 | 如 "2025-06-05" — 闰月加 윤/LM — 或区域 |

## 返回

返回公历日期序列值（标量数字），输入区域时以同尺寸数组溢出。无法解析文本、超出农历表范围（918~2050 年）或农历日期不存在时返回 #VALUE! 错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=TOSOLAR("2025-01-01")` | 45686 | 农历春节 → 2025-01-29 |
| `=TOSOLAR("2025-08-15")` | 45936 | 农历中秋 → 2025-10-06 |

## 备注

- 闰月加 "윤" 或 "LM" 表示（如 "2025-윤06-01"）。
- 请为结果单元格设置日期数字格式后使用。
- 相关函数：TOLUNAR
- 支持：Excel 2010+。在所有 Excel 版本中均按 `TOSOLAR` 名称注册。
