# COUNTIFCOLOR

**类别**：EGTools 专用函数

统计颜色与基准单元格一致的单元格数。

## 语法

```
=COUNTIFCOLOR(检查区域, 基准单元格, [字体色], [条件格式])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 检查区域 | 必需 | 要检查的区域 |
| 基准单元格 | 必需 | 保存基准色的单元格(多个时取第一个) |
| 字体色 | 可选 | TRUE 时比较字体色，默认 FALSE |
| 条件格式 | 可选 | TRUE 时使用含条件格式的显示颜色(仅在函数所在工作表为活动时准确)，默认 FALSE=单元格自身格式颜色 |

## 返回

以数字返回与基准单元格颜色相同（默认为单元格格式颜色，条件格式=TRUE 时为显示颜色）的单元格个数。COM 连接失败、读取基准色失败、检查单元格数超过 100,000 时返回 #VALUE!；检查区域与已用区域不相交时返回 0。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=COUNTIFCOLOR(A1:A10,C1)` |  | 与 C1 填充色相同的单元格数（结果取决于单元格格式） |
| `=COUNTIFCOLOR(A1:A10,C1,,TRUE)` |  | 按条件格式颜色统计的个数（结果取决于单元格格式） |

## 备注

- 字体色=TRUE 时仅统计非空单元格。
- 默认（省略条件格式或为 FALSE）仅使用单元格格式中直接设置的颜色（Interior.Color / Font.Color），忽略由条件格式填充的颜色。无论哪个工作表处于活动状态，编辑其他工作表或执行 F9·完全重算，结果都保持稳定，因此除非确实需要条件格式颜色，建议使用默认值。
- 条件格式=TRUE 时，使用反映条件格式后的实际显示颜色（DisplayFormat）。只有在函数所在工作表处于活动状态时重算，才能正确反映条件格式颜色。
- 注意：条件格式=TRUE 时，若在其他工作表（或其他工作簿）处于活动状态时重算（编辑该工作表、F9、完全重算均如此），将无法正确读取条件格式颜色，得到错误的值。这些函数是易失性函数，仅编辑其他工作表就会重算，因此实际中经常发生。
- 注意：这样产生的错误值在返回函数所在工作表后仍会保留，需在函数所在工作表处于活动状态时按 F9 才能纠正。
- 注意：如需按条件格式颜色汇总，建议尽量直接按条件格式的条件本身汇总（例如 `=COUNTIF(A1:A10,">5")`）。
- 这是接收单元格引用的宏类函数，Excel 将其视为易失性（volatile）函数，工作簿中任意位置的值发生变化都会重算；但仅更改单元格颜色或条件格式规则不会触发重算，需按 F9。也被排除在多线程重算之外。
- 只用到第 3 个参数（字体色）的现有公式保持兼容；但依赖条件格式颜色的现有公式需在第 4 个参数指定 TRUE，才能得到与以前相同的结果。
- 合并单元格按 1 个计数(只检查合并区域的第一个单元格)。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `COUNTIFCOLOR` 名称注册。
