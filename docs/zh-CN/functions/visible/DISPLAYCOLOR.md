# DISPLAYCOLOR

**类别**：EGTools 专用函数

返回区域中每个单元格显示的填充色或字体色。

## 语法

```
=DISPLAYCOLOR(颜色区域, [字体色])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 颜色区域 | 必需 | 要检查颜色的单元格区域 |
| 字体色 | 可选 | TRUE 为字体色，默认 FALSE=填充色 |

## 返回

以与区域同尺寸的数字数组返回每个单元格实际显示的填充色（字体色=TRUE 时为字体色）值，并溢出。单元格数超过 100,000 或 COM 连接·读色失败时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=DISPLAYCOLOR(A1:B2)` |  | 各单元格的显示颜色编号（结果取决于单元格格式） |

## 备注

- 基于 DisplayFormat，返回反映条件格式后的显示颜色。
- 仅更改格式不会触发重算，需按 F9 重新计算。
- 宏类函数，被排除在多线程重算之外。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `DISPLAYCOLOR` 名称注册。
