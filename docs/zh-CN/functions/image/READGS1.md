# READGS1

**类别**：EGTools 专用函数

将 GS1 文本拆分为 AI 与值的数组。

## 语法

```
=READGS1(GS1文本, [连接])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| GS1文本 | 必需 | (AI)值 形式或从条码读取的原文 |
| 连接 | 可选 | TRUE 时连接为一个 (AI)值 字符串 |

## 返回

将 GS1 文本分解为 (AI) 与值的 N×2 数组返回并溢出（连接=TRUE 时为 (AI)值 形式的一个字符串）。输入为空时返回 #VALUE!，在原文流中遇到未知 AI 时返回 #NUM!，没有分解出的条目时返回 #N/A。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=READGS1("(01)04012345678901(10)LOT42")` | {"(01)","04012345678901";"(10)","LOT42"} | 分解为 (AI) 与值的行 |
| `=READGS1("(01)04012345678901(10)LOT42",TRUE)` | (01)04012345678901(10)LOT42 | 连接为一个字符串 |

## 备注

- (AI)值 括号形式和从条码读取的原文流（含 GS 分隔符）都可输入。
- 使用固定长度/可变长度 GS1 AI 表分解流。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `READGS1` 名称注册。
