# READBARCODE

**类别**：EGTools 专用函数

从图片文件或 URL 解码条形码。

## 语法

```
=READBARCODE(来源, [结果类型])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 来源 | 必需 | 本地文件路径或 http(s) URL |
| 结果类型 | 可选 | 1=文本(默认), 2=代码文本, 3=格式, 4=符号体系ID, 5=Raw HEX — 可用 {1,3} 数组 |

## 返回

以与结果类型参数相同的形状返回从图片读取的条形码内容（如 {1,3} 为数组时溢出）。来源为空或结果类型值无效时返回 #VALUE!，URL 下载失败时返回 #NULL!，文件不存在、无法读取图片或找不到条形码时返回 #N/A。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=READBARCODE("C:\barcodes\qr.png")` |  | 图片中的条形码文本（结果取决于文件内容） |
| `=READBARCODE("https://example.com/code.png",{1,3})` |  | 同时返回文本和格式（取决于网络） |

## 备注

- 读取 WIC 支持的 PNG/JPG/BMP/GIF 格式，本地文件路径和 http(s) URL 均可使用。
- 结果类型：1 文本（默认）、2 代码文本（控制字符显示为 <GS> 等）、3 格式、4 符号体系 ID、5 Raw HEX。
- 对旋转·低质量图片也会尝试识别（TryHarder/TryRotate），但只读取一个条形码。
- 来源指定为数组时返回 #VALUE! — 多条数据请将公式按行复制使用。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `READBARCODE` 名称注册。
