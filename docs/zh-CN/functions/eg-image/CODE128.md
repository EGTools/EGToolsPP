# CODE128

**类别**：EGTools 专用函数

将文本生成 CODE128 条形码图片并插入调用单元格。

## 语法

```
=CODE128(文本, [显示文本], [GS1], [文本大小])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 要编码的字符串 |
| 显示文本 | 可选 | TRUE 时在条码下方显示原文 |
| GS1 | 可选 | TRUE 时为 GS1-128(FNC1) — (AI)值、[AI]值 表示法或以 GS 分隔的原始串 |
| 文本大小 | 可选 | 标签相对大小 |

## 返回

成功时返回空字符串（""），并按调用单元格大小另行插入 Code128 条形码图片。文本为空、GS1 转换或编码失败时返回 #VALUE!，无法确定调用单元格时返回 #REF!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=CODE128("ABC-1234",TRUE)` |  | 含下方文本显示的插入（插入图片，取决于环境） |
| `=CODE128("(01)04012345678901(10)LOT42",FALSE,TRUE)` |  | 按 GS1-128（FNC1）格式插入（插入图片，取决于环境） |

## 备注

- gs1=TRUE 时，将 "(01)04012345678901(10)LOT42" 这类带括号的 AI 表示法编码为 GS1-128（符号体系标识符 ]C1）— FNC1 置于首位，可变长度 AI 之后按规范插入分隔符。方括号表示法 "[01]04012345678901[10]LOT42" 和扫描器读取的原始流 `]C10104012345678901<GS>10LOT42`（`<GS>`=分隔符 0x1D — 按字面写成 `<GS>` 也能识别，开头的 ]C1 标识符即使存在也会忽略）也会编码为相同的符号；AI 格式、长度、校验位违规、未知 AI 或非 ASCII 字符返回 #VALUE!。
- 图片填满调用单元格（1D 格式）。
- 文本大小为相对值，反映在下方文本条带的高度上。
- 文本指定为数组时返回 #VALUE!（每个单元格一张图片）— 多条数据请将公式按行复制使用。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `CODE128` 名称注册。
