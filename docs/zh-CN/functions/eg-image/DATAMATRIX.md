# DATAMATRIX

**类别**：EGTools 专用函数

将文本生成 DataMatrix 图片并插入调用单元格（保持比例，单元格较大时居中）。

## 语法

```
=DATAMATRIX(文本, [边距], [GS1])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 要编码的字符串 |
| 边距 | 可选 | 以模块为单位的空白(默认 0) |
| GS1 | 可选 | TRUE 时按 GS1 规范编码(FNC1) — (AI)值、[AI]值 表示法或以 GS 分隔的原始串 |

## 返回

成功时返回空字符串（""），并按调用单元格大小另行插入 DataMatrix 图片。文本为空、GS1 转换或编码失败时返回 #VALUE!，无法确定调用单元格时返回 #REF!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=DATAMATRIX("LOT-2026-08")` |  | 插入 DataMatrix 图片（插入图片，取决于环境） |

## 备注

- gs1=TRUE 时，将 "(01)04012345678901(10)LOT42" 这类带括号的 AI 表示法编码为 GS1 DataMatrix（符号体系标识符 ]d2）— FNC1 置于首位，可变长度 AI 之后按规范插入分隔符。方括号表示法 "[01]04012345678901[10]LOT42" 和扫描器读取的原始流 `]d20104012345678901<GS>10LOT42`（`<GS>`=分隔符 0x1D — 按字面写成 `<GS>` 也能识别，开头的 ]d2 标识符即使存在也会忽略）也会编码为相同的符号；未知 AI 返回 #VALUE!。
- GS1 数据会校验 AI 的格式、长度和校验位（如 (01) GTIN 校验位），违规时返回 #VALUE!，且仅允许可打印 ASCII（中文等返回 #VALUE!）。普通文本按 UTF-8 编码，非 Latin-1 字符会自动插入 ECI（大多数读取器支持）。
- 图片在保持规范比例（模块为正方形）的前提下适配到调用单元格内，剩余空间居中对齐；margin 以模块为单位（默认 0）。
- 文本指定为数组时返回 #VALUE!（每个单元格一张图片）— 多条数据请将公式按行复制使用。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `DATAMATRIX` 名称注册。
