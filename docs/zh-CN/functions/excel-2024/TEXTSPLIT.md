# TEXTSPLIT

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2024

使用列和行分隔符将文本拆分为数组。

## 语法

```
=TEXTSPLIT(文本, 列分隔符, [行分隔符], [忽略空值], [匹配模式], [填充值])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 要拆分的文本 |
| 列分隔符 | 必需 | 列之间的分隔符 |
| 行分隔符 | 可选 | 行之间的分隔符(可选) |
| 忽略空值 | 可选 | 为 TRUE 时跳过空值 |
| 匹配模式 | 可选 | 0 区分大小写(默认)，1 不区分 |
| 填充值 | 可选 | 不齐行的填充值(默认 #N/A) |

## 返回

返回拆分后的文本数组，在动态数组 Excel 中溢出。长度不齐的行用填充值（默认 #N/A）补齐；拆分结果为空时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=TEXTSPLIT("a,b,c",",")` | {a,b,c} | 拆分为列 |
| `=TEXTSPLIT("a,b;c",",",";")` | {a,b;c,#N/A} | 按行列拆分并补齐 |
| `=TEXTSPLIT("1,,2",",",,TRUE)` | {1,2} | 忽略空值 |

## 备注

- 分隔符指定为数组时作为备选分隔符列表（多分隔符，与原生一致）。
- 匹配模式（match_mode）=1 时忽略大小写。
- text 指定为数组时返回相同形状的数组，每个元素为该文本拆分后的第一个标记（与原生一致的降级提升）。
- 相关函数：TEXTBEFORE、TEXTAFTER、TEXTJOIN
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `TEXTSPLIT` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.TEXTSPLIT`。
