# TEXTBEFORE

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2024

返回分隔符之前的文本。

## 语法

```
=TEXTBEFORE(文本, 分隔符, [序号], [匹配模式], [匹配结尾], [未找到值])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 源文本 |
| 分隔符 | 必需 | 要查找的分隔符 |
| 序号 | 可选 | 第几个，负数从末尾(默认 1) |
| 匹配模式 | 可选 | 1 忽略大小写(默认 0) |
| 匹配结尾 | 可选 | 1 将文本结尾视为分隔符(默认 0) |
| 未找到值 | 可选 | 找不到时的值(默认 #N/A) |

## 返回

返回分隔符之前的单一文本（标量）。序号为 0 时返回 #VALUE!；找不到分隔符时返回未找到值（默认 #N/A）。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=TEXTBEFORE("red-blue-green","-")` | red | 第一个分隔符之前 |
| `=TEXTBEFORE("a,b,c",",",-1)` | a,b | 倒数第一个之前 |
| `=TEXTBEFORE("abc","x")` | #N/A | 没有分隔符 |

## 备注

- 匹配结尾（match_end）=1 时，将文本结尾（正序号）/开头（负序号）视为 1 个虚拟分隔符。
- 匹配模式（match_mode）=1 时忽略大小写。
- text 指定为数组时按元素计算，以相同形状的数组溢出返回（错误元素原样返回该错误）；分隔符指定为数组时返回 #VALUE!。
- 相关函数：TEXTAFTER、TEXTSPLIT
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `TEXTBEFORE` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.TEXTBEFORE`。
