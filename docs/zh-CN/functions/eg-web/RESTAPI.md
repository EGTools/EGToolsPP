# RESTAPI

**类别**：EGTools 专用函数

调用 REST API 并返回响应文本。

## 语法

```
=RESTAPI(网址, [方法], [请求头], [请求体])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 网址 | 必需 | API URL(含 GET 参数) |
| 方法 | 可选 | "GET"(默认)、"POST"、"PUT"、"PATCH"、"DELETE" 等 |
| 请求头 | 可选 | 名称/值两列区域 |
| 请求体 | 可选 | 请求体文本 |

## 返回

以单一文本标量返回响应正文（按 UTF-8 解释）。缺少地址、地址为空或 HTTP 请求失败时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=RESTAPI("https://api.example.com/users","GET")` |  | 结果取决于服务器响应 |

## 备注

- 使用 WinHTTP，需要网络连接。接收响应的超时为 30 秒。
- 无论 HTTP 状态码如何都原样返回响应正文。
- 注册为非宏·线程安全，可并行重算。
- 地址·方法·请求正文指定为数组时返回 #VALUE! — 多条数据请将公式按行复制使用。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `RESTAPI` 名称注册。
