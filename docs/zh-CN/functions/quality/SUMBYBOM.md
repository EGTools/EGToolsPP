# SUMBYBOM

**类别**：EGTools 专用函数

展开一级 BOM 并按品目汇总所需数量。

## 语法

```
=SUMBYBOM(数组1, ...)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组1 | 必需 | 列顺序: 父项、子项、用量、品名、数量列 — 可拆成多个参数 |
| … | 可选 | 以上参数可重复指定 |

## 返回

返回由品名 1 列 + 与数量列数相同的合计列组成的数组（溢出），按品名升序排序。列少于 5 个、列长度不同、用量·数量非数字时返回 #VALUE!；数量为负时返回 #NUM!；没有可汇总的项目时返回 #N/A。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=SUMBYBOM({"X","P",2,"X",1;"X","Q",3,"P",5})` | {"P",7;"Q",3} | 将 X 展开一级后汇总 |

## 备注

- BOM 仅展开一级（非多级展开）。
- 品名不区分大小写地汇总，结果按名称升序。
- 非父项的品目在数量为 0 时从结果中排除。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `SUMBYBOM` 名称注册。
