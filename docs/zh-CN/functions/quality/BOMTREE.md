# BOMTREE

**类别**：EGTools 专用函数

由父项/子项/用量列表构建 BOM 树。

## 语法

```
=BOMTREE(父项, 子项, 用量, [标题行], [WBS])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 父项 | 必需 | 父项列 |
| 子项 | 必需 | 子项列(相同长度) |
| 用量 | 必需 | 用量列(相同长度) |
| 标题行 | 可选 | TRUE 添加标题行 |
| WBS | 可选 | TRUE 添加 WBS 列 |

## 返回

以二维数组（溢出）返回按层级·父项·子项·值（选择 WBS 时为 5 列）展开的 BOM 树。三个列表为空或长度不同时返回 #VALUE!；同一父项-子项对存在不同值时以 "Error: ..." 文本返回。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=BOMTREE({"X";"X";"Y"},{"Y";"Z";"W"},{1;2;3})` | {0,"Top Level","X","";1,"X","Y",1;2,"Y","W",3;1,"X","Z",2} | 展开 BOM 树 |
| `=BOMTREE({"X";"X";"Y"},{"Y";"Z";"W"},{1;2;3},TRUE)` | {"level","Parent","Child","Value";0,"Top Level","X","";1,"X","Y",1;2,"Y","W",3;1,"X","Z",2} | 含标题行 |

## 备注

- WBS 编号用零宽空格（U+200B）补足 5 位以保持排序。
- 展开深度限制为 64（循环引用防护）。
- 遇到父项单元格为空的行时，从该处停止读取列表。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `BOMTREE` 名称注册。
