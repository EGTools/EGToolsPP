# TEXTBETWEEN

**类别**：EGTools 专用函数

提取 起始键 与 结束键 之间的文本。

## 语法

```
=TEXTBETWEEN(文本, 起始键, 结束键, [分隔符或序号], [包含键])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 源文本 |
| 起始键 | 必需 | 起始标记 |
| 结束键 | 必需 | 结束标记 |
| 分隔符或序号 | 可选 | 全部连接符(默认 ",")，或数字 N 仅取第 N 个 |
| 包含键 | 可选 | TRUE 时包含标记 |

## 返回

返回提取出的单一文本（标量）。文本·起始键·结束键任一为空时返回 #VALUE!；指定的第 N 个超出区段数量时返回 #VALUE!；没有匹配区段时返回空字符串。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=TEXTBETWEEN("[a] and [b]","[","]")` | a,b | 全部区段用 , 连接 |
| `=TEXTBETWEEN("[a] and [b]","[","]",2)` | b | 仅第 2 个区段 |
| `=TEXTBETWEEN("<x><y>","<",">","/",TRUE)` | <x>/<y> | 含键连接 |

## 备注

- 键搜索忽略大小写。
- 第 4 个参数为数字时仅取第 N 个区段，为文本时作为全部区段的连接分隔符（默认 ","）。
- 文本指定为数组时按元素处理，以相同形状的数组溢出返回（错误元素原样返回该错误）；起始键·结束键等其他参数指定为数组时返回 #VALUE!。
- 相关函数：TEXTREPLACE
- 支持：Excel 2010+。在所有 Excel 版本中均按 `TEXTBETWEEN` 名称注册。
