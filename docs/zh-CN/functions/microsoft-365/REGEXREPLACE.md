# REGEXREPLACE

**类别**：MS Excel 兼容函数 · **原生引入**：Microsoft 365

替换与正则表达式匹配的文本($1.. 反向引用)。

## 语法

```
=REGEXREPLACE(文本, 模式, 替换文本, [次序], [区分大小写])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 源文本 |
| 模式 | 必需 | 正则模式 |
| 替换文本 | 必需 | 替换内容($1, $2…) |
| 次序 | 可选 | 0 全部(默认)，N = 第 N 个 |
| 区分大小写 | 可选 | 0 区分(默认)，1 忽略 |

## 返回

返回替换后的单一文本（标量）。正则表达式无效时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=REGEXREPLACE("a1b2c3","\d","-")` | a-b-c- | 全部替换 |
| `=REGEXREPLACE("a1b2c3","\d","-",2)` | a1b-c3 | 仅替换第 2 个 |
| `=REGEXREPLACE("john smith","(\w+) (\w+)","$2 $1")` | smith john | 反向引用替换 |

## 备注

- 替换文本支持 $1、$2 反向引用。
- 次序 0（默认）替换全部，N>0 仅替换第 N 个匹配。
- 正则语法为 std::wregex 的 ECMAScript。
- text·pattern·replacement指定为数组时按元素计算，以相同形状的数组溢出返回 — 标量重复使用，列向量×行向量按外积扩展，大小不匹配的元素为 #N/A，错误元素原样返回该错误。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `REGEXREPLACE` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.REGEXREPLACE`。
