# HASANY

**类别**：MS Excel 兼容函数 · **原生引入**：Microsoft 365（2026 年新增）

若任一值出现在列表或数组中则返回 TRUE。

## 语法

```
=HASANY(数组, 值集)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组 | 必需 | 要搜索的列表文本、区域或数组 |
| 值集 | 必需 | 要查找的值(区域、数组或列表文本) |

## 返回

返回 TRUE/FALSE（标量）。数组或值集参数本身是错误时原样返回该错误；省略值集时返回 #VALUE!。值集为空时为 FALSE。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=HASANY("a, b, c",{"x","c"})` | TRUE | 任一存在即 TRUE |
| `=HASANY("1, 2",{"1"})` | FALSE | 数组常量中的文本 "1" 与数字 1 不同 |

## 备注

- 值集参数可接受区域、数组常量和列表文本，包含嵌套在内的所有项被展平为一个值集合，每个值按与 HAS 相同的规则查找（不区分大小写的整项匹配、数值相等）。值集给文本时会按列表文本解析，以逗号拆分，拆分后数字形状的项变为数字（可像 "z, B" 一样指定多个值；"1, 2" 是数字 1 和 2）。要把单个值按文本原样比较，请用数组常量 {"1"}。
- 数组参数的解析规则（列表文本、区域、数组常量；无逗号的单个文本保持文本；无法解析时为 1 个项）与 HAS 相同。单元格内列表请先用功能区 [EGTools] › [列表/数组单元格 → 文本] 转换后再使用。
- 相关函数：HAS、HASALL、FLATTEN
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `HASANY` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.HASANY`。
