# EXPAND

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2024

将数组扩展到指定大小，并用值填充。

## 语法

```
=EXPAND(数组, 行数, [列数], [填充值])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组 | 必需 | 数组 |
| 行数 | 必需 | 总行数 |
| 列数 | 可选 | 总列数(可选) |
| 填充值 | 可选 | 填充值(默认 #N/A) |

## 返回

返回扩展到指定行数×列数大小的数组，在支持动态数组的 Excel 中溢出。新增位置用填充值（默认 #N/A）填充。数组为空或指定大小小于原数组时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=EXPAND({1,2;3,4},3,3,0)` | {1,2,0;3,4,0;0,0,0} | 扩展为 3×3 并填 0 |
| `=EXPAND({1,2},1,4)` | {1,2,#N/A,#N/A} | 默认填充值 #N/A |
| `=EXPAND({1,2;3,4},1,1)` | #VALUE! | 不能缩小 |

## 备注

- 省略行数·列数时保持原大小。
- 省略填充值时以 #N/A 填充。
- 行数·列数·填充值指定为数组时，返回与该数组相同形状的数组，每个元素为该元素结果的第一个值（与原生一致的降级提升）。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `EXPAND` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.EXPAND`。
