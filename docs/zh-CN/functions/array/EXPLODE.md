# EXPLODE

**类别**：EGTools 专用函数

按分隔符拆分指定列并展开为行或列；其他列原样复制。

## 语法

```
=EXPLODE(数组, 列号, [分隔符], [按列], [填充值], [忽略空值])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组 | 必需 | 源表 |
| 列号 | 必需 | 要拆分的列，从 1 起 |
| 分隔符 | 可选 | 分隔符(可多个)，默认空格 |
| 按列 | 可选 | TRUE 横向展开(默认 FALSE: 纵向) |
| 填充值 | 可选 | 按列展开时空格的填充值(默认 "") |
| 忽略空值 | 可选 | TRUE 丢弃空片段 |

## 返回

以二维数组（溢出）返回展开结果。数组参数不是数组时返回 #VALUE!；列号超出 1~列数范围时返回 #NUM!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=EXPLODE({"A","x,y";"B","z"},2,",")` | {"A","x";"A","y";"B","z"} | 第 2 列展开为行 |
| `=EXPLODE({"A","x,y";"B","z"},2,",",TRUE)` | {"A","x","y";"B","z",""} | 展开为列并填充空位 |

## 备注

- 可指定多个分隔符，从较长的分隔符开始应用（默认：空格）。
- 横向展开时不足的位置用填充值（默认 ""）填充。
- 忽略空值为 TRUE 时删除空片段（全部为空时保留 1 个空字符串）。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `EXPLODE` 名称注册。
