# SORTBY

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2021

按其他数组的值对数组排序。

## 语法

```
=SORTBY(数组, 依据数组1, [顺序1], ...)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组 | 必需 | 要排序的数据 |
| 依据数组1 | 必需 | 排序键(按行) |
| 顺序1 | 可选 | 1 升(默认)，-1 降 |
| … | 可选 | 以上参数可重复指定 |

## 返回

返回按依据数组的值顺序重排行后的数组，并会溢出。没有任何与 array 行数相同的有效依据数组时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=SORTBY({"a";"b";"c"},{3;1;2})` | {b;c;a} | 按依据数组排序 |
| `=SORTBY({1;2;3},{2;2;1},1,{9;1;5},-1)` | {3;1;2} | 第二依据降序 |

## 备注

- 依据数组必须是与 array 行数相同的纵向（列）向量，且仅支持按行排序（不支持列方向排序）。
- 行数不同的依据数组会被静默忽略。
- 相关函数：SORT。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `SORTBY` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.SORTBY`。
