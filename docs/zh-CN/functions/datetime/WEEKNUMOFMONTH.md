# WEEKNUMOFMONTH

**类别**：EGTools 专用函数

按周起始日与归属日计算月内周数。

## 语法

```
=WEEKNUMOFMONTH(日期, [周起始日], [归属日])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 日期 | 必需 | 基准日期 |
| 周起始日 | 可选 | 1=日~7=六(默认 2=一) |
| 归属日 | 可选 | 决定所属月的星期(默认 5=四) |

## 返回

返回月内周数（标量数字）。无法解析日期，或周起始日·归属日超出 1~7 范围时返回 #VALUE! 错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=WEEKNUMOFMONTH(DATE(2026,1,15))` | 3 | 1 月第三周 |
| `=WEEKNUMOFMONTH(DATE(2026,2,1))` | 5 | 2/1 属于 1 月第 5 周 |

## 备注

- 星期编号为 1=日 ~ 7=六，默认为周一开始·周四归属。
- 周的归属月·周数以归属日所在的月份为准计算。
- 日期指定为数组时按元素计算，以相同形状的数组溢出返回（错误元素原样返回该错误）。
- 相关函数：MONTHBHYWEEK
- 支持：Excel 2010+。在所有 Excel 版本中均按 `WEEKNUMOFMONTH` 名称注册。
