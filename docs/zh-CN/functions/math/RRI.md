# RRI

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

返回投资增长的等效利率。

## 语法

```
=RRI(nper, pv, fv)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| nper | 必需 | 期数 |
| pv | 必需 | 现值 |
| fv | 必需 | 终值 |

## 返回

返回与投资增长对应的每期等效利率（标量数字）。参数非数字、nper 小于等于 0 或 pv 为 0 时返回 #NUM! 错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=RRI(96,10000,11000)` | 0.000993307 | 96 期 10000→11000 的利率 |

## 备注

- 所有参数指定为数组时按元素计算，以相同形状的数组溢出返回 — 标量重复使用，列向量×行向量按外积扩展，大小不匹配的元素为 #N/A，错误元素原样返回该错误。
- 相关函数：PDURATION
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `RRI` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.RRI`。
