# UNIQUE

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2021

返回数组中唯一的行(或列)。

## 语法

```
=UNIQUE(数组, [按列], [仅一次])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组 | 必需 | 数据 |
| 按列 | 可选 | TRUE 则唯一列 |
| 仅一次 | 可选 | TRUE 则仅出现一次的项 |

## 返回

返回去除重复后的唯一行（或列）数组，并会溢出。没有剩余项时返回 #N/A，内部错误返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=UNIQUE({1;2;2;3})` | {1;2;3} | 去除重复 |
| `=UNIQUE({1;2;2;3},,TRUE)` | {1;3} | 仅出现一次的值 |

## 备注

- 无结果时返回 #N/A 而非 #CALC!。
- 相关函数：FILTER、SORT。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `UNIQUE` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.UNIQUE`。
