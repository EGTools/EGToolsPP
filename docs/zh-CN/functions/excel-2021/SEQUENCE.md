# SEQUENCE

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2021

生成连续数字的数组。

## 语法

```
=SEQUENCE(行数, [列数], [起始], [步长])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 行数 | 必需 | 行的数量 |
| 列数 | 可选 | 列的数量(默认 1) |
| 起始 | 可选 | 起始值(默认 1) |
| 步长 | 可选 | 增量(默认 1) |

## 返回

返回 rows×cols 大小的连续数字数组（按行优先递增），并会溢出。rows 或 cols 小于等于 0 时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=SEQUENCE(3)` | {1;2;3} | 默认 3 行数列 |
| `=SEQUENCE(2,3,0,10)` | {0,10,20;30,40,50} | 指定起始值与步长 |

## 备注

- 省略 rows 时按 1 处理（原生函数为必需参数）。
- 所有参数指定为数组时，返回与该数组相同形状的数组，每个元素为该元素结果的第一个值（与原生一致的降级提升）。
- 相关函数：RANDARRAY。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `SEQUENCE` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.SEQUENCE`。
