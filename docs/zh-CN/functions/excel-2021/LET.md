# LET

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2021

> ⚠️ 在部分旧版本中因保留字冲突注册为 `xLET`。

为值指定名称，并在最终计算中使用这些名称。

## 语法

```
=LET(name1, value1, calculation, ...)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| name1 | 必需 | 要定义的名称 |
| value1 | 必需 | 此名称的值 |
| calculation | 必需 | 使用上述名称的最终计算式 |
| … | 可选 | 以上参数可重复指定 |

## 返回

返回将名称替换为值后的最终计算式的求值结果，结果为数组时会溢出。参数结构错误或无法读取调用单元格的公式时返回 #VALUE!；求值失败时返回替换后的公式字符串而非错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=LET(x,3,x*2)` | 6 | 定义名称后计算 |
| `=LET(x,2,y,x+1,x*y)` | 6 | 可引用前面的名称 |

## 备注

- 它不像原生函数那样绑定名称，而是在调用单元格的公式文本中将名称替换为值后交给 Application.Evaluate 求值的宏表函数。
- 名称 "R"、"C" 是 Excel R1C1 解析器的保留字，不能使用。
- 求值失败时为便于调试，原样返回替换后的公式字符串。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `LET` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.LET`。
