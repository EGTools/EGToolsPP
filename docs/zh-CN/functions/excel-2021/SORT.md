# SORT

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2021

对数组进行排序。

## 语法

```
=SORT(数组, [排序索引], [排序顺序], [按列])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组 | 必需 | 要排序的数据 |
| 排序索引 | 可选 | 排序依据的列(或行)，默认 1 |
| 排序顺序 | 可选 | 1 升序(默认)，-1 降序 |
| 按列 | 可选 | TRUE 则按列排序 |

## 返回

返回按指定列（或行）排序后的同尺寸数组，并会溢出。sort_index 超出数组范围或发生内部错误时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=SORT({3;1;2})` | {1;2;3} | 升序排序 |
| `=SORT({1,3;2,1;3,2},2)` | {2,1;3,2;1,3} | 按第 2 列排序 |
| `=SORT({5;3;9},1,-1)` | {9;5;3} | 降序排序 |
| `=SORT({1,1;2,5;1,3;2,2},{1,2},{1,-1})` | {1,3;1,1;2,5;2,2} | 多列排序（第 1 列升序·第 2 列降序） |

## 备注

- sort_order 为负数时按降序，其余值（含 0）按升序处理（原生函数仅允许 1/-1）。
- 相同键保持原始顺序（稳定排序）。
- sort_index·sort_order 指定为数组时为多列优先级排序（如 {1,2} 与 {1,-1} = 第 1 列升序 → 第 2 列降序）；仅 sort_order 为数组时返回 #VALUE!。
- 相关函数：SORTBY、UNIQUE。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `SORT` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.SORT`。 在部分旧版本中因保留字冲突注册为 `xSORT`。
