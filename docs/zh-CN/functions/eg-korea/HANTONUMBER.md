# HANTONUMBER

**类别**：EGTools 专用函数

将韩文(汉字)金额表示转换为数字。

## 语法

```
=HANTONUMBER(文本, [仅数字])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 韩文金额文本 |
| 仅数字 | 可选 | TRUE 返回数字(默认)；FALSE 返回带格式文本 |

## 返回

默认（仅数字=TRUE）返回数字（标量），整数部分超过 15 位时为保持精度以文本返回。仅数字=FALSE 时返回 "금1,234원" 形式的文本。文本为空，或阿拉伯数字·小数点连续出现 2 个以上时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=HANTONUMBER("일금오만원정")` | 50000 | 韩文金额转数字 |
| `=HANTONUMBER("삼억이천오백만")` | 325000000 | 处理亿·万单位 |
| `=HANTONUMBER("일금오만원정",FALSE)` | 일금50,000원정 | 返回带格式文本 |

## 备注

- 也可识别汉字写法及异体字（一二三、壹貳參、拾佰仟萬 等）。
- 输入中的空格和逗号被忽略；금/일금·원/원정 前后缀在仅数字=FALSE 时按原样还原。
- 文本指定为数组时按元素处理，以相同形状的数组溢出返回（错误元素原样返回该错误）；其他参数指定为数组时返回 #VALUE!。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `HANTONUMBER` 名称注册。
