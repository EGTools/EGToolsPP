# TOLUNAR

**类别**：EGTools 专用函数

将公历日期转换为韩国农历(919~2050年)。

## 语法

```
=TOLUNAR(公历日期)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 公历日期 | 必需 | 日期、序列值、"yyyy-mm-dd" 文本、yyyymmdd 数字或区域 |

## 返回

以标量返回农历日期文本 "yyyy-mm-dd"（闰月带后缀），输入区域时以同尺寸数组溢出。无法解析日期或超出农历表范围（918~2050 年）时返回 #VALUE! 错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=TOLUNAR(DATE(2025,1,29))` | 2025-01-01 | 2025 年春节 → 农历 1/1 |
| `=TOLUNAR(DATE(2025,10,6))` | 2025-08-15 | 2025 年中秋 → 农历 8/15 |

## 备注

- 闰月按语言设置带 "(윤)"（韩语）或 "(LM)"（英语）后缀。
- 使用由 .NET KoreanLunisolarCalendar 生成的内置表（918~2050 年）。
- 相关函数：TOSOLAR
- 支持：Excel 2010+。在所有 Excel 版本中均按 `TOLUNAR` 名称注册。
