# IMPORTCSV

**类别**：MS Excel 兼容函数 · **原生引入**：Microsoft 365（2026 年新增）

将 CSV 文件(本地路径/URL)导入为数组 — 逗号分隔、UTF-8。

## 语法

```
=IMPORTCSV(路径, [跳过行], [读取行], [区域设置])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 路径 | 必需 | 本地文件路径或 URL |
| 跳过行 | 可选 | 跳过的行数 — 负数从末尾 |
| 读取行 | 可选 | 读取的行数 — 负数从末尾 |
| 区域设置 | 可选 | 数字解析区域，如 "de-DE" |

## 返回

将 CSV 内容以二维数组溢出返回，数字和日期（yyyy-M-d 等）文本自动转换为值。缺少路径或文件读取·下载失败时返回 #VALUE!，没有内容（剩余行）时返回 #N/A。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=IMPORTCSV("C:\data\sales.csv",1)` |  | 取决于文件内容 |

## 备注

- 固定为逗号分隔·UTF-8 编码（有 BOM 时以 BOM 优先）。需要其他分隔符·编码时使用 IMPORTTEXT。
- 可识别双引号引用字段（含 "" 转义）。
- skip_rows/take_rows 为负数时从末尾计算。
- 路径·take_rows指定为数组时返回 #VALUE! — 多条数据请将公式按行复制使用。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `IMPORTCSV` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.IMPORTCSV`。
