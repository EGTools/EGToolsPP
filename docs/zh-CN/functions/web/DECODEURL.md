# DECODEURL

**类别**：EGTools 专用函数

将百分号编码的 URL 字符串解码为文本。

## 语法

```
=DECODEURL(文本)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 要解码的 URL 文本 |

## 返回

返回将 %-编码（UTF-8）还原为原文本的字符串。输入数组时按元素处理，以同尺寸数组溢出。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=DECODEURL("a%20b%26c")` | a b&c | 解码 %-编码 |
| `=DECODEURL("%ED%95%9C%EA%B8%80")` | 한글 | 解码 UTF-8 韩文 |

## 备注

- 无效的 % 序列不转换，保持原样。
- + 号不会替换为空格（不支持表单编码）。
- 是 ENCODEURL 的反函数。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `DECODEURL` 名称注册。
