# JSONFILTER

**类别**：EGTools 专用函数

将 JSON 文本解析为(路径, 值)两列表。

## 语法

```
=JSONFILTER(JSON文本, [键路径])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| JSON文本 | 必需 | 要解析的 JSON 文本 |
| 键路径 | 可选 | 筛选路径，如 "data.items[0].name"(默认: 全部) |

## 返回

以（路径, 值）2 列数组（溢出）返回 — 数字为数字、true/false 为布尔值、null 为空字符串。文本为空、JSON 解析失败或找不到键路径时返回 #VALUE!；结果为空对象·数组时返回 #N/A。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=JSONFILTER("{""a"":1,""b"":[true,null]}")` | {"a",1;"b[0]",TRUE;"b[1]",""} | 整个 JSON 展平 |
| `=JSONFILTER("{""a"":{""b"":5,""c"":""x""}}","a")` | {"b",5;"c","x"} | 仅输出键路径以下 |

## 备注

- 不依赖外部库，使用自带的轻量解析器。
- 整个文本必须是有效的 JSON，不支持注释·尾随逗号。
- 键路径形如 "a.b[0].c"，数组索引从 0 开始。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `JSONFILTER` 名称注册。
