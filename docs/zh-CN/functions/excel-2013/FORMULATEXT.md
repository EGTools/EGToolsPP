# FORMULATEXT

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

以文本形式返回所引用单元格的公式。

## 语法

```
=FORMULATEXT(引用)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 引用 | 必需 | 要返回其公式的单元格 |

## 返回

以文本标量返回所引用单元格的公式。省略引用、单元格没有公式或查询失败时返回 #N/A。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=FORMULATEXT(A1)` |  | 取决于 A1 的内容 |

## 备注

- 注册为宏表函数。
- 相关函数：ISFORMULA。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `FORMULATEXT` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.FORMULATEXT`。
