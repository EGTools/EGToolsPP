# ISOWEEKNUM

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

返回某日期的 ISO 8601 年度周数。

## 语法

```
=ISOWEEKNUM(日期)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 日期 | 必需 | 日期 |

## 返回

以数字返回日期的 ISO 8601 年度周数（1~53）。参数为数组时按元素计算返回同尺寸数组，在动态数组 Excel 中溢出。日期不是数字或为负数时返回 #VALUE!，序列值无法转换为日期时返回 #NUM!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=ISOWEEKNUM(DATE(2026,1,1))` | 1 | 2026-01-01 是第 1 周 |
| `=ISOWEEKNUM(DATE(2023,1,1))` | 52 | 上一年的最后一周 |

## 备注

- 输入数组时按元素计算，返回同尺寸数组。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `ISOWEEKNUM` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.ISOWEEKNUM`。
