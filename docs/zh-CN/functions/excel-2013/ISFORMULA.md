# ISFORMULA

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

如果引用的单元格包含公式，则返回 TRUE。

## 语法

```
=ISFORMULA(引用)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 引用 | 必需 | 要检验的单元格 |

## 返回

所引用单元格含有公式时返回 TRUE，否则返回 FALSE。省略引用或查询失败时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=ISFORMULA(A1)` |  | 取决于 A1 的内容 |

## 备注

- 注册为宏表函数。
- 相关函数：FORMULATEXT。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `ISFORMULA` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.ISFORMULA`。
