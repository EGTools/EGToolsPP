# SHEET

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

返回引用的工作表编号（或当前工作表）。

## 语法

```
=SHEET([值])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 值 | 可选 | 引用（可选；默认：当前工作表） |

## 返回

以数字返回引用（省略时为输入公式的单元格）所在工作表的位置（从 1 开始）。找不到工作表时返回 #N/A，查询工作表列表失败时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=SHEET()` |  | 当前工作表位置（取决于文档） |

## 备注

- 参数只接受单元格引用（原生函数还接受工作表名文本）。
- 注册为宏表函数。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `SHEET` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.SHEET`。
