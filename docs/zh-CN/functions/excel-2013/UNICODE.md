# UNICODE

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

返回文本首字符的 Unicode 代码点。

## 语法

```
=UNICODE(文本)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 要检查首字符的文本 |

## 返回

返回首字符的代码点数字（标量）；文本参数为数组时按元素计算并溢出。空文本返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=UNICODE("A")` | 65 | 拉丁字符 |
| `=UNICODE("가")` | 44032 | 韩文音节 |
| `=UNICODE("😀")` | 128512 | BMP 之外的字符 |

## 备注

- 可识别代理对，对 BMP 之外的字符也返回完整代码点。
- 相关函数：UNICHAR
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `UNICODE` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.UNICODE`。
