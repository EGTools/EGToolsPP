# UNICHAR

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

返回给定数字（代码点）对应的 Unicode 字符。

## 语法

```
=UNICHAR(数字)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数字 | 必需 | Unicode 代码点 |

## 返回

返回代码点对应的字符文本（标量）；数字参数为数组时按元素计算并溢出。代码超出 1~1114111 范围或位于代理区（55296~57343）时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=UNICHAR(44032)` | 가 | 韩文音节 |
| `=UNICHAR(128512)` | 😀 | BMP 之外的字符 |
| `=UNICHAR(0)` | #VALUE! | 超出范围 |

## 备注

- 0x10000 及以上的字符以代理对（UTF-16）形式返回。
- 相关函数：UNICODE
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `UNICHAR` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.UNICHAR`。
