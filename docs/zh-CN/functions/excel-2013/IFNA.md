# IFNA

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

如果值为 #N/A 错误，则返回替代值；否则返回该值。

## 语法

```
=IFNA(值, 替代值)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 值 | 必需 | 值或表达式 |
| 替代值 | 必需 | 为 #N/A 时返回的值 |

## 返回

值为 #N/A 错误时返回替代值，否则返回原值。传入数组时按元素应用并返回数组，且会溢出。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=IFNA(NA(),"none")` | none | 替换 #N/A |
| `=IFNA(1/0,0)` | #DIV/0! | #N/A 以外的错误保持不变 |
| `=IFNA(5,0)` | 5 | 正常值保持不变 |

## 备注

- 值与替代值都可指定数组并相互广播，按元素仅替换 #N/A（标量重复使用，大小不匹配的元素为 #N/A；返回数组并溢出）。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `IFNA` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.IFNA`。
