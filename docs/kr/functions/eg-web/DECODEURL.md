# DECODEURL

**종류**: EGTools 전용 함수

%-인코딩된 URL 문자열을 원래 텍스트로 되돌립니다.

## 구문

```
=DECODEURL(텍스트)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 디코딩할 URL 텍스트 |

## 반환

%-인코딩(UTF-8)을 원래 텍스트로 되돌린 문자열을 반환합니다. 배열을 입력하면 요소별로 처리해 같은 크기의 배열로 스필됩니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=DECODEURL("a%20b%26c")` | a b&c | %-인코딩 디코드 |
| `=DECODEURL("%ED%95%9C%EA%B8%80")` | 한글 | UTF-8 한글 디코드 |

## 참고

- 유효하지 않은 % 시퀀스는 변환하지 않고 그대로 둡니다.
- + 기호는 공백으로 바꾸지 않습니다(폼 인코딩 미지원).
- ENCODEURL의 역함수입니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `DECODEURL` 이름 그대로 등록됩니다.
