# SHEETS

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

통합 문서(또는 참조)의 시트 수를 반환합니다.

## 구문

```
=SHEETS([참조])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 참조 | 선택 | 참조(선택) |

## 반환

참조를 생략하면 통합 문서의 시트 수를, 참조를 지정하면 항상 1을 숫자로 반환합니다. 시트 수 조회에 실패하면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=SHEETS()` |  | 문서의 시트 수(문서 의존) |

## 참고

- 참조를 지정하면 항상 1을 반환합니다(3-D 참조의 시트 수 계산 미지원).
- 매크로 시트형 함수로 등록됩니다.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `SHEETS` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.SHEETS`으로 등록됩니다.
