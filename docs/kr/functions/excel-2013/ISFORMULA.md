# ISFORMULA

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

참조한 셀이 수식을 포함하면 TRUE를 반환합니다.

## 구문

```
=ISFORMULA(참조)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 참조 | 필수 | 검사할 셀 |

## 반환

참조한 셀에 수식이 있으면 TRUE, 없으면 FALSE를 반환합니다. 참조를 생략했거나 조회에 실패하면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=ISFORMULA(A1)` |  | A1 내용에 따라 다름 |

## 참고

- 매크로 시트형 함수로 등록됩니다.
- 관련 함수: FORMULATEXT.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `ISFORMULA` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.ISFORMULA`으로 등록됩니다.
