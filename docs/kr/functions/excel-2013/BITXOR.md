# BITXOR

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

두 수의 비트 XOR 결과를 반환합니다.

## 구문

```
=BITXOR(number1, number2)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| number1 | 필수 | 첫째 수(0 이상) |
| number2 | 필수 | 둘째 수(0 이상) |

## 반환

두 수의 비트 XOR 결과를 숫자(스칼라)로 반환합니다. 인수가 숫자·논리값이 아니거나, 음수·소수이거나, 2^48-1(281,474,976,710,655)을 넘으면 #NUM!을 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=BITXOR(5,3)` | 6 | 101 XOR 011 = 110 |
| `=BITXOR(5,"a")` | #NUM! | 숫자 아니면 오류 |

## 참고

- 숫자가 아닌 인수에도 #VALUE!가 아닌 #NUM!을 반환합니다.
- 모든 인수에 배열을 지정하면 원소별로 계산해 같은 모양의 배열로 스필됩니다 — 스칼라는 반복, 열 벡터×행 벡터는 외적으로 확장, 크기가 맞지 않는 원소는 #N/A, 오류 원소는 그 오류를 그대로 반환합니다.
- 관련 함수: BITAND, BITOR
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `BITXOR` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.BITXOR`으로 등록됩니다.
