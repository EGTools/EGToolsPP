# XOR

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

인수들의 배타적 논리합을 반환합니다(TRUE 개수가 홀수면 TRUE).

## 구문

```
=XOR(논리1, ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 논리1 | 필수 | 검사할 값 또는 범위 |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |

## 반환

TRUE인 값의 개수가 홀수면 TRUE, 짝수면 FALSE를 논리 스칼라로 반환합니다. 인수에 오류가 있으면 첫 오류를 그대로 반환하고, 논리로 평가할 값이 하나도 없으면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=XOR(TRUE,FALSE)` | TRUE | 홀수 개 TRUE |
| `=XOR(TRUE,TRUE)` | FALSE | 짝수 개 TRUE |
| `=XOR(1,0,1,"text")` | FALSE | 텍스트는 무시 |

## 참고

- 텍스트와 빈 값은 무시합니다(네이티브는 변환할 수 없는 텍스트에 #VALUE!).
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `XOR` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.XOR`으로 등록됩니다.
