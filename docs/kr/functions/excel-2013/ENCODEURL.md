# ENCODEURL

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

URL 인코딩(퍼센트 인코딩)된 문자열을 반환합니다.

## 구문

```
=ENCODEURL(텍스트)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | URL 인코딩할 텍스트 |

## 반환

URL 인코딩된 텍스트를 스칼라로 반환합니다. 배열을 입력하면 요소별로 적용해 같은 크기의 배열을 스필로 반환하며, 입력은 텍스트로 변환되므로 별도의 오류 값은 없습니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=ENCODEURL("a b&c")` | a%20b%26c | 공백·&를 %XX로 변환 |
| `=ENCODEURL("한글")` | %ED%95%9C%EA%B8%80 | 한글 UTF-8 인코딩 |

## 참고

- RFC 3986 비예약 문자(영문자·숫자·- _ . ~)만 그대로 두고 나머지는 UTF-8 바이트 단위로 %XX 인코딩합니다.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `ENCODEURL` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.ENCODEURL`으로 등록됩니다.
