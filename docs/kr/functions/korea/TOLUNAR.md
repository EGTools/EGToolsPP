# TOLUNAR

**종류**: EGTools 전용 함수

양력(그레고리력)을 한국 음력으로 변환합니다(919~2050년).

## 구문

```
=TOLUNAR(양력날짜)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 양력날짜 | 필수 | 날짜, 직렬값, "yyyy-mm-dd" 텍스트, yyyymmdd 숫자 또는 범위 |

## 반환

음력 날짜 텍스트 "yyyy-mm-dd"(윤달이면 접미사 포함)를 스칼라로 반환하며, 범위를 입력하면 같은 크기의 배열로 스필됩니다. 날짜를 해석할 수 없거나 음력표 범위(918~2050년) 밖이면 #VALUE! 오류를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=TOLUNAR(DATE(2025,1,29))` | 2025-01-01 | 2025년 설날 → 음력 1/1 |
| `=TOLUNAR(DATE(2025,10,6))` | 2025-08-15 | 2025년 추석 → 음력 8/15 |

## 참고

- 윤달은 언어 설정에 따라 "(윤)"(한국어) 또는 "(LM)"(영어) 접미사가 붙습니다.
- .NET KoreanLunisolarCalendar에서 생성한 내장 표(918~2050년)를 사용합니다.
- 관련 함수: TOSOLAR
- 지원: Excel 2010+. 모든 Excel 버전에서 `TOLUNAR` 이름 그대로 등록됩니다.
