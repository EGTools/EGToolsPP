# SAMPLINGSIZE

**종류**: EGTools 전용 함수

ISO 2859-1의 LOT 크기·AQL에 따른 시료수(n)를 구합니다.

## 구문

```
=SAMPLINGSIZE(LOT수량, AQL, [검사수준], [엄격도], [방식], [차수])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| LOT수량 | 필수 | 검사할 LOT/배치 수량 |
| AQL | 필수 | 합격품질한계, 예 1.0 |
| 검사수준 | 선택 | G1/G2/G3/S1~S4 (기본 G2) |
| 엄격도 | 선택 | 0 보통(기본), 1 까다로운, -1 수월한 |
| 방식 | 선택 | 1 1회(기본), 2 2회, 3~5 다회; +10이면 전환 없이 강제 |
| 차수 | 선택 | 검사 차수: 1회=1, 2회=최대2, 다회=최대5 |

## 반환

ISO 2859-1 시료수 n(스칼라 숫자)을 반환합니다. AQL이 0~1000 밖이거나 검사수준·방식·차수가 잘못되면 #VALUE!, LOT수량이 2 미만이거나 AQL이 0.01 미만이면 #NUM!, 표에서 해당 값을 찾지 못하면 #N/A 오류를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=SAMPLINGSIZE(1000,1)` | 80 | G2·보통·1회, AQL 1.0 |
| `=SAMPLINGSIZE(1000,1,"G2",0,2,1)` | 50 | 2회 샘플링 1차 시료수 |
| `=SAMPLINGSIZE(30,0.065)` | 30 | LOT수량으로 제한 |

## 참고

- 계산된 n이 LOT수량보다 크면 LOT수량을 반환하고, LOT수량이 1이면 1을 반환합니다.
- 방식에 10을 더하면 표의 전환 규칙(*, ++)을 무시하고 해당 방식을 강제합니다.
- 모든 인수에 배열을 지정할 수 있어 LOT 목록이나 AQL 표를 한 번에 계산할 수 있습니다 — 원소별로 계산해 같은 모양의 배열로 스필되며, 스칼라는 반복, 열 벡터×행 벡터는 외적으로 확장, 크기 불일치 원소는 #N/A입니다.
- 관련 함수: SAMPLINGLABEL, SAMPLINGAC, SAMPLINGRE
- 지원: Excel 2010+. 모든 Excel 버전에서 `SAMPLINGSIZE` 이름 그대로 등록됩니다.
