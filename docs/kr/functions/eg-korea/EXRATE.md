# EXRATE

**종류**: EGTools 전용 함수

지정일의 원화 기준환율을 조회합니다(최대 10일 소급).

## 구문

```
=EXRATE([통화], [날짜])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 통화 | 선택 | 3자리 통화코드, 예 USD(기본), EUR, JPY… |
| 날짜 | 선택 | 조회할 날짜(기본: 오늘) |

## 반환

원화 기준환율을 숫자 스칼라로 반환합니다. 미래 날짜를 지정하면 #VALUE!를, 지원하지 않는 통화 코드이거나 10일 소급 범위에 고시 환율이 없으면 #N/A를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=EXRATE("USD")` |  | 결과는 조회일·네트워크에 따라 다릅니다 |

## 참고

- smbs.biz(서울외국환중개) 기준환율을 HTTP로 조회합니다 — 네트워크 연결이 필요합니다.
- 지정일에 고시가 없으면 최대 10일 전까지 소급 조회합니다(휴일 대응).
- CNY는 CNH로 자동 변환됩니다. 비매크로·스레드 안전으로 등록되어 병렬 재계산됩니다.
- 통화·날짜에 배열을 지정하면 #VALUE!를 반환합니다 — 여러 건은 수식을 행별로 복사해 사용합니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `EXRATE` 이름 그대로 등록됩니다.
