# NETWORKHOUR

**종류**: EGTools 전용 함수

휴식시간을 반영하여 순 근무시간을 계산합니다.

## 구문

```
=NETWORKHOUR(시작시간, 종료시간, [휴식시간])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 시작시간 | 필수 | 근무 시작시간(들) |
| 종료시간 | 필수 | 근무 종료시간(들), 같은 크기 |
| 휴식시간 | 선택 | 휴식 구간: 첫째 열 시작, 둘째 열 종료 |

## 반환

시작·종료를 브로드캐스트한 크기의 배열로 스필되며(단일 값이면 스칼라), 값은 하루=1인 일 단위 숫자입니다. 시작·종료가 브로드캐스트할 수 없는 크기이거나(1이 아닌 서로 다른 크기) 휴식 배열이 2열 미만이면 #VALUE!를 반환하고, 시작·종료가 숫자가 아닌 셀은 빈 텍스트, 날짜가 포함된 종료가 시작보다 앞서는 셀은 #VALUE!가 됩니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=NETWORKHOUR(TIME(9,0,0),TIME(18,0,0))*24` | 9 | 9시~18시 근무시간 |
| `=NETWORKHOUR(TIME(9,0,0),TIME(18,0,0),HSTACK(TIME(12,0,0),TIME(13,0,0)))*24` | 8 | 점심 1시간 제외 |
| `=NETWORKHOUR(TIME(22,0,0),TIME(6,0,0))*24` | 8 | 자정 넘김 근무 |

## 참고

- 결과는 일(day) 단위이므로 24를 곱하면 시간이 됩니다.
- 시각만 준 경우 종료가 시작보다 작으면 자정을 넘긴 것으로 처리합니다.
- 겹치는 휴식 구간은 자동으로 병합되고, 자정을 넘는 휴식은 분할해 계산합니다.
- 시작·종료는 스칼라↔배열 브로드캐스트를 지원합니다 — 예: =NETWORKHOUR(A2:A100,$B$1)처럼 종료시각을 한 셀로 고정할 수 있습니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `NETWORKHOUR` 이름 그대로 등록됩니다.
