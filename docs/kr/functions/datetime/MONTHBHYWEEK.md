# MONTHBHYWEEK

**종류**: EGTools 전용 함수

시작요일·기준요일에 따라 날짜의 주가 속한 월을 계산합니다.

## 구문

```
=MONTHBHYWEEK(날짜, [시작요일], [기준요일])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 날짜 | 필수 | 기준 날짜 |
| 시작요일 | 선택 | 주 시작요일 1=일~7=토(기본 2=월) |
| 기준요일 | 선택 | 주 소속 월을 정하는 요일(기본 5=목) |

## 반환

날짜의 주가 속한 월(1~12, 스칼라 숫자)을 반환합니다. 날짜를 해석할 수 없거나 시작요일·기준요일이 1~7 범위를 벗어나면 #VALUE! 오류를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=MONTHBHYWEEK(DATE(2026,2,1))` | 1 | 일요일 2/1의 주는 1월 |
| `=MONTHBHYWEEK(DATE(2026,2,2))` | 2 | 2/2의 주는 2월 |

## 참고

- 요일 번호는 1=일 ~ 7=토이며, 기본값은 월요일 시작·목요일 기준입니다.
- 주의 소속 월은 기준요일이 속한 달로 정합니다.
- 날짜에 배열을 지정하면 원소별로 계산해 같은 모양의 배열로 스필됩니다(오류 원소는 그 오류를 그대로 반환합니다).
- 관련 함수: WEEKNUMOFMONTH
- 지원: Excel 2010+. 모든 Excel 버전에서 `MONTHBHYWEEK` 이름 그대로 등록됩니다.
