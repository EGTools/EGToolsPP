# MVLOOKUP

**종류**: EGTools 전용 함수

여러 검색값의 VLOOKUP을 한 번에 실행합니다(다중 반환 열).

## 구문

```
=MVLOOKUP(검색값, 검색배열, 반환열, [일치방법], [없을때값])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 검색값 | 필수 | 검색값 열(또는 단일 값) |
| 검색배열 | 필수 | 데이터 표 — 첫 열이 키 |
| 반환열 | 필수 | 반환할 열 번호(들), 예 2 또는 {2,3} |
| 일치방법 | 선택 | FALSE 정확 일치(기본), TRUE 유사 일치(작거나 같은 최대값) |
| 없을때값 | 선택 | 일치 없을 때 값(기본 "") |

## 반환

검색값 원소 수(행 우선) × 반환열 수 크기의 배열(스필)로 반환하며, 일치가 없는 행은 없을때값(기본 "")이 들어갑니다. 필수 인수 누락, 검색배열이 배열이 아닌 경우, 반환열 번호가 잘못된 경우 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=MVLOOKUP({"a";"c"},{"a",1;"b",2},2)` | {1;""} | 여러 키 정확 일치 |
| `=MVLOOKUP("b",{"a",1,"x";"b",2,"y"},{2,3})` | {2,"y"} | 여러 열 동시 반환 |
| `=MVLOOKUP(15,{10,"low";20,"high"},2,TRUE)` | low | 유사 일치(작거나 같은 최대값) |

## 참고

- 정확 일치는 해시 기반이며 키가 중복되면 첫 번째 행을 반환합니다.
- 유사 일치는 내부에서 정렬 후 이진 탐색하므로 데이터를 미리 정렬할 필요가 없습니다.
- 키 비교는 대소문자를 구분하지 않습니다.
- 검색값은 세로 목록 외에 가로(1×N)·2차원 배열도 허용하며, 행 우선 순서로 읽어 세로 결과를 반환합니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `MVLOOKUP` 이름 그대로 등록됩니다.
