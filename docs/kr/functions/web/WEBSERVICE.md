# WEBSERVICE

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

지정한 URL의 웹 서비스 응답을 반환합니다(HTTP GET).

## 구문

```
=WEBSERVICE(url)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| url | 필수 | 요청할 URL |

## 반환

HTTP(S) GET 응답 본문을 UTF-8로 해석한 텍스트 스칼라로 반환합니다. URL 형식 오류나 연결·요청 실패 시 #VALUE!를 반환합니다(연결 5초, 응답 수신 15초 타임아웃).

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=WEBSERVICE("https://api.frankfurter.app/latest")` |  | 외부 응답에 따름 |

## 참고

- WinHTTP GET으로 동작하며 인터넷 연결이 필요합니다.
- 응답 본문은 항상 UTF-8로 해석합니다.
- 스레드 안전으로 등록되어 다중 스레드 재계산에서 병렬 실행됩니다.
- url에 배열을 지정하면 #VALUE!를 반환합니다 — 여러 건은 수식을 행별로 복사해 사용합니다.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `WEBSERVICE` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.WEBSERVICE`으로 등록됩니다.
