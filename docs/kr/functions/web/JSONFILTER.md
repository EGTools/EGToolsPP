# JSONFILTER

**종류**: EGTools 전용 함수

JSON 문자열을 (경로, 값) 2열 표로 분석합니다.

## 구문

```
=JSONFILTER(JSON텍스트, [키경로])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| JSON텍스트 | 필수 | 분석할 JSON 텍스트 |
| 키경로 | 선택 | 필터링할 경로, 예 "data.items[0].name" (기본: 전체) |

## 반환

(경로, 값) 2열 배열(스필)로 반환합니다 — 숫자는 숫자, true/false는 불린, null은 빈 문자열. 텍스트가 비었거나 JSON 파싱에 실패하거나 키경로를 찾지 못하면 #VALUE!를, 결과가 빈 객체·배열이면 #N/A를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=JSONFILTER("{""a"":1,""b"":[true,null]}")` | {"a",1;"b[0]",TRUE;"b[1]",""} | JSON 전체 평탄화 |
| `=JSONFILTER("{""a"":{""b"":5,""c"":""x""}}","a")` | {"b",5;"c","x"} | 키경로 이하만 출력 |

## 참고

- 외부 라이브러리 없이 자체 경량 파서를 사용합니다.
- 텍스트 전체가 유효한 JSON이어야 하며 주석·후행 쉼표는 지원하지 않습니다.
- 키경로는 "a.b[0].c" 형식이며 배열 인덱스는 0부터 시작합니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `JSONFILTER` 이름 그대로 등록됩니다.
