# DIRFOLDER

**종류**: EGTools 전용 함수

지정 폴더의 파일(선택 시 폴더 포함) 목록을 출력합니다.

## 구문

```
=DIRFOLDER(경로, [필터], [폴더포함], [하위폴더], [숨김포함])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 경로 | 필수 | 폴더 경로 |
| 필터 | 선택 | 파일 필터, 예 "*.xlsx;*.csv" (기본 *.*) |
| 폴더포함 | 선택 | TRUE면 폴더 이름 포함 |
| 하위폴더 | 선택 | TRUE면 하위 폴더까지 나열 |
| 숨김포함 | 선택 | TRUE면 숨김 항목 포함 |

## 반환

항목 이름을 담은 배열(스필)로 반환하며, 하위폴더 포함 시 깊이별로 열이 나뉩니다(계단식). 경로가 없거나 비면 #VALUE!를, 일치하는 항목이 없으면 #N/A를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=DIRFOLDER("C:\Data","*.xlsx;*.csv",FALSE,TRUE)` |  | 결과는 폴더 내용에 따라 다릅니다 |

## 참고

- 비매크로 함수로 Win32 API를 직접 사용해 폴더를 읽습니다.
- 필터는 ";"로 여러 개 지정할 수 있고 *·? 와일드카드를 지원합니다.
- 숨김 항목은 기본 제외되며 숨김포함 TRUE로 포함할 수 있습니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `DIRFOLDER` 이름 그대로 등록됩니다.
