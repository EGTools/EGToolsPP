# EVAL

**종류**: EGTools 전용 함수

문자열로 준 수식을 계산해 결과를 반환합니다.

## 구문

```
=EVAL(수식)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 수식 | 필수 | 수식 문자열, 예 "SUM(A1:A3)*2" |

## 반환

계산 결과를 그대로 반환합니다 — 스칼라면 단일 값, 배열이면 스필로 출력됩니다. 수식이 비었거나 계산에 실패하면(COM 연결 불가 포함) #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=EVAL("SUM(A1:A3)*2")` |  | 결과는 시트 값에 따라 다릅니다 |

## 참고

- 매크로형 함수로 COM Application.Evaluate를 사용합니다(스레드 안전 아님).
- 수식 앞의 "="는 자동으로 붙습니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `EVAL` 이름 그대로 등록됩니다.
