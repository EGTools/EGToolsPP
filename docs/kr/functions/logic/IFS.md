# IFS

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2016/2019

조건을 순서대로 검사해 처음 TRUE인 조건의 값을 반환합니다.

## 구문

```
=IFS(조건1, 값1, ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 조건1 | 필수 | 검사할 조건 |
| 값1 | 필수 | 조건이 TRUE일 때 결과 |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |

## 반환

처음으로 참인 조건의 값을 그대로 반환합니다(스칼라 또는 배열). 참인 조건이 없으면 #N/A, 조건이 오류 값이면 그 오류를 그대로 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=IFS(1>2,"a",2>1,"b")` | b | 첫 TRUE 조건의 값 |
| `=IFS(1>2,"a")` | #N/A | 참인 조건 없음 |

## 참고

- 조건이 텍스트나 빈 값이면 FALSE로 처리합니다(네이티브는 #VALUE!).
- 조건과 값에 배열을 지정하면 원소별로 평가해 같은 모양의 배열로 스필됩니다. 평가된 조건이 오류면 그 원소는 그 오류가 되고, 사용되지 않은 인수의 오류는 전파되지 않습니다.
- 관련 함수: SWITCH.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `IFS` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.IFS`으로 등록됩니다.
