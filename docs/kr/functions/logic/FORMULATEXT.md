# FORMULATEXT

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

참조한 셀의 수식을 텍스트로 반환합니다.

## 구문

```
=FORMULATEXT(참조)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 참조 | 필수 | 수식을 가져올 셀 |

## 반환

참조한 셀의 수식을 텍스트 스칼라로 반환합니다. 참조를 생략했거나 셀에 수식이 없거나 조회에 실패하면 #N/A를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=FORMULATEXT(A1)` |  | A1 내용에 따라 다름 |

## 참고

- 매크로 시트형 함수로 등록됩니다.
- 관련 함수: ISFORMULA.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `FORMULATEXT` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.FORMULATEXT`으로 등록됩니다.
