# EXPLODE

**종류**: EGTools 전용 함수

지정 열을 구분자로 분해해 행/열로 전개합니다. 나머지 열은 그대로 복사됩니다.

## 구문

```
=EXPLODE(배열, 열번호, [구분자], [가로전개], [채움값], [빈값무시])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 원본 표 |
| 열번호 | 필수 | 분해할 열, 1부터 |
| 구분자 | 선택 | 구분자(들), 예 " " 또는 {",",";"} (기본 공백) |
| 가로전개 | 선택 | TRUE면 열로 나열(기본 FALSE: 행으로 나열) |
| 채움값 | 선택 | 가로전개 시 빈칸에 넣을 값(기본 "") |
| 빈값무시 | 선택 | TRUE면 빈 조각 제거 |

## 반환

분해 결과를 2차원 배열(스필)로 반환합니다. 배열 인수가 배열이 아니면 #VALUE!를, 열번호가 1~열 수 범위를 벗어나면 #NUM!을 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=EXPLODE({"A","x,y";"B","z"},2,",")` | {"A","x";"A","y";"B","z"} | 2열을 행으로 전개 |
| `=EXPLODE({"A","x,y";"B","z"},2,",",TRUE)` | {"A","x","y";"B","z",""} | 열로 전개, 빈칸 채움 |

## 참고

- 구분자를 여러 개 지정할 수 있으며 긴 구분자부터 적용됩니다(기본: 공백).
- 가로전개 시 부족한 칸은 채움값(기본 "")으로 채워집니다.
- 빈값무시 TRUE면 빈 조각을 제거합니다(전부 비면 빈 문자열 1개 유지).
- 지원: Excel 2010+. 모든 Excel 버전에서 `EXPLODE` 이름 그대로 등록됩니다.
