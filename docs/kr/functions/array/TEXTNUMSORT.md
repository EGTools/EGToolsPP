# TEXTNUMSORT

**종류**: EGTools 전용 함수

텍스트와 숫자를 분리해 자연스러운 순서로 행을 정렬합니다.

## 구문

```
=TEXTNUMSORT(배열, [기준열], [정렬순서], [텍스트무시])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 정렬할 데이터 |
| 기준열 | 선택 | 정렬 기준 열 번호, 1부터 (기본 1) |
| 정렬순서 | 선택 | 1 오름차순(기본), -1 내림차순 |
| 텍스트무시 | 선택 | TRUE면 숫자 부분만 비교 |

## 반환

입력과 같은 크기의 정렬된 배열을 반환하며 동적 배열에서 스필됩니다. 배열이 아닌 단일 값은 그대로 반환합니다. 배열이 누락되거나 기준열이 범위를 벗어나거나 정렬순서가 1/-1이 아니면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=TEXTNUMSORT({"a10";"a2";"a1"})` | {a1;a2;a10} | 자연 정렬 오름차순 |
| `=TEXTNUMSORT({"a1";"a10";"a2"},1,-1)` | {a10;a2;a1} | 내림차순 |

## 참고

- 문자 구간과 숫자 구간을 분리해 숫자는 수치로 비교합니다(a2 < a10).
- 숫자에 붙은 쉼표는 천 단위 기호로 무시하고 '.'은 소수점으로 처리합니다.
- 안정 정렬(stable sort)이므로 같은 키의 행 순서가 유지됩니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `TEXTNUMSORT` 이름 그대로 등록됩니다.
