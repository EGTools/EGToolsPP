# UNIQUE

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2021

배열의 고유한 행(또는 열)을 반환합니다.

## 구문

```
=UNIQUE(배열, [열기준], [한번만])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 데이터 |
| 열기준 | 선택 | TRUE면 고유 열 |
| 한번만 | 선택 | TRUE면 한 번만 나타난 항목 |

## 반환

중복을 제거한 고유 행(또는 열)의 배열을 반환하며 스필됩니다. 남는 항목이 없으면 #N/A, 내부 오류면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=UNIQUE({1;2;2;3})` | {1;2;3} | 중복 제거 |
| `=UNIQUE({1;2;2;3},,TRUE)` | {1;3} | 한 번만 나온 값 |

## 참고

- 결과가 없으면 #CALC! 대신 #N/A를 반환합니다.
- 관련 함수: FILTER, SORT.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `UNIQUE` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.UNIQUE`으로 등록됩니다.
