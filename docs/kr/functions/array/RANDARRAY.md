# RANDARRAY

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2021

난수 배열을 반환합니다.

## 구문

```
=RANDARRAY([행수], [열수], [최소], [최대], [정수])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 행수 | 선택 | 행 개수(기본 1) |
| 열수 | 선택 | 열 개수(기본 1) |
| 최소 | 선택 | 최소값(기본 0) |
| 최대 | 선택 | 최대값(기본 1) |
| 정수 | 선택 | TRUE면 정수 |

## 반환

rows×cols 크기의 난수 배열을 반환하며 스필됩니다. rows나 cols가 0 이하이거나 max가 min보다 작으면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=RANDARRAY(2,3,1,10,TRUE)` |  | 난수라 매번 결과 다름 |

## 참고

- integer=TRUE면 min~max 정수(양 끝 포함), 아니면 min 이상 max 미만의 실수를 생성합니다.
- 모든 인수에 배열을 지정하면 지정한 배열과 같은 모양의 배열을 반환하며, 각 원소는 원소별 결과의 첫 값입니다(네이티브와 같은 강등 리프팅).
- 관련 함수: SEQUENCE.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `RANDARRAY` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.RANDARRAY`으로 등록됩니다.
