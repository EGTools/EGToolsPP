# ADVANCEDFILTER

**종류**: EGTools 전용 함수

고급필터 방식의 조건 그리드(행=OR, 열=AND)로 표를 필터링합니다.

## 구문

```
=ADVANCEDFILTER(데이터, 필터, [중복제거])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 데이터 | 필수 | 제목 행 포함 데이터 |
| 필터 | 필수 | 제목 행 포함 조건 그리드 — =, <>, >, <, >=, <=, *, ? 지원 |
| 중복제거 | 선택 | TRUE면 중복 행 제거 |

## 반환

제목 행을 포함한 필터 결과를 2차원 배열(스필)로 반환합니다. 데이터·필터가 배열이 아니거나 2행 미만이면, 또는 필터 제목이 데이터 제목에 없으면 #VALUE!를, 일치하는 데이터 행이 하나도 없으면 #N/A를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=ADVANCEDFILTER({"Name","Qty";"A",10;"B",5;"A",7},{"Qty";">6"})` | {"Name","Qty";"A",10;"A",7} | Qty>6인 행만 추출 |
| `=ADVANCEDFILTER({"Name","Qty";"Apple",10;"Banana",5;"Avocado",7},{"Name";"A*"})` | {"Name","Qty";"Apple",10;"Avocado",7} | 와일드카드 A* 필터 |

## 참고

- 연산자 없는 텍스트 조건은 Excel 고급필터처럼 "시작 문자열" 일치로 동작합니다.
- 와일드카드 *, ?는 = 및 <> 조건에서 지원됩니다.
- 결과에는 항상 데이터의 제목 행이 포함됩니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `ADVANCEDFILTER` 이름 그대로 등록됩니다.
