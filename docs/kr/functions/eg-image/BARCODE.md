# BARCODE

**종류**: EGTools 전용 함수

텍스트를 바코드로 인코딩해 호출 셀에 이미지로 삽입합니다(2D 형식은 비율 유지, 셀이 크면 중앙 정렬).

## 구문

```
=BARCODE(텍스트, [종류], [옵션])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 인코딩할 문자열 |
| 종류 | 선택 | QRCODE(기본), CODE128, DATAMATRIX, EAN13/8, ITF, PDF417, AZTEC, CODE39/93, UPC-A/E, CODABAR, GS1-128/DM/QR |
| 옵션 | 선택 | 숫자=여백(2D 형식), TRUE=하단 문자 표시(1D 형식) |

## 반환

성공하면 빈 문자열("")을 반환하고, 바코드 그림이 호출 셀 크기에 맞춰 별도로 삽입됩니다. 텍스트가 비었거나 종류를 인식할 수 없거나 해당 형식으로 인코딩할 수 없으면 #VALUE!, 호출 셀을 알 수 없으면 #REF!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=BARCODE("12345678","CODE128")` |  | Code128 그림 삽입(이미지 삽입, 환경 의존) |
| `=BARCODE("https://example.com")` |  | 기본 QR코드 삽입(이미지 삽입, 환경 의존) |

## 참고

- 지원 종류: CODE128, CODE39/93, EAN13/8, UPC-A/E, ITF, CODABAR, PDF417, QRCODE(기본), DATAMATRIX, AZTEC, GS1-128/GS1DATAMATRIX/GS1QRCODE(숫자 코드도 허용).
- 생성은 zint, 판독(READBARCODE)은 zxing-cpp입니다. GS1-128/GS1DATAMATRIX/GS1QRCODE는 "(01)04012345678901(10)LOT42" 같은 괄호 AI 표기를 규격대로 인코딩하며(FNC1 첫 자리 + 가변 길이 AI 뒤 구분자, 심볼로지 식별자 ]C1/]d2/]Q3), 대괄호 [AI]값 표기나 스캐너가 읽은 원문 스트림 `]C10104012345678901<GS>10LOT42`(`<GS>`=구분자 0x1D — 글자 그대로 `<GS>`라고 적어도 인식, 앞의 ]C1 식별자는 있어도 무시)도 같은 심볼로 인코딩됩니다. AI 형식·길이·검사숫자 위반, 표에 없는 AI, 비 ASCII 문자는 #VALUE!를 반환합니다.
- EAN13/EAN8/UPC-A/UPC-E는 검사숫자 없이(12/7/11/6~7자리) 주면 계산해 붙이고, 검사숫자를 포함해 주면 검증합니다(틀리면 #VALUE!). ITF는 홀수 자릿수면 앞에 0을 붙입니다.
- 옵션 인수는 숫자면 여백(2D 형식, 모듈 단위), TRUE면 하단 문자 표시(1D 형식)로 해석합니다.
- 2D 형식은 규격 비율(모듈 정사각)을 유지한 채 호출 셀 안에 맞춰 셀 중앙에 정렬되며, 1D 형식은 셀을 채웁니다.
- 텍스트에 배열을 지정하면 #VALUE!를 반환합니다(셀당 그림 1장) — 여러 건은 수식을 행별로 복사해 사용합니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `BARCODE` 이름 그대로 등록됩니다.
