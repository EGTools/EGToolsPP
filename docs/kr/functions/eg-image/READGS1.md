# READGS1

**종류**: EGTools 전용 함수

GS1 텍스트를 AI와 값의 배열로 분해합니다.

## 구문

```
=READGS1(GS1텍스트, [연결])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| GS1텍스트 | 필수 | (AI)값 형식 또는 바코드에서 읽은 원문 |
| 연결 | 선택 | TRUE면 (AI)값 형태의 한 문자열로 연결 |

## 반환

GS1 텍스트를 (AI)와 값의 N×2 배열로 분해해 반환하며 스필됩니다(연결=TRUE면 (AI)값 형태의 한 문자열). 입력이 비었으면 #VALUE!, 원문 스트림에서 알 수 없는 AI를 만나면 #NUM!, 분해된 항목이 없으면 #N/A를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=READGS1("(01)04012345678901(10)LOT42")` | {"(01)","04012345678901";"(10)","LOT42"} | (AI)와 값 행으로 분해 |
| `=READGS1("(01)04012345678901(10)LOT42",TRUE)` | (01)04012345678901(10)LOT42 | 한 문자열로 연결 |

## 참고

- (AI)값 괄호 형식과 바코드에서 읽은 원문 스트림(GS 구분자 포함) 둘 다 입력할 수 있습니다.
- 고정길이/가변길이 GS1 AI 표를 사용해 스트림을 분해합니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `READGS1` 이름 그대로 등록됩니다.
