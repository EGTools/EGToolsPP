# DATAMATRIX

**종류**: EGTools 전용 함수

텍스트를 DataMatrix 이미지로 만들어 호출 셀에 삽입합니다(비율 유지, 셀이 크면 중앙 정렬).

## 구문

```
=DATAMATRIX(텍스트, [여백], [GS1])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 인코딩할 문자열 |
| 여백 | 선택 | 모듈 단위 여백(기본 0) |
| GS1 | 선택 | TRUE면 GS1 규격으로 인코딩(FNC1) — (AI)값·[AI]값 표기 또는 GS 구분자 원문 스트림 |

## 반환

성공하면 빈 문자열("")을 반환하고, DataMatrix 그림이 호출 셀 크기에 맞춰 별도로 삽입됩니다. 텍스트가 비었거나 GS1 변환 또는 인코딩에 실패하면 #VALUE!, 호출 셀을 알 수 없으면 #REF!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=DATAMATRIX("LOT-2026-08")` |  | DataMatrix 그림 삽입(이미지 삽입, 환경 의존) |

## 참고

- gs1=TRUE면 "(01)04012345678901(10)LOT42" 같은 괄호 AI 표기를 GS1 DataMatrix(심볼로지 식별자 ]d2)로 인코딩합니다 — FNC1이 첫 자리에 들어가고 가변 길이 AI 뒤에는 구분자가 규격대로 삽입됩니다. 대괄호 "[01]04012345678901[10]LOT42" 표기나 스캐너가 읽은 원문 스트림 `]d20104012345678901<GS>10LOT42`(`<GS>`=구분자 0x1D — 글자 그대로 `<GS>`라고 적어도 인식, 앞의 ]d2 식별자는 있어도 무시)도 같은 심볼로 인코딩되며, 표에 없는 AI는 #VALUE!를 반환합니다.
- GS1 데이터는 AI 형식·길이·검사숫자(예: (01) GTIN 검사숫자)를 검사해 위반 시 #VALUE!를 반환하며, 인쇄 가능 ASCII만 허용됩니다(한글 등은 #VALUE!). 일반 텍스트는 UTF-8로 인코딩하고 한글 등 비 Latin-1 문자는 ECI를 자동 삽입합니다(대부분의 판독기가 지원).
- 그림은 모듈이 정사각인 규격 비율을 유지한 채 호출 셀 안에 맞춰지며, 남는 공간은 셀 중앙에 정렬됩니다. margin은 모듈 단위(기본 0)입니다.
- 텍스트에 배열을 지정하면 #VALUE!를 반환합니다(셀당 그림 1장) — 여러 건은 수식을 행별로 복사해 사용합니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `DATAMATRIX` 이름 그대로 등록됩니다.
