# COUNTIFCOLOR

**종류**: EGTools 전용 함수

기준 셀과 색이 일치하는 셀의 개수를 반환합니다.

## 구문

```
=COUNTIFCOLOR(검사범위, 기준셀, [글자색], [조건부서식])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 검사범위 | 필수 | 색을 점검할 범위 |
| 기준셀 | 필수 | 기준색이 설정된 셀(여러 셀이면 첫 셀 사용) |
| 글자색 | 선택 | TRUE면 글자색 비교, 기본값 FALSE=바탕색 |
| 조건부서식 | 선택 | TRUE면 조건부 서식이 반영된 표시 색 사용(함수 시트가 활성일 때만 정확), 기본값 FALSE=셀에 지정한 색 |

## 반환

기준셀과 같은 색(기본은 셀에 지정한 서식 색, 조건부서식=TRUE면 표시 색)인 셀의 개수를 숫자로 반환합니다. COM 연결 실패, 기준 색 읽기 실패, 검사 셀 수 100,000개 초과면 #VALUE!를 반환하고, 검사범위가 사용 영역과 겹치지 않으면 0을 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=COUNTIFCOLOR(A1:A10,C1)` |  | C1과 같은 바탕색 셀 개수(셀 서식에 따라 결과 다름) |
| `=COUNTIFCOLOR(A1:A10,C1,,TRUE)` |  | 조건부 서식 색 기준 개수(셀 서식에 따라 결과 다름) |

## 참고

- 글자색=TRUE면 비어 있지 않은 셀만 셉니다.
- 기본값(조건부서식 생략/FALSE)은 셀 서식에 직접 지정한 색(Interior.Color / Font.Color)만 사용하며, 조건부 서식으로 칠해진 색은 무시합니다. 어느 시트가 활성이든, 다른 시트를 편집하거나 F9·전체 재계산을 해도 결과가 안정적이므로 조건부 서식 색이 꼭 필요하지 않으면 기본값을 권장합니다.
- 조건부서식=TRUE면 조건부 서식이 반영된 실제 표시 색(DisplayFormat)을 사용합니다. 함수가 있는 시트가 활성인 상태에서 재계산될 때만 조건부 서식 색이 정확히 반영됩니다.
- 주의: 조건부서식=TRUE일 때 다른 시트(또는 다른 통합문서)가 활성인 상태에서 재계산되면(그 시트 편집, F9, 전체 재계산 모두) 조건부 서식 색을 제대로 읽지 못해 틀린 값이 나옵니다. 이 함수들은 휘발성이라 다른 시트를 편집하기만 해도 재계산되므로 실제로 흔히 발생합니다.
- 주의: 이렇게 생긴 틀린 값은 함수 시트로 돌아와도 그대로 남습니다. 함수 시트가 활성인 상태에서 F9를 눌러야 바로잡힙니다.
- 주의: 조건부 서식 색 기준으로 집계해야 한다면 가능하면 조건부 서식의 조건 자체로 집계하는 것을 권장합니다(예: `=COUNTIF(A1:A10,">5")`).
- 셀 참조를 받는 매크로형 함수라 Excel이 휘발성(volatile)으로 취급하므로 통합문서 어디서든 값이 바뀌면 다시 계산됩니다. 반면 셀 색이나 조건부 서식 규칙만 바꾸면 재계산되지 않으므로 F9가 필요하며, 멀티스레드 재계산에서도 제외됩니다.
- 3번째 인수(글자색)까지 쓴 기존 수식은 그대로 호환됩니다. 다만 조건부 서식 색에 의존하던 기존 수식은 4번째 인수에 TRUE를 지정해야 이전과 같은 결과가 나옵니다.
- 병합된 셀은 1개로 셉니다(병합 영역의 첫 셀만 검사).
- 지원: Excel 2010+. 모든 Excel 버전에서 `COUNTIFCOLOR` 이름 그대로 등록됩니다.
