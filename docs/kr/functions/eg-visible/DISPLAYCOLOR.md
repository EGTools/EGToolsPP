# DISPLAYCOLOR

**종류**: EGTools 전용 함수

범위의 각 셀에 표시된 바탕색 또는 글자색을 반환합니다.

## 구문

```
=DISPLAYCOLOR(색범위, [글자색])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 색범위 | 필수 | 색을 알아낼 셀 범위 |
| 글자색 | 선택 | TRUE면 글자색, 기본값 FALSE=바탕색 |

## 반환

각 셀에 실제 표시되는 바탕색(글자색=TRUE면 글자색) 값을 범위와 같은 크기의 숫자 배열로 반환하며 스필됩니다. 셀 수가 100,000개를 넘거나 COM 연결·색 읽기에 실패하면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=DISPLAYCOLOR(A1:B2)` |  | 각 셀의 표시 색 번호(셀 서식에 따라 결과 다름) |

## 참고

- DisplayFormat 기반이라 조건부 서식이 반영된 표시 색을 반환합니다.
- 서식만 바꿔서는 재계산되지 않으므로 F9로 다시 계산해야 합니다.
- 매크로형 함수라 멀티스레드 재계산에서 제외됩니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `DISPLAYCOLOR` 이름 그대로 등록됩니다.
