# SUMIFCOLOR

**종류**: EGTools 전용 함수

기준 셀과 표시 색이 일치하는 셀의 합을 반환합니다.

## 구문

```
=SUMIFCOLOR(검사범위, 기준셀, [글자색])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 검사범위 | 필수 | 색을 기준으로 합산할 범위 |
| 기준셀 | 필수 | 기준색이 설정된 셀(여러 셀이면 첫 셀 사용) |
| 글자색 | 선택 | TRUE면 글자색 비교, 기본값 FALSE=바탕색 |

## 반환

기준셀과 표시 색이 같은 셀의 숫자 합을 반환합니다. COM 연결 실패, 기준 색 읽기 실패, 검사 셀 수 100,000개 초과면 #VALUE!를 반환하고, 일치한 셀에 오류 값이 있으면 그 오류를 그대로 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=SUMIFCOLOR(A1:A10,C1)` |  | C1과 같은 바탕색 셀의 합(셀 서식에 따라 결과 다름) |

## 참고

- DisplayFormat 기반이라 조건부 서식이 반영된 표시 색으로 비교합니다.
- 서식만 바꿔서는 재계산되지 않아 F9가 필요하며, 매크로형이라 멀티스레드 재계산에서도 제외됩니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `SUMIFCOLOR` 이름 그대로 등록됩니다.
