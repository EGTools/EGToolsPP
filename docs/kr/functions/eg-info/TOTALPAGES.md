# TOTALPAGES

**종류**: EGTools 전용 함수

현재 인쇄 설정으로 인쇄할 때의 전체 페이지 수입니다(인쇄 전 재계산 필요).

## 구문

```
=TOTALPAGES([시작번호무시])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 시작번호무시 | 선택 | TRUE면 시작 페이지 번호 설정을 무시하고 1부터 |

## 반환

전체 페이지 수를 숫자 스칼라로 반환하며, 인쇄 설정의 시작 페이지 번호가 반영됩니다(시작번호무시 TRUE면 1부터). 페이지 수 조회에 실패하면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=TOTALPAGES()` |  | 결과는 인쇄 설정에 따라 다릅니다 |

## 참고

- 매크로형 함수로 XLM GET.DOCUMENT를 사용합니다(스레드 안전 아님).
- 인쇄 설정을 바꾼 뒤에는 재계산해야 값이 갱신됩니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `TOTALPAGES` 이름 그대로 등록됩니다.
