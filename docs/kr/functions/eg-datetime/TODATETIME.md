# TODATETIME

**종류**: EGTools 전용 함수

한글·한자(년월일시분초)가 포함된 문자열을 날짜와 시간 값으로 변환합니다.

## 구문

```
=TODATETIME(텍스트)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 날짜/시간이 포함된 문자열 |

## 반환

날짜·시간 직렬값(스칼라 숫자)을 반환합니다. 날짜만 있으면 정수, 시간만 있으면 1 미만의 소수를 반환하고, 날짜·시간을 찾지 못하면 빈 텍스트를, 파싱 중 오류가 나면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=TODATETIME("2026년 1월 15일")` | 46037 | 한글 날짜를 직렬값으로 |
| `=TODATETIME("오후 2시 30분")` | 0.604166667 | 오후 시각을 시간값으로 |

## 참고

- 한자(年月日時分秒)와 오전/오후·AM/PM·上午/下午 표기도 인식합니다.
- 월-일만 있으면 올해 연도로 해석하고, 31보다 큰 2자리 연도는 2000년대로 보정합니다.
- 결과 셀에 날짜/시간 표시 형식을 지정해 사용합니다.
- 텍스트에 배열을 지정하면 원소별로 계산해 같은 모양의 배열로 스필됩니다(오류 원소는 그 오류를 그대로 반환합니다).
- 지원: Excel 2010+. 모든 Excel 버전에서 `TODATETIME` 이름 그대로 등록됩니다.
