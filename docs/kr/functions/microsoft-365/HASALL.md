# HASALL

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Microsoft 365 (2026 신규)

값이 모두 목록·배열에 있으면 TRUE를 반환합니다.

## 구문

```
=HASALL(배열, 값들)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 검색할 목록 텍스트·범위·배열 |
| 값들 | 필수 | 찾을 값들(범위·배열·목록 텍스트) |

## 반환

TRUE/FALSE(스칼라)를 반환합니다. 배열 또는 값들 인수 자체가 오류면 그 오류를 그대로 반환하고, 값들을 생략하면 #VALUE!를 반환합니다. 값들이 비어 있으면 TRUE입니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=HASALL("a, b, c",{"a","c"})` | TRUE | 모두 있으면 TRUE |
| `=HASALL("a, b",{"a","z"})` | FALSE | 하나라도 없으면 FALSE |

## 참고

- 값들 인수는 범위·배열상수·목록 텍스트를 모두 받으며, 중첩 포함 모든 항목을 하나의 값 집합으로 평탄화해 각각 HAS와 같은 규칙(대소문자 무시 전체 일치, 숫자는 수치 동등)으로 찾습니다. 값들에 텍스트를 주면 목록 텍스트로 해석되어 콤마로 나뉘고 나뉜 항목 중 숫자 모양은 숫자가 됩니다("z, B"처럼 여러 값 지정 가능, "1, 2"는 숫자 1·2). 값 하나를 텍스트 그대로 비교하려면 배열상수 {"1"}로 주세요.
- 값들 범위의 빈 셀은 빈 텍스트 항목으로 취급되므로, 목록에 빈 항목이 없으면 FALSE가 됩니다. 배열 인수의 해석 규칙(목록 텍스트·범위·배열상수, 콤마 없는 단일 텍스트는 텍스트 그대로, 파싱 불능 시 항목 1개)은 HAS와 같습니다. 셀 내 목록은 먼저 리본 [EGTools] › [목록/배열 셀 → 텍스트]로 변환한 뒤 사용합니다.
- 관련 함수: HAS, HASANY, FLATTEN
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `HASALL` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.HASALL`으로 등록됩니다.
