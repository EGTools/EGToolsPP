# HAS

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Microsoft 365 (2026 신규)

목록·배열(목록 텍스트, 범위, 배열상수) 어디든 값이 있으면 TRUE를 반환합니다.

## 구문

```
=HAS(배열, 값)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 검색할 목록 텍스트·범위·배열 |
| 값 | 필수 | 찾을 값(항목 전체 일치, 대소문자 무시) |

## 반환

TRUE/FALSE(스칼라)를 반환하며, 값에 배열을 지정하면 원소별로 계산되어 스필됩니다. 배열 인수 자체가 오류면 그 오류를 그대로 반환하고, 값을 생략하면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=HAS("Mon, Tue, Wed","tue")` | TRUE | 항목 전체 일치·대소문자 무시 |
| `=HAS("Ann, Bob","An")` | FALSE | 부분 일치는 아님 |
| `=HAS("{""a"",{""b"",""c""}}","c")` | TRUE | 중첩 배열 텍스트 |
| `=HAS("1, 2","1")` | FALSE | 텍스트 "1" ≠ 숫자 1 |

## 참고

- 배열 인수는 목록 텍스트(Mon, Tue, Wed 또는 {"a",{"b","c"}} 같은 배열상수 형식), 범위, 배열상수를 모두 받고 중첩 안까지 재귀 탐색합니다. 콤마로 나뉜 목록이나 {…} 안의 항목은 숫자 모양이면 숫자, TRUE/FALSE면 논리, #N/A 등 오류 이름이면 오류로 읽히지만, 콤마·중괄호가 없는 단일 텍스트는 분류하지 않고 텍스트 그대로 항목 1개가 됩니다(일반 셀의 "1"은 텍스트 "1"). 따옴표가 닫히지 않는 등 파싱할 수 없으면 오류 없이 전체를 항목 1개로 취급합니다.
- 비교는 텍스트는 대소문자 무시 전체 일치("Ann"≠"Anna"), 숫자는 수치 동등이며 텍스트 "1"과 숫자 1은 다릅니다. 목록 안의 오류 항목은 어떤 값과도 일치하지 않습니다. 배열 인수는 리프팅하지 않습니다 — 범위를 주면 범위 전체가 하나의 배열이므로, 행별 결과는 표의 [@열] 참조나 BYROW로 구합니다.
- Microsoft 365 베타의 셀 내 목록은 구버전 Excel에서 #UNKNOWN!(Excel 2016은 #VALUE!)로만 보이므로, 먼저 리본 [EGTools] › [목록/배열 셀 → 텍스트]로 변환한 뒤 사용합니다. 관련 함수: HASANY, HASALL, FLATTEN
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `HAS` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.HAS`으로 등록됩니다.
