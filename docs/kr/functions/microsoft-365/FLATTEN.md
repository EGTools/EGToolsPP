# FLATTEN

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Microsoft 365 (2026 신규)

목록·배열 텍스트의 중첩을 풀어 항목을 그리드로 스필합니다.

## 구문

```
=FLATTEN(배열, [채울값], [수준])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 풀어낼 목록 텍스트·범위·배열 |
| 채울값 | 선택 | 들쭉날쭉 행 채움(기본 #N/A) |
| 수준 | 선택 | 풀어낼 중첩 단계(기본 전부) |

## 반환

중첩을 푼 2차원 배열을 반환하며 동적 배열에서 스필됩니다. 배열 인수 자체가 오류면 그 오류를 그대로 반환하고, 채울값에 배열을 지정하거나 수준이 숫자가 아니거나 음수이거나 결과가 비면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=FLATTEN("a, b, c")` | {a;b;c} | 목록 → 1열 |
| `=FLATTEN("{""a"",""b"";""c""}")` | {a,b;c,#N/A} | 2D 배열 텍스트, 부족분 #N/A |
| `=FLATTEN({"a, b";"c"})` | {a;b;c} | 목록 셀 열은 세로로 쌓임 |

## 참고

- 한 단계 = 외곽 배열의 각 행에서 원소(스칼라=1×1, 배열=그 모양)를 가로로 잇고 행들을 세로로 쌓되 폭은 채울값(기본 #N/A)으로 맞춥니다. 수준을 생략하거나 0이면 중첩이 없어질 때까지 반복하고, 양수 N이면 N회만 풀며 남은 중첩 항목은 목록 텍스트 표기({…})로 표시됩니다. 예: =FLATTEN("{""a"",{""b"",""c""}}",,1) → {a,{"b","c"}} — 그 셀의 첫 중첩만 풀립니다.
- 1열 목록 텍스트는 세로 1열, 목록 셀이 여러 개인 열 범위는 세로로 쌓이고, 셀 하나의 2D 배열 텍스트는 그 모양 그대로 나옵니다. 배열 텍스트 자체의 들쭉날쭉한 행은 채울값과 무관하게 항상 #N/A로 채워지며, 목록 안의 오류 항목(#N/A 등)은 데이터로 보존됩니다. 콤마·중괄호가 없는 단일 텍스트는 텍스트 그대로 1×1이 됩니다.
- Microsoft 365 베타의 셀 내 목록은 구버전 Excel에서 #UNKNOWN!(Excel 2016은 #VALUE!)로만 보이므로, 먼저 리본 [EGTools] › [목록/배열 셀 → 텍스트]로 변환한 뒤 사용합니다. 관련 함수: HAS, HASANY, HASALL
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `FLATTEN` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.FLATTEN`으로 등록됩니다.
