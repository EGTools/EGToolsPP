# ILOOKUP

**종류**: EGTools 전용 함수

일치 항목을 찾아 해당 셀에 배치된 이미지를 호출 셀로 복사합니다.

## 구문

```
=ILOOKUP(찾을값, 찾을범위, 이미지범위, [찾지못하면], [일치모드], [검색모드])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 찾을값 | 필수 | 검색할 값 |
| 찾을범위 | 필수 | 검색할 배열 또는 범위 |
| 이미지범위 | 필수 | 이미지가 배치된 셀 범위 |
| 찾지못하면 | 선택 | 일치 없을 때 반환값(기본 #N/A) |
| 일치모드 | 선택 | 0 정확(기본), -1 작은값, 1 큰값, 2 와일드카드, 3 정규식 |
| 검색모드 | 선택 | 1 처음부터(기본), -1 끝에서부터 |

## 반환

일치 항목을 찾아 성공하면 빈 문자열("")을 반환하고, 일치 셀에 배치된 그림이 호출 셀 크기에 맞춰 별도로 삽입됩니다. 찾을범위와 이미지범위의 크기가 다르면 #REF!, 일치 항목이나 그림이 없으면 찾지못하면 값(기본 #N/A), 잘못된 정규식이나 COM·클립보드 실패는 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=ILOOKUP("apple",A1:A5,B1:B5)` |  | 일치 행에 배치된 그림 복사(이미지 삽입, 환경 의존) |

## 참고

- 이미지범위에서 일치 셀을 TopLeftCell로 하여 배치된 그림(msoPicture/msoLinkedPicture)을 클립보드를 거쳐 복사합니다.
- 일치모드: 0 정확(기본), -1 작은값, 1 큰값, 2 와일드카드, 3 정규식; 검색모드: 1 처음부터(기본), -1 끝에서부터.
- 그림 배치나 서식을 바꾸는 것만으로는 재계산되지 않아 F9가 필요하며, 매크로형이라 멀티스레드 재계산에서도 제외됩니다.
- 찾을값에 배열을 지정하면 #VALUE!를 반환합니다(셀당 그림 1장) — 여러 건은 수식을 행별로 복사해 사용합니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `ILOOKUP` 이름 그대로 등록됩니다.
