# LET

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2021

> ⚠️ 일부 구버전에서는 예약어 충돌로 `xLET` 이름으로 등록됩니다.

이름에 값을 지정하고 마지막 계산식에서 사용합니다.

## 구문

```
=LET(name1, value1, calculation, ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| name1 | 필수 | 정의할 이름 |
| value1 | 필수 | 이 이름의 값 |
| calculation | 필수 | 이름들을 사용한 최종 계산식 |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |

## 반환

이름을 값으로 치환한 최종 계산식의 평가 결과를 반환하며, 결과가 배열이면 스필됩니다. 인수 구조가 잘못되었거나 호출 셀의 수식을 읽지 못하면 #VALUE!, 평가에 실패하면 오류 대신 치환된 수식 문자열을 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=LET(x,3,x*2)` | 6 | 이름 정의 후 계산 |
| `=LET(x,2,y,x+1,x*y)` | 6 | 앞의 이름 참조 가능 |

## 참고

- 네이티브처럼 이름을 바인딩하지 않고, 호출 셀의 수식 텍스트에서 이름을 값으로 치환한 뒤 Application.Evaluate로 평가하는 매크로 시트형 함수입니다.
- 이름 "R", "C"는 Excel R1C1 파서의 예약어라 사용할 수 없습니다.
- 평가에 실패하면 디버깅을 위해 치환된 수식 문자열을 그대로 반환합니다.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `LET` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.LET`으로 등록됩니다.
