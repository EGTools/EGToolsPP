# UNICODE

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

텍스트 첫 문자의 유니코드 코드 포인트를 반환합니다.

## 구문

```
=UNICODE(텍스트)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 첫 문자를 검사할 텍스트 |

## 반환

첫 문자의 코드 포인트 숫자(스칼라)를 반환하며, 텍스트에 배열을 지정하면 요소별로 계산되어 스필됩니다. 빈 텍스트면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=UNICODE("A")` | 65 | 라틴 문자 |
| `=UNICODE("가")` | 44032 | 한글 음절 |
| `=UNICODE("😀")` | 128512 | BMP 밖 문자 |

## 참고

- 서러게이트 쌍을 인식해 BMP 밖 문자도 전체 코드 포인트를 반환합니다.
- 관련 함수: UNICHAR
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `UNICODE` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.UNICODE`으로 등록됩니다.
