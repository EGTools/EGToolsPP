# UNICHAR

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

지정한 숫자(코드 포인트)의 유니코드 문자를 반환합니다.

## 구문

```
=UNICHAR(숫자)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 숫자 | 필수 | 유니코드 코드 포인트 |

## 반환

코드 포인트에 해당하는 문자 텍스트(스칼라)를 반환하며, 숫자에 배열을 지정하면 요소별로 계산되어 스필됩니다. 코드가 1~1114111 범위 밖이거나 서러게이트 영역(55296~57343)이면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=UNICHAR(44032)` | 가 | 한글 음절 |
| `=UNICHAR(128512)` | 😀 | BMP 밖 문자 |
| `=UNICHAR(0)` | #VALUE! | 범위 밖 |

## 참고

- 0x10000 이상 문자는 서러게이트 쌍(UTF-16)으로 반환합니다.
- 관련 함수: UNICODE
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `UNICHAR` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.UNICHAR`으로 등록됩니다.
