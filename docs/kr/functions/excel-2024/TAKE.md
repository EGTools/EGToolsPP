# TAKE

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024

배열의 처음/끝에서 행·열을 가져옵니다.

## 구문

```
=TAKE(배열, 행수, [열수])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 대상 배열 |
| 행수 | 필수 | 가져올 행(음수=뒤에서) |
| 열수 | 선택 | 가져올 열(선택) |

## 반환

배열의 처음(양수) 또는 끝(음수)에서 지정한 수의 행·열을 가져온 배열을 반환하며, 동적 배열을 지원하는 Excel에서는 스필됩니다. 배열이 비었거나 가져올 행·열 수가 0이면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=TAKE({1,2,3;4,5,6;7,8,9},2)` | {1,2,3;4,5,6} | 처음 2행 |
| `=TAKE({1,2,3;4,5,6;7,8,9},-1,2)` | {7,8} | 끝 행의 처음 2열 |
| `=TAKE({1,2;3,4},0)` | #VALUE! | 0행이면 오류 |

## 참고

- 행수·열수가 음수이면 끝에서부터 가져옵니다.
- 결과가 빈 배열이 되면 네이티브의 #CALC! 대신 #VALUE!를 반환합니다.
- 행수·열수에 배열을 지정하면 지정한 배열과 같은 모양의 배열을 반환하며, 각 원소는 원소별 결과의 첫 값입니다(네이티브와 같은 강등 리프팅).
- 관련 함수: DROP
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `TAKE` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.TAKE`으로 등록됩니다.
