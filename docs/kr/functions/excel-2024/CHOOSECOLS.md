# CHOOSECOLS

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024

배열에서 지정한 열들을 반환합니다.

## 구문

```
=CHOOSECOLS(배열, 열번호1, ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 대상 배열 |
| 열번호1 | 필수 | 반환할 열(음수=뒤에서) |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |

## 반환

선택한 열들로 이루어진 배열을 반환하며, 동적 배열을 지원하는 Excel에서는 스필됩니다. 배열이 비었거나, 열 번호가 0 또는 범위를 벗어나거나, 열 번호를 하나도 지정하지 않으면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=CHOOSECOLS({1,2,3;4,5,6},1,3)` | {1,3;4,6} | 1·3열 선택 |
| `=CHOOSECOLS({1,2,3;4,5,6},-1)` | {3;6} | 마지막 열 선택 |
| `=CHOOSECOLS({1,2;3,4},5)` | #VALUE! | 범위 밖 열 번호 |

## 참고

- 열 번호가 음수이면 뒤에서부터 셉니다.
- 행을 선택하려면 CHOOSEROWS를 사용합니다.
- 열 번호에는 {1,3}이나 SEQUENCE(n) 같은 배열도 지정할 수 있습니다.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `CHOOSECOLS` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.CHOOSECOLS`으로 등록됩니다.
