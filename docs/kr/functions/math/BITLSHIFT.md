# BITLSHIFT

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

수를 지정한 비트 수만큼 왼쪽으로 시프트한 값을 반환합니다.

## 구문

```
=BITLSHIFT(number, shift_amount)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| number | 필수 | 시프트할 수(0 이상) |
| shift_amount | 필수 | 왼쪽 시프트 비트 수(음수는 오른쪽) |

## 반환

왼쪽 시프트 결과를 숫자(스칼라)로 반환합니다. number가 [0, 2^48-1] 범위의 정수가 아니거나, shift_amount가 정수가 아니거나 절대값이 53을 넘거나, 결과가 2^53을 넘으면 #NUM!을 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=BITLSHIFT(4,2)` | 16 | 2비트 왼쪽 시프트 |
| `=BITLSHIFT(4,-1)` | 2 | 음수는 오른쪽 시프트 |

## 참고

- shift_amount가 음수이면 오른쪽 시프트로 동작합니다.
- 모든 인수에 배열을 지정하면 원소별로 계산해 같은 모양의 배열로 스필됩니다 — 스칼라는 반복, 열 벡터×행 벡터는 외적으로 확장, 크기가 맞지 않는 원소는 #N/A, 오류 원소는 그 오류를 그대로 반환합니다.
- 관련 함수: BITRSHIFT
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `BITLSHIFT` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.BITLSHIFT`으로 등록됩니다.
