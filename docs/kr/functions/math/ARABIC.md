# ARABIC

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

로마 숫자를 아라비아 숫자로 변환합니다.

## 구문

```
=ARABIC(text)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| text | 필수 | 로마 숫자 텍스트 |

## 반환

로마 숫자를 변환한 숫자 값(스칼라)을 반환합니다. 로마 숫자 기호(I·V·X·L·C·D·M)와 맨 앞의 '-' 이외의 문자가 있으면 #VALUE! 오류를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=ARABIC("LVII")` | 57 | 로마 숫자를 숫자로 |
| `=ARABIC("MCMXII")` | 1912 | 큰 로마 숫자 변환 |
| `=ARABIC("-X")` | -10 | 음수 표기 지원 |

## 참고

- 공백은 무시하고 대소문자를 구분하지 않습니다.
- 빈 텍스트는 0을 반환합니다.
- 텍스트에 배열을 지정하면 원소별로 계산해 같은 모양의 배열로 스필됩니다(오류 원소는 그 오류를 그대로 반환합니다).
- 관련 함수: BASE, DECIMAL
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `ARABIC` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.ARABIC`으로 등록됩니다.
