# 홈 탭 맞춤 그룹 (선택 영역의 가운데로)

**위치**: Excel `홈` 탭 → `맞춤` 그룹(EGTools++가 교체) → 병합 버튼 아래 `선택 영역의 가운데로`

EGTools++를 로드하면 Excel `홈` 탭의 기본 **맞춤** 그룹이 숨겨지고, 같은 자리에 같은 구성의
**맞춤** 그룹이 다시 만들어집니다. Office 기본 그룹 안에는 추가기능이 컨트롤을 끼워 넣을 수
없기 때문에 그룹 전체를 재구성하는 방식이며, 달라지는 것은 병합 버튼 아래에 추가된
**선택 영역의 가운데로** 버튼 하나뿐입니다. 이 버튼은 셀을 병합하지 않고 가로 맞춤만
"선택 영역의 가운데로"로 바꿔, 제목을 여러 열에 걸쳐 가운데 배치하면서도 정렬·필터·수식 참조가
그대로 동작하게 합니다.

교체는 Excel의 병합 드롭다운에 네이티브 "선택 영역의 가운데로" 항목(idMso `CenterAcrossSelection`)이
**없을 때만** 이루어집니다. 네이티브 항목이 이미 있는 Excel에서는 기본 `맞춤` 그룹을 그대로 두며,
EGTools++ 버튼은 나타나지 않습니다(Excel 자체 항목을 사용하면 됩니다).

## 그룹 구성

| 위치 | 컨트롤 | 출처 |
|---|---|---|
| 왼쪽 1행 | 위쪽 맞춤 · 가운데 맞춤 · 아래쪽 맞춤 · 방향 | Excel 내장 |
| 왼쪽 2행 | 왼쪽 맞춤 · 가운데 맞춤 · 오른쪽 맞춤 · 내어쓰기 · 들여쓰기 | Excel 내장 |
| 오른쪽 1행 | 자동 줄 바꿈 | Excel 내장 |
| 오른쪽 2행 | 병합하고 가운데 맞춤(드롭다운) | Excel 내장 |
| 오른쪽 3행 | **선택 영역의 가운데로** | EGTools++ 추가 |
| 대화상자 실행기 | 셀 서식: 맞춤 | Excel 내장 |

Excel 내장 컨트롤은 숨겨진 기본 그룹의 컨트롤을 그대로 다시 배치한 것이므로 동작·레이블·바로 가기 키가
Excel 것과 같습니다.

## 동작 절차 — 선택 영역의 가운데로

1. 가운데에 놓을 내용이 있는 셀을 왼쪽 끝으로 하여, 같은 행에서 가로로 펼칠 열 범위를 선택합니다
   (예: `A1:F1`). 여러 행을 함께 선택하면 각 행에 적용됩니다.
2. `홈` 탭 → `맞춤` 그룹의 **선택 영역의 가운데로**를 누릅니다.
3. 선택 영역의 가로 맞춤이 **선택 영역의 가운데로**(`xlHAlignCenterAcrossSelection`)로 설정되어,
   각 행에서 내용이 오른쪽으로 이어진 빈 셀 범위의 가운데에 표시됩니다. 셀은 병합되지 않습니다.
4. 같은 영역에서 한 번 더 누르면 가로 맞춤이 **일반**(`xlHAlignGeneral`)으로 되돌아갑니다(토글).

## 규칙

| 상황 | 동작 |
|---|---|
| 선택 영역 전체가 이미 "선택 영역의 가운데로" | **일반** 맞춤으로 되돌립니다 |
| 선택 영역이 혼합 상태(일부만 적용) 또는 미적용 | 선택 영역 전체에 **선택 영역의 가운데로**를 적용합니다 |
| 셀이 아닌 개체(도형·차트·그림 등)가 선택됨 | 아무 일도 하지 않습니다 |
| 세로 방향 | 가로 맞춤만 바꾸며 세로로는 가운데 배치하지 않습니다(Excel의 "선택 영역의 가운데로" 규격). 세로 가운데는 위쪽/가운데/아래쪽 맞춤 버튼으로 따로 지정합니다 |
| 실행 취소 | 추가기능 명령이므로 Excel의 실행 취소(`Ctrl+Z`)에 기록되지 않습니다. 되돌리려면 버튼을 다시 누르거나 셀 서식에서 가로 맞춤을 바꾸세요 |

## 참고

- Microsoft는 병합 드롭다운 안의 "선택 영역의 가운데로" 항목을 Microsoft 365 Insider 채널부터
  점진 배포하고 있습니다(2026년 9월 What's New). EGTools++는 이 기능을 Excel 2010~2024와 아직
  배포되지 않은 Microsoft 365에서도 쓸 수 있게 `홈` 탭에 제공합니다. 네이티브 항목이 이미 있는
  Excel에서는 로드 시 이를 감지해 `맞춤` 그룹을 교체하지 않으므로 두 가지가 함께 보이지 않으며,
  Excel 자체 항목을 사용하면 됩니다. 이 판정은 EGTools++ 로드 시 한 번만 하므로, 채널·빌드가 바뀌어
  네이티브 항목이 생기거나 없어지면 Excel을 다시 시작한 뒤 반영됩니다.
- 같은 효과는 `셀 서식` 대화상자(`Ctrl+1`) → `맞춤` 탭 → 가로 `선택 영역의 가운데로`에서도 얻을 수
  있습니다. 이 버튼은 그 설정을 한 번의 클릭으로 적용/해제하는 단축 수단입니다.
- 값이 있는 셀 여러 개를 겉모습만 병합해 보이게 하려면 [내용감춘 병합](merge-split.md#내용감춘-병합)을
  참고하세요. 그쪽은 병합 서식을 입히는 방식이고, 이 버튼은 가로 맞춤만 바꾸는 방식입니다.
- EGTools++를 언로드하면 교체 그룹이 사라지고 Excel 기본 `맞춤` 그룹이 다시 나타납니다.
