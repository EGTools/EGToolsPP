# 도구

**위치**: 리본 `EGTools` 탭 → `도구` 그룹

자주 쓰는 보조 기능을 모은 스플릿 버튼입니다. 버튼을 바로 누르면 기본 동작인
**오류 정리**가 실행되고, 화살표를 누르면 메뉴 10개가 나옵니다.

## 스타일 삭제

활성 통합문서에 쌓인 **사용자 정의 셀 스타일**을 일괄 삭제합니다.
다른 문서에서 복사해 오며 눈덩이처럼 늘어난 스타일이 문서를 무겁게 할 때
사용합니다. 확인 창에서 삭제 범위를 고릅니다.

| 선택 | 동작 |
|---|---|
| 예 | 내장(Built-In) 스타일만 남기고 사용자 정의 스타일을 모두 삭제 |
| 아니오 | 내장 스타일 + **실제 사용 중인** 스타일은 유지하고 나머지만 삭제 |
| 취소 | 작업 취소 |

- "사용 중" 검사는 모든 시트의 사용 영역을 셀 단위로 훑기 때문에
  **큰 문서에서는 오래 걸릴 수 있습니다**(상태 표시줄에 진행 표시).
- 잠긴 스타일은 잠금을 해제한 뒤 삭제하며, 완료 후 삭제/실패 개수를 안내합니다.

## 이름 삭제

활성 통합문서의 정의된 이름 가운데 다음에 해당하는 이름을 삭제합니다.

| 삭제 대상 | 조건 |
|---|---|
| 참조가 깨진 이름 | 참조 대상(RefersTo)에 `#NAME?` / `#REF!` / `#N/A` 포함 |
| 매크로 잔재 | 참조 대상에 `BlankMacro1` 포함 |
| 숨겨진 이름 | 이름 관리자에 보이지 않는(Visible=False) 이름 |

Excel 내부 이름(`_xl*.*` 형식, 예: 인쇄 영역·필터 관련)은 절대 건드리지 않습니다.
이름이 많으면 진행 상황이 상태 표시줄에 표시되고, 완료 후 삭제된 개수를 안내합니다
(대상이 없으면 없음 안내).

## 오류 정리

활성 시트의 사용 영역에서 **오류값을 내고 있는 수식**을 `=IFERROR(원래수식,"")`
로 감싸 오류 표시를 감춥니다. CSE 배열 수식(`{=…}`)은 배열 전체 단위로 감쌉니다.
수식이 아닌 셀(직접 입력된 오류 상수)은 건드리지 않으며, 완료 후 수정한 개수를
안내합니다.

- 오류의 원인이 고쳐지는 것이 아니라 **빈 문자열로 표시**되는 것입니다.
  인쇄·배포 직전 정리에 적합합니다.
- 감싼 뒤에도 수식이 다시 오류를 내는 상태에서 반복 실행하면 IFERROR가
  중첩될 수 있습니다.

## 빈셀 정리

**길이 0 문자열("")만 든 셀**을 진짜 빈 셀로 만듭니다(내용 지우기).
수식 결과나 외부 데이터가 남긴 `""` 셀은 겉보기엔 비었지만 ISBLANK·COUNTA·
끝 셀(Ctrl+End) 판정에서는 빈 셀로 취급되지 않는데, 이를 정리합니다.

1. 범위를 선택하고 실행합니다. **단일 셀만 선택돼 있으면 시트의 사용 영역
   전체**가 대상이 됩니다.
2. "수식은 제외할까요?" 확인 창 — **예** = `""`를 반환하는 수식 셀은 보존 /
   **아니오** = 수식 셀도 내용을 지움(수식이 삭제됨) / **취소** = 중단.
3. 완료 후 정리한 셀 수를 안내합니다. CSE 배열 수식은 배열 전체가 지워집니다.

## 메모 정돈

활성 시트의 **모든 메모(노트)** 를 해당 셀의 오른쪽 바로 옆으로 이동하고
내용에 맞게 자동 크기 조정합니다. 셀이 병합돼 있으면 병합 영역 오른쪽 옆으로
이동합니다. 완료 후 정돈한 메모 수를 안내합니다.

## 테두리 색 변경

색 선택 대화상자에서 색을 고르면(취소 시 종료) 선택 영역의 모든 테두리
— 위/아래/왼쪽/오른쪽 + 대각선 2종 — 색을 일괄 변경합니다.
**선 종류(실선·점선·굵기)는 그대로 유지**되고 색만 바뀌며, 테두리가 없는
방향에는 새 테두리를 만들지 않습니다.

## 모양 뽑기

선택 영역에서 **배경색이 칠해진 셀**들의 외곽선을 따라 자유형(Freeform) 도형을
만듭니다. 셀에 색을 칠해 그린 지도·구역 표시 등을 하나의 도형으로 뽑아낼 때
사용합니다.

1. 색칠된 셀이 포함된 범위를 선택하고 실행합니다. 색칠된 셀이 없으면
   "배경색이 칠해진 셀 영역을 선택하세요" 안내 후 종료됩니다.
2. **흰색 배경(채우기 없음 포함)** 은 배경으로 간주하고, 그 외의 색이 칠해진
   셀을 도형 영역으로 봅니다.
3. 색칠된 셀 가운데 처음 만나는 **연결된 한 덩어리**의 외곽선을 셀의 실제
   너비·높이를 따라 추적해 도형을 만들고, 결과 도형에 스타일 프리셋을
   적용합니다.

- 서로 떨어진 덩어리가 여럿이면 첫 덩어리만 도형이 됩니다. 나머지는 범위를
  나눠 다시 실행하세요.
- 도형 생성에 실패하면 "도형 변환에 실패했습니다" 안내가 표시됩니다.

## UDF 값 고정

EGTools 함수(`EG.`/`x` 접두 변형 포함)가 든 수식을 **계산된 값**으로 바꿉니다.
추가기능이 없는 곳에 문서를 보낼 때, 수식이 `#NAME?`로 깨지는 대신 값이
그대로 남게 하는 배포용 기능입니다.

1. **스캔** — 전체 워크시트의 수식을 읽기 전용으로 훑어 대상 개수를
   확인 창으로 보여줍니다(대상이 없으면 안내 후 종료).
2. **저장 게이트 + 백업** — 저장되지 않았으면 저장 여부를 묻고, 적용 직전에
   백업 파일(SaveCopyAs)이 자동 저장됩니다. 백업 실패 시 진행하지 않습니다.
3. **값 고정** — 대상 수식을 값으로 바꿉니다. CSE 배열은 배열 전체,
   스필 수식은 스필 범위 전체가 값이 됩니다. 원래 수식은 셀 메모에
   `EgUdfRemoved: <수식>` 형태로 보존됩니다(기존 메모가 있으면 뒤에 이어 붙임).
4. 완료 후 고정한 셀 수와 백업 파일 경로를 안내합니다.

- 대상 함수 목록은 추가기능의 함수 등록 목록과 단일 소스로 관리되어 항상 일치합니다.
- [구버전 호환 적용](apply-compat.md)이 함수 **이름을 변환**해 수식을 살려 두는
  기능이라면, UDF 값 고정은 수식을 **값으로 바꾸는** 기능입니다.

## CheckBox 적용

선택 영역을 0/1 입력으로 체크박스처럼 표시되게 만듭니다.

1. 선택 영역에 **0 또는 1만 허용하는 유효성 검사**를 적용합니다.
2. 표시 형식을 `[=1]"✅";[=0]"⬜";""` 로 설정합니다
   — 1을 입력하면 ✅, 0을 입력하면 ⬜, 그 외에는 빈 표시.
3. 빈 셀은 0으로 채우고 가운데 정렬합니다.

셀 값은 여전히 0/1 숫자이므로 `SUM`·`COUNTIF` 등으로 바로 집계할 수 있습니다.

## 전체 재계산

열려 있는 **모든 통합문서**를 강제로 전체 재계산합니다(`CalculateFull`).
자동 계산이 놓친 셀, 휘발성 함수, 외부 참조까지 처음부터 다시 계산할 때 사용합니다.

> 공공 API 함수용 키 등록/삭제는 [EGTools 그룹의 API 키 관리](api-keys.md)로
> 이동했습니다.
