# TEXTNUMSORT

**種類**: EGTools 専用関数

テキストと数値を分けて自然順で行を並べ替えます。

## 構文

```
=TEXTNUMSORT(配列, [基準列], [並び順], [テキスト無視])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 配列 | 必須 | 並べ替えるデータ |
| 基準列 | 省略可能 | キー列番号、1 から(既定 1) |
| 並び順 | 省略可能 | 1 昇順(既定)、-1 降順 |
| テキスト無視 | 省略可能 | TRUE で数値部分のみ比較 |

## 戻り値

入力と同じサイズの並べ替えられた配列を返し、動的配列ではスピルします。配列でない単一の値はそのまま返します。配列が省略されている場合、基準列が範囲外の場合、または並べ替え順序が 1/-1 でない場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=TEXTNUMSORT({"a10";"a2";"a1"})` | {a1;a2;a10} | 自然順で昇順に並べ替え |
| `=TEXTNUMSORT({"a1";"a10";"a2"},1,-1)` | {a10;a2;a1} | 降順 |

## 解説

- 文字部分と数値部分を分離し、数値は数値として比較します(a2 < a10)。
- 数値に付いたカンマは桁区切り記号として無視し、'.' は小数点として処理します。
- 安定ソート(stable sort)のため、同じキーを持つ行の順序は維持されます。
- 対応: Excel 2010+。すべての Excel バージョンで `TEXTNUMSORT` の名前のまま登録されます。
