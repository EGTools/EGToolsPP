# UNPIVOT

**種類**: EGTools 専用関数

クロス集計表を正規化されたデータ表に変換します。

## 構文

```
=UNPIVOT(配列, [固定列], [固定行], [並び順], [列名], [セット有無])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 配列 | 必須 | 元の表(見出し含む) |
| 固定列 | 省略可能 | 左側の行見出し列数(既定 1) |
| 固定行 | 省略可能 | 上側の列見出し行数(既定 1) |
| 並び順 | 省略可能 | 結果の並べ替え: 列番号、負数で降順、例 {1,-3} |
| 列名 | 省略可能 | 結果に適用する見出し |
| セット有無 | 省略可能 | 値列がセットで繰り返す場合 TRUE |

## 戻り値

見出し行を含む正規化されたデータ表を 2 次元配列(スピル)で返します。配列でない入力、固定列・固定行が負数または範囲外か両方とも 0 の場合、並び順が 0 または結果の列範囲外の場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=UNPIVOT({"Item","Jan","Feb";"A",10,20;"B",30,40},1,1,,{"Item","Month","Qty"})` | {"Item","Month","Qty";"A","Jan",10;"A","Feb",20;"B","Jan",30;"B","Feb",40} | クロス集計表のアンピボット |
| `=UNPIVOT({"Item","Jan","Feb";"A",10,20;"B",30,40},1,1,-3,{"Item","Month","Qty"})` | {"Item","Month","Qty";"B","Feb",40;"B","Jan",30;"A","Feb",20;"A","Jan",10} | 3 列目の降順ソート |

## 解説

- 値のみに基づいて動作し、結合セルの補完はサポートしていません。
- 値がすべて空の項目(セル)は結果から除外されます。
- 列名を省略すると、既定の見出しは UI 言語(韓国語/英語)によって異なります。
- 対応: Excel 2010+。すべての Excel バージョンで `UNPIVOT` の名前のまま登録されます。
