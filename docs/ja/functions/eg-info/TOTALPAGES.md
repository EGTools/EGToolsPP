# TOTALPAGES

**種類**: EGTools 専用関数

現在の印刷設定での総ページ数(印刷前に再計算が必要)。

## 構文

```
=TOTALPAGES([開始番号無視])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 開始番号無視 | 省略可能 | TRUE で先頭ページ番号設定を無視し 1 から |

## 戻り値

総ページ数を数値スカラーとして返し、印刷設定の先頭ページ番号が反映されます(開始番号無視が TRUE の場合は 1 から)。ページ数の取得に失敗した場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=TOTALPAGES()` |  | 結果は印刷設定によって異なります |

## 解説

- マクロ型関数として XLM の GET.DOCUMENT を使用します(スレッドセーフではありません)。
- 印刷設定を変更した後は、再計算しないと値が更新されません。
- 対応: Excel 2010+。すべての Excel バージョンで `TOTALPAGES` の名前のまま登録されます。
