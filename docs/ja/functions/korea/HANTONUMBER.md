# HANTONUMBER

**種類**: EGTools 専用関数

韓国語(漢字)の金額表記を数値に変換します。

## 構文

```
=HANTONUMBER(テキスト, [数値のみ])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| テキスト | 必須 | 金額表記 |
| 数値のみ | 省略可能 | TRUE で数値を返す(既定)、FALSE で書式付きテキスト |

## 戻り値

既定(数値のみ=TRUE)では数値(スカラー)を返し、整数部が 15 桁を超える場合は精度保持のためテキストで返します。数値のみ=FALSE の場合は「금1,234원」(金1,234ウォン)形式のテキストを返します。テキストが空の場合や、アラビア数字・小数点が 2 つ以上連続する場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=HANTONUMBER("일금오만원정")` | 50000 | ハングルの金額を数値に |
| `=HANTONUMBER("삼억이천오백만")` | 325000000 | 億・万の単位を処理 |
| `=HANTONUMBER("일금오만원정",FALSE)` | 일금50,000원정 | 書式付きテキストを返す |

## 解説

- 漢字表記や異体字(一二三、壹貳參、拾佰仟萬 など)も認識します。
- 入力中の空白とカンマは無視され、「금」「일금」(金・一金)の接頭辞や「원」「원정」(ウォン・ウォン整)の接尾辞は、数値のみ=FALSE のときそのまま復元されます。
- テキストに配列を指定すると要素ごとに処理され、同じ形状の配列としてスピルされます(エラー要素はそのエラーのまま)。その他の引数に配列を指定すると #VALUE! を返します。
- 対応: Excel 2010+。すべての Excel バージョンで `HANTONUMBER` の名前のまま登録されます。
