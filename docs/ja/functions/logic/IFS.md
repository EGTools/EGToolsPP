# IFS

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2016/2019

条件を順に調べ、最初に TRUE になった条件の値を返します。

## 構文

```
=IFS(条件1, 値1, ...)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 条件1 | 必須 | 1 番目の条件 |
| 値1 | 必須 | 条件が TRUE のときの結果 |
| … | 省略可能 | 上記の引数を繰り返し指定できます |

## 戻り値

最初に TRUE となった条件の値をそのまま返します(スカラーまたは配列)。TRUE の条件がない場合は #N/A、条件がエラー値の場合はそのエラーをそのまま返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=IFS(1>2,"a",2>1,"b")` | b | 最初の TRUE 条件の値 |
| `=IFS(1>2,"a")` | #N/A | TRUE の条件なし |

## 解説

- 条件がテキストや空の値の場合は FALSE として扱います(ネイティブでは #VALUE!)。
- 条件と値に配列を指定すると要素ごとに評価され、同じ形状の配列としてスピルされます。評価された条件がエラーの場合はその要素がそのエラーになります(使用されない引数のエラーは伝播しません)。
- 関連関数: SWITCH。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `IFS` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.IFS` として登録されます。
