# NUMBERVALUE

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2013

ロケールに依存せずにテキストを数値に変換します。

## 構文

```
=NUMBERVALUE(文字列, [小数点記号], [桁区切り記号])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 文字列 | 必須 | 変換する文字列 |
| 小数点記号 | 省略可能 | 小数点の記号（既定 .） |
| 桁区切り記号 | 省略可能 | 桁区切りの記号（既定 ,） |

## 戻り値

数値(スカラー)を返し、テキストに配列を指定すると要素ごとに計算され、動的配列ではスピルします。区切り文字を除去した後に数値として解釈できない場合は #VALUE! を返し、空のテキスト(空白のみを含む)は 0 を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=NUMBERVALUE("2.500,27",",",".")` | 2500.27 | ヨーロッパ式表記の変換 |
| `=NUMBERVALUE("9%%")` | 0.0009 | % ごとに 100 で除算 |
| `=NUMBERVALUE("abc")` | #VALUE! | 数値ではない |

## 解説

- すべての空白文字は位置に関係なく無視され、桁区切り文字はどこにあっても除去されます。
- 末尾の % 記号は個数分だけ 100 で除算します。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `NUMBERVALUE` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.NUMBERVALUE` として登録されます。
