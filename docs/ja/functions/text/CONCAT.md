# CONCAT

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2016/2019

値と範囲のテキストを区切りなしで連結します。

## 構文

```
=CONCAT(テキスト1, ...)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| テキスト1 | 必須 | テキスト/範囲 |
| … | 省略可能 | 上記の引数を繰り返し指定できます |

## 戻り値

すべての引数(範囲・配列を含む)を順序どおりに連結した単一のテキスト(スカラー)を返します。引数のいずれかにエラー値があると、そのエラーをそのまま返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=CONCAT("A",1,"B")` | A1B | 値をそのまま連結 |
| `=CONCAT({1,2;3,4})` | 1234 | 配列を行優先で連結 |

## 解説

- 区切り文字なしで連結します。区切り文字が必要な場合は TEXTJOIN を使用します。
- 最大 255 個の引数までサポートします。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `CONCAT` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.CONCAT` として登録されます。
