# DECODEURL

**種類**: EGTools 専用関数

%エンコードされた URL 文字列を元のテキストに戻します。

## 構文

```
=DECODEURL(テキスト)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| テキスト | 必須 | デコードする URL テキスト |

## 戻り値

%-エンコード(UTF-8)を元のテキストに戻した文字列を返します。配列を入力すると要素ごとに処理し、同じサイズの配列としてスピルされます。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=DECODEURL("a%20b%26c")` | a b&c | %-エンコードのデコード |
| `=DECODEURL("%ED%95%9C%EA%B8%80")` | 한글 | UTF-8 ハングルのデコード |

## 解説

- 無効な % シーケンスは変換せず、そのまま残します。
- + 記号は空白に置き換えません(フォームエンコードはサポートしていません)。
- ENCODEURL の逆関数です。
- 対応: Excel 2010+。すべての Excel バージョンで `DECODEURL` の名前のまま登録されます。
