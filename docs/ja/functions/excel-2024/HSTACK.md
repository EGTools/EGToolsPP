# HSTACK

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2024

複数の配列を横に並べて 1 つにします。

## 構文

```
=HSTACK(配列1, ...)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 配列1 | 必須 | 結合する配列 |
| … | 省略可能 | 上記の引数を繰り返し指定できます |

## 戻り値

引数に指定した配列を横方向に連結した配列を返し、動的配列をサポートする Excel ではスピルします。高さが異なる場合は、短い配列の空いた部分を #N/A で埋めます。有効な配列引数が 1 つもない場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=HSTACK({1;2},{3,4;5,6})` | {1,3,4;2,5,6} | 2 つの配列を横に結合 |
| `=HSTACK({1,2},{3;4;5})` | {1,2,3;#N/A,#N/A,4;#N/A,#N/A,5} | 高さが異なると #N/A |

## 解説

- 省略された引数はスキップします。
- 関連関数: VSTACK。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `HSTACK` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.HSTACK` として登録されます。
