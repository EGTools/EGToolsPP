# TAKE

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2024

配列の先頭または末尾から行・列を取り出します。

## 構文

```
=TAKE(配列, 行数, [列数])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 配列 | 必須 | 配列 |
| 行数 | 必須 | 取り出す行(負=末尾から) |
| 列数 | 省略可能 | 取り出す列(省略可) |

## 戻り値

配列の先頭(正数)または末尾(負数)から指定した数の行・列を取り出した配列を返し、動的配列をサポートする Excel ではスピルします。配列が空の場合や、取り出す行・列数が 0 の場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=TAKE({1,2,3;4,5,6;7,8,9},2)` | {1,2,3;4,5,6} | 先頭の 2 行 |
| `=TAKE({1,2,3;4,5,6;7,8,9},-1,2)` | {7,8} | 最後の行の先頭 2 列 |
| `=TAKE({1,2;3,4},0)` | #VALUE! | 0 行はエラー |

## 解説

- 行数・列数が負数の場合は末尾から取り出します。
- 結果が空の配列になる場合は、ネイティブの #CALC! の代わりに #VALUE! を返します。
- 行数・列数に配列を指定すると、その配列と同じ形状の配列を返し、各要素は要素ごとの結果の最初の値になります(ネイティブと同じ降格リフティング)。
- 関連関数: DROP。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `TAKE` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.TAKE` として登録されます。
