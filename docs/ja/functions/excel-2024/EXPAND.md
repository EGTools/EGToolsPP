# EXPAND

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2024

配列を指定サイズに拡張し、値で埋めます。

## 構文

```
=EXPAND(配列, 行数, [列数], [埋める値])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 配列 | 必須 | 配列 |
| 行数 | 必須 | 全体の行数 |
| 列数 | 省略可能 | 全体の列数(省略可) |
| 埋める値 | 省略可能 | 埋め値(既定 #N/A) |

## 戻り値

指定した行数×列数のサイズに拡張した配列を返し、動的配列をサポートする Excel ではスピルします。新しくできる部分は埋め込み値(既定は #N/A)で埋めます。配列が空の場合や、指定サイズが元の配列より小さい場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=EXPAND({1,2;3,4},3,3,0)` | {1,2,0;3,4,0;0,0,0} | 3×3 に拡張、0 で埋める |
| `=EXPAND({1,2},1,4)` | {1,2,#N/A,#N/A} | 既定の埋め込み値は #N/A |
| `=EXPAND({1,2;3,4},1,1)` | #VALUE! | 縮小は不可 |

## 解説

- 行数・列数を省略すると元のサイズを維持します。
- 埋め込み値を省略すると #N/A で埋めます。
- 行数・列数・埋める値に配列を指定すると、その配列と同じ形状の配列を返し、各要素は要素ごとの結果の最初の値になります(ネイティブと同じ降格リフティング)。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `EXPAND` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.EXPAND` として登録されます。
