# SORTBY

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2021

他の配列の値で配列を並べ替えます。

## 構文

```
=SORTBY(配列, 基準配列1, [順序1], ...)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 配列 | 必須 | 並べ替えるデータ |
| 基準配列1 | 必須 | 並べ替えキー(行に対応) |
| 順序1 | 省略可能 | 1 昇順(既定)、-1 降順 |
| … | 省略可能 | 上記の引数を繰り返し指定できます |

## 戻り値

基準配列の値の順序で行を並べ替えた配列を返し、スピルします。array と行数が同じ有効な基準配列が 1 つもない場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=SORTBY({"a";"b";"c"},{3;1;2})` | {b;c;a} | 基準配列で並べ替え |
| `=SORTBY({1;2;3},{2;2;1},1,{9;1;5},-1)` | {3;1;2} | 第 2 基準を降順に |

## 解説

- 基準配列は array と行数が同じ縦方向(列)のベクトルである必要があり、行の並べ替えのみをサポートします(列方向の並べ替えはサポートしていません)。
- 行数が異なる基準配列は警告なしに無視されます。
- 関連関数: SORT。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `SORTBY` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.SORTBY` として登録されます。
