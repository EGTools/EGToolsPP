# GTRS

**種類**: Google スプレッドシート互換関数

GOOGLETRANSLATE の短い別名 — Google でテキストを翻訳します。

## 構文

```
=GTRS(テキスト, [元言語], [対象言語])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| テキスト | 必須 | 翻訳するテキスト(または範囲) |
| 元言語 | 省略可能 | 元の言語コード、例 "en"(既定 "auto" 自動検出) |
| 対象言語 | 省略可能 | 結果の言語コード(既定: UI 言語) |

## 戻り値

GOOGLETRANSLATE と同様に、翻訳されたテキストをスカラーで返します。HTTP リクエストの失敗時は #VALUE!、サービスエラー・無効な言語コード・5000 文字超過は "ERROR:…" テキストとして返し、空のテキストには空文字列を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=GTRS("안녕하세요","ko","en")` |  | 翻訳結果に依存します |

## 解説

- GOOGLETRANSLATE の短い別名で、同一の実装を使用します。詳細な動作は GOOGLETRANSLATE のドキュメントを参照してください。
- 対応: Excel 2010+。すべての Excel バージョンで `GTRS` の名前のまま登録されます。
