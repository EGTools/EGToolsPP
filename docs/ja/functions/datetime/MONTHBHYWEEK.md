# MONTHBHYWEEK

**種類**: EGTools 専用関数

週の開始曜日・基準曜日により日付の週が属する月を返します。

## 構文

```
=MONTHBHYWEEK(日付, [週開始曜日], [基準曜日])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 日付 | 必須 | 基準日 |
| 週開始曜日 | 省略可能 | 1=日~7=土(既定 2=月) |
| 基準曜日 | 省略可能 | 所属月を決める曜日(既定 5=木) |

## 戻り値

日付の週が属する月(1~12、スカラー数値)を返します。日付を解釈できない場合や、週開始曜日・基準曜日が 1~7 の範囲外の場合は #VALUE! エラーを返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=MONTHBHYWEEK(DATE(2026,2,1))` | 1 | 日曜日 2/1 の週は 1 月 |
| `=MONTHBHYWEEK(DATE(2026,2,2))` | 2 | 2/2 の週は 2 月 |

## 解説

- 曜日番号は 1=日 ~ 7=土で、既定値は月曜開始・木曜基準です。
- 週の所属月は基準曜日が属する月で決まります。
- 日付に配列を指定すると要素ごとに計算され、同じ形状の配列としてスピルされます(エラー要素はそのエラーをそのまま返します)。
- 関連関数: WEEKNUMOFMONTH。
- 対応: Excel 2010+。すべての Excel バージョンで `MONTHBHYWEEK` の名前のまま登録されます。
