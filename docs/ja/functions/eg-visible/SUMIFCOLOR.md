# SUMIFCOLOR

**種類**: EGTools 専用関数

基準セルと表示色が一致するセルの合計を返します。

## 構文

```
=SUMIFCOLOR(検査範囲, 基準セル, [文字色])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 検査範囲 | 必須 | 合計する範囲 |
| 基準セル | 必須 | 基準色のセル(複数なら先頭セル) |
| 文字色 | 省略可能 | TRUE で文字色を比較、既定 FALSE |

## 戻り値

基準セルと表示色が同じセルの数値の合計を返します。COM 接続の失敗、基準色の読み取り失敗、検査対象セル数が 100,000 個を超える場合は #VALUE! を返し、一致したセルにエラー値がある場合はそのエラーをそのまま返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=SUMIFCOLOR(A1:A10,C1)` |  | C1 と同じ背景色のセルの合計(セルの書式によって結果が異なります) |

## 解説

- DisplayFormat ベースのため、条件付き書式が反映された表示色で比較します。
- 書式を変更しただけでは再計算されないため F9 が必要で、マクロ型のためマルチスレッド再計算からも除外されます。
- 対応: Excel 2010+。すべての Excel バージョンで `SUMIFCOLOR` の名前のまま登録されます。
