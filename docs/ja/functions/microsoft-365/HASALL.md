# HASALL

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Microsoft 365 (2026 新規)

値がすべてリスト・配列にあれば TRUE を返します。

## 構文

```
=HASALL(配列, 値群)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 配列 | 必須 | 検索するリストテキスト・範囲・配列 |
| 値群 | 必須 | 探す値(範囲・配列・リストテキスト) |

## 戻り値

TRUE/FALSE(スカラー)を返します。配列または値群の引数自体がエラーの場合はそのエラーをそのまま返し、値群を省略すると #VALUE! を返します。値群が空なら TRUE です。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=HASALL("a, b, c",{"a","c"})` | TRUE | すべてあれば TRUE |
| `=HASALL("a, b",{"a","z"})` | FALSE | 1 つでもなければ FALSE |

## 解説

- 値群引数は範囲・配列定数・リストテキストをすべて受け取り、入れ子を含むすべての項目を 1 つの値集合に平坦化して、それぞれ HAS と同じ規則(大文字小文字無視の項目全体一致、数値は数値同等)で探します。値群にテキストを指定するとリストテキストとして解釈されてカンマで分割され、分割後の項目のうち数値の形は数値になります("z, B" のように複数の値を指定可能、"1, 2" は数値 1・2)。1 つの値をテキストのまま比較するには配列定数 {"1"} で指定します。
- 値群の範囲にある空セルは空テキストの項目として扱われるため、リストに空の項目がなければ FALSE になります。配列引数の解釈規則(リストテキスト・範囲・配列定数、カンマのない単一テキストはテキストのまま、解析不能なら項目 1 個)は HAS と同じです。セル内リストは先にリボン [EGTools] › [リスト/配列セル → テキスト] で変換してから使います。
- 関連関数: HAS, HASANY, FLATTEN
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `HASALL` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.HASALL` として登録されます。
