# TOLUNAR

**種類**: EGTools 専用関数

太陽暦を韓国の旧暦に変換します(919~2050年)。

## 構文

```
=TOLUNAR(太陽暦日付)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 太陽暦日付 | 必須 | 日付、シリアル値、"yyyy-mm-dd"、yyyymmdd 数値または範囲 |

## 戻り値

陰暦の日付テキスト "yyyy-mm-dd"(閏月の場合は接尾辞付き)をスカラーで返し、範囲を入力すると同じサイズの配列としてスピルされます。日付を解釈できない場合や陰暦表の範囲(918~2050 年)外の場合は #VALUE! エラーを返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=TOLUNAR(DATE(2025,1,29))` | 2025-01-01 | 2025 年の旧正月 → 陰暦 1/1 |
| `=TOLUNAR(DATE(2025,10,6))` | 2025-08-15 | 2025 年の秋夕 → 陰暦 8/15 |

## 解説

- 閏月には言語設定に応じて "(윤)"(韓国語)または "(LM)"(英語)の接尾辞が付きます。
- .NET の KoreanLunisolarCalendar で生成した内蔵表(918~2050 年)を使用します。
- 関連関数: TOSOLAR。
- 対応: Excel 2010+。すべての Excel バージョンで `TOLUNAR` の名前のまま登録されます。
