# TOSOLAR

**種類**: EGTools 専用関数

韓国の旧暦を太陽暦に変換します(919~2050年)。

## 構文

```
=TOSOLAR(旧暦日付)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 旧暦日付 | 必須 | "2025-06-05" 形式 — 閏月は 윤/LM 表記 — または範囲 |

## 戻り値

陽暦の日付のシリアル値(スカラー数値)を返し、範囲を入力すると同じサイズの配列としてスピルされます。テキストを解釈できない場合、陰暦表の範囲(918~2050 年)外の場合、または存在しない陰暦の日付の場合は #VALUE! エラーを返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=TOSOLAR("2025-01-01")` | 45686 | 陰暦の旧正月 → 2025-01-29 |
| `=TOSOLAR("2025-08-15")` | 45936 | 陰暦の秋夕 → 2025-10-06 |

## 解説

- 閏月は "윤"(韓国語)または "LM" を付けて表記します(例: "2025-윤06-01")。
- 結果のセルに日付の表示形式を設定して使用します。
- 関連関数: TOLUNAR。
- 対応: Excel 2010+。すべての Excel バージョンで `TOSOLAR` の名前のまま登録されます。
