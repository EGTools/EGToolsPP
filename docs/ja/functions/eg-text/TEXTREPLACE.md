# TEXTREPLACE

**種類**: EGTools 専用関数

開始キー~終了キーの区間をすべて置換します。

## 構文

```
=TEXTREPLACE(テキスト, 開始キー, 終了キー, [置換文字], [キー保持])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| テキスト | 必須 | 対象の文字列 |
| 開始キー | 必須 | 区間の開始 |
| 終了キー | 必須 | 区間の終了 |
| 置換文字 | 省略可能 | 置換する文字列(既定 空) |
| キー保持 | 省略可能 | TRUE でキーを残して内側のみ置換 |

## 戻り値

置換が適用された単一のテキスト(スカラー)を返します。テキスト・開始キー・終了キーのいずれかが空の場合は、エラーではなく元のテキストをそのまま返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=TEXTREPLACE("a[x]b[y]c","[","]","*")` | a*b*c | すべての区間を * に置換 |
| `=TEXTREPLACE("a<1>b","<",">","2",TRUE)` | a<2>b | キーを維持して置換 |

## 解説

- キーの検索では大文字と小文字を区別しません。
- 終了キーのない開始キーに遭遇した場合は、その開始キーの部分のみが置換され、残りのテキストはそのまま残ります。
- テキストに配列を指定すると要素ごとに処理され、同じ形状の配列としてスピルされます(エラー要素はそのエラーのまま)。開始キー・終了キーなどその他の引数に配列を指定すると #VALUE! を返します。
- 関連関数: TEXTBETWEEN。
- 対応: Excel 2010+。すべての Excel バージョンで `TEXTREPLACE` の名前のまま登録されます。
