# BASE

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2013

数値を指定した基数（進数）のテキストに変換します。

## 構文

```
=BASE(number, radix, [min_length])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| number | 必須 | 変換する数値（0 以上） |
| radix | 必須 | 基数 2〜36 |
| min_length | 省略可能 | [省略可] 結果の最小長 |

## 戻り値

指定した基数で表記したテキスト(スカラー)を返します。number が負数または数値でない場合、あるいは radix が 2~36 の範囲外の場合は #NUM! エラーを返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=BASE(255,16)` | FF | 255 を 16 進数に |
| `=BASE(15,2,8)` | 00001111 | 最小桁数まで 0 で埋める |

## 解説

- number の小数部分は切り捨てます。
- 結果が min_length より短い場合は先頭を 0 で埋めます。
- すべての引数に配列を指定すると要素ごとに計算され、同じ形状の配列としてスピルされます — スカラーは繰り返し、列ベクトル×行ベクトルは外積として拡張、サイズが一致しない要素は #N/A、エラー要素はそのエラーをそのまま返します。
- 関連関数: DECIMAL。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `BASE` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.BASE` として登録されます。
