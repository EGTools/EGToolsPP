# ISFORMULA

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2013

参照したセルが数式を含む場合に TRUE を返します。

## 構文

```
=ISFORMULA(参照)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 参照 | 必須 | 検査するセル |

## 戻り値

参照したセルに数式がある場合は TRUE、ない場合は FALSE を返します。参照を省略した場合や取得に失敗した場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=ISFORMULA(A1)` |  | A1 の内容によって異なります |

## 解説

- マクロシート型関数として登録されます。
- 関連関数: FORMULATEXT。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `ISFORMULA` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.ISFORMULA` として登録されます。
