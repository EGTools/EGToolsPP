# SAMPLINGLABEL

**種類**: EGTools 専用関数

ISO 2859-1 のロットサイズ・検査水準によるサンプル文字を返します。

## 構文

```
=SAMPLINGLABEL(ロット数量, [検査水準])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| ロット数量 | 必須 | ロット/バッチ数量(2 以上) |
| 検査水準 | 省略可能 | 通常 Ⅰ,Ⅱ,Ⅲ→G1/G2/G3、特別→S1~S4(既定 G2) |

## 戻り値

ISO 2859-1 のサンプル文字 1 文字(テキストのスカラー)を返します。ロット数量が 2 未満の場合は #NUM!、検査水準が S1~S4・G1~G3 でない場合は #VALUE! エラーを返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=SAMPLINGLABEL(1000)` | J | 既定の G2、ロット 1000 |
| `=SAMPLINGLABEL(1000,"S3")` | E | 特別検査水準 S-3 |

## 解説

- 検査水準表記のハイフン・空白は無視します("G-2"="G2")。
- ISO 2859-1:1999 の表を内蔵して計算します。
- すべての引数に配列を指定でき、LOT の一覧や AQL 表を一度に計算できます — 要素ごとに計算され同じ形状の配列としてスピルされます。スカラーは繰り返し、列ベクトル×行ベクトルは外積として拡張、サイズ不一致の要素は #N/A です。
- 関連関数: SAMPLINGSIZE、SAMPLINGAC、SAMPLINGRE。
- 対応: Excel 2010+。すべての Excel バージョンで `SAMPLINGLABEL` の名前のまま登録されます。
