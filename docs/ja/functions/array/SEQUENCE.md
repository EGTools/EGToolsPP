# SEQUENCE

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2021

連続した数値の配列を生成します。

## 構文

```
=SEQUENCE(行数, [列数], [開始], [増分])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 行数 | 必須 | 行の数 |
| 列数 | 省略可能 | 列の数(既定 1) |
| 開始 | 省略可能 | 開始値(既定 1) |
| 増分 | 省略可能 | 増分(既定 1) |

## 戻り値

rows×cols サイズの連続した数値の配列(行優先で増加)を返し、スピルします。rows や cols が 0 以下の場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=SEQUENCE(3)` | {1;2;3} | 既定の 3 行の数列 |
| `=SEQUENCE(2,3,0,10)` | {0,10,20;30,40,50} | 開始値と増分を指定 |

## 解説

- rows を省略した場合は 1 として扱います(ネイティブでは必須の引数)。
- すべての引数に配列を指定すると、その配列と同じ形状の配列を返し、各要素は要素ごとの結果の最初の値になります(ネイティブと同じ降格リフティング)。
- 関連関数: RANDARRAY。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `SEQUENCE` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.SEQUENCE` として登録されます。
