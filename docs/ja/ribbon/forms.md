# フォーム

**場所**: リボン `EGTools` タブ → `フォーム` グループ

シートに作成しておいたフォーム（書式領域）をデータリストで埋めて繰り返し生成する機能グループです。
スプリットボタン 1 つ（既定の動作 = ラベル作成）で構成されます。

| メニュー | 説明 |
|---|---|
| [ラベル作成](#ラベル作成) | フォームをデータ行ごとに 1 枚のシートへ繰り返し配置し、`{{列名}}` を値に置換 |
| [差し込み](mailmerge.md) | データ行ごとにフォームシートを複製して、個別シート/ファイル（xlsx/PDF）・個別印刷・メール送信（ファイル添付） |

## ラベル作成

フォームをデータリストの行数分だけ複製しながら `{{列名}}` プレースホルダーを各行の値に
置換して、印刷用ラベル（名札・宛名ラベルなど）のシートを作成します。

### 動作手順

1. **フォーム領域の指定** — 範囲入力ウィンドウでフォーム領域を指定します
   （既定値 = 現在の選択範囲の連続領域、キャンセル時は終了）。値のない単一セルを
   指定すると終了します。
2. **データリストの指定** — データリストの領域を指定します。**先頭行が列名**で、
   2 行目以降がデータです。
3. **横方向の配置数の入力** — 1 行に横に並べるラベル数（1~10、既定 1）を
   入力します。
4. 新しいシート（フォームシート名 + `_1` 形式）にデータ行ごとにフォームがコピーされ、
   `{{列名}}` がその行の値に置換されます。完了後に案内が表示されます。

### 置換ルール

| 項目 | ルール |
|---|---|
| プレースホルダー | `{{列名}}` を含むセルだけが置換対象です。1 つのセルに複数書くことができ、前後の文言と組み合わせられます（例: `住所: {{住所}}`） |
| プレースホルダーなし | フォームに `{{ }}` プレースホルダーが 1 つもない場合は、空のフォームがデータ行数分だけ複製されるだけです |
| 空の列名 | リストの先頭行が空になっている列は `Empty1`、`Empty2` … という名前で参照できます |
| 存在しない列名 | リストにない列名を参照すると、警告の後に処理が中断されます |
| 書式 | フォームの書式（罫線・色など）も一緒にコピーされ、**列の幅・行の高さもフォームと同一に**複製されます |

### 参考

- 置換されたセルは**テキスト値**として入力されます（数式ではありません）。
- 行ごとに個別のシート/ファイルを作成するには[差し込み](mailmerge.md)を使用してください
  （ラベル = 1 枚のシートに繰り返し配置、差し込み = 行ごとに個別シート/ファイル）。
