# ホームタブの配置グループ(選択範囲内で中央)

**場所**: Excel `ホーム` タブ → `配置` グループ(EGTools++ が置き換え) → 結合ボタンの下の `選択範囲内で中央`

EGTools++ を読み込むと、Excel `ホーム` タブの既定の **配置** グループが非表示になり、同じ場所に
同じ構成の **配置** グループが作り直されます。アドインは Office の既定グループの中にコントロールを
差し込めないため、グループ全体を再構成する方式です。違いは結合ボタンの下に追加された
**選択範囲内で中央** ボタン 1 つだけです。このボタンはセルを結合せずに横位置だけを「選択範囲内で中央」に
変更するので、見出しを複数列の中央に配置しながら、並べ替え・フィルター・数式参照がそのまま動作します。

置き換えは、Excel の結合ドロップダウンにネイティブの「選択範囲内で中央」項目(idMso `CenterAcrossSelection`)が
**ない場合にのみ** 行われます。ネイティブ項目がすでにある Excel では既定の `配置` グループをそのまま残し、
EGTools++ のボタンは表示されません(Excel 自体の項目を使ってください)。

## グループ構成

| 位置 | コントロール | 出所 |
|---|---|---|
| 左 1 行目 | 上揃え · 上下中央揃え · 下揃え · 方向 | Excel 組み込み |
| 左 2 行目 | 左揃え · 中央揃え · 右揃え · インデントを減らす · インデントを増やす | Excel 組み込み |
| 右 1 行目 | 折り返して全体を表示する | Excel 組み込み |
| 右 2 行目 | セルを結合して中央揃え(ドロップダウン) | Excel 組み込み |
| 右 3 行目 | **選択範囲内で中央** | EGTools++ 追加 |
| ダイアログ起動ツール | セルの書式設定: 配置 | Excel 組み込み |

Excel 組み込みコントロールは非表示にした既定グループのコントロールをそのまま配置し直したものなので、
動作・ラベル・ショートカットキーは Excel のものと同じです。

## 動作手順 — 選択範囲内で中央

1. 中央に置きたい内容があるセルを左端にして、同じ行で横に広げる列範囲を選択します(例: `A1:F1`)。
   複数行をまとめて選択すると各行に適用されます。
2. `ホーム` タブ → `配置` グループの **選択範囲内で中央** を押します。
3. 選択範囲の横位置が **選択範囲内で中央**(`xlHAlignCenterAcrossSelection`)に設定され、各行で内容が
   右側に続く空セル範囲の中央に表示されます。セルは結合されません。
4. 同じ範囲でもう一度押すと、横位置が **標準**(`xlHAlignGeneral`)に戻ります(トグル)。

## ルール

| 状況 | 動作 |
|---|---|
| 選択範囲全体がすでに「選択範囲内で中央」 | **標準** に戻します |
| 選択範囲が混在(一部だけ適用)または未適用 | 選択範囲全体に **選択範囲内で中央** を適用します |
| セル以外のオブジェクト(図形・グラフ・画像など)を選択中 | 何もしません |
| 縦方向 | 横位置だけを変更し、縦方向の中央配置は行いません(Excel の「選択範囲内で中央」の仕様)。縦位置は上揃え/上下中央揃え/下揃えボタンで別途指定します |
| 元に戻す | アドインのコマンドなので Excel の元に戻す(`Ctrl+Z`)には記録されません。戻すにはボタンをもう一度押すか、セルの書式設定で横位置を変更してください |

## 参考

- Microsoft は結合ドロップダウン内の「選択範囲内で中央」項目を、Microsoft 365 Insider チャネルから
  段階的に展開しています(2026 年 9 月の What's New)。EGTools++ はこの機能を Excel 2010~2024 と、まだ
  展開されていない Microsoft 365 でも使えるように `ホーム` タブで提供します。ネイティブ項目がすでにある
  Excel では読み込み時にそれを検出して `配置` グループを置き換えないため、両方が同時に表示されることはなく、
  Excel 自体の項目を使ってください。この判定は EGTools++ の読み込み時に 1 回だけ行うので、チャネルや
  ビルドの変更でネイティブ項目が追加・削除された場合は Excel の再起動後に反映されます。
- 同じ効果は `セルの書式設定` ダイアログ(`Ctrl+1`)→ `配置` タブ → 横位置 `選択範囲内で中央` でも
  得られます。このボタンはその設定をワンクリックで適用/解除するショートカットです。
- 値のある複数セルを見た目だけ結合して見せたい場合は [内容を残す結合](merge-split.md#内容を残す結合) を
  参照してください。そちらは結合書式を貼り付ける方式で、このボタンは横位置だけを変更する方式です。
- EGTools++ をアンロードすると置き換えグループが消え、Excel 既定の `配置` グループが再び表示されます。
