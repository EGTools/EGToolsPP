# セルの右クリックメニュー

**位置**: セル範囲を右クリック → コンテキストメニュー

EGTools++ を読み込むと、セルの右クリックメニューに項目が追加されます。
通常のセル・テーブル(リスト)範囲、ページレイアウトビューでも同じ位置に表示されます。

## 日付入力

右クリックしたセルの横にカレンダーを表示し、日付を選んで入力します。日付を手入力する
代わりに、2 回のクリックで入力できます。

1. セルを右クリックして**日付入力**を押すと、アクティブセルの右側にカレンダーが表示されます
   (画面の端を超える場合は左側へ位置を移動)。現在のセル値が日付の場合は**その
   日付が選択された月**で、そうでない場合は今日から始まります。
2. 上部の `◀◀`/`◀`/`▶`/`▶▶` で年/月を移動します。**日付をクリックするとその日付が
   セルに入力**され、カレンダーが閉じます(灰色で表示される前月/翌月の日付もクリック
   可能)。
3. 下部の **「Today: yyyy-mm-dd」の行をクリックすると今日の日付に移動**します。
   `Esc` またはウィンドウを閉じる(X)でキャンセルすると、セルは変わりません。

- 日曜日・**祝日は赤**、土曜日は青、今日は枠線で表示されます。
  祝日のセルにマウスを乗せると、下部に祝日の名前が表示されます。
- 祝日は内蔵計算基準で、data.go.kr キーが登録されていれば**臨時祝日**も
  反映されます — [カレンダー/予定表 — 祝日の案内](calendar.md#祝日の案内) を参照してください。

## リンクを開く

選択したセルの内容から `http://` または `https://` で始まる URL を探し、
既定のブラウザーで開きます。

- セルのテキスト内で URL が他の文字と混在していても、最初の URL を見つけて開きます。
- 複数のセルを選択した場合は**先頭のセル(左上)** を基準に動作します。
- セルに URL がない場合は何も行いません。

ハイパーリンク書式のない通常のテキスト URL を 2 回のクリックで開けるため、
セルの編集モードに入ったりハイパーリンクを作成したりする必要がありません。
