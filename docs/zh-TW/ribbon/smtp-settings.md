# SMTP 設定

**位置**: 功能區 `EGTools` 索引標籤 → `EGTools` 群組 → 分割按鈕下拉式選單

用來登錄[郵件合併](mailmerge.md)的**寄送郵件**（選項 4·5·6·7）所用 SMTP 伺服器
資訊的對話方塊。

## 設定項目

| 項目 | 說明 |
|---|---|
| 寄件人姓名 | 顯示給收件人的寄件者名稱（可省略 — 省略時僅顯示信箱地址） |
| 寄件人信箱 | 寄件者地址，同時是 **SMTP 登入帳戶** |
| 外寄郵件伺服器 | SMTP 伺服器位址（例：`smtp.gmail.com`） |
| 伺服器連接埠 | 預設 **465** |
| SSL | 是否使用 SSL（預設開啟） |

## 規則

- 設定儲存於使用者帳戶，**不會留在活頁簿中**。
- **密碼絕不會儲存。** 每次寄送郵件時輸入，僅在記憶體中
  使用。
- 在郵件合併中選擇了寄送選項但設定為空時（信箱、伺服器、連接埠
  任一未填），此對話方塊會**自動開啟**。若仍未填妥，
  寄送會中止。

## 重要限制 — 僅支援隱含式 SSL

寄送引擎 (Windows CDO) **僅支援隱含式 SSL (implicit SSL)**。通常
**連接埠 465** 屬於此類。**不支援連接埠 587 的 STARTTLS**，
輸入 587 會導致寄送失敗。

- Gmail：伺服器 `smtp.gmail.com`、連接埠 `465`、SSL 開啟 —
  請申請**應用程式密碼**代替帳戶密碼輸入。
- 其他服務也請使用「SSL (465)」方式的連接埠；使用兩步驟驗證的帳戶
  可能需要應用程式密碼。

## 備註

- 韓文等非 ASCII 主旨/內文會以 UTF-8 編碼寄送。
- 寄送失敗時，伺服器回報的錯誤說明會原樣顯示在[郵件合併](mailmerge.md)
  完成摘要的失敗清單中。
