# 常用索引標籤的對齊方式群組(跨欄置中)

**位置**: Excel `常用` 索引標籤 → `對齊方式` 群組(由 EGTools++ 取代) → 合併按鈕下方的 `跨欄置中`

載入 EGTools++ 後,Excel `常用` 索引標籤中預設的 **對齊方式** 群組會被隱藏,並在原位置重新建立一個
配置相同的 **對齊方式** 群組。增益集無法在 Office 預設群組內部插入控制項,因此採用整個群組重建的方式;
唯一的差異是合併按鈕下方新增的 **跨欄置中** 按鈕。此按鈕不合併儲存格,只將水平對齊改為「跨欄置中」,
讓標題跨多欄置中顯示的同時,排序、篩選與公式參照仍照常運作。

**只有在** Excel 合併下拉式選單中尚無原生「跨欄置中」項目(idMso `CenterAcrossSelection`)時才會取代。
在已有原生項目的 Excel 中,預設的 `對齊方式` 群組維持不變,EGTools++ 按鈕不會出現(請使用 Excel 本身的項目)。

## 群組配置

| 位置 | 控制項 | 來源 |
|---|---|---|
| 左側第 1 列 | 靠上對齊 · 置中對齊 · 靠下對齊 · 方向 | Excel 內建 |
| 左側第 2 列 | 靠左對齊 · 置中 · 靠右對齊 · 減少縮排 · 增加縮排 | Excel 內建 |
| 右側第 1 列 | 自動換行 | Excel 內建 |
| 右側第 2 列 | 跨欄置中(合併,下拉式) | Excel 內建 |
| 右側第 3 列 | **跨欄置中** | EGTools++ 新增 |
| 對話方塊啟動器 | 儲存格格式: 對齊方式 | Excel 內建 |

Excel 內建控制項是把被隱藏的預設群組中的控制項原樣重新放置,因此其行為、標籤與快速鍵與 Excel 相同。

## 操作步驟 — 跨欄置中

1. 以含有內容的儲存格為最左端,在同一列中選取要橫向展開的欄範圍(例如 `A1:F1`)。
   同時選取多列時會逐列套用。
2. 按一下 `常用` 索引標籤 → `對齊方式` 群組中的 **跨欄置中**。
3. 選取範圍的水平對齊被設為 **跨欄置中**(`xlHAlignCenterAcrossSelection`):每一列中,內容顯示在
   其右側連續空白儲存格範圍的中央。儲存格不會被合併。
4. 在同一範圍再按一次,水平對齊會還原為 **一般**(`xlHAlignGeneral`)— 此按鈕為切換式。

## 規則

| 情況 | 行為 |
|---|---|
| 選取範圍已全部為「跨欄置中」 | 還原為 **一般** 對齊 |
| 混合狀態(僅部分已套用)或未套用 | 對整個選取範圍套用 **跨欄置中** |
| 選取的是非儲存格物件(圖案、圖表、圖片等) | 不執行任何動作 |
| 垂直方向 | 只變更水平對齊,不做垂直置中(這是 Excel「跨欄置中」的定義)。垂直位置請以靠上/置中/靠下對齊按鈕另行設定 |
| 復原 | 這是增益集命令,不會記錄到 Excel 的復原(`Ctrl+Z`)。要還原,請再按一次按鈕,或在「儲存格格式」中變更水平對齊 |

## 參考

- Microsoft 正從 Microsoft 365 Insider 通道開始,逐步推出合併下拉式選單內的「跨欄置中」項目(2026 年 9 月
  What's New)。EGTools++ 在 `常用` 索引標籤提供此功能,使其在 Excel 2010~2024 以及尚未收到推出的
  Microsoft 365 中也可使用。在已有原生項目的 Excel 中,EGTools++ 會在載入時偵測到它而不取代 `對齊方式` 群組,
  因此兩者不會同時出現,請使用 Excel 本身的項目。此判定只在 EGTools++ 載入時進行一次,若通道或組建變更
  導致原生項目新增或消失,需重新啟動 Excel 後才會生效。
- 透過 `儲存格格式` 對話方塊(`Ctrl+1`)→ `對齊方式` 索引標籤 → 水平 `跨欄置中` 也可得到相同效果。
  此按鈕是一鍵套用/取消該設定的捷徑。
- 若要讓多個含值的儲存格僅在外觀上看起來已合併,請參閱 [保留值的合併](merge-split.md#保留值的合併);
  該命令套用的是合併格式,而此按鈕只變更水平對齊。
- 卸載 EGTools++ 後,取代群組會消失,Excel 預設的 `對齊方式` 群組會重新顯示。
