# 郵件合併

**位置**：功能區 `EGTools` 索引標籤 → `表單` 群組 → `標籤` 分割按鈕的選單 → **郵件合併**

依資料清單的**每一列整份複製表單工作表**，將 `{{欄位名}}` 佔位符取代為該列的
值，並依選擇的選項執行個別檔案儲存（xlsx/PDF）、逐一列印、**寄送
郵件**（附加各列的檔案）。寄送郵件所用的 SMTP 伺服器資訊在
[SMTP 設定](smtp-settings.md)中登錄（密碼不會儲存）。

## 操作流程

1. **輸入選項** — 以數字（0~7，預設 1）輸入要執行的作業。是 1（儲存檔案）、
   2（列印）、4（寄送郵件）的**位元組合**。
   `0` = 複製表單工作表（保留工作表）/ `1` = 儲存檔案 / `2` = 列印 /
   `3` = 儲存 + 列印 / `4` = 寄送郵件 / `5` = 儲存 + 寄送郵件 /
   `6` = 列印 + 寄送郵件 / `7` = 儲存 + 列印 + 寄送郵件。
2. **印表機設定** — 若選項包含列印（2·3·6·7），會先顯示印表機設定
   對話方塊。取消則中斷作業。
3. **指定表單工作表** — 在範圍輸入視窗中選擇表單工作表的任一儲存格。
   所選範圍所屬的**整個工作表**會作為表單使用。
4. **指定資料範圍** — 選擇資料清單的儲存格。選取範圍會自動擴充為連續範圍
   （CurrentRegion），**首列為欄位名**，第二列起為
   資料。
5. **寄送郵件準備**（包含寄送的選項 4~7）— 確認收件人欄與郵件範本
   工作表後，若 [SMTP 設定](smtp-settings.md)為空，設定
   對話方塊會自動開啟。接著要求輸入 **SMTP 帳戶密碼**
   （密碼不會儲存，取消則中斷作業）。
6. 每個資料列都會在活頁簿最後複製表單工作表並取代 `{{欄位名}}`，
   依選項執行列印、儲存、寄送。完成後顯示「已完成的項目: N」—
   若選擇了寄送，也會一併顯示「已寄送郵件: N」。

## 規則

| 項目 | 規則 |
|---|---|
| 佔位符 | `{{欄位名}}` 與清單標題列的欄位名以**不區分大小寫、忽略前後空格**的方式對應。一個儲存格可寫多個，也可與前後文字組合。若有清單中沒有的欄位名，會連同該欄位名顯示錯誤並中斷 |
| 工作表/檔案名稱 | **首欄的值**會成為複製工作表與儲存檔案的名稱。首欄為空的列會跳過，名稱中的禁用字元會改為 `_`。若已有相同工作表名稱，會加上 `_1`、`_2` … 後綴 |
| 儲存位置 | 檔案儲存在活頁簿所在資料夾的 `Output\` 子資料夾。**活頁簿必須已儲存**，否則顯示說明後中斷（寄送郵件也要建立附件檔案，同樣適用） |
| PDF 儲存 | 若清單**首欄的標題為 `PDF`**（不區分大小寫），則以 PDF 取代 xlsx 儲存 |
| 開啟密碼 | 若清單有 `PassWord`（或韓文 `암호`）欄，該列的值會設為 xlsx 的**開啟密碼**（空值則無密碼，不適用於 PDF） |
| 複製工作表清理 | 選項不是 0 時，複製的工作表會在列印、儲存、寄送後刪除。選項 0 則工作表保留在活頁簿中 |

## 寄送郵件 (選項 4·5·6·7)

選擇包含寄送的選項時，會額外套用下列規則。

| 項目 | 規則 |
|---|---|
| 收件人欄 | 資料清單**必須**有標題為 `eMail`（或韓文 `이메일`，不區分大小寫）的欄。沒有則顯示說明後中斷。收件人儲存格**為空的列只跳過寄送**，工作表複製、儲存、列印照常執行 |
| 郵件範本工作表 | 活頁簿**必須**有名為 `Email`（或韓文 `이메일`）的工作表。以**第 1 欄 = 鍵、第 2 欄 = 值**輸入。鍵：`Subject`（**必填**）、`Body`、`CC`、`BCC`（也接受韓文 `제목`/`본문`/`참조`/`숨은참조`） |
| 主旨/內文取代 | 主旨與內文也會套用 `{{欄位名}}` 取代，可**為每列寄送個人化郵件**。清單中沒有的欄位名維持原文 |
| 附件 | 該列儲存的檔案（xlsx 或 PDF，支援開啟密碼）會**附加**到郵件。若未選擇儲存檔案（位元 1），附件用檔案會在寄送後刪除 |
| 寄件人/伺服器 | 使用 [SMTP 設定](smtp-settings.md)的寄件人名稱、郵件地址、伺服器、連接埠、SSL。設定為空時會自動開啟設定對話方塊，仍不完整則中斷 |
| 密碼 | SMTP 帳戶密碼**每次執行都要輸入**，不會儲存在任何地方 |
| 失敗處理 | 即使某一列寄送失敗，也會**繼續處理下一列**。完成摘要會以「名稱 - 錯誤內容」清單顯示失敗的列 |

## 備註

- 取代後的儲存格以**文字值**輸入（不是公式）。
- 檔案儲存是將複製的工作表複製到單一工作表的新活頁簿、儲存後關閉的
  方式，因此儲存的檔案只包含那一個工作表。
- 寄送引擎**僅支援隱含式 SSL（通常為連接埠 465）**，不支援
  587 STARTTLS。詳細限制請參閱 [SMTP 設定](smtp-settings.md)。
- 與[製作標籤](forms.md#製作標籤)的差異：標籤是**在同一工作表反覆
  排列表單**，郵件合併是**為每列建立個別工作表/檔案**。
