# 工具

**位置**: 功能區 `EGTools` 索引標籤 → `工具` 群組

彙集常用輔助功能的分割按鈕。直接按下按鈕會執行預設動作
**整理錯誤**，按下箭頭則會展開 10 個選單項目。

## 刪除樣式

批次刪除作用中活頁簿裡累積的**自訂儲存格樣式**。
當從其他文件複製而來、如滾雪球般增加的樣式使文件變得笨重時
使用。在確認視窗中選擇刪除範圍。

| 選擇 | 動作 |
|---|---|
| 是 | 僅保留內建 (Built-In) 樣式，刪除所有自訂樣式 |
| 否 | 保留內建樣式 + **實際使用中**的樣式，只刪除其餘樣式 |
| 取消 | 取消作業 |

- 「使用中」檢查會逐儲存格掃描所有工作表的使用範圍，
  **在大型文件中可能耗時較久**（進度顯示於狀態列）。
- 鎖定的樣式會先解除鎖定再刪除，完成後會告知刪除/失敗的數量。

## 刪除名稱

刪除作用中活頁簿的名稱中符合下列條件者。

| 刪除對象 | 條件 |
|---|---|
| 參照損毀的名稱 | 參照對象 (RefersTo) 含 `#NAME?` / `#REF!` / `#N/A` |
| 巨集殘留 | 參照對象含 `BlankMacro1` |
| 隱藏的名稱 | 在名稱管理員中看不到的 (Visible=False) 名稱 |

Excel 內部名稱（`_xl*.*` 格式，例如列印範圍、篩選相關）絕不會被更動。
名稱很多時進度會顯示於狀態列，完成後會告知刪除的數量
（若無對象則提示沒有可刪除項目）。

## 整理錯誤

將作用中工作表使用範圍內**正在產生錯誤值的公式**以 `=IFERROR(原公式,"")`
包裹，隱藏錯誤顯示。CSE 陣列公式（`{=…}`）以整個陣列為單位包裹。
非公式的儲存格（直接輸入的錯誤常數）不會被更動，完成後會告知修改的
數量。

- 錯誤的原因並未被修正，只是**顯示為空字串**。
  適合在列印、發佈前整理。
- 若包裹後公式仍持續出錯的狀態下重複執行，IFERROR 可能會
  層層疊套。

## 清理空文字

將**只含長度為 0 的字串 ("")** 的儲存格變成真正的空儲存格（清除內容）。
公式結果或外部資料留下的 `""` 儲存格看似是空的，但在 ISBLANK、COUNTA、
結尾儲存格 (Ctrl+End) 判定中不被視為空儲存格；此功能可加以清理。

1. 選取範圍後執行。**若只選取單一儲存格，則以工作表的整個使用範圍**
   為對象。
2. 「是否排除公式儲存格?」確認視窗 — **是** = 保留傳回 `""` 的公式儲存格 /
   **否** = 公式儲存格也一併清除內容（公式會被刪除）/ **取消** = 中止。
3. 完成後會告知清理的儲存格數。CSE 陣列公式會整個陣列被清除。

## 整理註解

將作用中工作表的**所有註解（附註）** 移到該儲存格右側緊鄰的位置，並依
內容自動調整大小。若儲存格已合併，則移到合併範圍的右側旁。
完成後會告知整理的註解數。

## 變更框線色彩

在色彩選擇對話方塊中選定色彩後（取消則結束），批次變更選取範圍內所有框線
— 上/下/左/右 + 兩種對角線 — 的色彩。
**線條樣式（實線、虛線、粗細）維持不變**，只變更色彩，原本沒有框線的
方向也不會新增框線。

## 描摹形狀

沿選取範圍中**填有背景色的儲存格**輪廓建立自由形狀 (Freeform)。
適合把用儲存格著色畫出的地圖、區域標示等擷取成單一形狀時
使用。

1. 選取包含著色儲存格的範圍後執行。若沒有著色儲存格，
   會顯示「請選取包含著色儲存格的範圍」後結束。
2. **白色背景（含無填滿）** 視為背景，其餘填有色彩的
   儲存格視為形狀區域。
3. 沿著色儲存格中最先遇到的**相連的一整塊**輪廓，依儲存格的實際
   寬度、高度描摹並建立形狀，並對結果形狀套用樣式預設集。

- 若有多個彼此分離的區塊，只有第一個區塊會成為形狀。其餘請縮小範圍
  再次執行。
- 形狀建立失敗時，會顯示「形狀轉換失敗」的提示。

## UDF 固定為值

將含有 EGTools 函數（含 `EG.`/`x` 前綴變形）的公式替換為**計算後的值**。
這是發佈用功能：把文件送到沒有增益集的環境時，讓值原樣保留，
而不是公式壞成 `#NAME?`。

1. **掃描** — 以唯讀方式掃描全部工作表的公式，以確認視窗顯示對象
   數量（若無對象則提示後結束）。
2. **儲存關卡 + 備份** — 若尚未儲存會先詢問是否儲存，套用前會
   自動儲存備份檔案 (SaveCopyAs)。備份失敗則不會進行。
3. **固定為值** — 將對象公式替換為值。CSE 陣列以整個陣列、
   溢出公式以整個溢出範圍為單位變成值。原公式會以
   `EgUdfRemoved: <公式>` 形式保存在儲存格註解中（已有註解時接在其後）。
4. 完成後會告知固定的儲存格數與備份檔案路徑。

- 對象函數清單與增益集的函數註冊清單以單一來源管理，永遠保持一致。
- 如果說[套用舊版相容](apply-compat.md)是**轉換函數名稱**、讓公式存活的
  功能，那麼 UDF 固定為值就是把公式**替換為值**的功能。

## 套用 CheckBox

使選取範圍以 0/1 輸入顯示為核取方塊的樣子。

1. 對選取範圍套用**僅允許 0 或 1 的資料驗證**。
2. 將顯示格式設為 `[=1]"✅";[=0]"⬜";""`
   — 輸入 1 顯示 ✅、輸入 0 顯示 ⬜、其他則顯示為空白。
3. 空儲存格會填入 0 並置中對齊。

儲存格的值仍是 0/1 數字，因此可直接用 `SUM`、`COUNTIF` 等彙總。

## 全部重算

強制對開啟中的**所有活頁簿**執行完整重算（`CalculateFull`）。
用於將自動計算遺漏的儲存格、揮發性函數乃至外部參照從頭重新計算。

> 公共 API 函數的金鑰註冊/刪除已移至
> [EGTools 群組的管理 API 金鑰](api-keys.md)。
