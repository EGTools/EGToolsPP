# BOMTREE

**類別**: EGTools 專用函數

由父項/子項/用量清單建構 BOM 樹。

## 語法

```
=BOMTREE(父項, 子項, 用量, [標題列], [WBS])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 父項 | 必要 | 父項欄 |
| 子項 | 必要 | 子項欄(相同長度) |
| 用量 | 必要 | 用量欄(相同長度) |
| 標題列 | 選用 | TRUE 加入標題列 |
| WBS | 選用 | TRUE 加入 WBS 欄 |

## 傳回

以二維陣列（溢出）傳回展開為層級·父項·子項·值欄（選用 WBS 時為 5 欄）的 BOM 樹。三個清單為空或長度不同時傳回 #VALUE!；同一父項-子項配對存在不同的值時以 "Error: ..." 文字傳回。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=BOMTREE({"X";"X";"Y"},{"Y";"Z";"W"},{1;2;3})` | {0,"Top Level","X","";1,"X","Y",1;2,"Y","W",3;1,"X","Z",2} | BOM 樹展開 |
| `=BOMTREE({"X";"X";"Y"},{"Y";"Z";"W"},{1;2;3},TRUE)` | {"level","Parent","Child","Value";0,"Top Level","X","";1,"X","Y",1;2,"Y","W",3;1,"X","Z",2} | 包含標題列 |

## 備註

- WBS 編號為維持排序，會以零寬空白（U+200B）補足 5 位。
- 展開深度限制為 64（循環參照防護）。
- 遇到父項儲存格為空的列時，會在該處停止讀取清單。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `BOMTREE` 原名註冊。
