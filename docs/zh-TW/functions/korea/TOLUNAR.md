# TOLUNAR

**類別**: EGTools 專用函數

將公曆日期轉換為韓國農曆(919~2050年)。

## 語法

```
=TOLUNAR(公曆日期)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 公曆日期 | 必要 | 日期、序列值、"yyyy-mm-dd" 文字、yyyymmdd 數字或範圍 |

## 傳回

以純量傳回農曆日期文字 "yyyy-mm-dd"(閏月時含後綴)，輸入範圍時會以相同大小的陣列溢出。無法解析日期或超出農曆表範圍(918~2050 年)時，傳回 #VALUE! 錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=TOLUNAR(DATE(2025,1,29))` | 2025-01-01 | 2025 年農曆新年 → 農曆 1/1 |
| `=TOLUNAR(DATE(2025,10,6))` | 2025-08-15 | 2025 年秋夕 → 農曆 8/15 |

## 備註

- 閏月會依語言設定加上 "(윤)"(韓文)或 "(LM)"(英文)後綴。
- 使用以 .NET KoreanLunisolarCalendar 產生的內建表(918~2050 年)。
- 相關函數: TOSOLAR
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `TOLUNAR` 原名註冊。
