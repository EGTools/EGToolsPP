# HANTONUMBER

**類別**: EGTools 專用函數

將韓文(漢字)金額表示轉換為數字。

## 語法

```
=HANTONUMBER(文字, [僅數字])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字 | 必要 | 韓文金額文字 |
| 僅數字 | 選用 | TRUE 傳回數字(預設)；FALSE 傳回帶格式文字 |

## 傳回

預設（僅數字=TRUE）傳回數字（純量）；若整數部分超過 15 位，為保留精確度會改以文字傳回。僅數字=FALSE 時，傳回如「금1,234원」形式的文字。若文字為空，或阿拉伯數字、小數點連續出現 2 個以上，則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=HANTONUMBER("일금오만원정")` | 50000 | 將韓文金額轉為數字 |
| `=HANTONUMBER("삼억이천오백만")` | 325000000 | 處理億、萬單位 |
| `=HANTONUMBER("일금오만원정",FALSE)` | 일금50,000원정 | 傳回格式化文字 |

## 備註

- 也可辨識漢字寫法與異體字（一二三、壹貳參、拾佰仟萬 等）。
- 輸入中的空白與逗號會被忽略；「금/일금」、「원/원정」等前綴、後綴在 僅數字=FALSE 時會原樣還原。
- 文字指定為陣列時會逐元素處理，以相同形狀的陣列溢出傳回（錯誤元素原樣傳回）；其他引數指定為陣列時傳回 #VALUE!。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `HANTONUMBER` 原名註冊。
