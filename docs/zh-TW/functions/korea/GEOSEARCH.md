# GEOSEARCH

**類別**: EGTools 專用函數

搜尋地址或場所並傳回 GPS 座標(VWorld)。

## 語法

```
=GEOSEARCH(關鍵字, [搜尋對象], [EPSG], [api_key])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 關鍵字 | 必要 | 地址或場所關鍵字 |
| 搜尋對象 | 選用 | 1 地址(預設), 2 場所 |
| EPSG | 選用 | 座標系 EPSG 代碼(預設 4326=WGS84) |
| api_key | 選用 | vworld.kr 認證金鑰，輸入一次後存入登錄檔 |

## 傳回

傳回搜尋結果的 x,y 座標陣列，並會溢出（結果為多筆時為含地址欄的 n×3）。關鍵字為空或搜尋對象/EPSG 無效時傳回 #VALUE!；沒有結果時傳回 #N/A；金鑰缺漏、網路或服務錯誤則以 "ERROR: …" 文字傳回。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=GEOSEARCH("서울특별시청",2)` |  | 場所搜尋座標（需要網路與 API 金鑰） |

## 備註

- 不隨附 API 金鑰。請至[空間資訊開放平台](https://www.vworld.kr)申請，以最後一個引數輸入一次後即儲存於使用者帳戶；金鑰被拒絕時會自動刪除並傳回重新申請的指引。
- 地址搜尋（搜尋對象=1）會依道路名 → 地番的順序自動重試。
- 搜尋詞·api_key 指定為陣列時傳回 #VALUE!（api_key 會在儲存前被拒絕，防止儲存錯誤的金鑰）— 多筆資料請將公式逐列複製使用。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `GEOSEARCH` 原名註冊。
