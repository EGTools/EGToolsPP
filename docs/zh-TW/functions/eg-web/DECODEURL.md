# DECODEURL

**類別**: EGTools 專用函數

將百分號編碼的 URL 字串解碼為文字。

## 語法

```
=DECODEURL(文字)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字 | 必要 | 要解碼的 URL 文字 |

## 傳回

傳回將 %-編碼(UTF-8)還原為原始文字的字串。輸入陣列時會逐一處理各元素，並以相同大小的陣列溢出。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=DECODEURL("a%20b%26c")` | a b&c | 解碼 %-編碼 |
| `=DECODEURL("%ED%95%9C%EA%B8%80")` | 한글 | 解碼 UTF-8 韓文 |

## 備註

- 無效的 % 序列不會轉換，將原樣保留。
- + 符號不會轉換為空格(不支援表單編碼)。
- 為 ENCODEURL 的反函數。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `DECODEURL` 原名註冊。
