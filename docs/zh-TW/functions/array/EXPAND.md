# EXPAND

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2024

將陣列擴展至指定大小，並以值填補。

## 語法

```
=EXPAND(陣列, 列數, [欄數], [填補值])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列 | 必要 | 陣列 |
| 列數 | 必要 | 總列數 |
| 欄數 | 選用 | 總欄數(選用) |
| 填補值 | 選用 | 填補值(預設 #N/A) |

## 傳回

傳回擴展為指定列數×欄數大小的陣列，在支援動態陣列的 Excel 中會溢出。新增的位置以填補值（預設 #N/A）填入。若陣列為空，或指定大小小於原始陣列，則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=EXPAND({1,2;3,4},3,3,0)` | {1,2,0;3,4,0;0,0,0} | 擴展為 3×3，以 0 填補 |
| `=EXPAND({1,2},1,4)` | {1,2,#N/A,#N/A} | 預設填補值 #N/A |
| `=EXPAND({1,2;3,4},1,1)` | #VALUE! | 無法縮小 |

## 備註

- 省略列數、欄數時，維持原始大小。
- 省略填補值時，以 #N/A 填補。
- 列數·欄數·填滿值指定為陣列時，會傳回與該陣列相同形狀的陣列，每個元素為該元素結果的第一個值（與原生一致的降級提升）。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `EXPAND` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.EXPAND`。
