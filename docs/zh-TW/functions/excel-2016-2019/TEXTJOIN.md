# TEXTJOIN

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2016/2019

使用分隔符號連接文字（可忽略空白儲存格）。

## 語法

```
=TEXTJOIN(分隔符號, 忽略空白, 文字1, ...)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 分隔符號 | 必要 | 各項之間的分隔符號 |
| 忽略空白 | 必要 | 為 TRUE 時略過空白儲存格 |
| 文字1 | 必要 | 文字/範圍 |
| … | 選用 | 上述引數可重複指定 |

## 傳回

傳回以分隔符號連結而成的單一文字（純量）。連結值·分隔符號·忽略空白任一處有錯誤值時，會原樣傳回該錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=TEXTJOIN("-",TRUE,"a","","b")` | a-b | 略過空值 |
| `=TEXTJOIN("-",FALSE,"a","","b")` | a--b | 保留空值 |
| `=TEXTJOIN(",",TRUE,{1,2;3,4})` | 1,2,3,4 | 連結陣列元素 |
| `=TEXTJOIN({"-";"+"},TRUE,"a","b","c")` | a-b+c | 分隔符號陣列循環使用 |

## 備註

- 省略忽略空白引數時視為 TRUE。
- 文字引數最多支援 255 個。
- 分隔符號指定為陣列時會循環使用其元素 — 如 {"-";"+"} 依序套用 -、+、-、…。
- 相關函數：CONCAT
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `TEXTJOIN` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.TEXTJOIN`。
