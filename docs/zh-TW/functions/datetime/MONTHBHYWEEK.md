# MONTHBHYWEEK

**類別**: EGTools 專用函數

依週起始日與歸屬日傳回日期所在週歸屬的月份。

## 語法

```
=MONTHBHYWEEK(日期, [週起始日], [歸屬日])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 日期 | 必要 | 基準日期 |
| 週起始日 | 選用 | 1=日~7=六(預設 2=一) |
| 歸屬日 | 選用 | 決定所屬月的星期(預設 5=四) |

## 傳回

傳回日期所在週所屬的月份(1~12，純量數字)。無法解析日期，或起始星期·基準星期超出 1~7 範圍時，傳回 #VALUE! 錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=MONTHBHYWEEK(DATE(2026,2,1))` | 1 | 星期日 2/1 所在週屬於 1 月 |
| `=MONTHBHYWEEK(DATE(2026,2,2))` | 2 | 2/2 所在週屬於 2 月 |

## 備註

- 星期編號為 1=日 ~ 7=六，預設為週一開始·週四基準。
- 週的所屬月份以基準星期所在的月份為準。
- 日期指定為陣列時會逐元素計算，以相同形狀的陣列溢出傳回（錯誤元素會原樣傳回該錯誤）。
- 相關函數: WEEKNUMOFMONTH
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `MONTHBHYWEEK` 原名註冊。
