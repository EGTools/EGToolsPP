# SUMIFCOLOR

**類別**: EGTools 專用函數

對顯示顏色與基準儲存格一致的儲存格求和。

## 語法

```
=SUMIFCOLOR(檢查範圍, 基準儲存格, [字型色])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 檢查範圍 | 必要 | 要求和的範圍 |
| 基準儲存格 | 必要 | 保存基準色的儲存格(多個時取第一個) |
| 字型色 | 選用 | TRUE 時比較字型色，預設 FALSE |

## 傳回

傳回顯示顏色與基準儲存格相同之儲存格的數字總和。COM 連線失敗、讀取基準色失敗，或檢查儲存格數超過 100,000 個時傳回 #VALUE!；符合的儲存格含有錯誤值時，會原樣傳回該錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=SUMIFCOLOR(A1:A10,C1)` |  | 與 C1 填滿色相同的儲存格總和（結果依儲存格格式而異） |

## 備註

- 以 DisplayFormat 為基礎，因此依已套用條件式格式設定的顯示顏色進行比較。
- 僅變更格式不會觸發重新計算，需按 F9；且屬巨集型函數，不參與多執行緒重新計算。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `SUMIFCOLOR` 原名註冊。
