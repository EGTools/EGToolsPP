# DISPLAYCOLOR

**類別**: EGTools 專用函數

傳回範圍中每個儲存格顯示的填滿色或字型色。

## 語法

```
=DISPLAYCOLOR(顏色範圍, [字型色])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 顏色範圍 | 必要 | 要檢查顏色的儲存格範圍 |
| 字型色 | 選用 | TRUE 為字型色，預設 FALSE=填滿色 |

## 傳回

以與範圍相同大小的數字陣列傳回各儲存格實際顯示的填滿色（字型色=TRUE 時為字型色）值，並會溢出。儲存格數超過 100,000 個，或 COM 連線、讀取顏色失敗時，傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=DISPLAYCOLOR(A1:B2)` |  | 各儲存格的顯示色號碼（結果依儲存格格式而異） |

## 備註

- 以 DisplayFormat 為基礎，因此傳回已套用條件式格式設定的顯示顏色。
- 僅變更格式不會觸發重新計算，需按 F9 重新計算。
- 屬於巨集型函數，因此不參與多執行緒重新計算。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `DISPLAYCOLOR` 原名註冊。
