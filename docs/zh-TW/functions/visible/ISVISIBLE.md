# ISVISIBLE

**類別**: EGTools 專用函數

檢查範圍中每個儲存格是否可見(列/欄未隱藏)。

## 語法

```
=ISVISIBLE(範圍)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 範圍 | 必要 | 要檢查的儲存格範圍 |

## 傳回

以與範圍相同大小的陣列傳回各儲存格是否可見：可見為 TRUE，列或欄被隱藏則為 FALSE，並會溢出。儲存格數超過 100,000 個或 COM 連線失敗時，傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=ISVISIBLE(A1:A5)` |  | 各儲存格是否可見（結果依隱藏狀態而異） |

## 備註

- 僅變更列/欄的隱藏狀態不會觸發重新計算，需按 F9 重新計算。
- 屬於巨集型函數，因此不參與多執行緒重新計算。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `ISVISIBLE` 原名註冊。
