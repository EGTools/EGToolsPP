# SORTBY

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2021

依其他陣列的值排序陣列。

## 語法

```
=SORTBY(陣列, 依據陣列1, [順序1], ...)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列 | 必要 | 要排序的資料 |
| 依據陣列1 | 必要 | 排序鍵(依列) |
| 順序1 | 選用 | 1 遞增(預設)，-1 遞減 |
| … | 選用 | 上述引數可重複指定 |

## 傳回

傳回依基準陣列之值的順序重新排列列後的陣列，並會溢出。若沒有任何與 array 列數相同的有效基準陣列則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=SORTBY({"a";"b";"c"},{3;1;2})` | {b;c;a} | 依基準陣列排序 |
| `=SORTBY({1;2;3},{2;2;1},1,{9;1;5},-1)` | {3;1;2} | 第二基準遞減排序 |

## 備註

- 基準陣列必須是與 array 列數相同的直向（單欄）向量，且僅支援列排序（不支援欄方向排序）。
- 列數不同的基準陣列會被靜默忽略。
- 相關函數：SORT。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `SORTBY` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.SORTBY`。
