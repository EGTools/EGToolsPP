# SORT

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2021

> ⚠️ 在部分舊版 Excel 中因保留字衝突，會以 `xSORT` 名稱註冊。

排序陣列。

## 語法

```
=SORT(陣列, [排序索引], [排序順序], [依欄])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列 | 必要 | 要排序的資料 |
| 排序索引 | 選用 | 排序依據的欄(或列)，預設 1 |
| 排序順序 | 選用 | 1 遞增(預設)，-1 遞減 |
| 依欄 | 選用 | TRUE 則依欄排序 |

## 傳回

傳回依指定欄（或列）排序、大小相同的陣列，並會溢出。若 sort_index 超出陣列範圍或發生內部錯誤則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=SORT({3;1;2})` | {1;2;3} | 遞增排序 |
| `=SORT({1,3;2,1;3,2},2)` | {2,1;3,2;1,3} | 依第 2 欄排序 |
| `=SORT({5;3;9},1,-1)` | {9;5;3} | 遞減排序 |
| `=SORT({1,1;2,5;1,3;2,2},{1,2},{1,-1})` | {1,3;1,1;2,5;2,2} | 多欄排序（第 1 欄遞增·第 2 欄遞減） |

## 備註

- sort_order 為負數時遞減排序，其他值（含 0）視為遞增排序（原生函數僅允許 1/-1）。
- 相同鍵值會保持原始順序（穩定排序）。
- sort_index·sort_order 指定為陣列時為多欄優先順序排序（如 {1,2} 與 {1,-1} = 第 1 欄遞增 → 第 2 欄遞減）；僅 sort_order 為陣列時傳回 #VALUE!。
- 相關函數：SORTBY、UNIQUE。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `SORT` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.SORT`。
