# HASALL

**類別**: MS Excel 相容函數 · **原生導入**: Microsoft 365 (2026 新增)

若所有值都出現在清單或陣列中則傳回 TRUE。

## 語法

```
=HASALL(陣列, 值集)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列 | 必要 | 要搜尋的清單文字、範圍或陣列 |
| 值集 | 必要 | 要尋找的值(範圍、陣列或清單文字) |

## 傳回

傳回 TRUE/FALSE（純量）。陣列或值集引數本身是錯誤時直接傳回該錯誤；省略值集時傳回 #VALUE!。值集為空時為 TRUE。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=HASALL("a, b, c",{"a","c"})` | TRUE | 全部存在即 TRUE |
| `=HASALL("a, b",{"a","z"})` | FALSE | 缺少任一即 FALSE |

## 備註

- 值集引數可接受範圍、陣列常數與清單文字，包含巢狀在內的所有項目會攤平為一個值集合，每個值依與 HAS 相同的規則尋找（不區分大小寫的整項比對、數值相等）。值集給文字時會依清單文字解析，以逗號拆分，拆分後數字形狀的項目變為數字（可像 "z, B" 一樣指定多個值；"1, 2" 是數字 1 與 2）。要把單一值以文字原樣比對，請用陣列常數 {"1"}。
- 值集範圍中的空白儲存格視為空文字項目，因此除非清單含有空項目，否則結果為 FALSE。陣列引數的解析規則（清單文字、範圍、陣列常數；無逗號的單一文字保持文字；無法解析時為 1 個項目）與 HAS 相同。儲存格內清單請先以功能區 [EGTools] › [清單/陣列儲存格 → 文字] 轉換後再使用。
- 相關函數：HAS、HASANY、FLATTEN
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `HASALL` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.HASALL`。
