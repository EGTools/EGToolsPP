# REGEXREPLACE

**類別**: MS Excel 相容函數 · **原生導入**: Microsoft 365

取代與正規表示式相符的文字($1.. 反向參照)。

## 語法

```
=REGEXREPLACE(文字, 模式, 取代文字, [次序], [區分大小寫])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字 | 必要 | 來源文字 |
| 模式 | 必要 | 正規模式 |
| 取代文字 | 必要 | 取代內容($1, $2…) |
| 次序 | 選用 | 0 全部(預設)，N = 第 N 個 |
| 區分大小寫 | 選用 | 0 區分(預設)，1 忽略 |

## 傳回

傳回取代後的單一文字（純量）。正規表示式無效時傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=REGEXREPLACE("a1b2c3","\d","-")` | a-b-c- | 全部取代 |
| `=REGEXREPLACE("a1b2c3","\d","-",2)` | a1b-c3 | 僅取代第 2 個 |
| `=REGEXREPLACE("john smith","(\w+) (\w+)","$2 $1")` | smith john | 反向參照取代 |

## 備註

- 取代文字支援 $1、$2 反向參照。
- 次序 0（預設）取代全部，N>0 僅取代第 N 個相符項。
- 正規表示式語法為 std::wregex 的 ECMAScript。
- text·pattern·replacement指定為陣列時會逐元素計算，以相同形狀的陣列溢出傳回 — 純量會重複使用，欄向量×列向量按外積擴充，大小不符的元素為 #N/A，錯誤元素會原樣傳回該錯誤。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `REGEXREPLACE` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.REGEXREPLACE`。
