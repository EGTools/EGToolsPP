# TEXTBETWEEN

**類別**: EGTools 專用函數

擷取 起始鍵 與 結束鍵 之間的文字。

## 語法

```
=TEXTBETWEEN(文字, 起始鍵, 結束鍵, [分隔符或序號], [包含鍵])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字 | 必要 | 來源文字 |
| 起始鍵 | 必要 | 起始標記 |
| 結束鍵 | 必要 | 結束標記 |
| 分隔符或序號 | 選用 | 全部連接符(預設 ",")，或數字 N 僅取第 N 個 |
| 包含鍵 | 選用 | TRUE 時包含標記 |

## 傳回

傳回擷取出的單一文字（純量）。文字、起始鍵、結束鍵任一為空時傳回 #VALUE!；指定的第 N 個超出區段數量時傳回 #VALUE!；沒有相符區段時傳回空字串。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=TEXTBETWEEN("[a] and [b]","[","]")` | a,b | 以 , 連接所有區段 |
| `=TEXTBETWEEN("[a] and [b]","[","]",2)` | b | 僅第 2 個區段 |
| `=TEXTBETWEEN("<x><y>","<",">","/",TRUE)` | <x>/<y> | 包含鍵連接 |

## 備註

- 鍵的搜尋會忽略大小寫。
- 第 4 個引數為數字時，僅取第 N 個區段；為文字時，則作為連接所有區段的分隔符（預設 ","）。
- 文字指定為陣列時會逐元素處理，以相同形狀的陣列溢出傳回（錯誤元素原樣傳回）；起始鍵·結束鍵等其他引數指定為陣列時傳回 #VALUE!。
- 相關函數：TEXTREPLACE
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `TEXTBETWEEN` 原名註冊。
