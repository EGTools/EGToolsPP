# TRIMENDS

**類別**: EGTools 專用函數

僅刪除首尾空白(保留中間空白)。

## 語法

```
=TRIMENDS(文字, [選項])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字 | 必要 | 文字或範圍 |
| 選項 | 選用 | 額外刪除: +1 控制字元，+2 nbsp，+4 不可見 Unicode(預設 0) |

## 傳回

傳回首尾清理後的文字（純量）；若文字指定為陣列/範圍，會逐元素處理並溢出。選項超出 0~7 範圍時傳回 #VALUE!，空白儲存格會變為空字串。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=TRIMENDS("  a  b  ")` | a  b | 僅刪除首尾空白 |
| `=TRIMENDS("a",8)` | #VALUE! | 選項超出範圍 |

## 備註

- 即使選項為 0，空白、Tab、CR、LF 也一定會從首尾刪除。
- 與 TRIM 不同，字串中間的空白會保持不變。
- 選項可加總：+1 控制字元、+2 NBSP、+4 不可見的 Unicode 空白（ZWSP、全形空白等）。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `TRIMENDS` 原名註冊。
