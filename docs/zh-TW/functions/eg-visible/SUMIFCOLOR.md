# SUMIFCOLOR

**類別**: EGTools 專用函數

對顏色與基準儲存格一致的儲存格求和。

## 語法

```
=SUMIFCOLOR(檢查範圍, 基準儲存格, [字型色], [條件式格式])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 檢查範圍 | 必要 | 要求和的範圍 |
| 基準儲存格 | 必要 | 保存基準色的儲存格(多個時取第一個) |
| 字型色 | 選用 | TRUE 時比較字型色，預設 FALSE |
| 條件式格式 | 選用 | TRUE 時使用含條件式格式的顯示顏色(僅在函數所在工作表為作用中時準確)，預設 FALSE=儲存格本身格式顏色 |

## 傳回

傳回與基準儲存格顏色相同（預設為儲存格格式顏色，條件式格式=TRUE 時為顯示顏色）之儲存格的數字總和。COM 連線失敗、讀取基準色失敗，或檢查儲存格數超過 100,000 個時傳回 #VALUE!；符合的儲存格含有錯誤值時，會原樣傳回該錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=SUMIFCOLOR(A1:A10,C1)` |  | 與 C1 填滿色相同的儲存格總和（結果依儲存格格式而異） |
| `=SUMIFCOLOR(A1:A10,C1,,TRUE)` |  | 依條件式格式顏色計算的總和（結果依儲存格格式而異） |

## 備註

- 預設（省略條件式格式或為 FALSE）僅使用儲存格格式中直接設定的顏色（Interior.Color / Font.Color），會忽略由條件式格式設定填滿的顏色。無論哪個工作表為作用中，編輯其他工作表或執行 F9、完整重新計算，結果都保持穩定，因此除非確實需要條件式格式設定的顏色，建議使用預設值。
- 條件式格式=TRUE 時，使用已套用條件式格式設定的實際顯示顏色（DisplayFormat）。只有在函數所在工作表為作用中狀態時重新計算，才能正確反映條件式格式設定的顏色。
- 注意：條件式格式=TRUE 時，若在其他工作表（或其他活頁簿）為作用中狀態時重新計算（編輯該工作表、F9、完整重新計算皆然），將無法正確讀取條件式格式設定的顏色，得到錯誤的值。這些函數屬易變函數，僅編輯其他工作表就會重新計算，因此實務上經常發生。
- 注意：如此產生的錯誤值在回到函數所在工作表後仍會保留，需在函數所在工作表為作用中狀態時按 F9 才能修正。
- 注意：如需依條件式格式設定的顏色彙總，建議盡可能直接以條件式格式設定的條件本身彙總（例如 `=SUMIF(A1:A10,">5")`）。
- 這是接收儲存格參照的巨集型函數，Excel 會將其視為易變（volatile）函數，活頁簿中任何位置的值變更都會重新計算；但僅變更儲存格顏色或條件式格式規則不會觸發重新計算，需按 F9。也不參與多執行緒重新計算。
- 只使用到第 3 個引數（字型色）的現有公式維持相容；但依賴條件式格式顏色的現有公式，需在第 4 個引數指定 TRUE，才能得到與先前相同的結果。
- 合併儲存格按 1 個處理(只檢查合併範圍的第一個儲存格，值也只在該儲存格)。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `SUMIFCOLOR` 原名註冊。
