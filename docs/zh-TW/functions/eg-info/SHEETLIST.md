# SHEETLIST

**類別**: EGTools 專用函數

傳回呼叫活頁簿中可見工作表名清單。

## 語法

```
=SHEETLIST([開始], [結束], [僅中間], [排除目前表])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 開始 | 選用 | 起始表編號/名稱(預設: 第一個) |
| 結束 | 選用 | 結束表編號/名稱(預設: 最後) |
| 僅中間 | 選用 | TRUE 排除起訖表 |
| 排除目前表 | 選用 | TRUE 排除目前工作表(預設) |

## 傳回

以單欄陣列(溢出)傳回可見工作表名稱。若無法確認呼叫位置或活頁簿、COM 連線失敗，或開始/結束指定有誤，傳回 #VALUE!；若篩選後沒有剩餘工作表，傳回 #N/A。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=SHEETLIST()` |  | 結果依活頁簿的組成而異 |

## 備註

- 此為巨集型函數，透過 COM 讀取工作表資訊(非執行緒安全)。
- 隱藏工作表一律排除；預設也會排除呼叫所在的工作表(排除目前表 預設 TRUE)。
- 開始/結束可用工作表編號或名稱指定。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `SHEETLIST` 原名註冊。
