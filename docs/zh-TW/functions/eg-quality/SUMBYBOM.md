# SUMBYBOM

**類別**: EGTools 專用函數

展開一階 BOM 並按品項彙總所需數量。

## 語法

```
=SUMBYBOM(陣列1, ...)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列1 | 必要 | 欄順序: 父項、子項、用量、品名、數量欄 — 可拆成多個參數 |
| … | 選用 | 上述引數可重複指定 |

## 傳回

傳回由品名 1 欄 + 與數量欄數相同的合計欄組成的陣列（溢出），並依品名遞增排序。欄少於 5 個、各欄長度不同、用量·數量不是數字時傳回 #VALUE!；數量為負時傳回 #NUM!；沒有可彙總的項目時傳回 #N/A。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=SUMBYBOM({"X","P",2,"X",1;"X","Q",3,"P",5})` | {"P",7;"Q",3} | 將 X 展開一階後加總 |

## 備註

- BOM 僅展開一階（非多階展開）。
- 品名不區分大小寫進行加總，結果依名稱遞增排序。
- 非父項的品項，數量為 0 時會從結果中排除。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `SUMBYBOM` 原名註冊。
