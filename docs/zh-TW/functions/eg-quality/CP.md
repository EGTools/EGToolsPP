# CP

**類別**: EGTools 專用函數

由測量值與規格界限計算製程能力指數 Cp。

## 語法

```
=CP(資料, [上限], [下限])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 資料 | 必要 | 測量值範圍或陣列 |
| 上限 | 選用 | USL(僅有下限時可省略) |
| 下限 | 選用 | LSL(僅有上限時可省略) |

## 傳回

以純量數字傳回製程能力指數 Cp = (USL-LSL)/(6σ)。沒有 data 或 USL·LSL 皆未提供時傳回 #VALUE!，數字資料少於 2 個時傳回 #NUM!，標準差為 0 時傳回 #DIV/0! 錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=CP({1;2;3;4;5},6,0)` | 0.632455532 | 規格 0~6 的 Cp |

## 備註

- 使用樣本標準差(n-1)。
- 只提供單邊規格時，會將缺少的一邊視為平均值來計算。
- USL·LSL（規格上下限）指定為陣列時會逐元素計算，以相同形狀的陣列溢出傳回 — 純量會重複使用，欄向量×列向量按外積擴充，大小不符的元素為 #N/A，錯誤元素會原樣傳回該錯誤。
- 相關函數: CPK
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `CP` 原名註冊。
