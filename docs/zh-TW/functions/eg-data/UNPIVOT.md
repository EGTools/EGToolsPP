# UNPIVOT

**類別**: EGTools 專用函數

將交叉表(樞紐表)轉換為正規化資料表。

## 語法

```
=UNPIVOT(陣列, [固定欄], [固定列], [排序], [欄名], [有子集])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列 | 必要 | 來源表(含標題) |
| 固定欄 | 選用 | 左側列標題欄數(預設 1) |
| 固定列 | 選用 | 頂部欄標題列數(預設 1) |
| 排序 | 選用 | 結果排序: 欄號，負數為遞減，如 {1,-3} |
| 欄名 | 選用 | 結果表的標題 |
| 有子集 | 選用 | 值欄按集合重複時為 TRUE |

## 傳回

以二維陣列（溢出）傳回包含標題列的正規化資料表。輸入不是陣列，固定欄·固定列為負數、超出範圍或兩者皆為 0，或排序為 0、超出結果欄範圍時傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=UNPIVOT({"Item","Jan","Feb";"A",10,20;"B",30,40},1,1,,{"Item","Month","Qty"})` | {"Item","Month","Qty";"A","Jan",10;"A","Feb",20;"B","Jan",30;"B","Feb",40} | 取消交叉表樞紐 |
| `=UNPIVOT({"Item","Jan","Feb";"A",10,20;"B",30,40},1,1,-3,{"Item","Month","Qty"})` | {"Item","Month","Qty";"B","Feb",40;"B","Jan",30;"A","Feb",20;"A","Jan",10} | 依第 3 欄遞減排序 |

## 備註

- 僅以值為準運作，不支援合併儲存格的填補。
- 值全部為空的項目（儲存格）會從結果中排除。
- 省略欄名時，預設標題會依 UI 語言（韓文/英文）而不同。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `UNPIVOT` 原名註冊。
