# TEXTNUMSORT

**類別**: EGTools 專用函數

依自然順序排序列(文字與內嵌數字分別比較)。

## 語法

```
=TEXTNUMSORT(陣列, [欄號], [排序方式], [忽略文字])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列 | 必要 | 要排序的資料 |
| 欄號 | 選用 | 關鍵欄，從 1 起(預設 1) |
| 排序方式 | 選用 | 1 遞增(預設)，-1 遞減 |
| 忽略文字 | 選用 | TRUE 時僅比較數字部分 |

## 傳回

傳回與輸入相同大小的排序後陣列，在動態陣列中會溢出。非陣列的單一值會原樣傳回。若缺少陣列引數、關鍵欄超出範圍，或排序方式不是 1/-1，則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=TEXTNUMSORT({"a10";"a2";"a1"})` | {a1;a2;a10} | 自然排序遞增 |
| `=TEXTNUMSORT({"a1";"a10";"a2"},1,-1)` | {a10;a2;a1} | 遞減 |

## 備註

- 會將文字區段與數字區段分開，數字以數值比較（a2 < a10）。
- 數字中的逗號視為千分位符號予以忽略，'.' 則視為小數點處理。
- 採用穩定排序（stable sort），相同鍵的列順序會維持不變。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `TEXTNUMSORT` 原名註冊。
