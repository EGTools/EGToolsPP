# ADVANCEDFILTER

**類別**: EGTools 專用函數

以進階篩選式條件網格(列=或，欄=且)篩選表格。

## 語法

```
=ADVANCEDFILTER(資料, 篩選, [去重])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 資料 | 必要 | 含標題列的資料 |
| 篩選 | 必要 | 含標題列的條件網格 — 支援 =, <>, >, <, >=, <=, *, ? |
| 去重 | 選用 | TRUE 刪除重複列 |

## 傳回

以二維陣列（溢出）傳回包含標題列的篩選結果。資料·篩選不是陣列或不足 2 列，或篩選標題不存在於資料標題中時傳回 #VALUE!；沒有任何相符的資料列時傳回 #N/A。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=ADVANCEDFILTER({"Name","Qty";"A",10;"B",5;"A",7},{"Qty";">6"})` | {"Name","Qty";"A",10;"A",7} | 只擷取 Qty>6 的列 |
| `=ADVANCEDFILTER({"Name","Qty";"Apple",10;"Banana",5;"Avocado",7},{"Name";"A*"})` | {"Name","Qty";"Apple",10;"Avocado",7} | 萬用字元 A* 篩選 |

## 備註

- 沒有運算子的文字條件與 Excel 進階篩選相同，以「開頭字串」比對方式運作。
- 萬用字元 *、? 可用於 = 及 <> 條件。
- 結果一律包含資料的標題列。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `ADVANCEDFILTER` 原名註冊。
