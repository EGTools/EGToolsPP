# EXPLODE

**類別**: EGTools 專用函數

依分隔符拆分指定欄並展開為列或欄；其他欄原樣複製。

## 語法

```
=EXPLODE(陣列, 欄號, [分隔符], [按欄], [填充值], [忽略空值])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列 | 必要 | 來源表 |
| 欄號 | 必要 | 要拆分的欄，從 1 起 |
| 分隔符 | 選用 | 分隔符(可多個)，預設空格 |
| 按欄 | 選用 | TRUE 橫向展開(預設 FALSE: 縱向) |
| 填充值 | 選用 | 按欄展開時空格的填充值(預設 "") |
| 忽略空值 | 選用 | TRUE 捨棄空片段 |

## 傳回

以二維陣列（溢出）傳回分解結果。陣列引數不是陣列時傳回 #VALUE!；欄號超出 1~欄數的範圍時傳回 #NUM!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=EXPLODE({"A","x,y";"B","z"},2,",")` | {"A","x";"A","y";"B","z"} | 將第 2 欄展開為列 |
| `=EXPLODE({"A","x,y";"B","z"},2,",",TRUE)` | {"A","x","y";"B","z",""} | 展開為欄，填補空格 |

## 備註

- 可指定多個分隔符，並從較長的分隔符優先套用（預設: 空格）。
- 水平展開時不足的儲存格以填補值（預設 ""）填入。
- 忽略空值為 TRUE 時會移除空片段（全部為空時保留 1 個空字串）。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `EXPLODE` 原名註冊。
