# QRCODE

**類別**: EGTools 專用函數

將文字產生 QR 碼圖片並插入呼叫儲存格。

## 語法

```
=QRCODE(文字, [邊界], [GS1])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字 | 必要 | 要編碼的字串 |
| 邊界 | 選用 | 以模組為單位的空白(預設 0) |
| GS1 | 選用 | TRUE 時依 (AI)值 形式的 GS1 處理 |

## 傳回

成功時傳回空字串("")，並另行插入符合呼叫儲存格大小的 QR 碼圖片。若文字為空，或 GS1 轉換或編碼失敗，傳回 #VALUE!；若無法得知呼叫儲存格，傳回 #REF!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=QRCODE("https://example.com")` |  | 插入 QR 碼圖片(插入影像，視環境而定) |

## 備註

- gs1=TRUE 以 GS(0x1D) 分隔符近似處理，並非完整的 FNC1 編碼。需要完整 GS1 時請使用 CODE128(GS1-128)。
- 圖片會在呼叫儲存格內維持正方形比例。
- 文字指定為陣列時傳回 #VALUE!（每個儲存格一張圖片）— 多筆資料請將公式逐列複製使用。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `QRCODE` 原名註冊。
