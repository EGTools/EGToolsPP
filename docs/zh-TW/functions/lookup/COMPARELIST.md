# COMPARELIST

**類別**: EGTools 專用函數

比較多個清單並傳回指定集合: 0 聯集，N 僅清單N，-1 僅一個，-2 全部，-3 部分。

## 語法

```
=COMPARELIST(集合類型, 按列, 陣列1, ...)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 集合類型 | 必要 | 0 聯集，N=僅在清單 N，-1 恰在一個，-2 在全部，-3 在部分 |
| 按列 | 必要 | TRUE 按整列比較 |
| 陣列1 | 必要 | 清單範圍或陣列 |
| … | 選用 | 上述引數可重複指定 |

## 傳回

以陣列（溢出）傳回屬於所選集合的項目（按列為 TRUE 時為多欄，否則為 1 欄）。沒有清單，或集合類型超出 -3~清單數的範圍時傳回 #VALUE!；結果為空時傳回 #N/A。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=COMPARELIST(0,FALSE,{"a";"b"},{"b";"c"})` | {"a";"b";"c"} | 聯集(去除重複) |
| `=COMPARELIST(-2,FALSE,{"a";"b"},{"b";"c"})` | b | 存在於所有清單的項目 |
| `=COMPARELIST(1,FALSE,{"a";"b"},{"b";"c"})` | a | 僅清單 1 才有的項目 |

## 備註

- 比較不區分大小寫，數字以值比較。
- 結果維持項目首次出現的順序。
- 按列為 TRUE 時，以整列作為單一鍵進行比較（忽略尾端的空白儲存格）。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `COMPARELIST` 原名註冊。
