# ILOOKUP

**類別**: EGTools 專用函數

尋找相符項目並將錨定於該儲存格的圖片複製到呼叫儲存格。

## 語法

```
=ILOOKUP(尋找值, 搜尋範圍, 圖片範圍, [找不到時], [符合模式], [搜尋模式])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 尋找值 | 必要 | 要搜尋的值 |
| 搜尋範圍 | 必要 | 要搜尋的陣列或範圍 |
| 圖片範圍 | 必要 | 錨定圖片的儲存格範圍 |
| 找不到時 | 選用 | 無相符時的傳回值(預設 #N/A) |
| 符合模式 | 選用 | 0 精確(預設), -1 次小, 1 次大, 2 萬用字元, 3 正則 |
| 搜尋模式 | 選用 | 1 從頭(預設), -1 從尾 |

## 傳回

尋找相符項目，成功時傳回空字串（""），並將錨定於相符儲存格的圖片依呼叫儲存格大小另行插入。搜尋範圍與圖片範圍大小不同時傳回 #REF!；沒有相符項目或圖片時傳回「找不到時」值（預設 #N/A）；正規表示式錯誤或 COM、剪貼簿失敗時傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=ILOOKUP("apple",A1:A5,B1:B5)` |  | 複製錨定於相符列的圖片（插入圖片，依環境而定） |

## 備註

- 從圖片範圍中，將以相符儲存格為 TopLeftCell 錨定的圖片（msoPicture/msoLinkedPicture）經由剪貼簿複製。
- 符合模式：0 精確(預設)、-1 較小值、1 較大值、2 萬用字元、3 正規表示式；搜尋模式：1 從頭開始(預設)、-1 從尾端開始。
- 僅變更圖片配置或格式不會觸發重新計算，需按 F9；且屬巨集型函數，不參與多執行緒重新計算。
- 查閱值指定為陣列時傳回 #VALUE!（每個儲存格一張圖片）— 多筆資料請將公式逐列複製使用。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `ILOOKUP` 原名註冊。
