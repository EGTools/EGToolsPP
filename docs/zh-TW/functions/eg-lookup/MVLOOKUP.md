# MVLOOKUP

**類別**: EGTools 專用函數

批次執行 VLOOKUP，可傳回多欄。

## 語法

```
=MVLOOKUP(查閱值, 查閱陣列, 傳回欄, [比對方式], [未找到值])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 查閱值 | 必要 | 鍵欄(或單一值) |
| 查閱陣列 | 必要 | 資料表 — 首欄為鍵 |
| 傳回欄 | 必要 | 要傳回的欄號，如 2 或 {2,3} |
| 比對方式 | 選用 | FALSE 精確(預設)，TRUE 近似 |
| 未找到值 | 選用 | 無符合時的值(預設 "") |

## 傳回

以「查閱值元素數（橫列優先）× 傳回欄數」大小的陣列（溢出）傳回；沒有相符的列會填入未找到值（預設 ""）。缺少必要引數、查閱陣列不是陣列、傳回欄號錯誤時傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=MVLOOKUP({"a";"c"},{"a",1;"b",2},2)` | {1;""} | 多個鍵的精確比對 |
| `=MVLOOKUP("b",{"a",1,"x";"b",2,"y"},{2,3})` | {2,"y"} | 同時傳回多欄 |
| `=MVLOOKUP(15,{10,"low";20,"high"},2,TRUE)` | low | 近似比對(小於或等於的最大值) |

## 備註

- 精確比對以雜湊為基礎，鍵重複時傳回第一列。
- 近似比對會在內部排序後進行二分搜尋，因此不需事先排序資料。
- 鍵的比較不區分大小寫。
- 查閱值除縱向清單外也可為橫向（1×N）或二維陣列，依橫列優先順序讀取並以縱向傳回結果。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `MVLOOKUP` 原名註冊。
