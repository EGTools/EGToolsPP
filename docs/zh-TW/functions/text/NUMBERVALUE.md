# NUMBERVALUE

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

以與地區設定無關的方式將文字轉換為數字。

## 語法

```
=NUMBERVALUE(文字, [小數分隔符號], [群組分隔符號])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字 | 必要 | 要轉換的文字 |
| 小數分隔符號 | 選用 | 小數點符號（預設 .） |
| 群組分隔符號 | 選用 | 千分位符號（預設 ,） |

## 傳回

傳回數字（純量）；若對文字指定陣列，會逐元素計算並在動態陣列環境中溢出。若移除分隔符號後仍無法解析為數字則傳回 #VALUE!；空文字（僅含空白）傳回 0。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=NUMBERVALUE("2.500,27",",",".")` | 2500.27 | 轉換歐式格式 |
| `=NUMBERVALUE("9%%")` | 0.0009 | 每個 % 各除以 100 |
| `=NUMBERVALUE("abc")` | #VALUE! | 非數字 |

## 備註

- 所有空白字元無論位置皆會被忽略，千分位分隔符號無論位於何處都會被移除。
- 結尾的 % 符號會依個數各除以 100。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `NUMBERVALUE` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.NUMBERVALUE`。
