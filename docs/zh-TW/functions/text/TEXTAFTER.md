# TEXTAFTER

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2024

傳回分隔符之後的文字。

## 語法

```
=TEXTAFTER(文字, 分隔符, [序號], [比對模式], [比對結尾], [未找到值])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字 | 必要 | 來源文字 |
| 分隔符 | 必要 | 要尋找的分隔符 |
| 序號 | 選用 | 第幾個，負數從末尾(預設 1) |
| 比對模式 | 選用 | 1 忽略大小寫(預設 0) |
| 比對結尾 | 選用 | 1 將文字結尾視為分隔符(預設 0) |
| 未找到值 | 選用 | 找不到時的值(預設 #N/A) |

## 傳回

傳回分隔符號之後的單一文字（純量）。若序數為 0 則傳回 #VALUE!；若找不到分隔符號則傳回未找到值（預設 #N/A）。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=TEXTAFTER("red-blue-green","-")` | blue-green | 第一個分隔符號之後 |
| `=TEXTAFTER("a,b,c",",",-1)` | c | 倒數第一個之後 |
| `=TEXTAFTER("abc","x",1,0,0,"none")` | none | 傳回未找到值 |

## 備註

- 比對結尾（match_end）=1 時，會將文字結尾（正序數）／開頭（負序數）視為 1 個虛擬分隔符號。
- 比對模式（match_mode）=1 時會忽略大小寫。
- text 指定為陣列時會逐元素計算，以相同形狀的陣列溢出傳回（錯誤元素原樣傳回）；分隔符號指定為陣列時傳回 #VALUE!。
- 相關函數：TEXTBEFORE、TEXTSPLIT
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `TEXTAFTER` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.TEXTAFTER`。
