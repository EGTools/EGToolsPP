# TOSOLAR

**類別**: EGTools 專用函數

將韓國農曆轉換為公曆(919~2050年)。

## 語法

```
=TOSOLAR(農曆日期)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 農曆日期 | 必要 | 如 "2025-06-05" — 閏月加 윤/LM — 或範圍 |

## 傳回

傳回公曆日期序列值(純量數字)，輸入範圍時會以相同大小的陣列溢出。無法解析文字、超出農曆表範圍(918~2050 年)或為不存在的農曆日期時，傳回 #VALUE! 錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=TOSOLAR("2025-01-01")` | 45686 | 農曆新年 → 2025-01-29 |
| `=TOSOLAR("2025-08-15")` | 45936 | 農曆秋夕 → 2025-10-06 |

## 備註

- 閏月以加上 "윤" 或 "LM" 表示(例: "2025-윤06-01")。
- 請在結果儲存格套用日期顯示格式後使用。
- 相關函數: TOLUNAR
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `TOSOLAR` 原名註冊。
