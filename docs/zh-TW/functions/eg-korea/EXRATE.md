# EXRATE

**類別**: EGTools 專用函數

查詢指定日期的韓元基準匯率(最多回溯 10 天)。

## 語法

```
=EXRATE([貨幣], [日期])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 貨幣 | 選用 | 3 位代碼，如 USD(預設)、EUR、JPY… |
| 日期 | 選用 | 查詢日期(預設: 今天) |

## 傳回

以數字純量傳回韓元基準匯率。指定未來日期時傳回 #VALUE!；若貨幣代碼不受支援，或 10 天回溯範圍內沒有公告匯率，則傳回 #N/A。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=EXRATE("USD")` |  | 結果依查詢日與網路而異 |

## 備註

- 透過 HTTP 查詢 smbs.biz(首爾外匯經紀)的基準匯率 — 需要網路連線。
- 若指定日沒有公告，最多回溯查詢至 10 天前(因應假日)。
- CNY 會自動轉換為 CNH。以非巨集、執行緒安全方式註冊，可平行重新計算。
- 貨幣·日期指定為陣列時傳回 #VALUE! — 多筆資料請將公式逐列複製使用。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `EXRATE` 原名註冊。
