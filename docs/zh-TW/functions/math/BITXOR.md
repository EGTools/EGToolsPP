# BITXOR

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

傳回兩個數字的位元 XOR。

## 語法

```
=BITXOR(number1, number2)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| number1 | 必要 | 第一個數字（≥0） |
| number2 | 必要 | 第二個數字（≥0） |

## 傳回

傳回兩數位元 XOR 結果的數字(純量)。若引數不是數字或邏輯值、為負數或小數、或超過 2^48-1(281,474,976,710,655)，則傳回 #NUM!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=BITXOR(5,3)` | 6 | 101 XOR 011 = 110 |
| `=BITXOR(5,"a")` | #NUM! | 非數字則錯誤 |

## 備註

- 對非數字的引數也是傳回 #NUM! 而非 #VALUE!。
- 所有引數指定為陣列時會逐元素計算，以相同形狀的陣列溢出傳回 — 純量會重複使用，欄向量×列向量按外積擴充，大小不符的元素為 #N/A，錯誤元素會原樣傳回該錯誤。
- 相關函數: BITAND, BITOR
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `BITXOR` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.BITXOR`。
