# BITRSHIFT

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

傳回數字右移指定位元數後的結果。

## 語法

```
=BITRSHIFT(number, shift_amount)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| number | 必要 | 要移位的數字（≥0） |
| shift_amount | 必要 | 右移位元數（負數為左移） |

## 傳回

傳回右移結果的數字(純量)(無條件捨去)。若 number 不是 [0, 2^48-1] 範圍內的整數、shift_amount 不是整數或其絕對值超過 53、或結果超過 2^53，則傳回 #NUM!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=BITRSHIFT(13,2)` | 3 | 右移 2 位元 |
| `=BITRSHIFT(3,-2)` | 12 | 負數則為左移 |

## 備註

- shift_amount 為負數時會以左移方式運算。
- 所有引數指定為陣列時會逐元素計算，以相同形狀的陣列溢出傳回 — 純量會重複使用，欄向量×列向量按外積擴充，大小不符的元素為 #N/A，錯誤元素會原樣傳回該錯誤。
- 相關函數: BITLSHIFT
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `BITRSHIFT` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.BITRSHIFT`。
