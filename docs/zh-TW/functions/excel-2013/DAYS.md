# DAYS

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

傳回兩個日期之間的天數（結束−開始）。

## 語法

```
=DAYS(結束日期, 開始日期)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 結束日期 | 必要 | 結束日期 |
| 開始日期 | 必要 | 開始日期 |

## 傳回

傳回結束日期減去開始日期的天數(純量數字)。計算時會捨去各日期的時間部分。省略引數時傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=DAYS(DATE(2026,3,1),DATE(2026,1,15))` | 45 | 兩日期之間的天數 |
| `=DAYS(DATE(2026,1,1),DATE(2026,1,31))` | -30 | 結束較早則為負數 |

## 備註

- 不會解析日期格式文字(如 "2026-01-15")，此類文字會傳回 #VALUE!；空儲存格視為 0。
- 兩個日期引數均指定為陣列時會逐元素計算，以相同形狀的陣列溢出傳回 — 純量會重複使用，欄向量×列向量按外積擴充，大小不符的元素為 #N/A，錯誤元素會原樣傳回該錯誤。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `DAYS` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.DAYS`。
