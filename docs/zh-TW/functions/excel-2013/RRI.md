# RRI

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

傳回投資成長的等效利率。

## 語法

```
=RRI(nper, pv, fv)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| nper | 必要 | 期數 |
| pv | 必要 | 現值 |
| fv | 必要 | 終值 |

## 傳回

傳回相當於投資成長的每期等值利率(純量數字)。引數不是數字、nper 小於等於 0 或 pv 為 0 時傳回 #NUM! 錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=RRI(96,10000,11000)` | 0.000993307 | 96 期 10000→11000 的利率 |

## 備註

- 所有引數指定為陣列時會逐元素計算，以相同形狀的陣列溢出傳回 — 純量會重複使用，欄向量×列向量按外積擴充，大小不符的元素為 #N/A，錯誤元素會原樣傳回該錯誤。
- 相關函數: PDURATION
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `RRI` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.RRI`。
