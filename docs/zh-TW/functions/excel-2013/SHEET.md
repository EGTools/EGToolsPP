# SHEET

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

傳回參照的工作表編號（或目前工作表）。

## 語法

```
=SHEET([值])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 值 | 選用 | 參照（選用；預設：目前工作表） |

## 傳回

以數字傳回參照（省略時為輸入公式的儲存格）所屬工作表的位置（從 1 開始）。若找不到工作表則傳回 #N/A；若查詢工作表清單失敗則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=SHEET()` |  | 目前工作表位置（視活頁簿而定） |

## 備註

- 引數僅接受儲存格參照（原生函數也允許工作表名稱文字）。
- 註冊為巨集表類型函數。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `SHEET` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.SHEET`。
