# UNICHAR

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

傳回指定數字（字碼指標）對應的 Unicode 字元。

## 語法

```
=UNICHAR(數字)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 數字 | 必要 | Unicode 字碼指標 |

## 傳回

傳回字碼指標對應的字元文字（純量）；若數字指定為陣列，會逐元素計算並溢出。若字碼超出 1~1114111 範圍或位於代理字組區域（55296~57343），則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=UNICHAR(44032)` | 가 | 韓文音節 |
| `=UNICHAR(128512)` | 😀 | BMP 之外的字元 |
| `=UNICHAR(0)` | #VALUE! | 超出範圍 |

## 備註

- 0x10000 以上的字元會以代理字組（UTF-16）形式傳回。
- 相關函數：UNICODE
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `UNICHAR` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.UNICHAR`。
