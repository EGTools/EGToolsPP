# ISFORMULA

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

如果參照的儲存格包含公式，則傳回 TRUE。

## 語法

```
=ISFORMULA(參照)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 參照 | 必要 | 要檢驗的儲存格 |

## 傳回

若參照的儲存格含有公式則傳回 TRUE，否則傳回 FALSE。若省略參照或查詢失敗則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=ISFORMULA(A1)` |  | 依 A1 內容而異 |

## 備註

- 註冊為巨集表類型函數。
- 相關函數：FORMULATEXT。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `ISFORMULA` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.ISFORMULA`。
