# DECIMAL

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

將給定進位制的文字數字轉換為十進位數。

## 語法

```
=DECIMAL(text, radix)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| text | 必要 | 要轉換的文字 |
| radix | 必要 | 基數 2-36 |

## 傳回

傳回進位法文字轉換後的十進位數字(純量)。若 radix 超出 2~36 範圍，或 text 含有該進位法不可使用的字元，則傳回 #NUM! 錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=DECIMAL("FF",16)` | 255 | 十六進位轉十進位 |
| `=DECIMAL("111",2)` | 7 | 二進位轉十進位 |

## 備註

- 不區分大小寫。
- 所有引數指定為陣列時會逐元素計算，以相同形狀的陣列溢出傳回 — 純量會重複使用，欄向量×列向量按外積擴充，大小不符的元素為 #N/A，錯誤元素會原樣傳回該錯誤。
- 相關函數: BASE
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `DECIMAL` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.DECIMAL`。
