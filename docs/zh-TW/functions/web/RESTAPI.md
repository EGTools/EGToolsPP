# RESTAPI

**類別**: EGTools 專用函數

呼叫 REST API 並傳回回應文字。

## 語法

```
=RESTAPI(網址, [方法], [要求標頭], [要求本文])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 網址 | 必要 | API URL(含 GET 參數) |
| 方法 | 選用 | "GET"(預設)、"POST"、"PUT"、"PATCH"、"DELETE" 等 |
| 要求標頭 | 選用 | 名稱/值兩欄範圍 |
| 要求本文 | 選用 | 要求本文文字 |

## 傳回

以單一文字純量傳回回應本文(以 UTF-8 解讀)。若網址缺少或為空，或 HTTP 要求失敗，則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=RESTAPI("https://api.example.com/users","GET")` |  | 結果依伺服器回應而異 |

## 備註

- 使用 WinHTTP，需要網路連線。接收回應的逾時為 30 秒。
- 無論 HTTP 狀態碼為何，都會原樣傳回回應本文。
- 以非巨集、執行緒安全方式註冊，可進行平行重新計算。
- 位址·方法·要求本文指定為陣列時傳回 #VALUE! — 多筆資料請將公式逐列複製使用。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `RESTAPI` 原名註冊。
