# JSONFILTER

**類別**: EGTools 專用函數

將 JSON 文字解析為(路徑, 值)兩欄表。

## 語法

```
=JSONFILTER(JSON文字, [鍵路徑])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| JSON文字 | 必要 | 要解析的 JSON 文字 |
| 鍵路徑 | 選用 | 篩選路徑，如 "data.items[0].name"(預設: 全部) |

## 傳回

以（路徑, 值）2 欄陣列（溢出）傳回 — 數字為數字、true/false 為布林值、null 為空字串。文字為空、JSON 剖析失敗或找不到鍵路徑時傳回 #VALUE!；結果為空物件·空陣列時傳回 #N/A。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=JSONFILTER("{""a"":1,""b"":[true,null]}")` | {"a",1;"b[0]",TRUE;"b[1]",""} | 整個 JSON 平坦化 |
| `=JSONFILTER("{""a"":{""b"":5,""c"":""x""}}","a")` | {"b",5;"c","x"} | 只輸出鍵路徑以下的部分 |

## 備註

- 不使用外部程式庫，採用自製的輕量剖析器。
- 整段文字必須是有效的 JSON，不支援註解·尾端逗號。
- 鍵路徑為 "a.b[0].c" 格式，陣列索引從 0 開始。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `JSONFILTER` 原名註冊。
