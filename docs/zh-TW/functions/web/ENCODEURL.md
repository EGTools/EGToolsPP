# ENCODEURL

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

傳回經過 URL 編碼（百分比編碼）的字串。

## 語法

```
=ENCODEURL(文字)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字 | 必要 | 要進行 URL 編碼的文字 |

## 傳回

以純量傳回經 URL 編碼的文字。輸入陣列時會逐元素套用並以溢出傳回相同大小的陣列；輸入會先轉換為文字，因此沒有另外的錯誤值。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=ENCODEURL("a b&c")` | a%20b%26c | 將空格·& 轉換為 %XX |
| `=ENCODEURL("한글")` | %ED%95%9C%EA%B8%80 | 韓文的 UTF-8 編碼 |

## 備註

- 僅保留 RFC 3986 非保留字元（英文字母·數字·- _ . ~），其餘以 UTF-8 位元組為單位進行 %XX 編碼。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `ENCODEURL` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.ENCODEURL`。
