# BARCODE

**類別**: EGTools 專用函數

將文字編碼為條碼並以圖片插入呼叫儲存格（2D 類型保持比例，儲存格較大時置中）。

## 語法

```
=BARCODE(文字, [類型], [選項])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字 | 必要 | 要編碼的字串 |
| 類型 | 選用 | QRCODE(預設), CODE128, DATAMATRIX, EAN13/8, ITF, PDF417, AZTEC, CODE39/93, UPC-A/E, CODABAR, GS1-128/DM/QR |
| 選項 | 選用 | 數字=邊界(2D)，TRUE=下方顯示文字(1D) |

## 傳回

成功時傳回空字串("")，並另行插入符合呼叫儲存格大小的條碼圖片。若文字為空、無法辨識類型，或無法以該格式編碼，傳回 #VALUE!；若無法得知呼叫儲存格，傳回 #REF!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=BARCODE("12345678","CODE128")` |  | 插入 Code128 圖片(插入影像，視環境而定) |
| `=BARCODE("https://example.com")` |  | 插入預設 QR 碼(插入影像，視環境而定) |

## 備註

- 支援類型：CODE128、CODE39/93、EAN13/8、UPC-A/E、ITF、CODABAR、PDF417、QRCODE(預設)、DATAMATRIX、AZTEC、GS1-128/GS1DATAMATRIX/GS1QRCODE(也接受數字代碼)。
- 產生使用 zint，讀取(READBARCODE)使用 zxing-cpp。GS1-128/GS1DATAMATRIX/GS1QRCODE 會依規範編碼 "(01)04012345678901(10)LOT42" 這類含括號的 AI 表示法(FNC1 置於首位、可變長度 AI 之後插入分隔符，符號體系識別碼 ]C1/]d2/]Q3)，方括號 [AI]值 表示法和掃描器讀取的原始串流 `]C10104012345678901<GS>10LOT42`(`<GS>`=分隔符 0x1D — 照字面寫成 `<GS>` 也能辨識，開頭的 ]C1 識別碼即使存在也會忽略)也會編碼為相同的符號。AI 格式、長度、檢查碼違規、未知 AI 或非 ASCII 字元傳回 #VALUE!。
- EAN13/EAN8/UPC-A/UPC-E 若未含檢查碼(12/7/11/6～7 位)會自動計算並附加，若含檢查碼則進行驗證(錯誤時傳回 #VALUE!)；ITF 位數為奇數時會在前面補 0。
- 選項引數為數字時解讀為邊界(2D 格式，以模組為單位)，為 TRUE 時解讀為在下方顯示文字(1D 格式)。
- 2D 格式會維持規範比例(模組正方形)配合呼叫儲存格並置中對齊，1D 格式會填滿儲存格。
- 文字指定為陣列時傳回 #VALUE!（每個儲存格一張圖片）— 多筆資料請將公式逐列複製使用。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `BARCODE` 原名註冊。
