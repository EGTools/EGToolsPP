# READBARCODE

**類別**: EGTools 專用函數

從圖片檔或 URL 解碼條碼。

## 語法

```
=READBARCODE(來源, [結果類型])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 來源 | 必要 | 本機檔案路徑或 http(s) URL |
| 結果類型 | 選用 | 1=文字(預設), 2=代碼文字, 3=格式, 4=符號體系ID, 5=Raw HEX — 可用 {1,3} 陣列 |

## 傳回

以與結果類型引數相同的形狀傳回從圖片讀取的條碼內容(如 {1,3} 為陣列時會溢出)。若來源為空或結果類型的值有誤，傳回 #VALUE!；URL 下載失敗傳回 #NULL!；檔案不存在、無法讀取圖片或找不到條碼時，傳回 #N/A。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=READBARCODE("C:\barcodes\qr.png")` |  | 圖片中的條碼文字(結果依檔案內容而異) |
| `=READBARCODE("https://example.com/code.png",{1,3})` |  | 同時傳回文字與格式(視網路而定) |

## 備註

- 可讀取 WIC 支援的 PNG/JPG/BMP/GIF 格式，本機檔案路徑與 http(s) URL 皆可使用。
- 結果類型：1 文字(預設)、2 代碼文字(控制字元以 <GS> 等顯示)、3 格式、4 符號體系 ID、5 Raw HEX。
- 也會嘗試旋轉或低品質圖片(TryHarder/TryRotate)，但只讀取一個條碼。
- 來源指定為陣列時傳回 #VALUE! — 多筆資料請將公式逐列複製使用。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `READBARCODE` 原名註冊。
