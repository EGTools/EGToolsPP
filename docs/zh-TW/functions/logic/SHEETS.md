# SHEETS

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

傳回活頁簿（或參照）中的工作表數。

## 語法

```
=SHEETS([參照])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 參照 | 選用 | 參照（選用） |

## 傳回

省略參照時傳回活頁簿的工作表數；指定參照時一律傳回 1（數字）。若查詢工作表數失敗則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=SHEETS()` |  | 活頁簿的工作表數（視活頁簿而定） |

## 備註

- 指定參照時一律傳回 1（不支援計算 3-D 參照的工作表數）。
- 註冊為巨集表類型函數。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `SHEETS` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.SHEETS`。
