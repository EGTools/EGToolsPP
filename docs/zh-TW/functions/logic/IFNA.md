# IFNA

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

如果值為 #N/A 錯誤，則傳回替代值；否則傳回該值。

## 語法

```
=IFNA(值, 替代值)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 值 | 必要 | 值或運算式 |
| 替代值 | 必要 | 為 #N/A 時傳回的值 |

## 傳回

若值為 #N/A 錯誤則傳回替代值，否則傳回原值。若給定陣列，會傳回逐元素套用後的陣列並溢出。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=IFNA(NA(),"none")` | none | 取代 #N/A |
| `=IFNA(1/0,0)` | #DIV/0! | 保留 #N/A 以外的錯誤 |
| `=IFNA(5,0)` | 5 | 保留正常值 |

## 備註

- 值與替代值都可指定陣列並相互廣播，逐元素僅取代 #N/A（純量重複使用，大小不符的元素為 #N/A；傳回陣列並溢出）。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `IFNA` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.IFNA`。
