# DIRFOLDER

**類別**: EGTools 專用函數

列出指定資料夾的檔案(可含資料夾)。

## 語法

```
=DIRFOLDER(路徑, [篩選], [含資料夾], [子資料夾], [含隱藏])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 路徑 | 必要 | 資料夾路徑 |
| 篩選 | 選用 | 如 "*.xlsx;*.csv"(預設 *.*) |
| 含資料夾 | 選用 | TRUE 包含資料夾名 |
| 子資料夾 | 選用 | TRUE 遞迴子資料夾 |
| 含隱藏 | 選用 | TRUE 包含隱藏項 |

## 傳回

以陣列（溢出）傳回項目名稱；包含子資料夾時會依深度分欄（階梯式）。路徑不存在或為空時傳回 #VALUE!；沒有相符的項目時傳回 #N/A。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=DIRFOLDER("C:\Data","*.xlsx;*.csv",FALSE,TRUE)` |  | 結果視資料夾內容而定 |

## 備註

- 為非巨集函數，直接使用 Win32 API 讀取資料夾。
- 篩選可用 ";" 指定多個，並支援 *·? 萬用字元。
- 隱藏項目預設排除，「含隱藏」為 TRUE 時可包含。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `DIRFOLDER` 原名註冊。
