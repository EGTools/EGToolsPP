# SWITCH

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2016/2019

將運算式與多個值比較，傳回第一個相符的結果（或預設值）。

## 語法

```
=SWITCH(運算式, 值1, 結果1, [預設值], ...)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 運算式 | 必要 | 要比較的值 |
| 值1 | 必要 | 用於比對的值 |
| 結果1 | 必要 | 值相符時的結果 |
| 預設值 | 選用 | 預設值 / 值2 … |
| … | 選用 | 上述引數可重複指定 |

## 傳回

原樣傳回與運算式第一個相符之值對應的結果（或最後的預設值）。若既無相符的值也無預設值則傳回 #N/A。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=SWITCH(2,1,"one",2,"two","other")` | two | 相符值的結果 |
| `=SWITCH(9,1,"one","other")` | other | 傳回預設值 |

## 備註

- 若中間的引數留空，其後的值／結果配對將被忽略。
- 運算式·比較值·結果可指定陣列並逐元素求值，以相同形狀的陣列溢出傳回；運算式或被求值的比較值為錯誤時會傳播該錯誤。
- 相關函數：IFS。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `SWITCH` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.SWITCH`。
