# EVAL

**類別**: EGTools 專用函數

計算文字形式的公式並傳回結果。

## 語法

```
=EVAL(公式)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 公式 | 必要 | 公式文字，如 "SUM(A1:A3)*2" |

## 傳回

直接傳回計算結果 — 純量時為單一值，陣列時以溢出方式輸出。若公式為空或計算失敗(包括無法連線 COM)，則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=EVAL("SUM(A1:A3)*2")` |  | 結果依工作表的值而異 |

## 備註

- 此為巨集型函數，使用 COM Application.Evaluate(非執行緒安全)。
- 公式開頭的 "=" 會自動補上。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `EVAL` 原名註冊。
