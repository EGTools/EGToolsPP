# BITLSHIFT

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

返回数字左移指定位数后的结果。

## 语法

```
=BITLSHIFT(number, shift_amount)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| number | 必需 | 要移位的数字（≥0） |
| shift_amount | 必需 | 左移位数（负数为右移） |

## 返回

以数字（标量）返回左移结果。number 不是 [0, 2^48-1] 范围内的整数、shift_amount 不是整数或绝对值超过 53、或结果超过 2^53 时返回 #NUM!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=BITLSHIFT(4,2)` | 16 | 左移 2 位 |
| `=BITLSHIFT(4,-1)` | 2 | 负数为右移 |

## 备注

- shift_amount 为负数时按右移处理。
- 所有参数指定为数组时按元素计算，以相同形状的数组溢出返回 — 标量重复使用，列向量×行向量按外积扩展，大小不匹配的元素为 #N/A，错误元素原样返回该错误。
- 相关函数：BITRSHIFT
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `BITLSHIFT` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.BITLSHIFT`。
