# IFS

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2016/2019

按顺序检查条件，返回第一个为 TRUE 的条件对应的值。

## 语法

```
=IFS(条件1, 值1, ...)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 条件1 | 必需 | 要检验的条件 |
| 值1 | 必需 | 条件为 TRUE 时的结果 |
| … | 可选 | 以上参数可重复指定 |

## 返回

原样返回第一个为 TRUE 的条件所对应的值（标量或数组）。没有为 TRUE 的条件时返回 #N/A；条件本身是错误值时原样返回该错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=IFS(1>2,"a",2>1,"b")` | b | 第一个 TRUE 条件的值 |
| `=IFS(1>2,"a")` | #N/A | 没有为 TRUE 的条件 |

## 备注

- 条件为文本或空值时按 FALSE 处理（原生函数返回 #VALUE!）。
- 相关函数：SWITCH。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `IFS` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.IFS`。
