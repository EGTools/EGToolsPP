# TRIMRANGE

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2024 / Microsoft 365

去除数组边缘的空白行/列。

## 语法

```
=TRIMRANGE(数组, [修剪行], [修剪列])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组 | 必需 | 目标数组或区域值 |
| 修剪行 | 可选 | 0 无, 1 前导, 2 尾部, 3 全部(默认) |
| 修剪列 | 可选 | 0 无, 1 前导, 2 尾部, 3 全部(默认) |

## 返回

返回去除边缘空行/空列后的数组，并会溢出。数组为空、修剪模式超出 0~3 范围或全部为空值时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=TRIMRANGE({"","";"a",1;"",""})` | {"a",1} | 去除空的边缘行·列 |
| `=TRIMRANGE({"";1;""},1)` | {1;""} | 仅去除前导空行 |

## 备注

- 原生 TRIMRANGE 修剪的是引用，本实现基于值，因此也可用于数组字面量和公式结果。
- 空字符串（""）也按空值处理。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `TRIMRANGE` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.TRIMRANGE`。
