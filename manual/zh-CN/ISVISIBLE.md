# ISVISIBLE

**类别**：EGTools 专用函数

检查区域中每个单元格是否可见(行/列未隐藏)。

## 语法

```
=ISVISIBLE(区域)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 区域 | 必需 | 要检查的单元格区域 |

## 返回

以与区域同尺寸的数组返回每个单元格可见时为 TRUE、行或列被隐藏时为 FALSE，并溢出。单元格数超过 100,000 或 COM 连接失败时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=ISVISIBLE(A1:A5)` |  | 各单元格是否可见（结果取决于隐藏状态） |

## 备注

- 仅更改行/列的隐藏状态不会触发重算，需按 F9 重新计算。
- 宏类函数，被排除在多线程重算之外。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `ISVISIBLE` 名称注册。
