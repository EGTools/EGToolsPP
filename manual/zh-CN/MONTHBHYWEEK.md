# MONTHBHYWEEK

**类别**：EGTools 专用函数

按周起始日与归属日返回日期所在周归属的月份。

## 语法

```
=MONTHBHYWEEK(日期, [周起始日], [归属日])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 日期 | 必需 | 基准日期 |
| 周起始日 | 可选 | 1=日~7=六(默认 2=一) |
| 归属日 | 可选 | 决定所属月的星期(默认 5=四) |

## 返回

返回日期所在周归属的月份（1~12，标量数字）。无法解析日期，或周起始日·归属日超出 1~7 范围时返回 #VALUE! 错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=MONTHBHYWEEK(DATE(2026,2,1))` | 1 | 周日 2/1 所在周属 1 月 |
| `=MONTHBHYWEEK(DATE(2026,2,2))` | 2 | 2/2 所在周属 2 月 |

## 备注

- 星期编号为 1=日 ~ 7=六，默认为周一开始·周四归属。
- 周的归属月按归属日所在的月份确定。
- 相关函数：WEEKNUMOFMONTH
- 支持：Excel 2010+。在所有 Excel 版本中均按 `MONTHBHYWEEK` 名称注册。
