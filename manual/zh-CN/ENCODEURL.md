# ENCODEURL

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

返回经过 URL 编码（百分号编码）的字符串。

## 语法

```
=ENCODEURL(文本)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 要进行 URL 编码的文本 |

## 返回

以标量返回 URL 编码后的文本。输入数组时按元素应用，以同尺寸数组溢出返回；输入会先转换为文本，因此没有额外的错误值。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=ENCODEURL("a b&c")` | a%20b%26c | 空格·& 转为 %XX |
| `=ENCODEURL("한글")` | %ED%95%9C%EA%B8%80 | 韩文 UTF-8 编码 |

## 备注

- 仅保留 RFC 3986 非保留字符（字母·数字·- _ . ~），其余按 UTF-8 字节逐一进行 %XX 编码。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `ENCODEURL` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.ENCODEURL`。
