# PDURATION

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

返回投资以给定利率达到目标值所需的期数。

## 语法

```
=PDURATION(rate, pv, fv)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| rate | 必需 | 每期利率 |
| pv | 必需 | 现值 |
| fv | 必需 | 终值 |

## 返回

返回达到目标金额所需的期数（标量数字）。rate·pv·fv 非数字或小于等于 0 时返回 #NUM! 错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=PDURATION(0.025,2000,2200)` | 3.859866163 | 按 2.5% 从 2000→2200 的期数 |

## 备注

- 相关函数：RRI
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `PDURATION` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.PDURATION`。
