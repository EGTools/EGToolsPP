# SAMPLINGSIZE

**类别**：EGTools 专用函数

按 ISO 2859-1 返回样本量(n)。

## 语法

```
=SAMPLINGSIZE(批量, AQL, [检验水平], [严格度], [方案], [次数])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 批量 | 必需 | 批/批次数量 |
| AQL | 必需 | 接收质量限，如 1.0 |
| 检验水平 | 可选 | G1/G2/G3/S1~S4(默认 G2) |
| 严格度 | 可选 | 0 正常(默认)，1 加严，-1 放宽 |
| 方案 | 可选 | 1 一次(默认)，2 二次，3~5 多次；+10 强制不转换 |
| 次数 | 可选 | 抽样次数 |

## 返回

返回 ISO 2859-1 样本量 n（标量数字）。AQL 超出 0~1000 或检验水平·方案·次数无效时返回 #VALUE!；批量小于 2 或 AQL 小于 0.01 时返回 #NUM!；在表中找不到对应值时返回 #N/A 错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=SAMPLINGSIZE(1000,1)` | 80 | G2·正常·一次，AQL 1.0 |
| `=SAMPLINGSIZE(1000,1,"G2",0,2,1)` | 50 | 二次抽样第 1 次样本量 |
| `=SAMPLINGSIZE(30,0.065)` | 30 | 受批量限制 |

## 备注

- 计算出的 n 大于批量时返回批量；批量为 1 时返回 1。
- 方案加 10 时忽略表中的转换规则（*、++），强制使用该方案。
- 相关函数：SAMPLINGLABEL、SAMPLINGAC、SAMPLINGRE
- 支持：Excel 2010+。在所有 Excel 版本中均按 `SAMPLINGSIZE` 名称注册。
