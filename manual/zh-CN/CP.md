# CP

**类别**：EGTools 专用函数

由测量值与规格限计算过程能力指数 Cp。

## 语法

```
=CP(数据, [上限], [下限])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数据 | 必需 | 测量值区域或数组 |
| 上限 | 可选 | USL(仅有下限时可省略) |
| 下限 | 可选 | LSL(仅有上限时可省略) |

## 返回

以标量数字返回过程能力指数 Cp = (USL-LSL)/(6σ)。没有 data 或 USL·LSL 均缺失时返回 #VALUE!，数字数据少于 2 个时返回 #NUM!，标准差为 0 时返回 #DIV/0! 错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=CP({1;2;3;4;5},6,0)` | 0.632455532 | 规格 0~6 的 Cp |

## 备注

- 使用样本标准差（n-1）。
- 只给出单侧规格限时，将缺失的一侧视为平均值进行计算。
- 相关函数：CPK
- 支持：Excel 2010+。在所有 Excel 版本中均按 `CP` 名称注册。
