# CHOOSEROWS

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2024

返回数组中指定的行。

## 语法

```
=CHOOSEROWS(数组, 行号1, ...)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组 | 必需 | 数组 |
| 行号1 | 必需 | 要返回的行(负=从末尾) |
| … | 可选 | 以上参数可重复指定 |

## 返回

返回由所选行组成的数组，在支持动态数组的 Excel 中溢出。数组为空、行号为 0 或超出范围、或未指定任何行号时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=CHOOSEROWS({1,2;3,4;5,6},1,-1)` | {1,2;5,6} | 首行与末行 |
| `=CHOOSEROWS({1,2;3,4},3)` | #VALUE! | 行号超出范围 |

## 备注

- 行号为负数时从末尾数起。
- 要选择列请使用 CHOOSECOLS。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `CHOOSEROWS` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.CHOOSEROWS`。
