# DAYS

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

返回两个日期之间的天数（结束−开始）。

## 语法

```
=DAYS(结束日期, 开始日期)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 结束日期 | 必需 | 结束日期 |
| 开始日期 | 必需 | 开始日期 |

## 返回

以数字（标量）返回结束日期减去开始日期的天数。计算时舍去各日期的时间部分。省略参数时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=DAYS(DATE(2026,3,1),DATE(2026,1,15))` | 45 | 两个日期之间的天数 |
| `=DAYS(DATE(2026,1,1),DATE(2026,1,31))` | -30 | 结束较早则为负数 |

## 备注

- 不解析日期格式文本（如 "2026-01-15"），此类文本返回 #VALUE!；空单元格按 0 处理。
- 两个日期参数均指定为数组时按元素计算，以相同形状的数组溢出返回 — 标量重复使用，列向量×行向量按外积扩展，大小不匹配的元素为 #N/A，错误元素原样返回该错误。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `DAYS` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.DAYS`。
