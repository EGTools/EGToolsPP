# GEOADDRESS

**类别**：EGTools 专用函数

返回坐标对应的地址(VWorld 逆地理编码)。

## 语法

```
=GEOADDRESS(x, y, [地址类型], [EPSG], [api_key])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| x | 必需 | 经度或 x 坐标 |
| y | 必需 | 纬度或 y 坐标 |
| 地址类型 | 可选 | 1 地番(默认), 2 道路名, 3 全部 |
| EPSG | 可选 | 坐标系 EPSG 代码(默认 4326=WGS84) |
| api_key | 可选 | vworld.kr 认证键，输入一次后存入注册表 |

## 返回

返回坐标对应的地址文本（地址类型=3 时以地番·道路名 2 行溢出）。地址类型超出 1~3、EPSG 无效或 EPSG 4326 下坐标超出范围时返回 #VALUE!，没有地址时返回 #N/A；缺少密钥·网络·服务错误以 "ERROR: …" 文本返回。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=GEOADDRESS(126.9779,37.5663)` |  | 坐标的地番地址（需要网络和 API 密钥） |

## 备注

- API 密钥不随附分发。请在空间信息开放平台（https://www.vworld.kr）申领后作为最后一个参数输入一次，密钥即保存到注册表；密钥被拒时自动删除并返回重新申领指引。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `GEOADDRESS` 名称注册。
