# EXRATE

**类别**：EGTools 专用函数

查询指定日期的韩元基准汇率(最多回溯 10 天)。

## 语法

```
=EXRATE([货币], [日期])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 货币 | 可选 | 3 位代码，如 USD(默认)、EUR、JPY… |
| 日期 | 可选 | 查询日期(默认: 今天) |

## 返回

以数字标量返回韩元基准汇率。指定未来日期时返回 #VALUE!；不支持的货币代码或 10 天回溯范围内没有公布汇率时返回 #N/A。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=EXRATE("USD")` |  | 结果取决于查询日和网络 |

## 备注

- 通过 HTTP 查询 smbs.biz（首尔外汇中介）基准汇率 — 需要网络连接。
- 指定日无公布汇率时最多回溯 10 天查询（应对节假日）。
- CNY 自动转换为 CNH。注册为非宏·线程安全，可并行重算。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `EXRATE` 名称注册。
