# TOCOL

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2024

将数组作为单列返回。

## 语法

```
=TOCOL(数组, [忽略], [按列扫描])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组 | 必需 | 数组 |
| 忽略 | 可选 | 0 无,1 空白,2 错误,3 两者 |
| 按列扫描 | 可选 | 为 TRUE 时按列 |

## 返回

返回将数组所有值排成一列（N×1）的数组，在支持动态数组的 Excel 中溢出。可用忽略选项（1=空值，2=错误，3=两者）排除值。数组为空或没有剩余值时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=TOCOL({1,2;3,4})` | {1;2;3;4} | 按行优先排成一列 |
| `=TOCOL({1,2;3,4},0,TRUE)` | {1;3;2;4} | 按列扫描 |
| `=TOCOL({1,"",2},1)` | {1;2} | 忽略空值 |

## 备注

- 空字符串（""）也视为空值，在忽略选项 1·3 中被排除。
- 所有值都被排除时返回 #VALUE! 而非原生的 #CALC!。
- 忽略·按列扫描选项指定为数组时，返回与该数组相同形状的数组，每个元素为该元素结果的第一个值（与原生一致的降级提升）。
- 相关函数：TOROW
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `TOCOL` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.TOCOL`。
