# IMPORTDATA

**类别**：Google 表格兼容函数

从 URL 或本地文件导入 CSV/TSV 数据。

## 语法

```
=IMPORTDATA(网址或路径, [分隔符], [区域设置], [字符集])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 网址或路径 | 必需 | 提供数据的网址或本地文件路径 |
| 分隔符 | 可选 | 字段分隔符(默认: 自动检测制表符/逗号) |
| 区域设置 | 可选 | 数字解析区域，如 "de-DE" |
| 字符集 | 可选 | 编码，默认 "utf-8" — euc-kr、代码页编号等 |

## 返回

将 URL 或本地文件的 CSV/TSV 内容以二维数组溢出返回，数字·日期文本自动转换为值。缺少路径、下载·读取失败、分隔符指定无效时返回 #VALUE!，内容为空时返回 #N/A。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=IMPORTDATA("https://example.com/data.csv")` |  | 取决于外部数据 |

## 备注

- 省略 delimiter 时自动检测：首行含制表符则为制表符，否则为逗号。
- 也向下兼容在第 2 个参数传入字符集名的旧式调用（IMPORTDATA(url,"euc-kr")）。
- 不同于 Google 只保留非空行的方式，内部空行保留，仅去除末尾的空行。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `IMPORTDATA` 名称注册。
