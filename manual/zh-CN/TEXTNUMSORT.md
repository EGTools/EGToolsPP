# TEXTNUMSORT

**类别**：EGTools 专用函数

按自然顺序排序行(文本与内嵌数字分别比较)。

## 语法

```
=TEXTNUMSORT(数组, [列号], [排序方式], [忽略文本])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组 | 必需 | 要排序的数据 |
| 列号 | 可选 | 关键列，从 1 起(默认 1) |
| 排序方式 | 可选 | 1 升序(默认)，-1 降序 |
| 忽略文本 | 可选 | TRUE 时仅比较数字部分 |

## 返回

返回与输入同尺寸的排序数组，在动态数组 Excel 中溢出。非数组的单一值原样返回。缺少数组、关键列超出范围或排序方式不是 1/-1 时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=TEXTNUMSORT({"a10";"a2";"a1"})` | {a1;a2;a10} | 自然排序升序 |
| `=TEXTNUMSORT({"a1";"a10";"a2"},1,-1)` | {a10;a2;a1} | 降序 |

## 备注

- 将文本段与数字段分离，数字按数值比较（a2 < a10）。
- 数字中的逗号视为千位分隔符忽略，'.' 按小数点处理。
- 稳定排序（stable sort），相同键的行保持原顺序。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `TEXTNUMSORT` 名称注册。
