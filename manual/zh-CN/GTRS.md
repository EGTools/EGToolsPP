# GTRS

**类别**：Google 表格兼容函数

GOOGLETRANSLATE 的简短别名 — 使用 Google 翻译文本。

## 语法

```
=GTRS(文本, [源语言], [目标语言])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 要翻译的文本(或区域) |
| 源语言 | 可选 | 源语言代码，如 "en"(默认 "auto" 自动检测) |
| 目标语言 | 可选 | 结果语言代码(默认: 界面语言) |

## 返回

与 GOOGLETRANSLATE 相同，以标量返回翻译后的文本。HTTP 请求失败时返回 #VALUE!；服务错误·语言代码无效·超过 5000 字符时以 "ERROR:…" 文本返回；空文本返回空字符串。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=GTRS("안녕하세요","ko","en")` |  | 取决于翻译结果 |

## 备注

- 是 GOOGLETRANSLATE 的简短别名，使用同一实现。详细行为请参阅 GOOGLETRANSLATE 文档。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `GTRS` 名称注册。
