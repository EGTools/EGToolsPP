# 工具

**位置**：功能区 `EGTools++` 选项卡 → `工具` 组

汇集常用辅助功能的拆分按钮。直接按下按钮执行默认动作
**全部重算**，按箭头则显示 10 个菜单。

## 删除样式

批量删除活动工作簿中堆积的**自定义单元格样式**。
用于因从其他文档复制而雪球式增多的样式使文档变得臃肿时。
在确认窗口中选择删除范围。

| 选择 | 动作 |
|---|---|
| 是 | 仅保留内置（Built-In）样式，删除所有自定义样式 |
| 否 | 保留内置样式 + **实际使用中的**样式，仅删除其余样式 |
| 取消 | 取消操作 |

- “使用中”检查会按单元格遍历所有工作表的已用区域，
  **大文档可能耗时较长**（状态栏显示进度）。
- 已锁定的样式先解锁再删除，完成后提示删除/失败数量。

## 删除名称

删除活动工作簿的定义名称中符合以下条件的名称。

| 删除对象 | 条件 |
|---|---|
| 引用已损坏的名称 | 引用对象（RefersTo）含 `#NAME?` / `#REF!` / `#N/A` |
| 宏残留 | 引用对象含 `BlankMacro1` |
| 隐藏的名称 | 名称管理器中不可见（Visible=False）的名称 |

Excel 内部名称（`_xl*.*` 形式，例如打印区域·筛选相关）绝不改动。
名称较多时状态栏显示进度，完成后提示删除数量
（没有对象时提示无）。

## 整理错误

将活动工作表已用区域中**正在产生错误值的公式**包裹为
`=IFERROR(原公式,"")`，隐藏错误显示。CSE 数组公式（`{=…}`）按整个
数组为单位包裹。非公式单元格（直接输入的错误常量）不改动，
完成后提示修正数量。

- 错误的原因并未修复，只是**显示为空字符串**。
  适合打印·分发前的整理。
- 若包裹后公式仍产生错误并反复执行，IFERROR 可能会嵌套。

## 清理空文本

将**只含长度为 0 的字符串("")的单元格**变为真正的空单元格（清除内容）。
公式结果或外部数据留下的 `""` 单元格看似为空，但在 ISBLANK·COUNTA·
末尾单元格（Ctrl+End）判定中不算空单元格，此功能用于清理这种情况。

1. 选择范围后执行。**只选择了单个单元格时，以工作表整个已用区域**
   为对象。
2. “是否排除公式单元格?”确认窗口 — **是** = 保留返回 `""` 的公式单元格 /
   **否** = 公式单元格也清除内容（公式被删除）/ **取消** = 中止。
3. 完成后提示清理的单元格数。CSE 数组公式会被整个数组清除。

## 整理批注

将活动工作表的**所有批注（注释）** 移到对应单元格右侧紧邻处，
并按内容自动调整大小。单元格已合并时移到合并区域右侧。
完成后提示整理的批注数。

## 更改边框颜色

在颜色选择对话框中选择颜色后（取消则结束），批量更改所选区域的
所有边框 — 上/下/左/右 + 2 种对角线 — 的颜色。
**线型（实线·虚线·粗细）保持不变**，仅更改颜色；没有边框的方向
不会新建边框。

## 描摹形状

沿所选区域中**填充了背景色的单元格**的外轮廓创建自由形状（Freeform）。
用于把用单元格涂色绘制的地图·区域标记等提取为一个形状。

1. 选择包含着色单元格的范围后执行。没有着色单元格时提示
   “请选择包含着色单元格的区域。”后结束。
2. **白色背景（含无填充）** 视为背景，其余着色单元格视为形状区域。
3. 沿着色单元格中最先遇到的**一个连通块**的外轮廓，按单元格实际
   宽高追踪并生成形状，并对结果形状应用样式预设。

- 存在多个彼此分离的块时，只有第一个块生成形状。其余请分割范围
  后重新执行。
- 形状生成失败时显示“形状转换失败。”提示。

## UDF 固定为值

将含 EGTools 函数（含 `EG.`/`x` 前缀变体）的公式替换为**计算后的值**。
把文档发给没有加载项的环境时，让值保留下来而不是公式变成
`#NAME?`，是用于分发的功能。

1. **扫描** — 以只读方式遍历全部工作表的公式，用确认窗口显示
   对象数量（没有对象时提示后结束）。
2. **保存关卡 + 备份** — 未保存时询问是否保存，应用前自动保存
   备份文件（SaveCopyAs）。备份失败则不继续。
3. **固定为值** — 将对象公式替换为值。CSE 数组按整个数组、
   溢出公式按整个溢出区域变为值。原公式以
   `EgUdfRemoved: <公式>` 形式保存为单元格批注（已有批注则接在后面）。
4. 完成后提示固定的单元格数和备份文件路径。

- 对象函数列表与加载项的函数注册列表按单一来源管理，始终保持一致。
- [应用旧版兼容](apply-compat.md)是**转换函数名**、保住公式的功能，
  而 UDF 固定为值是把公式**替换为值**的功能。

## 应用 CheckBox

让所选区域以 0/1 输入显示为复选框。

1. 对所选区域应用**只允许 0 或 1 的数据验证**。
2. 将数字格式设置为 `[=1]"✅";[=0]"⬜";""`
   — 输入 1 显示 ✅，输入 0 显示 ⬜，其他为空显示。
3. 空单元格填 0 并居中对齐。

单元格的值仍是 0/1 数字，可直接用 `SUM`·`COUNTIF` 等汇总。

## 全部重算

强制完全重算所有打开的**工作簿**（`CalculateFull`）。
用于把自动计算遗漏的单元格、易失性函数、外部引用等从头重新计算。

> 公共 API 函数的密钥注册/删除已移至
> [EGTools 组的管理 API 密钥](api-keys.md)。
