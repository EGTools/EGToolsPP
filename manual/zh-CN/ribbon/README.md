# 功能区菜单

加载 EGTools++ 后，功能区会新增 **EGTools++** 选项卡。
功能按钮按性质分为若干**组**，今后新增功能时将以组为单位扩展。

## 组：可见单元格

处理筛选·隐藏状态下的复制·粘贴（2 个拆分按钮：复制 = 仅复制可见单元格 /
粘贴 = 仅粘贴值）。详见：[可见单元格](visible-cells.md)

| 菜单 | 说明 |
|---|---|
| [仅复制可见单元格](visible-cells.md#仅复制可见单元格) | 仅将所选区域的可见单元格记为复制源并复制到剪贴板 |
| [全部复制](visible-cells.md#全部复制) | 将整个所选区域（含隐藏单元格）记为复制源 |
| [仅粘贴值](visible-cells.md#仅粘贴值--粘贴公式--全部粘贴) | 将记住的复制源仅按值粘贴到目标的可见单元格 |
| [粘贴公式](visible-cells.md#仅粘贴值--粘贴公式--全部粘贴) | 仅向可见单元格粘贴公式 |
| [全部粘贴](visible-cells.md#仅粘贴值--粘贴公式--全部粘贴) | 仅向可见单元格整体粘贴值·公式·格式 |

## 组：合并/拆分单元格

处理合并单元格的功能（2 个拆分按钮：合并 = 无格式合并内容 /
拆分 = 无格式拆分为行）。详见：[合并/拆分单元格](merge-split.md)

| 菜单 | 说明 |
|---|---|
| [合并连续相同值](merge-split.md#合并连续相同值) | 将纵向连续的相同值区段实际合并（多列时为层级式） |
| [保留值的合并](merge-split.md#保留值的合并) | 保留各单元格的值，仅在外观上合并 — 函数·筛选仍可正常工作 |
| [保留连续值的合并](merge-split.md#保留连续值的合并) | 将连续相同值区段分别仅做外观合并 |
| [无格式/保留格式合并内容](merge-split.md#无格式合并内容--保留格式合并内容) | 将区域合并为一个单元格，并用分隔符·换行连接内容（保留格式版保留字符格式） |
| [按行无格式/保留格式合并](merge-split.md#按行无格式合并--按行保留格式合并) | 将每行合并为一个单元格并连接内容 |
| [按列无格式/保留格式合并](merge-split.md#按列无格式合并--按列保留格式合并) | 将每列合并为一个单元格，内容以换行连接 |
| [拆分并填充](merge-split.md#拆分并填充) | 取消合并并把原合并值重新填入各单元格（公式将变为值） |
| [无格式/保留格式拆分为行](merge-split.md#无格式拆分为行--保留格式拆分为行) | 将合并单元格文本按换行拆分并逐行分配（不足时插入行） |
| [无格式/保留格式拆分为列](merge-split.md#无格式拆分为列--保留格式拆分为列) | 将合并单元格文本按分隔符拆分并逐列分配（不足时插入列） |

## 组：图片

按单元格插入·排列·导出图片（2 个拆分按钮：图片 = 插入图片 / 调整 = 调整所选）。
详见：[图片](pictures.md)

| 菜单 | 说明 |
|---|---|
| [插入图片](pictures.md#插入图片) | 选择图片文件并按所选区域大小插入 |
| [按名称插入](pictures.md#按名称插入) | 在文件夹中查找与单元格值同名的图片并插入该单元格 |
| [插入到表单](pictures.md#插入到表单) | 复制表单并在 `{{}}` 位置依次插入文件夹中的图片 |
| [调整所选](pictures.md#调整所选) | 将所选图片调整为各自左上角单元格的大小 |
| [全部调整](pictures.md#全部调整) | 将工作表中所有图片批量调整为单元格大小 |
| [全部导出](pictures.md#全部导出) | 将工作表中所有图片以原始画质保存到指定文件夹 |

## 组：日历/日程表

创建日历·日程表工作表（2 个拆分按钮：日历 = 月历 / 日程表 = 日B）。
详见：[日历/日程表](calendar.md)

| 菜单 | 说明 |
|---|---|
| [月历](calendar.md#月历) | 月历工作表（显示周数·节假日·农历） |
| [年历A](calendar.md#年历a--年历b) | 年历纵向版（3×4） |
| [年历B](calendar.md#年历a--年历b) | 年历横向版（4×3） |
| [周](calendar.md#周) | 周日程表（日~六，08:00~21:00 时间轴） |
| [日A](calendar.md#日a--日b) | 日日程表两栏版（结转未完成任务） |
| [日B](calendar.md#日a--日b) | 日日程表三栏版（结转未完成任务） |

## 组：表单

用数据列表填充表单并重复生成（拆分按钮，默认 = 制作标签）。
详见：[表单](forms.md)

| 菜单 | 说明 |
|---|---|
| [制作标签](forms.md#制作标签) | 按数据行复制表单，并将 `{{列名}}` 替换为值 |
| [邮件合并](mailmerge.md) | 按数据行复制表单工作表，生成单独工作表/文件（xlsx/PDF）·逐个打印·发送邮件（附加文件） |

## 组：工具

常用辅助功能合集（拆分按钮，默认 = 整理错误）。详见：[工具](utilities.md)

| 菜单 | 说明 |
|---|---|
| [删除样式](utilities.md#删除样式) | 批量删除自定义单元格样式（可选择保留内置/使用中的样式） |
| [删除名称](utilities.md#删除名称) | 删除引用已损坏或隐藏的定义名称 |
| [整理错误](utilities.md#整理错误) | 用 `IFERROR` 包裹出错公式以隐藏错误显示 |
| [清理空文本](utilities.md#清理空文本) | 将零长度字符串单元格清理为真正的空单元格 |
| [整理批注](utilities.md#整理批注) | 将工作表中所有批注移到单元格右侧 + 自动调整大小 |
| [更改边框颜色](utilities.md#更改边框颜色) | 批量更改所选区域所有边框的颜色（保留线型） |
| [描摹形状](utilities.md#描摹形状) | 沿着色单元格的轮廓生成自由形状 |
| [UDF 固定为值](utilities.md#udf-固定为值) | 将 EGTools 函数公式替换为值并把原公式保存为批注（用于分发） |
| [应用 CheckBox](utilities.md#应用-checkbox) | 应用将 0/1 输入显示为 ✅/⬜ 的单元格格式 |
| [全部重算](utilities.md#全部重算) | 强制完全重算所有打开的工作簿 |

## 组：EGTools

汇集公式函数名批量转换、SMTP 设置、API 密钥管理和加载项信息的
拆分按钮（默认 = 关于 EGTools++）。

| 菜单 | 说明 |
|---|---|
| [应用旧版兼容](apply-compat.md) | 将现代/原生（`_xlfn.*`）函数标记批量转换为 EGTools 兼容函数名 |
| [还原为内置函数](restore-native.md) | 将 EGTools 函数名批量还原为原生内置函数 |
| [SMTP 设置](smtp-settings.md) | 登记邮件合并发送邮件所用的 SMTP 服务器（不保存密码） |
| [管理 API 密钥](api-keys.md) | 注册/删除公共 API 密钥（地址搜索 · data.go.kr · vworld — data.go.kr 密钥由节假日·日历·营业登记共用） |
| 关于 EGTools++ | 显示版本·发布页·基础库；GitHub Release 上有新版本时会通知并提供发布页链接 |

新版本检查还会在 Excel 启动、功能区加载时自动执行一次；如有新版本，
将弹出带发布页链接的通知对话框（每次会话一次）。

| 项目 | 说明 |
|---|---|
| [日期选择](context-menu.md#日期选择) | 在单元格旁弹出日历，将点击的日期填入单元格 |
| [打开链接](context-menu.md#打开链接) | 用默认浏览器打开单元格内容中的 http/https URL |

## 插入选项卡 CheckBox

Excel 的`插入`选项卡中也会新增 [应用 CheckBox](utilities.md#应用-checkbox) 按钮。
在具有原生复选框的 Microsoft 365 中不显示。
