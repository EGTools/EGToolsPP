# 图片

**位置**：功能区 `EGTools++` 选项卡 → `图片` 组

按单元格插入·排列·导出图片的功能组。由 2 个拆分按钮组成 —
**图片**（默认动作 = 插入图片；菜单：插入图片·按名称插入·插入到表单）和
**调整**（默认动作 = 调整所选；菜单：调整所选·全部调整·全部导出）。

## 插入图片

选择一个图片文件，按当前所选区域大小插入。

1. 在文件选择对话框中选择图片文件
   （jpg·jpeg·png·gif·bmp·tif·tiff·svg·emf·wmf 等，取消则结束）。
2. 图片按所选区域的位置·大小留 **0.2pt 边距**插入
   （嵌入文档保存，非文件链接）。
3. 插入图片的**名称设为文件名**，且**纵横比锁定被解除**，
   便于之后适配单元格时自由变形。

## 按名称插入

选择文件夹后，查找与工作表单元格值**同名的图片文件**并插入该单元格。
用于给名册·商品列表等已输入名称的表格批量贴图。

1. 在文件夹选择窗口中选择存放图片的文件夹（取消则结束）。
2. 检查活动工作表已用区域（从 A1 起）的所有单元格值，
   在文件夹中查找与值同名的图片文件。
   - 扩展名带不带均可（单元格值 `照片1` ↔ 文件 `照片1.jpg` 均匹配）。
     忽略大小写。
   - 仅以 jpg·jpeg·png·gif·bmp·tif·tiff·svg·emf·wmf 等图片扩展名文件为对象。
3. 将找到的图片按该单元格（合并单元格则为整个合并区域）大小留
   **0.3pt 边距**插入（嵌入文档保存）。图片名称设为去掉扩展名的
   文件名，纵横比锁定解除。
4. 完成后显示结果（已插入的文件夹提示 / 没有添加任何图片）。

同一值出现在多个单元格时，每个单元格都会插入。

## 插入到表单

复制表单的同时，在 `{{}}` 占位符位置依次插入文件夹中的图片。
用于填写照片台账（照片报告）表单。

1. **指定表单区域** — 在区域输入窗口中指定表单区域（默认 = 当前
   所选，取消则结束）。表单内必须至少有 1 个只输入了 `{{}}` 的
   单元格（照片位置），没有则提示后结束。
2. **输入复制方式** — `1` = 整表复制表单工作表 / `2` = 将表单区域
   向下重复 / `3` = 向右重复。
3. **选择文件夹** — 文件夹中的图片文件按**名称顺序**排序使用
   （没有图片则提示后结束）。
4. 复制表单直至图片用完，在每个 `{{}}` 单元格（合并单元格则为
   合并区域）留 **0.3pt 边距**插入图片。**单元格值记为文件名**，
   图片名称也是文件名。图片用完后剩余的 `{{}}` 会被清除。
   进度显示在状态栏。

- 方式 1 会复制工作表，工作表名按 `原名_1`、`_2` … 递增。
- 方式 2/3 复制整行/整列，因此行高·列宽保持不变
  （复制位置的原有内容会被清除）。

## 调整所选

将所选图片适配到各图片左上角顶点所在的单元格。

1. 选择图片后按下按钮会出现**边距输入**窗口
   （0~10，默认 0.3）。输入非数字值或取消则结束。
2. 将每张图片按左上角单元格大小向内缩进边距量适配。
   左上角单元格为**合并区域**时，按整个合并区域大小适配。
3. **旋转 90 度/270 度**的图片会交换宽高，在保持旋转状态下
   校正为适配单元格。

未选择图片时显示“未选择图片。”提示。
仅处理图片（照片）对象，不改动形状·图表等。

## 全部调整

将活动工作表的**所有图片**按与调整所选相同的方式批量适配。

1. 同意确认窗口（是否继续）后出现**边距输入**窗口（0~5，默认 0.3）。
2. 将工作表所有图片适配到各自的左上角单元格（合并区域则为合并
   大小）。进度以图片名称显示在 Excel **状态栏**。
3. 完成后提示结果（整理完成 / 没有图片）。

## 全部导出

将活动工作表的**所有图片**以**原始画质**保存到指定文件夹。
用于把贴在工作表上的照片还原为文件。

1. 工作表没有图片时提示后结束。选择保存文件夹（取消则结束）。
2. 文件名为**图片左上角顶点所在单元格的值**。单元格为空时为
   `图片名_R行C列` 形式。文件名不可用的字符替换为 `_`，
   名称重复时附加 `_1`、`_2`…。扩展名保持文档中保存的原始
   格式（jpg·png 等）。
3. 内部动作：将工作簿的**副本保存到临时文件夹**，原样取出文档内的
   原始图片数据。不是按屏幕显示画质重绘的方式，因此**保留放入
   文档时的画质**，且原文档完全不被更改（临时文件自动删除）。
4. 完成后提示导出数量和保存文件夹。

- 文档必须为 **xlsx/xlsm 格式**。其他格式（.xls 等）下可能显示
  “图片导出失败。”的提示。
- 对象为图片（照片）对象。形状·图表不保存。

## 备注

- 边距为 0 时图片填满单元格，值越大与单元格边框的间距越大。
- 适配基准为图片**左上角顶点所在的单元格**。若不在期望的单元格上，
  请把图片移到该单元格上方后重新执行。
