# 邮件合并

**位置**：功能区 `EGTools++` 选项卡 → `表单` 组 → `标签` 拆分按钮的菜单 → **邮件合并**

按数据列表的**每一行整表复制表单工作表**，把 `{{字段名}}` 占位符替换为
该行的值，并按所选选项执行单独文件保存（xlsx/PDF）·逐个打印·**发送
邮件**（按行附加文件）。发送邮件所用的 SMTP 服务器信息在
[SMTP 设置](smtp-settings.md)中登记（不保存密码）。

## 操作流程

1. **输入选项** — 用数字（0~7，默认 1）输入要执行的任务。是 1（保存文件）·
   2（打印）·4（发送邮件）的**位组合**。
   `0` = 仅复制表单工作表（保留复制的工作表）/ `1` = 保存文件 / `2` = 打印 /
   `3` = 保存文件 + 打印 / `4` = 发送邮件 / `5` = 保存文件 + 发送邮件 /
   `6` = 打印 + 发送邮件 / `7` = 保存文件 + 打印 + 发送邮件。
2. **打印设置** — 选项包含打印（2·3·6·7）时会先显示打印机设置对话框。
   取消则中止操作。
3. **指定表单工作表** — 在区域输入窗口中选择表单工作表的任意单元格。
   所选区域所在的**整个工作表**将作为表单使用。
4. **指定数据区域** — 选择数据列表的单元格。所选内容会自动扩展为连续
   区域（CurrentRegion），**首行为字段名**，第二行起为数据。
5. **发送邮件准备**（含发送的选项 4~7）— 确认收件人列和邮件模板工作表后，
   若 [SMTP 设置](smtp-settings.md)为空，设置对话框会自动打开。
   随后要求输入 **SMTP 账户密码**
   （密码不会保存，取消则中止操作）。
6. 每个数据行的表单工作表复制到工作簿最后并替换 `{{字段名}}`，
   随后按选项执行打印·保存·发送。完成后显示“已完成的项目: N” —
   若选择了发送，还会一并显示“已发送邮件: N”。

## 规则

| 项目 | 规则 |
|---|---|
| 占位符 | `{{字段名}}` 与列表标题行的字段名按**忽略大小写·忽略前后空格**对应。一个单元格可写多个，并可与前后文字组合。存在列表中没有的字段名时，连同该字段名一起提示错误并中止 |
| 工作表/文件名 | **第一列的值**作为复制工作表和保存文件的名称。第一列为空的行跳过，名称中的禁用字符替换为 `_`。已有同名工作表时附加 `_1`、`_2` … 后缀 |
| 保存位置 | 文件保存在工作簿所在文件夹的 `Output\` 子文件夹。**工作簿必须已保存**，否则提示后中止（发送邮件也要生成附件，同样适用） |
| PDF 保存 | 列表**第一列的标题为 `PDF`**（忽略大小写）时，改为保存 PDF 而非 xlsx |
| 打开密码 | 列表中有 `PassWord` 或 `암호` 列时，该行的值将设为 xlsx 的**打开密码**（空值则无密码，不适用于 PDF） |
| 复制工作表清理 | 选项不为 0 时，复制的工作表在打印·保存·发送后删除。选项为 0 时工作表保留在工作簿中 |

## 发送邮件（选项 4·5·6·7）

选择包含发送的选项时，追加适用以下规则。

| 项目 | 规则 |
|---|---|
| 收件人列 | 数据列表中标题为 `eMail` 或 `이메일` 的列（忽略大小写）为**必需**。没有则提示后中止。收件人单元格**为空的行仅跳过发送**，工作表复制·保存·打印照常执行 |
| 邮件模板工作表 | 工作簿中必须有名为 `이메일` 或 `Email` 的工作表。以**第 1 列 = 键，第 2 列 = 值**输入。键：`제목`/`Subject`（**必需**）、`본문`/`Body`、`참조`/`CC`、`숨은참조`/`BCC` |
| 主题/正文替换 | 主题和正文同样应用 `{{字段名}}` 替换，可**按行发送个性化邮件**。列表中没有的字段名保持原文 |
| 附件 | 该行保存的文件（xlsx 或 PDF，支持打开密码）会**附加**到邮件。若未选择保存文件（位 1），附件用文件在发送后删除 |
| 发件人/服务器 | 使用 [SMTP 设置](smtp-settings.md)的发件人姓名·邮箱·服务器·端口·SSL。设置为空时设置对话框自动打开，仍不完整则中止 |
| 密码 | SMTP 账户密码**每次执行时输入**，不在任何地方保存 |
| 失败处理 | 某一行发送失败也会**继续处理下一行**。完成汇总中以“名称 - 错误内容”列表显示失败的行 |

## 备注

- 替换后的单元格以**文本值**输入（不是公式）。
- 文件保存采用把复制工作表复制为单工作表新工作簿、保存后关闭的方式，
  因此保存的文件中只有那一个工作表。
- 发送引擎**仅支持隐式 SSL（通常端口 465）**，不支持 587 STARTTLS。
  详细限制参见 [SMTP 设置](smtp-settings.md)。
- 与[制作标签](forms.md#制作标签)的区别：制作标签是**在一个工作表中
  重复排布表单**，邮件合并是**每行生成单独的工作表/文件**。
