# 表单

**位置**：功能区 `EGTools++` 选项卡 → `表单` 组

用数据列表填充工作表上绘制的表单（格式区域）并重复生成的功能组。
由一个拆分按钮（默认动作 = 制作标签）组成。

| 菜单 | 说明 |
|---|---|
| [制作标签](#制作标签) | 按数据行在一个工作表中重复排布表单，并将 `{{列名}}` 替换为值 |
| [邮件合并](mailmerge.md) | 按数据行复制表单工作表，生成单独工作表/文件（xlsx/PDF）·逐个打印·发送邮件（附加文件） |

## 制作标签

按数据列表的行数复制表单，并把 `{{列名}}` 占位符替换为各行的值，
生成打印用标签（名牌·地址标签等）工作表。

### 操作流程

1. **指定表单区域** — 在区域输入窗口中指定表单区域
   （默认 = 当前所选的连续区域，取消则结束）。指定没有值的单个
   单元格时结束。
2. **指定数据列表** — 指定数据列表区域。**首行为列名**，
   第二行起为数据。
3. **输入横向排列数** — 输入一行内横向排列的标签数（1~10，默认 1）。
4. 在新工作表（表单工作表名 + `_1` 形式）中按数据行复制表单，
   并将 `{{列名}}` 替换为该行的值。完成后显示提示。

### 替换规则

| 项目 | 规则 |
|---|---|
| 占位符 | 仅含 `{{列名}}` 的单元格是替换对象。一个单元格可写多个，并可与前后文字组合（如：`地址: {{地址}}`） |
| 没有占位符 | 表单中一个 `{{ }}` 占位符都没有时，仅按数据行数复制空表单 |
| 空列名 | 列表首行为空的列可用 `Empty1`、`Empty2` … 名称引用 |
| 不存在的列名 | 引用列表中不存在的列名时，警告后中止操作 |
| 格式 | 表单的格式（边框·颜色等）一并复制，且**列宽·行高也与表单相同**地复制 |

### 备注

- 替换后的单元格以**文本值**输入（不是公式）。
- 需要按行生成单独工作表/文件时请使用[邮件合并](mailmerge.md)
  （制作标签 = 在一个工作表中重复排布，邮件合并 = 每行单独工作表/文件）。
