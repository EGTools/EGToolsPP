# ARABIC

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

将罗马数字转换为阿拉伯数字。

## 语法

```
=ARABIC(text)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| text | 必需 | 罗马数字文本 |

## 返回

返回罗马数字转换后的数字值（标量）。含有罗马数字符号（I·V·X·L·C·D·M）及开头 '-' 以外的字符时返回 #VALUE! 错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=ARABIC("LVII")` | 57 | 罗马数字转数字 |
| `=ARABIC("MCMXII")` | 1912 | 转换较大的罗马数字 |
| `=ARABIC("-X")` | -10 | 支持负数表示 |

## 备注

- 忽略空格，不区分大小写。
- 空文本返回 0。
- 相关函数：BASE、DECIMAL
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `ARABIC` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.ARABIC`。
