# CONCAT

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2016/2019

连接值和区域中的文本（无分隔符）。

## 语法

```
=CONCAT(文本1, ...)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本1 | 必需 | 文本/区域 |
| … | 可选 | 以上参数可重复指定 |

## 返回

返回将所有参数（含区域·数组）按顺序连接的单一文本（标量）。实现本身不返回额外的错误值。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=CONCAT("A",1,"B")` | A1B | 按原值连接 |
| `=CONCAT({1,2;3,4})` | 1234 | 数组按行优先连接 |

## 备注

- 不带分隔符连接。需要分隔符时使用 TEXTJOIN。
- 最多支持 255 个参数。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `CONCAT` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.CONCAT`。
