# DECIMAL

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

将给定进制的文本数字转换为十进制数。

## 语法

```
=DECIMAL(text, radix)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| text | 必需 | 要转换的文本 |
| radix | 必需 | 基数 2-36 |

## 返回

返回进制文本转换后的十进制数字（标量）。radix 超出 2~36 范围，或 text 含有该进制不可用的字符时返回 #NUM! 错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=DECIMAL("FF",16)` | 255 | 十六进制转十进制 |
| `=DECIMAL("111",2)` | 7 | 二进制转十进制 |

## 备注

- 不区分大小写。
- 所有参数指定为数组时按元素计算，以相同形状的数组溢出返回 — 标量重复使用，列向量×行向量按外积扩展，大小不匹配的元素为 #N/A，错误元素原样返回该错误。
- 相关函数：BASE
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `DECIMAL` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.DECIMAL`。
