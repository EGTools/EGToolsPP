# COMPARELIST

**类别**：EGTools 专用函数

比较多个列表并返回指定集合: 0 并集，N 仅列表N，-1 仅一个，-2 全部，-3 部分。

## 语法

```
=COMPARELIST(集合类型, 按行, 数组1, ...)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 集合类型 | 必需 | 0 并集，N=仅在列表 N，-1 恰在一个，-2 在全部，-3 在部分 |
| 按行 | 必需 | TRUE 按整行比较 |
| 数组1 | 必需 | 列表区域或数组 |
| … | 可选 | 以上参数可重复指定 |

## 返回

以数组（溢出）返回属于所选集合的项目（按行为 TRUE 时为多列，否则 1 列）。没有列表或集合类型超出 -3~列表数范围时返回 #VALUE!；结果为空时返回 #N/A。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=COMPARELIST(0,FALSE,{"a";"b"},{"b";"c"})` | {"a";"b";"c"} | 并集（去重） |
| `=COMPARELIST(-2,FALSE,{"a";"b"},{"b";"c"})` | b | 存在于所有列表的项 |
| `=COMPARELIST(1,FALSE,{"a";"b"},{"b";"c"})` | a | 仅列表 1 独有的项 |

## 备注

- 比较不区分大小写，数字按值比较。
- 结果保持项目首次出现的顺序。
- 按行为 TRUE 时以整行作为一个键比较（忽略行尾的空单元格）。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `COMPARELIST` 名称注册。
