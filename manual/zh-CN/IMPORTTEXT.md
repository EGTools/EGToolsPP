# IMPORTTEXT

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 365（2026 年新增）

将文本文件(本地路径/URL)导入为数组。

## 语法

```
=IMPORTTEXT(路径, [分隔符], [跳过行], [读取行], [编码], [区域设置])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 路径 | 必需 | 本地文件路径或 URL |
| 分隔符 | 可选 | 分隔文本(默认制表符)，{1,3} 等升序数字为固定宽度列 |
| 跳过行 | 可选 | 跳过的行数 — 负数从末尾 |
| 读取行 | 可选 | 读取的行数 — 负数从末尾 |
| 编码 | 可选 | 默认 "utf-8" — windows-1252、euc-kr 等 |
| 区域设置 | 可选 | 数字解析区域，如 "de-DE" |

## 返回

将文本文件（本地路径或 URL）按分隔符或固定宽度拆分为二维数组溢出返回，数字·日期文本自动转换。缺少路径·读取/下载失败·分隔符/固定宽度指定无效时返回 #VALUE!；应用 skip/take 后没有剩余行时返回 #N/A。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=IMPORTTEXT("C:\data\log.txt",";",1)` |  | 取决于文件内容 |

## 备注

- 省略 delimiter 时默认制表符。字符串（可多个）作为分隔符，数字数组（{1,11,21}）解释为固定宽度列的起始位置（从 1 起升序）。
- encoding 支持 "euc-kr" 等字符集名或代码页编号，有 BOM 时以 BOM 优先。
- skip_rows/take_rows 为负数时从末尾计算。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `IMPORTTEXT` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.IMPORTTEXT`。
