# SWITCH

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2016/2019

将表达式与多个值比较，返回第一个匹配的结果（或默认值）。

## 语法

```
=SWITCH(表达式, 值1, 结果1, [默认值], ...)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 表达式 | 必需 | 要比较的值 |
| 值1 | 必需 | 用于匹配的值 |
| 结果1 | 必需 | 值匹配时的结果 |
| 默认值 | 可选 | 默认值 / 值2 … |
| … | 可选 | 以上参数可重复指定 |

## 返回

原样返回与表达式首个匹配的值所对应的结果（或末尾的默认值）。既无匹配值也无默认值时返回 #N/A。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=SWITCH(2,1,"one",2,"two","other")` | two | 匹配值的结果 |
| `=SWITCH(9,1,"one","other")` | other | 返回默认值 |

## 备注

- 中间参数留空时，其后的值/结果对将被忽略。
- 相关函数：IFS。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `SWITCH` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.SWITCH`。
