# TEXTJOIN

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2016/2019

使用分隔符连接文本（可忽略空单元格）。

## 语法

```
=TEXTJOIN(分隔符, 忽略空白, 文本1, ...)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 分隔符 | 必需 | 各项之间的分隔符 |
| 忽略空白 | 必需 | 为 TRUE 时跳过空单元格 |
| 文本1 | 必需 | 文本/区域 |
| … | 可选 | 以上参数可重复指定 |

## 返回

返回用分隔符连接而成的单一文本（标量）。实现本身不返回额外的错误值。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=TEXTJOIN("-",TRUE,"a","","b")` | a-b | 跳过空值 |
| `=TEXTJOIN("-",FALSE,"a","","b")` | a--b | 保留空值 |
| `=TEXTJOIN(",",TRUE,{1,2;3,4})` | 1,2,3,4 | 连接数组元素 |

## 备注

- 省略忽略空白时按 TRUE 处理。
- 文本参数最多支持 255 个。
- 相关函数：CONCAT
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `TEXTJOIN` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.TEXTJOIN`。
