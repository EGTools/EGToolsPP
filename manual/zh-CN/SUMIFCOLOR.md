# SUMIFCOLOR

**类别**：EGTools 专用函数

对显示颜色与基准单元格一致的单元格求和。

## 语法

```
=SUMIFCOLOR(检查区域, 基准单元格, [字体色])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 检查区域 | 必需 | 要求和的区域 |
| 基准单元格 | 必需 | 保存基准色的单元格(多个时取第一个) |
| 字体色 | 可选 | TRUE 时比较字体色，默认 FALSE |

## 返回

返回与基准单元格显示颜色相同的单元格的数字之和。COM 连接失败、读取基准色失败、检查单元格数超过 100,000 时返回 #VALUE!；匹配单元格中有错误值时原样返回该错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=SUMIFCOLOR(A1:A10,C1)` |  | 与 C1 填充色相同单元格之和（结果取决于单元格格式） |

## 备注

- 基于 DisplayFormat，以反映条件格式后的显示颜色进行比较。
- 仅改格式不触发重算，需按 F9；宏类函数，也被排除在多线程重算之外。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `SUMIFCOLOR` 名称注册。
