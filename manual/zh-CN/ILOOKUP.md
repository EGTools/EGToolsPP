# ILOOKUP

**类别**：EGTools 专用函数

查找匹配项并将锚定在该单元格的图片复制到调用单元格。

## 语法

```
=ILOOKUP(查找值, 查找区域, 图片区域, [未找到时], [匹配模式], [搜索模式])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 查找值 | 必需 | 要搜索的值 |
| 查找区域 | 必需 | 要搜索的数组或区域 |
| 图片区域 | 必需 | 锚定图片的单元格区域 |
| 未找到时 | 可选 | 无匹配时的返回值(默认 #N/A) |
| 匹配模式 | 可选 | 0 精确(默认), -1 次小, 1 次大, 2 通配符, 3 正则 |
| 搜索模式 | 可选 | 1 从头(默认), -1 从尾 |

## 返回

找到匹配项并成功时返回空字符串（""），并将放置在匹配单元格上的图片按调用单元格大小另行插入。查找区域与图片区域大小不同时返回 #REF!；没有匹配项或图片时返回未找到时值（默认 #N/A）；正则无效或 COM·剪贴板失败时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=ILOOKUP("apple",A1:A5,B1:B5)` |  | 复制放在匹配行的图片（插入图片，取决于环境） |

## 备注

- 在图片区域中将以匹配单元格为 TopLeftCell 放置的图片（msoPicture/msoLinkedPicture）经剪贴板复制。
- 匹配模式：0 精确（默认）、-1 较小值、1 较大值、2 通配符、3 正则；搜索模式：1 从头（默认）、-1 从尾。
- 仅更改图片位置或格式不会触发重算，需按 F9；宏类函数，也被排除在多线程重算之外。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `ILOOKUP` 名称注册。
