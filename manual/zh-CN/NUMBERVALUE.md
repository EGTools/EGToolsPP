# NUMBERVALUE

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

以与区域设置无关的方式将文本转换为数字。

## 语法

```
=NUMBERVALUE(文本, [小数分隔符], [分组分隔符])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 要转换的文本 |
| 小数分隔符 | 可选 | 小数点符号（默认 .） |
| 分组分隔符 | 可选 | 千位分隔符（默认 ,） |

## 返回

返回数字（标量）；文本参数为数组时按元素计算，在动态数组 Excel 中溢出。去除分隔符后无法解析为数字时返回 #VALUE!；空文本（仅含空格）返回 0。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=NUMBERVALUE("2.500,27",",",".")` | 2500.27 | 转换欧式记法 |
| `=NUMBERVALUE("9%%")` | 0.0009 | 每个 % 除以 100 |
| `=NUMBERVALUE("abc")` | #VALUE! | 不是数字 |

## 备注

- 所有空白字符无论位置一律忽略；分组分隔符无论位于何处都会被去除。
- 结尾的 % 符号按个数依次除以 100。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `NUMBERVALUE` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.NUMBERVALUE`。
