# COMBINA

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

返回给定数目项目的可重复组合数。

## 语法

```
=COMBINA(number, number_chosen)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| number | 必需 | 项目总数 |
| number_chosen | 必需 | 每个组合的项目数 |

## 返回

返回可重复组合数（标量数字）。参数非数字或为负数时返回 #NUM! 错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=COMBINA(4,3)` | 20 | 4 选 3 可重复组合 |
| `=COMBINA(10,3)` | 220 | 10 选 3 可重复组合 |

## 备注

- 舍去小数部分，按 C(n+k-1, k) 计算。
- 相关函数：PERMUTATIONA
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `COMBINA` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.COMBINA`。
