# QRCODE

**类别**：EGTools 专用函数

将文本生成 QR 码图片并插入调用单元格。

## 语法

```
=QRCODE(文本, [边距], [GS1])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 要编码的字符串 |
| 边距 | 可选 | 以模块为单位的空白(默认 0) |
| GS1 | 可选 | TRUE 时按 (AI)值 形式的 GS1 处理 |

## 返回

成功时返回空字符串（""），并按调用单元格大小另行插入 QR 码图片。文本为空、GS1 转换或编码失败时返回 #VALUE!，无法确定调用单元格时返回 #REF!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=QRCODE("https://example.com")` |  | 插入 QR 码图片（插入图片，取决于环境） |

## 备注

- gs1=TRUE 以 GS(0x1D) 分隔符近似处理，并非完整的 FNC1 编码。需要完整 GS1 时请使用 CODE128（GS1-128）。
- 图片在调用单元格内保持正方形比例。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `QRCODE` 名称注册。
