# GEOCODER

**类别**：EGTools 专用函数

返回地址的 GPS 坐标(VWorld，先道路名后地番)。

## 语法

```
=GEOCODER(关键字, [EPSG], [api_key])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 关键字 | 必需 | 地址 |
| EPSG | 可选 | 坐标系 EPSG 代码(默认 4326=WGS84) |
| api_key | 可选 | vworld.kr 认证键，输入一次后存入注册表 |

## 返回

返回 {x, y, 规范化地址} 的 1×3 数组并溢出。地址为空或 EPSG 无效时返回 #VALUE!，找不到坐标时返回 #N/A；缺少密钥·网络·服务错误以 "ERROR: …" 文本返回。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=GEOCODER("세종대로 110")` |  | 地址的 GPS 坐标（需要网络和 API 密钥） |

## 备注

- API 密钥不随附分发。请在空间信息开放平台（https://www.vworld.kr）申领后作为最后一个参数输入一次，密钥即保存到注册表；密钥被拒时自动删除并返回重新申领指引。
- 先尝试道路名地理编码器，失败后按地番重试。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `GEOCODER` 名称注册。
