# CPK

**类别**：EGTools 专用函数

由测量值与规格限计算过程能力指数 Cpk。

## 语法

```
=CPK(数据, [上限], [下限])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数据 | 必需 | 测量值区域或数组 |
| 上限 | 可选 | USL(仅有下限时可省略) |
| 下限 | 可选 | LSL(仅有上限时可省略) |

## 返回

以标量数字返回过程能力指数 Cpk = min((USL-μ)/3σ, (μ-LSL)/3σ)。没有 data 或 USL·LSL 均缺失时返回 #VALUE!，数字数据少于 2 个时返回 #NUM!，标准差为 0 时返回 #DIV/0! 错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=CPK({1;2;3;4;5},5,0)` | 0.421637021 | 规格 0~5 的 Cpk |

## 备注

- 使用样本标准差（n-1）。
- 只给出单侧规格限时仅按该方向计算。
- USL·LSL（规格上下限）指定为数组时按元素计算，以相同形状的数组溢出返回 — 标量重复使用，列向量×行向量按外积扩展，大小不匹配的元素为 #N/A，错误元素原样返回该错误。
- 相关函数：CP
- 支持：Excel 2010+。在所有 Excel 版本中均按 `CPK` 名称注册。
