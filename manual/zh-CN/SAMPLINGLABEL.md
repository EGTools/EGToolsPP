# SAMPLINGLABEL

**类别**：EGTools 专用函数

按 ISO 2859-1 的批量与检验水平返回样本量字码。

## 语法

```
=SAMPLINGLABEL(批量, [检验水平])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 批量 | 必需 | 批/批次数量(2 以上) |
| 检验水平 | 可选 | 一般 Ⅰ,Ⅱ,Ⅲ→G1/G2/G3，特殊→S1~S4(默认 G2) |

## 返回

返回 ISO 2859-1 样本量字码一个字符（文本标量）。批量小于 2 时返回 #NUM!，检验水平不是 S1~S4·G1~G3 时返回 #VALUE! 错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=SAMPLINGLABEL(1000)` | J | 默认 G2，批量 1000 |
| `=SAMPLINGLABEL(1000,"S3")` | E | 特殊检验水平 S-3 |

## 备注

- 忽略检验水平写法中的连字符和空格（"G-2"="G2"）。
- 内置 ISO 2859-1:1999 表进行计算。
- 相关函数：SAMPLINGSIZE、SAMPLINGAC、SAMPLINGRE
- 支持：Excel 2010+。在所有 Excel 版本中均按 `SAMPLINGLABEL` 名称注册。
