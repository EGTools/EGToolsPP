# CHOOSECOLS

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2024 / Microsoft 365

返回数组中指定的列。

## 语法

```
=CHOOSECOLS(数组, 列号1, ...)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组 | 必需 | 数组 |
| 列号1 | 必需 | 要返回的列(负=从末尾) |
| … | 可选 | 以上参数可重复指定 |

## 返回

返回由所选列组成的数组，在支持动态数组的 Excel 中溢出。数组为空、列号为 0 或超出范围、或未指定任何列号时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=CHOOSECOLS({1,2,3;4,5,6},1,3)` | {1,3;4,6} | 选择第 1·3 列 |
| `=CHOOSECOLS({1,2,3;4,5,6},-1)` | {3;6} | 选择最后一列 |
| `=CHOOSECOLS({1,2;3,4},5)` | #VALUE! | 列号超出范围 |

## 备注

- 列号为负数时从末尾数起。
- 要选择行请使用 CHOOSEROWS。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `CHOOSECOLS` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.CHOOSECOLS`。
