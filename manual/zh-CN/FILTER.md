# FILTER

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2021

筛选数组，保留条件为 TRUE 的行/列。

## 语法

```
=FILTER(数组, 包含, [为空时])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组 | 必需 | 要筛选的数据 |
| 包含 | 必需 | 布尔数组(行或列) |
| 为空时 | 可选 | 无匹配时的值(可选) |

## 返回

返回仅保留条件为 TRUE 的行或列的数组，并会溢出。include 的大小与 array 的行数或列数不一致时返回 #VALUE!；没有剩余项且省略 if_empty 时返回 #N/A。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=FILTER({1;2;3;4},{1;0;1;0})` | {1;3} | 筛选行 |
| `=FILTER({1,2;3,4;5,6},{0;1;1})` | {3,4;5,6} | 多列行筛选 |
| `=FILTER({1;2},{0;0},"none")` | none | 无结果时返回替代值 |

## 备注

- include 中的文本和空值按 FALSE 处理（原生函数返回 #VALUE!）。
- 无结果且省略 if_empty 时返回 #N/A 而非 #CALC!。
- 相关函数：SORT、UNIQUE。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `FILTER` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.FILTER`。 在部分旧版本中因保留字冲突注册为 `xFILTER`。
