# TEXTREPLACE

**类别**：EGTools 专用函数

替换文本中每个 起始键…结束键 区段。

## 语法

```
=TEXTREPLACE(文本, 起始键, 结束键, [替换文本], [保留键])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 源文本 |
| 起始键 | 必需 | 区段起始标记 |
| 结束键 | 必需 | 区段结束标记 |
| 替换文本 | 可选 | 替换内容(默认空) |
| 保留键 | 可选 | TRUE 时保留标记仅替换内部 |

## 返回

返回应用替换后的单一文本（标量）。文本·起始键·结束键任一为空时不返回错误，而是原样返回原文本。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=TEXTREPLACE("a[x]b[y]c","[","]","*")` | a*b*c | 全部区段替换为 * |
| `=TEXTREPLACE("a<1>b","<",">","2",TRUE)` | a<2>b | 保留键替换 |

## 备注

- 键搜索忽略大小写。
- 遇到没有结束键的起始键时，仅替换该起始键所在位置，其余文本保留。
- 相关函数：TEXTBETWEEN
- 支持：Excel 2010+。在所有 Excel 版本中均按 `TEXTREPLACE` 名称注册。
