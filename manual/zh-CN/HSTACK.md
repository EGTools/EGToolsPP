# HSTACK

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2024 / Microsoft 365

将多个数组水平堆叠为一个数组。

## 语法

```
=HSTACK(数组1, ...)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组1 | 必需 | 要堆叠的数组 |
| … | 可选 | 以上参数可重复指定 |

## 返回

返回将参数数组横向拼接而成的数组，在支持动态数组的 Excel 中溢出。高度不同时，较矮数组的空位用 #N/A 填充。没有任何有效数组参数时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=HSTACK({1;2},{3,4;5,6})` | {1,3,4;2,5,6} | 两个数组横向合并 |
| `=HSTACK({1,2},{3;4;5})` | {1,2,3;#N/A,#N/A,4;#N/A,#N/A,5} | 高度不同则 #N/A |

## 备注

- 跳过被省略的参数。
- 相关函数：VSTACK
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `HSTACK` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.HSTACK`。
