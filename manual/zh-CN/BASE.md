# BASE

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

将数字转换为给定基数（进制）的文本。

## 语法

```
=BASE(number, radix, [min_length])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| number | 必需 | 要转换的数字（≥0） |
| radix | 必需 | 基数 2-36 |
| min_length | 可选 | [可选] 结果最小长度 |

## 返回

返回按指定进制表示的文本（标量）。number 为负数或非数字、radix 超出 2~36 范围时返回 #NUM! 错误。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=BASE(255,16)` | FF | 255 转十六进制 |
| `=BASE(15,2,8)` | 00001111 | 按最小长度补 0 |

## 备注

- 舍去 number 的小数部分（向下取整）。
- 结果短于 min_length 时在前面补 0。
- 相关函数：DECIMAL
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `BASE` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.BASE`。
