# XOR

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2013

返回参数的逻辑异或(为 TRUE 的个数为奇数时返回 TRUE)。

## 语法

```
=XOR(逻辑1, ...)
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 逻辑1 | 必需 | 要检验的值或区域 |
| … | 可选 | 以上参数可重复指定 |

## 返回

TRUE 值的个数为奇数时返回 TRUE，偶数时返回 FALSE（逻辑标量）。参数中有错误时原样返回第一个错误；没有任何可按逻辑求值的值时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=XOR(TRUE,FALSE)` | TRUE | 奇数个 TRUE |
| `=XOR(TRUE,TRUE)` | FALSE | 偶数个 TRUE |
| `=XOR(1,0,1,"text")` | FALSE | 忽略文本 |

## 备注

- 忽略文本和空值（原生函数对无法转换的文本返回 #VALUE!）。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `XOR` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.XOR`。
