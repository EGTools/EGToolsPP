# RANDARRAY

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2021

返回随机数数组。

## 语法

```
=RANDARRAY([行数], [列数], [最小], [最大], [整数])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 行数 | 可选 | 行的数量(默认 1) |
| 列数 | 可选 | 列的数量(默认 1) |
| 最小 | 可选 | 最小值(默认 0) |
| 最大 | 可选 | 最大值(默认 1) |
| 整数 | 可选 | TRUE 则整数 |

## 返回

返回 rows×cols 大小的随机数数组，并会溢出。rows 或 cols 小于等于 0，或 max 小于 min 时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=RANDARRAY(2,3,1,10,TRUE)` |  | 随机数，每次结果不同 |

## 备注

- integer=TRUE 时生成 min~max 的整数（含两端），否则生成大于等于 min 且小于 max 的实数。
- 相关函数：SEQUENCE。
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `RANDARRAY` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.RANDARRAY`。
