# GEOSEARCH

**类别**：EGTools 专用函数

搜索地址或场所并返回 GPS 坐标(VWorld)。

## 语法

```
=GEOSEARCH(关键字, [搜索对象], [EPSG], [api_key])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 关键字 | 必需 | 地址或场所关键字 |
| 搜索对象 | 可选 | 1 地址(默认), 2 场所 |
| EPSG | 可选 | 坐标系 EPSG 代码(默认 4326=WGS84) |
| api_key | 可选 | vworld.kr 认证键，输入一次后存入注册表 |

## 返回

返回搜索结果的 x,y 坐标数组并溢出（多条结果时为含地址列的 n×3）。关键字为空或搜索对象/EPSG 无效时返回 #VALUE!，无结果时返回 #N/A；缺少密钥·网络·服务错误以 "ERROR: …" 文本返回。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=GEOSEARCH("서울특별시청",2)` |  | 场所搜索坐标（需要网络和 API 密钥） |

## 备注

- API 密钥不随附分发。请在空间信息开放平台（https://www.vworld.kr）申领后作为最后一个参数输入一次，密钥即保存到注册表；密钥被拒时自动删除并返回重新申领指引。
- 地址搜索（搜索对象=1）按道路名 → 地番顺序自动重试。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `GEOSEARCH` 名称注册。
