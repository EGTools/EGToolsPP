# ADDRESSMAP

**类别**：EGTools 专用函数

将地址的地籍图图片插入调用单元格(VWorld WMS)。

## 语法

```
=ADDRESSMAP(地址, [缩放级别], [api_key])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 地址 | 必需 | 道路名或地番地址 |
| 缩放级别 | 可选 | 1~10(默认 5)，越大越放大 |
| api_key | 可选 | vworld.kr 认证键，输入一次后存入注册表 |

## 返回

成功时返回空字符串（""），并将地址一带的地籍图（VWorld WMS）图片按调用单元格大小另行插入。地址为空或缩放级别超出 1~10 时返回 #VALUE!，找不到地址时返回 #N/A，无法确定调用单元格时返回 #REF!；缺少密钥·网络·服务错误以 "ERROR: …" 文本返回。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=ADDRESSMAP("세종대로 110",7)` |  | 插入地籍图图片（插入图片·需要网络和 API 密钥） |

## 备注

- API 密钥不随附分发。请在空间信息开放平台（https://www.vworld.kr）申领后作为最后一个参数输入一次，密钥即保存到注册表；密钥被拒时自动删除并返回重新申领指引。
- 将地址转换为坐标（道路名→地番）后，获取包含连续地籍图图层的地图。
- 地址·api_key 指定为数组时返回 #VALUE!（api_key 在保存前被拒绝，防止保存错误的密钥）— 多条数据请将公式按行复制使用。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `ADDRESSMAP` 名称注册。
