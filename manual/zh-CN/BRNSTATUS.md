# BRNSTATUS

**类别**：EGTools 专用函数

查询营业执照号码的当前状态(韩国国税厅, data.go.kr)。

## 语法

```
=BRNSTATUS(登记号码, [api_key])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 登记号码 | 必需 | 营业登记号码(可多个，允许连字符) |
| api_key | 可选 | data.go.kr 认证键，输入一次后存入注册表 |

## 返回

以与输入相同的形状返回各营业执照号码的课税类型文本（tax_type）（数组输入时溢出）。输入为空时返回 #VALUE!；缺少密钥·网络·服务错误以 "ERROR: …" 文本显示，未查询到的号码显示为 "#N/A" 文本。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=BRNSTATUS("123-45-67890")` |  | 查询营业登记状态（需要网络和 API 密钥） |

## 备注

- API 密钥不随附分发。请在公共数据门户的国税厅营业登记信息状态查询（https://www.data.go.kr ）申领后作为最后一个参数输入一次，或在功能区 [EGTools] → [管理 API 密钥] 中注册，密钥即保存到用户账户，此后可省略。
- data.go.kr 认证密钥每个账户只有一个，因此与 KOREANHOLIDAYS·功能区日历/日程表共用同一密钥。旧版本中为营业登记单独注册的密钥会在首次使用时自动迁移到统一槽位（用户无需重新注册）。
- 服务拒绝密钥（HTTP 401/403 等）时，自动删除已保存的密钥并返回重新申领指引。
- **以数字保存的**营业执照号码单元格也可直接查询 — 数字转换为不带指数表示的整数字符串，因前导 0 丢失而变成 9 位的值会还原为 10 位。连字符·空格等非数字字符被忽略，空单元格返回空字符串。
- 按每 100 条打包 POST 请求，适合批量查询。
- 编号数组的批量查询（每 100 条一批）保持不变。api_key 指定为数组时在保存前返回 #VALUE!（防止保存错误的密钥）。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `BRNSTATUS` 名称注册。
