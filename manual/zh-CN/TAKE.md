# TAKE

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2024

从数组的开头或末尾获取行/列。

## 语法

```
=TAKE(数组, 行数, [列数])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组 | 必需 | 数组 |
| 行数 | 必需 | 获取的行(负=从末尾) |
| 列数 | 可选 | 获取的列(可选) |

## 返回

返回从数组开头（正数）或末尾（负数）获取指定数量的行·列后的数组，在支持动态数组的 Excel 中溢出。数组为空或要获取的行·列数为 0 时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=TAKE({1,2,3;4,5,6;7,8,9},2)` | {1,2,3;4,5,6} | 前 2 行 |
| `=TAKE({1,2,3;4,5,6;7,8,9},-1,2)` | {7,8} | 末行的前 2 列 |
| `=TAKE({1,2;3,4},0)` | #VALUE! | 0 行则出错 |

## 备注

- 行数·列数为负数时从末尾获取。
- 结果为空数组时返回 #VALUE! 而非原生的 #CALC!。
- 相关函数：DROP
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `TAKE` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.TAKE`。
