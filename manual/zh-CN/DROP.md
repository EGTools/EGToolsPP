# DROP

**类别**：MS Excel 兼容函数 · **原生引入**：Excel 2024

从数组的开头或末尾删除行/列。

## 语法

```
=DROP(数组, 行数, [列数])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 数组 | 必需 | 数组 |
| 行数 | 必需 | 删除的行(负=从末尾) |
| 列数 | 可选 | 删除的列(可选) |

## 返回

返回删除指定数量的行·列后剩余的数组，在支持动态数组的 Excel 中溢出。数组为空或删除后没有剩余行·列时返回 #VALUE!。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=DROP({1,2,3;4,5,6;7,8,9},1)` | {4,5,6;7,8,9} | 删除首行 |
| `=DROP({1,2,3;4,5,6;7,8,9},1,-1)` | {4,5;7,8} | 删除首行·末列 |
| `=DROP({1,2},5)` | #VALUE! | 全部删除则出错 |

## 备注

- 行数·列数为负数时从末尾删除。
- 结果为空数组时返回 #VALUE! 而非原生的 #CALC!。
- 行数·列数指定为数组时，返回与该数组相同形状的数组，每个元素为该元素结果的第一个值（与原生一致的降级提升）。
- 相关函数：TAKE
- 支持：Excel 2010+。在没有原生函数的旧版本中按 `DROP` 原名注册（直接替换），在具有原生函数的新版 Excel 中注册为 `EG.DROP`。
