# SEARCHADDRESS

**类别**：EGTools 专用函数

搜索韩国地址(juso.go.kr)。

## 语法

```
=SEARCHADDRESS(文本, [输出项], [行], [api_key])
```

## 参数

| 参数 | 必需 | 说明 |
|---|---|---|
| 文本 | 必需 | 要搜索的地址关键字 |
| 输出项 | 可选 | 输出列 1~27，可用数组 {1,2}: 1 邮编, 2 道路名地址(默认), 3 地番地址, 4 英文地址 |
| 行 | 可选 | 输出的行号，0/省略为全部 |
| api_key | 可选 | juso.go.kr 授权键，输入一次后存入注册表 |

## 返回

以所选输出项为列返回搜索到的地址文本数组并溢出（行=0 时为全部，最多 100 条）。关键字为空或输出项超出 1~27 时返回 #VALUE!，无结果时返回 #N/A；缺少密钥·网络·服务错误以 "ERROR: …" 文本返回。

## 示例

| 公式 | 结果 | 说明 |
|---|---|---|
| `=SEARCHADDRESS("세종대로 110")` |  | 道路名地址搜索（需要网络和 API 密钥） |
| `=SEARCHADDRESS("세종대로 110",{1,2},1)` |  | 邮编+道路名地址 1 行（需要网络和 API 密钥） |

## 备注

- API 密钥不随附分发。请在[地址基础产业支援服务](https://www.juso.go.kr)申领后作为最后一个参数输入一次，密钥即保存到注册表，此后可省略。
- 服务拒绝密钥（过期/未注册）时，自动删除已保存的密钥并返回重新申领指引。
- 输出项完整列表（1~27）见下表。默认值为 2（道路名地址），可用 {1,2} 这样的数组指定多列。

| 编号 | 字段 | 说明 |
|---|---|---|
| 1 | zipNo | 邮政编码 |
| 2 | roadAddr | 完整道路名地址（默认） |
| 3 | jibunAddr | 地番地址 |
| 4 | engAddr | 道路名地址（英文） |
| 5 | roadAddrPart1 | 道路名地址（不含参考项目） |
| 6 | roadAddrPart2 | 道路名地址参考项目 |
| 7 | admCd | 行政区划代码 |
| 8 | rnMgtSn | 道路名代码 |
| 9 | bdMgtSn | 建筑物管理编号 |
| 10 | detBdNmList | 详细建筑物名列表 |
| 11 | bdNm | 建筑物名 |
| 12 | bdKdcd | 是否集合住宅（1：集合住宅，0：非集合住宅） |
| 13 | siNm | 市/道名 |
| 14 | sggNm | 市/郡/区名 |
| 15 | emdNm | 邑/面/洞名 |
| 16 | liNm | 法定里名 |
| 17 | rn | 道路名 |
| 18 | udrtYn | 是否地下（0：地上，1：地下） |
| 19 | buldMnnm | 建筑物主号 |
| 20 | buldSlno | 建筑物副号 |
| 21 | mtYn | 是否山地（0：宅地，1：山） |
| 22 | lnbrMnnm | 地番主号（番地） |
| 23 | lnbrSlno | 地番副号（号） |
| 24 | emdNo | 邑面洞序号 |
| 25 | hstryYn | 是否有变动记录 |
| 26 | relJibun | 相关地番 |
| 27 | hemdNm | 管辖居民中心 |

- 搜索词·api_key 指定为数组时返回 #VALUE!（api_key 在保存前被拒绝，防止保存错误的密钥）— 多条数据请将公式按行复制使用。
- 支持：Excel 2010+。在所有 Excel 版本中均按 `SEARCHADDRESS` 名称注册。
