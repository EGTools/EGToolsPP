# TOCOL

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024 / Microsoft 365

배열을 한 열로 반환합니다.

## 구문

```
=TOCOL(배열, [무시], [열기준스캔])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 대상 배열 |
| 무시 | 선택 | 0 없음,1 빈칸,2 오류,3 둘다 |
| 열기준스캔 | 선택 | TRUE면 열 기준 |

## 반환

배열의 모든 값을 한 열(N×1)로 늘어놓은 배열을 반환하며, 동적 배열을 지원하는 Excel에서는 스필됩니다. 무시 옵션(1=빈 값, 2=오류, 3=둘 다)으로 값을 제외할 수 있습니다. 배열이 비었거나 남는 값이 없으면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=TOCOL({1,2;3,4})` | {1;2;3;4} | 행 우선으로 한 열 |
| `=TOCOL({1,2;3,4},0,TRUE)` | {1;3;2;4} | 열 기준 스캔 |
| `=TOCOL({1,"",2},1)` | {1;2} | 빈 값 무시 |

## 참고

- 빈 문자열("")도 빈 값으로 간주하여 무시 옵션 1·3에서 제외됩니다.
- 모든 값이 제외되면 네이티브의 #CALC! 대신 #VALUE!를 반환합니다.
- 관련 함수: TOROW
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `TOCOL` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.TOCOL`으로 등록됩니다.
