# CODE128

**종류**: EGTools 전용 함수

텍스트를 CODE128 바코드 이미지로 만들어 호출 셀에 삽입합니다.

## 구문

```
=CODE128(텍스트, [문자표시], [GS1], [문자크기])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 인코딩할 문자열 |
| 문자표시 | 선택 | TRUE면 바코드 아래에 원본 문자 표시 |
| GS1 | 선택 | TRUE면 GS1-128(FNC1) 형식 |
| 문자크기 | 선택 | 표시 문자 크기(상대값) |

## 반환

성공하면 빈 문자열("")을 반환하고, Code128 바코드 그림이 호출 셀 크기에 맞춰 별도로 삽입됩니다. 텍스트가 비었거나 GS1 변환 또는 인코딩에 실패하면 #VALUE!, 호출 셀을 알 수 없으면 #REF!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=CODE128("ABC-1234",TRUE)` |  | 하단 문자 표시 포함 삽입(이미지 삽입, 환경 의존) |
| `=CODE128("(01)04012345678901(10)LOT42",FALSE,TRUE)` |  | GS1-128(FNC1) 형식 삽입(이미지 삽입, 환경 의존) |

## 참고

- gs1=TRUE면 (AI)값 텍스트를 FNC1 완전 준수 GS1-128로 인코딩합니다(심볼로지 식별자 ]C1).
- 이미지는 호출 셀을 가득 채웁니다(1D 형식).
- 문자크기는 상대값으로 하단 문자 밴드 높이에 반영됩니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `CODE128` 이름 그대로 등록됩니다.
