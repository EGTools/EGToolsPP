# TRIMRANGE

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024 / Microsoft 365

배열 가장자리의 빈 행/열을 제거합니다.

## 구문

```
=TRIMRANGE(배열, [행제거], [열제거])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 대상 배열 또는 범위 값 |
| 행제거 | 선택 | 0 없음, 1 앞, 2 뒤, 3 모두(기본) |
| 열제거 | 선택 | 0 없음, 1 앞, 2 뒤, 3 모두(기본) |

## 반환

가장자리의 빈 행/열을 제거한 배열을 반환하며 스필됩니다. 배열이 비었거나 제거 모드가 0~3 범위를 벗어나거나 전체가 빈 값이면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=TRIMRANGE({"","";"a",1;"",""})` | {"a",1} | 빈 가장자리 행·열 제거 |
| `=TRIMRANGE({"";1;""},1)` | {1;""} | 앞쪽 빈 행만 제거 |

## 참고

- 네이티브 TRIMRANGE는 참조를 다듬지만 이 구현은 값 기반이라 배열 리터럴과 수식 결과에도 사용할 수 있습니다.
- 빈 문자열("")도 빈 값으로 취급합니다.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `TRIMRANGE` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.TRIMRANGE`으로 등록됩니다.
