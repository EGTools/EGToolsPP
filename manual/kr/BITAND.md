# BITAND

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

두 수의 비트 AND 결과를 반환합니다.

## 구문

```
=BITAND(number1, number2)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| number1 | 필수 | 첫째 수(0 이상) |
| number2 | 필수 | 둘째 수(0 이상) |
