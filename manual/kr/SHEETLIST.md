# SHEETLIST

**종류**: EGTools 전용 함수

호출한 통합문서의 보이는 시트 이름 목록을 반환합니다.

## 구문

```
=SHEETLIST([시작], [끝], [사이만], [현재시트제외])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 시작 | 선택 | 시작 시트 번호/이름(기본: 첫 시트) |
| 끝 | 선택 | 마지막 시트 번호/이름(기본: 끝 시트) |
| 사이만 | 선택 | TRUE면 시작·끝 시트 제외 |
| 현재시트제외 | 선택 | TRUE면 현재 시트 제외(기본) |

## 반환

보이는 시트 이름을 1열 배열(스필)로 반환합니다. 호출 위치·통합문서 확인 실패, COM 연결 실패, 시작·끝 지정이 잘못된 경우 #VALUE!를, 필터링 후 남는 시트가 없으면 #N/A를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=SHEETLIST()` |  | 결과는 통합문서 구성에 따라 다릅니다 |

## 참고

- 매크로형 함수로 COM을 통해 시트 정보를 읽습니다(스레드 안전 아님).
- 숨김 시트는 항상 제외되며, 기본값으로 호출한 시트도 제외됩니다(현재시트제외 기본 TRUE).
- 시작·끝은 시트 번호 또는 이름으로 지정할 수 있습니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `SHEETLIST` 이름 그대로 등록됩니다.
