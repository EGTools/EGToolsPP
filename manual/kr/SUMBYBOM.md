# SUMBYBOM

**종류**: EGTools 전용 함수

BOM 1단계를 전개해 품목별 소요 수량을 합산합니다.

## 구문

```
=SUMBYBOM(배열1, ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열1 | 필수 | 열 순서: 모품목, 자품목, 소요량, 품목명, 수량열(들) — 여러 인수로 나눠 지정 가능 |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |
