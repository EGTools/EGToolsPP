# SUMBYBOM

**종류**: EGTools 전용 함수

BOM 1단계를 전개해 품목별 소요 수량을 합산합니다.

## 구문

```
=SUMBYBOM(배열1, ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열1 | 필수 | 열 순서: 모품목, 자품목, 소요량, 품목명, 수량열(들) — 여러 인수로 나눠 지정 가능 |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |

## 반환

품목명 1열 + 수량열 수만큼의 합계 열로 구성된 배열(스필)을 반환하며, 품목명 오름차순으로 정렬됩니다. 열이 5개 미만이거나 열 길이가 다르거나 소요량·수량이 숫자가 아니면 #VALUE!, 수량이 음수면 #NUM!, 집계할 항목이 없으면 #N/A를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=SUMBYBOM({"X","P",2,"X",1;"X","Q",3,"P",5})` | {"P",7;"Q",3} | X를 1단계 전개 후 합산 |

## 참고

- BOM은 1단계만 전개합니다(다단계 전개 아님).
- 품목명은 대소문자 구분 없이 합산되며 결과는 이름 오름차순입니다.
- 모품목이 아닌 품목은 수량이 0이면 결과에서 제외됩니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `SUMBYBOM` 이름 그대로 등록됩니다.
