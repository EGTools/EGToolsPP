# STREXT

**종류**: EGTools 전용 함수

문자 종류별(숫자/영문/한글/일본어/한자) 또는 정규식으로 추출·제거합니다.

## 구문

```
=STREXT(텍스트, 옵션, [구분자])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 분석할 문자열 |
| 옵션 | 필수 | S=공백 A=영문 N=숫자 K=한글 J=일본어 H=한자, "-"로 시작하면 제거, 그 외는 정규식 |
| 구분자 | 선택 | 추출 조각 사이 연결자(기본 없음) |

## 반환

추출(또는 제거) 결과인 단일 텍스트(스칼라)를 반환합니다. 텍스트·옵션이 누락되거나 옵션이 비었거나, 유효한 문자 클래스가 없거나, 정규식이 잘못되면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=STREXT("abc123한글45","N")` | 12345 | 숫자만 추출 |
| `=STREXT("abc123한글45","K")` | 한글 | 한글만 추출 |
| `=STREXT("a1b2","N","-")` | 1-2 | 구분자로 연결 |

## 참고

- N 클래스에는 소수점 '.'도 포함됩니다.
- 옵션이 -SANKJH 조합이 아니면 전체를 ECMAScript 정규식(std::wregex)으로 해석합니다.
- 옵션이 '-'로 시작하면 해당 문자들을 추출하는 대신 제거합니다.
- 텍스트에 배열을 지정하면 원소별로 처리해 같은 모양의 배열로 스필되며(오류 원소는 그 오류 그대로), 옵션·구분자에 배열을 지정하면 #VALUE!를 반환합니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `STREXT` 이름 그대로 등록됩니다.
