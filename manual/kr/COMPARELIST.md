# COMPARELIST

**종류**: EGTools 전용 함수

목록들을 비교해 지정한 집합을 출력합니다: 0 합집합, N번 목록 전용, -1 단독, -2 교집합, -3 부분교집합.

## 구문

```
=COMPARELIST(집합종류, 행단위, 배열1, ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 집합종류 | 필수 | 0 합집합, N=N번 목록에만, -1 하나에만, -2 모두에, -3 일부에만 |
| 행단위 | 필수 | TRUE면 행 전체 비교, FALSE면 셀별 비교 |
| 배열1 | 필수 | 목록 범위 또는 배열 |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |

## 반환

선택한 집합에 속하는 항목을 배열(스필)로 반환합니다(행단위 TRUE면 여러 열, 아니면 1열). 목록이 없거나 집합종류가 -3~목록 수 범위를 벗어나면 #VALUE!를, 결과가 비면 #N/A를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=COMPARELIST(0,FALSE,{"a";"b"},{"b";"c"})` | {"a";"b";"c"} | 합집합(중복 제거) |
| `=COMPARELIST(-2,FALSE,{"a";"b"},{"b";"c"})` | b | 모든 목록에 있는 항목 |
| `=COMPARELIST(1,FALSE,{"a";"b"},{"b";"c"})` | a | 1번 목록 전용 항목 |

## 참고

- 비교는 대소문자를 구분하지 않으며 숫자는 값으로 비교합니다.
- 결과는 항목이 처음 등장한 순서를 유지합니다.
- 행단위 TRUE면 행 전체를 하나의 키로 비교합니다(뒤쪽 빈 칸은 무시).
- 지원: Excel 2010+. 모든 Excel 버전에서 `COMPARELIST` 이름 그대로 등록됩니다.
