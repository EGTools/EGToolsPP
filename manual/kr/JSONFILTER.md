# JSONFILTER

**종류**: EGTools 전용 함수

JSON 문자열을 (경로, 값) 2열 표로 분석합니다.

## 구문

```
=JSONFILTER(JSON텍스트, [키경로])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| JSON텍스트 | 필수 | 분석할 JSON 텍스트 |
| 키경로 | 선택 | 필터링할 경로, 예 "data.items[0].name" (기본: 전체) |
