# IMPORTRANGE

**종류**: Google Sheets 호환 함수

공유된 Google 스프레드시트의 자료를 가져옵니다.

## 구문

```
=IMPORTRANGE(시트주소, [범위주소])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 시트주소 | 필수 | 구글시트 URL — 공유가 설정되어 있어야 합니다 |
| 범위주소 | 선택 | 가져올 범위, 예 "A1:C10" (기본: 시트 전체) |
