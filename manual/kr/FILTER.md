# FILTER

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2021

조건이 TRUE인 행/열만 남겨 배열을 필터링합니다.

## 구문

```
=FILTER(배열, 조건, [비어있으면])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 필터할 데이터 |
| 조건 | 필수 | 불린 배열(행 또는 열) |
| 비어있으면 | 선택 | 결과 없을 때 값(선택) |

## 반환

조건이 참인 행 또는 열만 남긴 배열을 반환하며 스필됩니다. include의 크기가 array의 행 수나 열 수와 맞지 않으면 #VALUE!, 남는 항목이 없는데 if_empty를 생략하면 #N/A를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=FILTER({1;2;3;4},{1;0;1;0})` | {1;3} | 행 필터링 |
| `=FILTER({1,2;3,4;5,6},{0;1;1})` | {3,4;5,6} | 여러 열 행 필터 |
| `=FILTER({1;2},{0;0},"none")` | none | 결과 없으면 대체값 |

## 참고

- include의 텍스트·빈 값은 FALSE로 처리합니다(네이티브는 #VALUE!).
- 결과가 없고 if_empty를 생략하면 #CALC! 대신 #N/A를 반환합니다.
- 관련 함수: SORT, UNIQUE.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `FILTER` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.FILTER`으로 등록됩니다. 일부 구버전에서는 예약어 충돌로 `xFILTER` 이름으로 등록됩니다.
