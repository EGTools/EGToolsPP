# FILTER

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2021

조건이 TRUE인 행/열만 남겨 배열을 필터링합니다.

## 구문

```
=FILTER(배열, 조건, [비어있으면])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 필터할 데이터 |
| 조건 | 필수 | 불린 배열(행 또는 열) |
| 비어있으면 | 선택 | 결과 없을 때 값(선택) |
