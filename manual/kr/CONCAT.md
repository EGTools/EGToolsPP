# CONCAT

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2016/2019

값과 범위의 텍스트를 구분자 없이 연결합니다.

## 구문

```
=CONCAT(텍스트1, ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트1 | 필수 | 텍스트/범위 |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |
