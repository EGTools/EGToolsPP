# CONCAT

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2016/2019

값과 범위의 텍스트를 구분자 없이 연결합니다.

## 구문

```
=CONCAT(텍스트1, ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트1 | 필수 | 텍스트/범위 |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |

## 반환

모든 인수(범위·배열 포함)를 순서대로 이어 붙인 단일 텍스트(스칼라)를 반환합니다. 구현 자체가 별도의 오류 값을 반환하지는 않습니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=CONCAT("A",1,"B")` | A1B | 값 그대로 연결 |
| `=CONCAT({1,2;3,4})` | 1234 | 배열 행 우선 연결 |

## 참고

- 구분 기호 없이 연결합니다. 구분 기호가 필요하면 TEXTJOIN을 사용합니다.
- 최대 255개 인수까지 지원합니다.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `CONCAT` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.CONCAT`으로 등록됩니다.
