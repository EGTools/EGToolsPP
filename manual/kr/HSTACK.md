# HSTACK

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024 / Microsoft 365

배열들을 가로로 이어 하나로 만듭니다.

## 구문

```
=HSTACK(배열1, ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열1 | 필수 | 결합할 배열 |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |

## 반환

인수로 준 배열들을 가로로 이어 붙인 배열을 반환하며, 동적 배열을 지원하는 Excel에서는 스필됩니다. 높이가 다르면 짧은 배열의 빈 자리를 #N/A로 채웁니다. 유효한 배열 인수가 하나도 없으면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=HSTACK({1;2},{3,4;5,6})` | {1,3,4;2,5,6} | 두 배열 가로 결합 |
| `=HSTACK({1,2},{3;4;5})` | {1,2,3;#N/A,#N/A,4;#N/A,#N/A,5} | 높이 다르면 #N/A |

## 참고

- 생략된 인수는 건너뜁니다.
- 관련 함수: VSTACK
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `HSTACK` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.HSTACK`으로 등록됩니다.
