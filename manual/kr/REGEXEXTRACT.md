# REGEXEXTRACT

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024 / Microsoft 365

텍스트에서 정규식과 일치하는 부분을 추출합니다.

## 구문

```
=REGEXEXTRACT(텍스트, 패턴, [반환모드], [대소문자구분])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 원본 텍스트 |
| 패턴 | 필수 | 정규식 패턴 |
| 반환모드 | 선택 | 0 첫 일치, 1 전체 일치, 2 캡처 그룹 |
| 대소문자구분 | 선택 | 0 구분(기본), 1 무시 |

## 반환

반환모드 0은 첫 일치 텍스트(스칼라), 1은 모든 일치(세로 1열 배열, 스필), 2는 첫 일치의 캡처 그룹(가로 1행 배열, 스필)을 반환합니다. 일치가 없거나(모드 2에서 그룹이 없는 경우 포함) #N/A, 정규식이 잘못되면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=REGEXEXTRACT("abc123def45","\d+")` | 123 | 첫 일치 |
| `=REGEXEXTRACT("abc123def45","\d+",1)` | {123;45} | 모든 일치(세로) |
| `=REGEXEXTRACT("2026-08-01","(\d+)-(\d+)",2)` | {2026,08} | 캡처 그룹(가로) |

## 참고

- 정규식 문법은 std::wregex의 ECMAScript입니다(네이티브 365의 PCRE2와 일부 다를 수 있습니다).
- 관련 함수: REGEXTEST, REGEXREPLACE
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `REGEXEXTRACT` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.REGEXEXTRACT`으로 등록됩니다.
