# IMPORTDATA

**종류**: Google Sheets 호환 함수

인터넷 URL이나 로컬 파일에서 CSV/TSV 자료를 가져옵니다.

## 구문

```
=IMPORTDATA(주소, [구분자], [로캘], [문자셋])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 주소 | 필수 | 자료를 제공하는 URL 또는 로컬 파일 경로 |
| 구분자 | 선택 | 필드 구분자(기본: 탭/콤마 자동감지) |
| 로캘 | 선택 | 숫자 해석 로캘, 예 "de-DE" |
| 문자셋 | 선택 | 인코딩, 기본 "utf-8" — euc-kr·코드페이지 번호 등 |
