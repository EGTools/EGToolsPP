# IMPORTDATA

**종류**: Google Sheets 호환 함수

인터넷 URL이나 로컬 파일에서 CSV/TSV 자료를 가져옵니다.

## 구문

```
=IMPORTDATA(주소, [구분자], [로캘], [문자셋])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 주소 | 필수 | 자료를 제공하는 URL 또는 로컬 파일 경로 |
| 구분자 | 선택 | 필드 구분자(기본: 탭/콤마 자동감지) |
| 로캘 | 선택 | 숫자 해석 로캘, 예 "de-DE" |
| 문자셋 | 선택 | 인코딩, 기본 "utf-8" — euc-kr·코드페이지 번호 등 |

## 반환

URL 또는 로컬 파일의 CSV/TSV 내용을 2차원 배열로 스필하여 반환하며, 숫자·날짜 텍스트는 자동으로 값으로 변환됩니다. 경로 누락, 다운로드·읽기 실패, 잘못된 구분자 지정이면 #VALUE!, 내용이 비어 있으면 #N/A를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=IMPORTDATA("https://example.com/data.csv")` |  | 외부 데이터에 따름 |

## 참고

- delimiter를 생략하면 첫 줄에 탭이 있을 때 탭, 없으면 콤마로 자동 감지합니다.
- 2번째 인수에 문자셋 이름을 주는 구버전 호출(IMPORTDATA(url,"euc-kr"))도 하위 호환으로 지원합니다.
- 빈 줄이 아닌 줄만 남기는 Google 방식 대신 내부 빈 줄은 유지하고 끝의 빈 줄만 제거합니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `IMPORTDATA` 이름 그대로 등록됩니다.
