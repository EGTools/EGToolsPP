# SHEET

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

참조의 시트 번호(또는 현재 시트)를 반환합니다.

## 구문

```
=SHEET([값])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 값 | 선택 | 참조(선택; 기본: 현재 시트) |

## 반환

참조(생략 시 수식이 입력된 셀)가 속한 시트의 위치(1부터 시작)를 숫자로 반환합니다. 시트를 찾지 못하면 #N/A, 시트 목록 조회에 실패하면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=SHEET()` |  | 현재 시트 위치(문서 의존) |

## 참고

- 인수로 셀 참조만 받습니다(네이티브는 시트 이름 텍스트도 허용).
- 매크로 시트형 함수로 등록됩니다.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `SHEET` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.SHEET`으로 등록됩니다.
