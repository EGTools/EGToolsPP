# ISOWEEKNUM

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

날짜의 ISO 8601 연중 주 번호를 반환합니다.

## 구문

```
=ISOWEEKNUM(날짜)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 날짜 | 필수 | 날짜 |
