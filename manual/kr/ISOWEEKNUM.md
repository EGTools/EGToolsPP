# ISOWEEKNUM

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

날짜의 ISO 8601 연중 주 번호를 반환합니다.

## 구문

```
=ISOWEEKNUM(날짜)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 날짜 | 필수 | 날짜 |

## 반환

날짜의 ISO 8601 주 번호(1~53)를 숫자로 반환합니다. 인수가 배열이면 같은 크기의 배열로 요소별 계산되어 동적 배열 Excel에서 스필됩니다. 날짜가 숫자가 아니거나 음수이면 #VALUE!, 직렬값을 날짜로 변환할 수 없으면 #NUM!을 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=ISOWEEKNUM(DATE(2026,1,1))` | 1 | 2026-01-01은 1주 |
| `=ISOWEEKNUM(DATE(2023,1,1))` | 52 | 전년도 마지막 주 |

## 참고

- 배열을 입력하면 요소별로 계산해 같은 크기의 배열을 반환합니다.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `ISOWEEKNUM` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.ISOWEEKNUM`으로 등록됩니다.
