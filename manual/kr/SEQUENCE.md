# SEQUENCE

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2021

연속된 숫자 배열을 생성합니다.

## 구문

```
=SEQUENCE(행수, [열수], [시작], [증분])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 행수 | 필수 | 행 개수 |
| 열수 | 선택 | 열 개수(기본 1) |
| 시작 | 선택 | 시작값(기본 1) |
| 증분 | 선택 | 증가량(기본 1) |
