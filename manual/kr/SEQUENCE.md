# SEQUENCE

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2021

연속된 숫자 배열을 생성합니다.

## 구문

```
=SEQUENCE(행수, [열수], [시작], [증분])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 행수 | 필수 | 행 개수 |
| 열수 | 선택 | 열 개수(기본 1) |
| 시작 | 선택 | 시작값(기본 1) |
| 증분 | 선택 | 증가량(기본 1) |

## 반환

rows×cols 크기의 연속 숫자 배열(행 우선으로 증가)을 반환하며 스필됩니다. rows나 cols가 0 이하면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=SEQUENCE(3)` | {1;2;3} | 기본 3행 수열 |
| `=SEQUENCE(2,3,0,10)` | {0,10,20;30,40,50} | 시작값·증분 지정 |

## 참고

- rows를 생략하면 1로 처리합니다(네이티브는 필수 인수).
- 관련 함수: RANDARRAY.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `SEQUENCE` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.SEQUENCE`으로 등록됩니다.
