# IMPORTCSV

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 365 (2026 신규)

CSV 파일(로컬 경로/URL)을 배열로 가져옵니다 — 콤마 구분·UTF-8.

## 구문

```
=IMPORTCSV(경로, [건너뛸행], [가져올행], [로캘])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 경로 | 필수 | 로컬 파일 경로 또는 URL |
| 건너뛸행 | 선택 | 건너뛸 행 수 — 음수면 끝에서부터 |
| 가져올행 | 선택 | 가져올 행 수 — 음수면 끝에서부터 |
| 로캘 | 선택 | 숫자 해석 로캘, 예 "de-DE" |
