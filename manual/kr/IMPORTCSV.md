# IMPORTCSV

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Microsoft 365 (2026 신규)

CSV 파일(로컬 경로/URL)을 배열로 가져옵니다 — 콤마 구분·UTF-8.

## 구문

```
=IMPORTCSV(경로, [건너뛸행], [가져올행], [로캘])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 경로 | 필수 | 로컬 파일 경로 또는 URL |
| 건너뛸행 | 선택 | 건너뛸 행 수 — 음수면 끝에서부터 |
| 가져올행 | 선택 | 가져올 행 수 — 음수면 끝에서부터 |
| 로캘 | 선택 | 숫자 해석 로캘, 예 "de-DE" |

## 반환

CSV 내용을 2차원 배열로 스필하여 반환하며, 숫자와 날짜(yyyy-M-d 등) 텍스트는 자동으로 값으로 변환됩니다. 경로 누락이나 파일 읽기·다운로드 실패 시 #VALUE!, 내용(남는 행)이 없으면 #N/A를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=IMPORTCSV("C:\data\sales.csv",1)` |  | 파일 내용에 따름 |

## 참고

- 구분자 콤마·인코딩 UTF-8 고정입니다(BOM이 있으면 BOM 우선). 다른 구분자·인코딩이 필요하면 IMPORTTEXT를 사용합니다.
- 큰따옴표 인용 필드("" 이스케이프 포함)를 인식합니다.
- skip_rows/take_rows에 음수를 주면 끝에서부터 계산합니다.
- 경로·take_rows에 배열을 지정하면 #VALUE!를 반환합니다 — 여러 건은 수식을 행별로 복사해 사용합니다.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `IMPORTCSV` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.IMPORTCSV`으로 등록됩니다.
