# SORT

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2021

배열을 정렬합니다.

## 구문

```
=SORT(배열, [정렬인덱스], [정렬순서], [열기준])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 정렬할 데이터 |
| 정렬인덱스 | 선택 | 정렬 기준 열(또는 행), 기본 1 |
| 정렬순서 | 선택 | 1 오름차순(기본), -1 내림차순 |
| 열기준 | 선택 | TRUE면 열 정렬 |

## 반환

지정한 열(또는 행)을 기준으로 정렬된 같은 크기의 배열을 반환하며 스필됩니다. sort_index가 배열 범위를 벗어나거나 내부 오류가 나면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=SORT({3;1;2})` | {1;2;3} | 오름차순 정렬 |
| `=SORT({1,3;2,1;3,2},2)` | {2,1;3,2;1,3} | 2열 기준 정렬 |
| `=SORT({5;3;9},1,-1)` | {9;5;3} | 내림차순 정렬 |

## 참고

- sort_order가 음수면 내림차순, 그 외 값(0 포함)은 오름차순으로 처리합니다(네이티브는 1/-1만 허용).
- 같은 키는 원래 순서를 유지합니다(안정 정렬).
- 관련 함수: SORTBY, UNIQUE.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `SORT` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.SORT`으로 등록됩니다. 일부 구버전에서는 예약어 충돌로 `xSORT` 이름으로 등록됩니다.
