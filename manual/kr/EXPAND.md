# EXPAND

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024 / Microsoft 365

배열을 지정 크기로 확장하고 값으로 채웁니다.

## 구문

```
=EXPAND(배열, 행수, [열수], [채울값])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 대상 배열 |
| 행수 | 필수 | 전체 행 수 |
| 열수 | 선택 | 전체 열 수(선택) |
| 채울값 | 선택 | 채움 값(기본 #N/A) |

## 반환

지정한 행수×열수 크기로 확장한 배열을 반환하며, 동적 배열을 지원하는 Excel에서는 스필됩니다. 새로 생기는 자리는 채울값(기본 #N/A)으로 채웁니다. 배열이 비었거나 지정 크기가 원본보다 작으면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=EXPAND({1,2;3,4},3,3,0)` | {1,2,0;3,4,0;0,0,0} | 3×3 확장, 0 채움 |
| `=EXPAND({1,2},1,4)` | {1,2,#N/A,#N/A} | 기본 채움값 #N/A |
| `=EXPAND({1,2;3,4},1,1)` | #VALUE! | 축소는 불가 |

## 참고

- 행수·열수를 생략하면 원본 크기를 유지합니다.
- 채울값을 생략하면 #N/A로 채웁니다.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `EXPAND` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.EXPAND`으로 등록됩니다.
