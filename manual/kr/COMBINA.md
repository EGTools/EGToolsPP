# COMBINA

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

중복을 허용한 조합의 수를 반환합니다.

## 구문

```
=COMBINA(number, number_chosen)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| number | 필수 | 전체 항목 수 |
| number_chosen | 필수 | 각 조합에서 선택할 항목 수 |

## 반환

중복을 허용한 조합의 수(스칼라 숫자)를 반환합니다. 인수가 숫자가 아니거나 음수이면 #NUM! 오류를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=COMBINA(4,3)` | 20 | 4개 중 중복 3개 조합 |
| `=COMBINA(10,3)` | 220 | 10개 중 중복 3개 조합 |

## 참고

- 소수 부분은 버리고 C(n+k-1, k)로 계산합니다.
- 관련 함수: PERMUTATIONA
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `COMBINA` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.COMBINA`으로 등록됩니다.
