# UNPIVOT

**종류**: EGTools 전용 함수

집계표(크로스탭)를 정규 데이터 표로 변환합니다.

## 구문

```
=UNPIVOT(배열, [고정열], [고정행], [정렬순서], [표제목], [집합여부])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 원본 표(제목 포함) |
| 고정열 | 선택 | 왼쪽 행머리 열 수(기본 1) |
| 고정행 | 선택 | 위쪽 열머리 행 수(기본 1) |
| 정렬순서 | 선택 | 결과 정렬: 열 번호, 음수면 내림차순, 예 {1,-3} |
| 표제목 | 선택 | 결과 표에 적용할 제목들 |
| 집합여부 | 선택 | 값 열이 집합으로 반복되면 TRUE |

## 반환

제목 행을 포함한 정규화 데이터 표를 2차원 배열(스필)로 반환합니다. 배열이 아닌 입력, 고정열·고정행이 음수이거나 범위를 벗어나거나 둘 다 0인 경우, 정렬순서가 0이거나 결과 열 범위를 벗어나면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=UNPIVOT({"Item","Jan","Feb";"A",10,20;"B",30,40},1,1,,{"Item","Month","Qty"})` | {"Item","Month","Qty";"A","Jan",10;"A","Feb",20;"B","Jan",30;"B","Feb",40} | 크로스탭 피벗 해제 |
| `=UNPIVOT({"Item","Jan","Feb";"A",10,20;"B",30,40},1,1,-3,{"Item","Month","Qty"})` | {"Item","Month","Qty";"B","Feb",40;"B","Jan",30;"A","Feb",20;"A","Jan",10} | 3열 내림차순 정렬 |

## 참고

- 값 기준으로만 동작하며 병합 셀 채움은 지원하지 않습니다.
- 값이 모두 빈 항목(셀)은 결과에서 제외됩니다.
- 표제목을 생략하면 기본 제목이 UI 언어(한국어/영어)에 따라 달라집니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `UNPIVOT` 이름 그대로 등록됩니다.
