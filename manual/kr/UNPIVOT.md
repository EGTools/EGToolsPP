# UNPIVOT

**종류**: EGTools 전용 함수

집계표(크로스탭)를 정규 데이터 표로 변환합니다.

## 구문

```
=UNPIVOT(배열, [고정열], [고정행], [정렬순서], [표제목], [집합여부])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 원본 표(제목 포함) |
| 고정열 | 선택 | 왼쪽 행머리 열 수(기본 1) |
| 고정행 | 선택 | 위쪽 열머리 행 수(기본 1) |
| 정렬순서 | 선택 | 결과 정렬: 열 번호, 음수면 내림차순, 예 {1,-3} |
| 표제목 | 선택 | 결과 표에 적용할 제목들 |
| 집합여부 | 선택 | 값 열이 집합으로 반복되면 TRUE |
