# TEXTAFTER

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024 / Microsoft 365

구분자 뒤의 텍스트를 반환합니다.

## 구문

```
=TEXTAFTER(텍스트, 구분자, [순번], [일치모드], [끝일치], [없을때값])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 원본 텍스트 |
| 구분자 | 필수 | 찾을 구분자 |
| 순번 | 선택 | 몇 번째 구분자인지, 음수면 뒤에서(기본 1) |
| 일치모드 | 선택 | 1이면 대소문자 무시(기본 0) |
| 끝일치 | 선택 | 1이면 텍스트 끝을 구분자로 간주(기본 0) |
| 없을때값 | 선택 | 못 찾을 때 값(기본 #N/A) |

## 반환

구분자 뒤의 단일 텍스트(스칼라)를 반환합니다. 순번이 0이면 #VALUE!, 구분자를 찾지 못하면 미발견값(기본 #N/A)을 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=TEXTAFTER("red-blue-green","-")` | blue-green | 첫 구분자 뒤 |
| `=TEXTAFTER("a,b,c",",",-1)` | c | 끝에서 첫 번째 뒤 |
| `=TEXTAFTER("abc","x",1,0,0,"none")` | none | 미발견값 반환 |

## 참고

- 끝일치(match_end)=1이면 텍스트 끝(양수 순번)/시작(음수 순번)을 가상 구분자 1개로 간주합니다.
- 일치모드(match_mode)=1이면 대소문자를 무시합니다.
- 관련 함수: TEXTBEFORE, TEXTSPLIT
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `TEXTAFTER` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.TEXTAFTER`으로 등록됩니다.
