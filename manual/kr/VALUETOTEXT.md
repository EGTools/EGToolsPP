# VALUETOTEXT

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024 / Microsoft 365

값을 텍스트 표현으로 반환합니다.

## 구문

```
=VALUETOTEXT(값, [형식])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 값 | 필수 | 대상 값 |
| 형식 | 선택 | 0 간단(기본), 1 엄격(텍스트 따옴표) |

## 반환

값의 텍스트 표현인 단일 텍스트(스칼라)를 반환합니다. 구현 자체가 별도의 오류 값을 반환하지는 않습니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=VALUETOTEXT(1.5)` | 1.5 | 숫자 그대로 |
| `=VALUETOTEXT("abc",1)` | "abc" | 엄격: 텍스트 따옴표 |
| `=VALUETOTEXT(TRUE)` | TRUE | 논리값 |

## 참고

- 엄격(1) 형식에서 텍스트 안의 큰따옴표는 두 번("")으로 표기됩니다.
- 관련 함수: ARRAYTOTEXT
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `VALUETOTEXT` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.VALUETOTEXT`으로 등록됩니다.
