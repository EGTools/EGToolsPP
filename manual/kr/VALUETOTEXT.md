# VALUETOTEXT

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024 / Microsoft 365

값을 텍스트 표현으로 반환합니다.

## 구문

```
=VALUETOTEXT(값, [형식])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 값 | 필수 | 대상 값 |
| 형식 | 선택 | 0 간단(기본), 1 엄격(텍스트 따옴표) |
