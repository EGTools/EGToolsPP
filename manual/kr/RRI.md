# RRI

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

투자 성장에 대한 기간당 등가 이자율을 반환합니다.

## 구문

```
=RRI(nper, pv, fv)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| nper | 필수 | 기간 수 |
| pv | 필수 | 현재 가치 |
| fv | 필수 | 미래 가치 |

## 반환

투자 성장에 해당하는 기간당 등가 이율(스칼라 숫자)을 반환합니다. 인수가 숫자가 아니거나 nper가 0 이하이거나 pv가 0이면 #NUM! 오류를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=RRI(96,10000,11000)` | 0.000993307 | 96기간 10000→11000 이율 |

## 참고

- 관련 함수: PDURATION
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `RRI` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.RRI`으로 등록됩니다.
