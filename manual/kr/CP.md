# CP

**종류**: EGTools 전용 함수

측정값과 규격 한계로 공정능력지수 Cp를 계산합니다.

## 구문

```
=CP(데이터, [상한규격], [하한규격])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 데이터 | 필수 | 측정값 범위 또는 배열 |
| 상한규격 | 선택 | USL (하한만 있으면 생략 가능) |
| 하한규격 | 선택 | LSL (상한만 있으면 생략 가능) |

## 반환

공정능력지수 Cp = (USL-LSL)/(6σ)를 스칼라 숫자로 반환합니다. data가 없거나 USL·LSL이 모두 없으면 #VALUE!, 숫자 데이터가 2개 미만이면 #NUM!, 표준편차가 0이면 #DIV/0! 오류를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=CP({1;2;3;4;5},6,0)` | 0.632455532 | 규격 0~6의 Cp |

## 참고

- 표본 표준편차(n-1)를 사용합니다.
- 한쪽 규격만 주면 없는 쪽을 평균으로 간주해 계산합니다.
- 관련 함수: CPK
- 지원: Excel 2010+. 모든 Excel 버전에서 `CP` 이름 그대로 등록됩니다.
