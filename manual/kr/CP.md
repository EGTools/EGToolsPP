# CP

**종류**: EGTools 전용 함수

측정값과 규격 한계로 공정능력지수 Cp를 계산합니다.

## 구문

```
=CP(데이터, [상한규격], [하한규격])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 데이터 | 필수 | 측정값 범위 또는 배열 |
| 상한규격 | 선택 | USL (하한만 있으면 생략 가능) |
| 하한규격 | 선택 | LSL (상한만 있으면 생략 가능) |
