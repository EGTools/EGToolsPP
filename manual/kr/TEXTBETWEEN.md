# TEXTBETWEEN

**종류**: EGTools 전용 함수

시작키와 끝키 사이의 문자열을 추출합니다.

## 구문

```
=TEXTBETWEEN(텍스트, 시작키, 끝키, [구분자또는순번], [키포함])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 처리할 문자열 |
| 시작키 | 필수 | 구간 시작 표시 |
| 끝키 | 필수 | 구간 끝 표시 |
| 구분자또는순번 | 선택 | 전체 연결자(기본 ",") 또는 숫자 N이면 N번째 하나만 |
| 키포함 | 선택 | TRUE면 시작키·끝키 포함해 추출 |

## 반환

추출된 단일 텍스트(스칼라)를 반환합니다. 텍스트·시작키·끝키 중 하나라도 비면 #VALUE!, N번째 지정이 구간 개수를 벗어나면 #VALUE!를 반환하고, 일치 구간이 없으면 빈 문자열을 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=TEXTBETWEEN("[a] and [b]","[","]")` | a,b | 모든 구간을 , 로 연결 |
| `=TEXTBETWEEN("[a] and [b]","[","]",2)` | b | 2번째 구간만 |
| `=TEXTBETWEEN("<x><y>","<",">","/",TRUE)` | <x>/<y> | 키 포함 연결 |

## 참고

- 키 검색은 대소문자를 무시합니다.
- 4번째 인수가 숫자면 N번째 구간 하나만, 텍스트면 전체 구간의 연결 구분자(기본 ",")입니다.
- 텍스트에 배열을 지정하면 원소별로 처리해 같은 모양의 배열로 스필되며(오류 원소는 그 오류 그대로), 시작키·끝키 등 다른 인수에 배열을 지정하면 #VALUE!를 반환합니다.
- 관련 함수: TEXTREPLACE
- 지원: Excel 2010+. 모든 Excel 버전에서 `TEXTBETWEEN` 이름 그대로 등록됩니다.
