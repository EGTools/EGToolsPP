# REGEXTEST

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024 / Microsoft 365

텍스트가 정규식과 일치하는지 검사합니다.

## 구문

```
=REGEXTEST(텍스트, 패턴, [대소문자구분])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 검사할 텍스트 |
| 패턴 | 필수 | 정규식 패턴(ECMAScript) |
| 대소문자구분 | 선택 | 0 구분(기본), 1 무시 |
