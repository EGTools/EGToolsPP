# XMATCH

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2021

배열에서 값의 위치를 반환합니다.

## 구문

```
=XMATCH(찾을값, 찾을배열, [일치모드], [검색모드])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 찾을값 | 필수 | 찾을 값 |
| 찾을배열 | 필수 | 검색 배열 |
| 일치모드 | 선택 | 0 정확(기본), -1 작은값, 1 큰값 |
| 검색모드 | 선택 | 1 앞에서(기본), -1 뒤에서 |

## 반환

찾은 위치(1부터 시작)를 숫자 스칼라로 반환합니다. 배열이 비었거나 일치 항목이 없으면 #N/A, 내부 오류면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=XMATCH(3,{1;2;3;4})` | 3 | 정확 일치 위치 |
| `=XMATCH(2.5,{1;2;3},1)` | 3 | 크거나 같은 값 위치 |
| `=XMATCH(5,{1;2;3})` | #N/A | 불일치 시 #N/A |

## 참고

- match_mode 2(와일드카드)와 search_mode 2/-2(이진 검색)는 지원하지 않습니다.
- 관련 함수: XLOOKUP.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `XMATCH` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.XMATCH`으로 등록됩니다.
