# XMATCH

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2021

배열에서 값의 위치를 반환합니다.

## 구문

```
=XMATCH(찾을값, 찾을배열, [일치모드], [검색모드])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 찾을값 | 필수 | 찾을 값 |
| 찾을배열 | 필수 | 검색 배열 |
| 일치모드 | 선택 | 0 정확(기본), -1 작은값, 1 큰값 |
| 검색모드 | 선택 | 1 앞에서(기본), -1 뒤에서 |
