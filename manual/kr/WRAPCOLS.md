# WRAPCOLS

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024 / Microsoft 365

벡터를 열마다 지정 개수씩 감싸 2차원 배열로 만듭니다.

## 구문

```
=WRAPCOLS(벡터, 감쌀개수, [채울값])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 벡터 | 필수 | 감쌀 벡터 |
| 감쌀개수 | 필수 | 열당 값 개수 |
| 채울값 | 선택 | 채움 값(기본 #N/A) |

## 반환

벡터의 값을 열마다 감쌀개수 개씩 세로로 배치한 2차원 배열을 반환하며, 동적 배열을 지원하는 Excel에서는 스필됩니다. 마지막 열의 부족한 자리는 채울값(기본 #N/A)으로 채웁니다. 벡터가 비었거나 감쌀개수가 0 이하이면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=WRAPCOLS({1,2,3,4,5},2)` | {1,3,5;2,4,#N/A} | 열당 2개씩 배치 |
| `=WRAPCOLS({1,2,3,4,5},3,0)` | {1,4;2,5;3,0} | 채울값 0 |

## 참고

- 2차원 배열 입력도 행 우선으로 평탄화하여 처리합니다.
- 관련 함수: WRAPROWS
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `WRAPCOLS` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.WRAPCOLS`으로 등록됩니다.
