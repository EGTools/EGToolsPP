# READBARCODE

**종류**: EGTools 전용 함수

이미지 파일이나 URL에서 바코드를 읽어 내용을 반환합니다.

## 구문

```
=READBARCODE(원본, [결과형식])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 원본 | 필수 | PC 파일 경로 또는 http(s) URL |
| 결과형식 | 선택 | 1=텍스트(기본), 2=코드텍스트, 3=형식, 4=심볼로지ID, 5=Raw HEX — {1,3}처럼 배열 지정 가능 |

## 반환

이미지에서 읽은 바코드 내용을 결과형식 인수와 같은 모양으로 반환합니다({1,3}처럼 배열이면 스필). 원본이 비었거나 결과형식 값이 잘못되면 #VALUE!, URL 다운로드에 실패하면 #NULL!, 파일이 없거나 이미지를 읽지 못하거나 바코드를 찾지 못하면 #N/A를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=READBARCODE("C:\barcodes\qr.png")` |  | 이미지의 바코드 텍스트(파일 내용에 따라 결과 다름) |
| `=READBARCODE("https://example.com/code.png",{1,3})` |  | 텍스트와 형식을 함께 반환(네트워크 의존) |

## 참고

- WIC가 지원하는 PNG/JPG/BMP/GIF 형식을 읽으며, 로컬 파일 경로와 http(s) URL 모두 사용할 수 있습니다.
- 결과형식: 1 텍스트(기본), 2 코드텍스트(제어문자를 <GS> 등으로 표시), 3 형식, 4 심볼로지 ID, 5 Raw HEX.
- 회전·저품질 이미지도 시도하지만(TryHarder/TryRotate) 바코드 하나만 읽습니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `READBARCODE` 이름 그대로 등록됩니다.
