# IFNA

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

값이 #N/A 오류이면 대체값을, 아니면 값을 반환합니다.

## 구문

```
=IFNA(값, 대체값)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 값 | 필수 | 값 또는 식 |
| 대체값 | 필수 | #N/A일 때 반환할 값 |

## 반환

값이 #N/A 오류면 대체값을, 아니면 원래 값을 반환합니다. 배열을 주면 요소별로 적용한 배열을 반환하며 스필됩니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=IFNA(NA(),"none")` | none | #N/A를 대체 |
| `=IFNA(1/0,0)` | #DIV/0! | #N/A 외 오류는 유지 |
| `=IFNA(5,0)` | 5 | 정상 값 유지 |

## 참고

- 배열 입력 시 요소별로 #N/A만 대체합니다(배열 반환·스필).
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `IFNA` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.IFNA`으로 등록됩니다.
