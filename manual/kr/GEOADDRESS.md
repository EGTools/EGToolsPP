# GEOADDRESS

**종류**: EGTools 전용 함수

좌표에 해당하는 주소를 구합니다(VWorld 역지오코딩).

## 구문

```
=GEOADDRESS(x, y, [주소유형], [EPSG], [api_key])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| x | 필수 | 경도 또는 x좌표 |
| y | 필수 | 위도 또는 y좌표 |
| 주소유형 | 선택 | 1 지번(기본), 2 도로명, 3 모두 |
| EPSG | 선택 | 좌표계 EPSG 코드(기본 4326=WGS84) |
| api_key | 선택 | vworld.kr 인증키, 1회 입력하면 레지스트리에 저장 |

## 반환

좌표에 해당하는 주소 텍스트를 반환합니다(주소유형=3이면 지번·도로명 2행으로 스필). 주소유형이 1~3을 벗어나거나 EPSG가 유효하지 않거나 EPSG 4326에서 좌표가 범위를 벗어나면 #VALUE!, 주소가 없으면 #N/A를 반환하고, 키 누락·네트워크·서비스 오류는 "ERROR: …" 텍스트로 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=GEOADDRESS(126.9779,37.5663)` |  | 좌표의 지번 주소(네트워크·API 키 필요) |

## 참고

- API 키는 배포되지 않습니다. 공간정보 오픈플랫폼(https://www.vworld.kr)에서 발급받아 마지막 인수로 1회 입력하면 레지스트리에 저장되며, 키가 거부되면 자동 삭제 후 재발급 안내를 반환합니다.
- x·y 좌표·api_key에 배열을 지정하면 #VALUE!를 반환합니다(api_key는 저장 전에 거부되어 잘못된 키 저장을 방지) — 여러 건은 수식을 행별로 복사해 사용합니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `GEOADDRESS` 이름 그대로 등록됩니다.
