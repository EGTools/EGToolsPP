# CHOOSECOLS

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024 / Microsoft 365

배열에서 지정한 열들을 반환합니다.

## 구문

```
=CHOOSECOLS(배열, 열번호1, ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 대상 배열 |
| 열번호1 | 필수 | 반환할 열(음수=뒤에서) |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |
