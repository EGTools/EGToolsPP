# KOREANHOLIDAYS

**종류**: EGTools 전용 함수

대한민국 공휴일 목록을 반환합니다(대체공휴일 규칙 포함).

## 구문

```
=KOREANHOLIDAYS([연도], [이름포함], [노동절], [api_key])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 연도 | 선택 | 연도(기본: 올해) |
| 이름포함 | 선택 | TRUE면 휴일 이름 포함(기본), FALSE면 날짜만 |
| 노동절 | 선택 | TRUE면 노동절 포함(기본) |
| api_key | 선택 | 임시공휴일 조회용 data.go.kr 키. 한 번 입력하면 저장되어 이후 생략 가능. 0을 지정하면 API를 쓰지 않고 내장 계산만 사용 |

## 반환

각 행이 [날짜 직렬값, 휴일 이름]인 2열 배열로 스필됩니다(이름포함=FALSE면 날짜 1열만). 연도가 919~2050 범위를 벗어나면 #VALUE! 오류를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=ROWS(KOREANHOLIDAYS(2025,,,0))` | 18 | 2025년 휴일 행 수 — 마지막 인수 0은 API를 쓰지 않고 내장 계산만 사용합니다 |
| `=INDEX(KOREANHOLIDAYS(2025,FALSE,,0),1,1)` | 45658 | 첫 휴일(1월 1일) 직렬값, 날짜만(이름 제외) |
| `=KOREANHOLIDAYS(2026)` |  | 기본 동작 — 저장된 data.go.kr 키로 임시공휴일(2026-06-03 전국동시지방선거일 등)까지 병합합니다. 결과 행 수는 키 등록·네트워크 상태에 따라 달라집니다 |

## 참고

- 대체공휴일 규칙을 시행 연도별로 반영합니다(어린이날 2014~, 삼일절·광복절·개천절 2022~, 석가탄신일·성탄절 2023~).
- 휴일 이름은 추가 기능 언어 설정(한국어/영어)을 따르며, 같은 날 겹치는 휴일 이름은 쉼표로 병합됩니다.
- 음력 휴일(설날·석가탄신일·추석)은 내장 음력표(918~2050년)로 계산합니다.
- api_key 인수는 세 가지로 씁니다. **생략**하면(기본 동작) 저장된 data.go.kr 키로 특일정보 API를 조회해 임시공휴일·선거일 등 내장 계산에 없는 항목을 자동 병합하고, 키가 없거나 조회에 실패하면 내장 계산 결과만 반환합니다(수식이 오류로 깨지지 않습니다). **키 문자열을 지정**하면 그 키를 저장하고 사용하며, 이때 조회에 실패하면 셀에 `ERROR: 공휴일 API - <사유>` 형태로 원인(키 없음 / 키 거부 + 서버 메시지 / 서버 연결 실패 / 응답에 항목 없음)을 표시합니다. **0을 지정**하면 API를 호출하지 않고 내장 계산만 사용합니다(네트워크 접근 없음).
- data.go.kr(공공데이터포털) 인증키는 계정당 하나이며 KOREANHOLIDAYS·리본 달력/일정표·BRNSTATUS가 같은 키를 공유합니다. 마지막 인수로 1회 전달하거나 리본 [EGTools] → [API 키 관리]에서 등록하면 사용자 계정에 저장되어 이후 생략할 수 있고, 예전 버전에서 사업자등록용으로 등록해 둔 키는 처음 사용할 때 자동으로 통합 슬롯으로 옮겨집니다.
- 조회 결과는 연도별로 캐시되어 재계산해도 같은 연도는 한 번만 호출합니다. 실패는 캐시하지 않으므로 키를 고치면 다음 계산에 바로 반영됩니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `KOREANHOLIDAYS` 이름 그대로 등록됩니다.
