# KOREANHOLIDAYS

**종류**: EGTools 전용 함수

대한민국 공휴일 목록을 반환합니다(대체공휴일 규칙 포함).

## 구문

```
=KOREANHOLIDAYS([연도], [이름포함], [노동절], [api_key])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 연도 | 선택 | 연도(기본: 올해) |
| 이름포함 | 선택 | TRUE면 휴일 이름 포함(기본), FALSE면 날짜만 |
| 노동절 | 선택 | TRUE면 노동절 포함(기본) |
| api_key | 선택 | 임시공휴일 조회용 data.go.kr 키. 한 번 입력하면 레지스트리에 저장됩니다 |

## 반환

각 행이 [날짜 직렬값, 휴일 이름]인 2열 배열로 스필됩니다(이름포함=FALSE면 날짜 1열만). 연도가 919~2050 범위를 벗어나면 #VALUE! 오류를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=ROWS(KOREANHOLIDAYS(2025))` | 18 | 2025년 휴일 행 수(내장 계산 기준 — api_key 등록 시 임시공휴일 등이 더해져 늘어날 수 있음) |
| `=INDEX(KOREANHOLIDAYS(2025,FALSE),1,1)` | 45658 | 첫 휴일(1월 1일) 직렬값 |

## 참고

- 대체공휴일 규칙을 시행 연도별로 반영합니다(어린이날 2014~, 삼일절·광복절·개천절 2022~, 석가탄신일·성탄절 2023~).
- 휴일 이름은 추가 기능 언어 설정(한국어/영어)을 따르며, 같은 날 겹치는 휴일 이름은 쉼표로 병합됩니다.
- 음력 휴일(설날·석가탄신일·추석)은 내장 음력표(918~2050년)로 계산합니다.
- api_key(공공데이터포털 data.go.kr 키)가 있으면 특일정보 API를 조회해 임시공휴일·선거일 등 내장 계산에 없는 항목을 병합합니다. 키는 한 번 인수로 전달하면 레지스트리(HKCU\Software\EGTools\ApiKeys)에 저장되어 이후 생략할 수 있고, 리본 EGTools→API 키 관리에서도 등록할 수 있습니다. 키가 없거나 조회에 실패하면 내장 계산 결과만 반환합니다(연도별 캐시).
- 지원: Excel 2010+. 모든 Excel 버전에서 `KOREANHOLIDAYS` 이름 그대로 등록됩니다.
