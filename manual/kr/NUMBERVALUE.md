# NUMBERVALUE

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

로캘과 무관하게 텍스트를 숫자로 변환합니다.

## 구문

```
=NUMBERVALUE(텍스트, [소수구분기호], [자리구분기호])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 변환할 텍스트 |
| 소수구분기호 | 선택 | 소수점 기호(기본 .) |
| 자리구분기호 | 선택 | 자릿수 구분 기호(기본 ,) |

## 반환

숫자(스칼라)를 반환하며, 텍스트에 배열을 지정하면 요소별로 계산되어 동적 배열에서 스필됩니다. 구분 기호 제거 후 숫자로 해석되지 않으면 #VALUE!를 반환하고, 빈 텍스트(공백만 포함)는 0을 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=NUMBERVALUE("2.500,27",",",".")` | 2500.27 | 유럽식 표기 변환 |
| `=NUMBERVALUE("9%%")` | 0.0009 | %마다 100으로 나눔 |
| `=NUMBERVALUE("abc")` | #VALUE! | 숫자 아님 |

## 참고

- 모든 공백 문자는 위치와 관계없이 무시되고, 자릿수 구분 기호는 어디에 있든 제거됩니다.
- 끝의 % 기호는 개수만큼 100으로 나눕니다.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `NUMBERVALUE` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.NUMBERVALUE`으로 등록됩니다.
