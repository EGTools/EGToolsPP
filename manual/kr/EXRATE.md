# EXRATE

**종류**: EGTools 전용 함수

지정일의 원화 기준환율을 조회합니다(최대 10일 소급).

## 구문

```
=EXRATE([통화], [날짜])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 통화 | 선택 | 3자리 통화코드, 예 USD(기본), EUR, JPY… |
| 날짜 | 선택 | 조회할 날짜(기본: 오늘) |
