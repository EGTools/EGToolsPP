# BASE

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

수를 지정한 진법(기수)의 텍스트로 변환합니다.

## 구문

```
=BASE(number, radix, [min_length])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| number | 필수 | 변환할 수(0 이상) |
| radix | 필수 | 기수 2~36 |
| min_length | 선택 | [선택] 결과 최소 길이 |

## 반환

지정한 진법으로 표기한 텍스트(스칼라)를 반환합니다. number가 음수이거나 숫자가 아니거나 radix가 2~36 범위를 벗어나면 #NUM! 오류를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=BASE(255,16)` | FF | 255를 16진수로 |
| `=BASE(15,2,8)` | 00001111 | 최소 길이만큼 0 채움 |

## 참고

- number의 소수 부분은 버립니다(내림).
- 결과가 min_length보다 짧으면 앞을 0으로 채웁니다.
- 관련 함수: DECIMAL
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `BASE` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.BASE`으로 등록됩니다.
