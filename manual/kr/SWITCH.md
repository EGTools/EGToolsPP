# SWITCH

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2016/2019

식을 값들과 비교해 처음 일치하는 결과(또는 기본값)를 반환합니다.

## 구문

```
=SWITCH(식, 값1, 결과1, [기본값], ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 식 | 필수 | 비교할 값 |
| 값1 | 필수 | 일치 비교 값 |
| 결과1 | 필수 | 값 일치 시 결과 |
| 기본값 | 선택 | 기본값 / 값2 … |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |

## 반환

식과 처음 일치하는 값의 결과(또는 마지막 기본값)를 그대로 반환합니다. 일치하는 값도 기본값도 없으면 #N/A를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=SWITCH(2,1,"one",2,"two","other")` | two | 일치 값의 결과 |
| `=SWITCH(9,1,"one","other")` | other | 기본값 반환 |

## 참고

- 중간 인수를 비워 두면 그 이후의 값/결과 쌍은 무시됩니다.
- 관련 함수: IFS.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `SWITCH` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.SWITCH`으로 등록됩니다.
