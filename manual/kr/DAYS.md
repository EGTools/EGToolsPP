# DAYS

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

두 날짜 사이의 일수를 반환합니다(끝−시작).

## 구문

```
=DAYS(끝날짜, 시작날짜)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 끝날짜 | 필수 | 끝 날짜 |
| 시작날짜 | 필수 | 시작 날짜 |

## 반환

끝날짜에서 시작날짜를 뺀 일수를 숫자(스칼라)로 반환합니다. 각 날짜의 시간 부분은 버리고 계산합니다. 인수를 생략하면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=DAYS(DATE(2026,3,1),DATE(2026,1,15))` | 45 | 두 날짜 사이 일수 |
| `=DAYS(DATE(2026,1,1),DATE(2026,1,31))` | -30 | 끝이 빠르면 음수 |

## 참고

- 날짜 형식 텍스트("2026-01-15" 등)는 해석하지 않고 #VALUE!를 반환하며, 빈 셀은 0으로 처리됩니다.
- 두 날짜 인수 모두에 배열을 지정하면 원소별로 계산해 같은 모양의 배열로 스필됩니다 — 스칼라는 반복, 열 벡터×행 벡터는 외적으로 확장, 크기가 맞지 않는 원소는 #N/A, 오류 원소는 그 오류를 그대로 반환합니다.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `DAYS` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.DAYS`으로 등록됩니다.
