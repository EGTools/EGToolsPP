# FILTERXML

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

지정한 XPath로 XML 내용에서 데이터를 반환합니다.

## 구문

```
=FILTERXML(xml, xpath)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| xml | 필수 | XML 텍스트 |
| xpath | 필수 | XPath 식 |
