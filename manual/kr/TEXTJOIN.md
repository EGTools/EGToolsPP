# TEXTJOIN

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2016/2019

구분 기호로 텍스트를 결합합니다(빈 셀 무시 옵션).

## 구문

```
=TEXTJOIN(구분기호, 빈칸무시, 텍스트1, ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 구분기호 | 필수 | 항목 사이 구분자 |
| 빈칸무시 | 필수 | TRUE면 빈 셀 제외 |
| 텍스트1 | 필수 | 텍스트/범위 |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |

## 반환

구분 기호로 이어 붙인 단일 텍스트(스칼라)를 반환합니다. 구현 자체가 별도의 오류 값을 반환하지는 않습니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=TEXTJOIN("-",TRUE,"a","","b")` | a-b | 빈 값 건너뜀 |
| `=TEXTJOIN("-",FALSE,"a","","b")` | a--b | 빈 값 유지 |
| `=TEXTJOIN(",",TRUE,{1,2;3,4})` | 1,2,3,4 | 배열 요소 연결 |

## 참고

- 빈칸무시를 생략하면 TRUE로 처리합니다.
- 텍스트 인수는 최대 255개까지 지원합니다.
- 관련 함수: CONCAT
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `TEXTJOIN` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.TEXTJOIN`으로 등록됩니다.
