# SAMPLINGRE

**종류**: EGTools 전용 함수

ISO 2859-1의 불합격판정개수(Re)를 구합니다.

## 구문

```
=SAMPLINGRE(LOT수량, AQL, [검사수준], [엄격도], [방식], [차수])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| LOT수량 | 필수 | 검사할 LOT/배치 수량 |
| AQL | 필수 | 합격품질한계 |
| 검사수준 | 선택 | 기본 G2 |
| 엄격도 | 선택 | 0 보통, 1 까다로운, -1 수월한 |
| 방식 | 선택 | 1 1회, 2 2회, 3~5 다회 |
| 차수 | 선택 | 검사 차수 |

## 반환

ISO 2859-1 불합격판정개수 Re(스칼라 숫자)를 반환합니다. AQL이 0~1000 밖이거나 검사수준·방식·차수가 잘못되면 #VALUE!, LOT수량이 2 미만이거나 AQL이 0.01 미만이면 #NUM!, 표에서 해당 값을 찾지 못하면 #N/A 오류를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=SAMPLINGRE(1000,1)` | 3 | G2·보통·1회, AQL 1.0 |
| `=SAMPLINGRE(1000,1,"G2",0,2,1)` | 3 | 2회 샘플링 1차 Re |

## 참고

- 1회 샘플링에서는 Re = Ac + 1입니다.
- LOT수량이 1이면 1을 반환합니다.
- 모든 인수에 배열을 지정할 수 있어 LOT 목록이나 AQL 표를 한 번에 계산할 수 있습니다 — 원소별로 계산해 같은 모양의 배열로 스필되며, 스칼라는 반복, 열 벡터×행 벡터는 외적으로 확장, 크기 불일치 원소는 #N/A입니다.
- 관련 함수: SAMPLINGSIZE, SAMPLINGAC, SAMPLINGLABEL
- 지원: Excel 2010+. 모든 Excel 버전에서 `SAMPLINGRE` 이름 그대로 등록됩니다.
