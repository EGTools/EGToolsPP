# TEXTREPLACE

**종류**: EGTools 전용 함수

시작키~끝키 구간을 모두 대체합니다.

## 구문

```
=TEXTREPLACE(텍스트, 시작키, 끝키, [대체문자], [키유지])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 처리할 문자열 |
| 시작키 | 필수 | 구간 시작 표시 |
| 끝키 | 필수 | 구간 끝 표시 |
| 대체문자 | 선택 | 대체할 문자열(기본 빈 문자열) |
| 키유지 | 선택 | TRUE면 시작키·끝키를 남기고 안쪽만 대체 |

## 반환

대체가 적용된 단일 텍스트(스칼라)를 반환합니다. 텍스트·시작키·끝키 중 하나라도 비면 오류 대신 원본 텍스트를 그대로 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=TEXTREPLACE("a[x]b[y]c","[","]","*")` | a*b*c | 모든 구간을 *로 대체 |
| `=TEXTREPLACE("a<1>b","<",">","2",TRUE)` | a<2>b | 키 유지 대체 |

## 참고

- 키 검색은 대소문자를 무시합니다.
- 끝키가 없는 시작키를 만나면 그 시작키 자리만 대체되고 나머지 텍스트는 남습니다.
- 관련 함수: TEXTBETWEEN
- 지원: Excel 2010+. 모든 Excel 버전에서 `TEXTREPLACE` 이름 그대로 등록됩니다.
