# TEXTREPLACE

**종류**: EGTools 전용 함수

시작키~끝키 구간을 모두 대체합니다.

## 구문

```
=TEXTREPLACE(텍스트, 시작키, 끝키, [대체문자], [키유지])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 처리할 문자열 |
| 시작키 | 필수 | 구간 시작 표시 |
| 끝키 | 필수 | 구간 끝 표시 |
| 대체문자 | 선택 | 대체할 문자열(기본 빈 문자열) |
| 키유지 | 선택 | TRUE면 시작키·끝키를 남기고 안쪽만 대체 |
