# RANDARRAY

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2021

난수 배열을 반환합니다.

## 구문

```
=RANDARRAY([행수], [열수], [최소], [최대], [정수])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 행수 | 선택 | 행 개수(기본 1) |
| 열수 | 선택 | 열 개수(기본 1) |
| 최소 | 선택 | 최소값(기본 0) |
| 최대 | 선택 | 최대값(기본 1) |
| 정수 | 선택 | TRUE면 정수 |
