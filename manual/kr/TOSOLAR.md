# TOSOLAR

**종류**: EGTools 전용 함수

한국 음력을 양력(그레고리력)으로 변환합니다(919~2050년).

## 구문

```
=TOSOLAR(음력날짜)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 음력날짜 | 필수 | "2025-06-05" 형식 — 윤달은 윤/LM 표기 — 또는 범위 |

## 반환

양력 날짜 직렬값(스칼라 숫자)을 반환하며, 범위를 입력하면 같은 크기의 배열로 스필됩니다. 텍스트를 해석할 수 없거나 음력표 범위(918~2050년)를 벗어나거나 존재하지 않는 음력 날짜이면 #VALUE! 오류를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=TOSOLAR("2025-01-01")` | 45686 | 음력 설날 → 2025-01-29 |
| `=TOSOLAR("2025-08-15")` | 45936 | 음력 추석 → 2025-10-06 |

## 참고

- 윤달은 "윤" 또는 "LM"을 붙여 표기합니다(예: "2025-윤06-01").
- 결과 셀에 날짜 표시 형식을 지정해 사용합니다.
- 관련 함수: TOLUNAR
- 지원: Excel 2010+. 모든 Excel 버전에서 `TOSOLAR` 이름 그대로 등록됩니다.
