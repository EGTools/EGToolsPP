# ADDRESSMAP

**종류**: EGTools 전용 함수

주소의 지적도 이미지를 호출 셀에 삽입합니다(VWorld WMS).

## 구문

```
=ADDRESSMAP(주소, [확대수준], [api_key])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 주소 | 필수 | 도로명 또는 지번 주소 |
| 확대수준 | 선택 | 1~10(기본 5), 클수록 좁은 지역 확대 |
| api_key | 선택 | vworld.kr 인증키, 1회 입력하면 레지스트리에 저장 |

## 반환

성공하면 빈 문자열("")을 반환하고, 주소 일대의 지적도(VWorld WMS) 그림이 호출 셀 크기에 맞춰 별도로 삽입됩니다. 주소가 비었거나 확대수준이 1~10을 벗어나면 #VALUE!, 주소를 찾지 못하면 #N/A, 호출 셀을 알 수 없으면 #REF!를 반환하고, 키 누락·네트워크·서비스 오류는 "ERROR: …" 텍스트로 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=ADDRESSMAP("세종대로 110",7)` |  | 지적도 그림 삽입(이미지 삽입·네트워크·API 키 필요) |

## 참고

- API 키는 배포되지 않습니다. 공간정보 오픈플랫폼(https://www.vworld.kr)에서 발급받아 마지막 인수로 1회 입력하면 레지스트리(HKCU\Software\EGTools\ApiKeys)에 저장되며, 키가 거부되면 자동 삭제 후 재발급 안내를 반환합니다.
- 주소를 좌표로 변환(도로명→지번)한 뒤 연속지적도 레이어가 포함된 지도를 가져옵니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `ADDRESSMAP` 이름 그대로 등록됩니다.
