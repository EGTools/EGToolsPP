# VISIBLEAGGR

**종류**: EGTools 전용 함수

범위에서 보이는 셀만 나열하거나 집계합니다.

## 구문

```
=VISIBLEAGGR(범위, [함수])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 범위 | 필수 | 계산할 셀 범위 |
| 함수 | 선택 | SUM/AVERAGE/COUNT/COUNTA/MAX/MIN/PRODUCT, 생략하면 보이는 셀 나열 |

## 반환

함수를 생략하면 보이는 셀만 모은 배열을 스필하고, SUM/AVERAGE/COUNT/COUNTA/MAX/MIN/PRODUCT를 지정하면 보이는 셀의 집계값을 반환합니다. 보이는 셀이 없으면 #N/A, 알 수 없는 함수명이면 #VALUE!, AVERAGE에 숫자가 없으면 #DIV/0!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=VISIBLEAGGR(A1:A10,"SUM")` |  | 보이는 셀의 합계(숨김 상태에 따라 결과 다름) |
| `=VISIBLEAGGR(A1:B10)` |  | 보이는 셀만 나열(숨김 상태에 따라 결과 다름) |

## 참고

- 오류 값이 있는 셀은 집계에서 건너뜁니다.
- 숨김 상태를 바꾸는 것만으로는 재계산되지 않아 F9가 필요하며, 매크로형이라 멀티스레드 재계산에서도 제외됩니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `VISIBLEAGGR` 이름 그대로 등록됩니다.
