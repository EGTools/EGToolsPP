# LET

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2021

이름에 값을 지정하고 마지막 계산식에서 사용합니다.

## 구문

```
=LET(name1, value1, calculation, ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| name1 | 필수 | 정의할 이름 |
| value1 | 필수 | 이 이름의 값 |
| calculation | 필수 | 이름들을 사용한 최종 계산식 |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |
