# PERMUTATIONA

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

중복을 허용한 순열의 수(number^number_chosen)를 반환합니다.

## 구문

```
=PERMUTATIONA(number, number_chosen)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| number | 필수 | 전체 항목 수 |
| number_chosen | 필수 | 각 순열에서 선택할 항목 수 |
