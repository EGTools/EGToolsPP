# TOTALPAGES

**종류**: EGTools 전용 함수

현재 인쇄 설정으로 인쇄할 때의 전체 페이지 수입니다(인쇄 전 재계산 필요).

## 구문

```
=TOTALPAGES([시작번호무시])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 시작번호무시 | 선택 | TRUE면 시작 페이지 번호 설정을 무시하고 1부터 |
