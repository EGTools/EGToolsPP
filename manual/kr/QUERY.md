# QUERY

**종류**: Google Sheets 호환 함수

데이터에 SQL 쿼리를 실행합니다(테이블명: EGTOOLS).

## 구문

```
=QUERY(데이터, 쿼리문, [제목행수])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 데이터 | 필수 | 쿼리할 범위 또는 배열 |
| 쿼리문 | 필수 | SQL 문, 예 "SELECT F1, SUM(F2) FROM EGTOOLS GROUP BY F1" |
| 제목행수 | 선택 | 헤더 행 수: N≥1이면 위 N행이 필드명, 0 없음(F1, F2, …), -1/생략 자동 추정 |
