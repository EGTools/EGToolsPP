# SEARCHADDRESS

**종류**: EGTools 전용 함수

주소를 검색합니다(도로명주소 juso.go.kr).

## 구문

```
=SEARCHADDRESS(텍스트, [출력항목], [행], [api_key])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 검색할 주소 키워드 |
| 출력항목 | 선택 | 출력할 열 1~27, {1,2}처럼 배열 가능: 1 우편번호, 2 도로명주소(기본), 3 지번주소, 4 영문주소 |
| 행 | 선택 | 출력할 행 번호, 0/생략이면 전체 |
| api_key | 선택 | juso.go.kr 승인키, 1회 입력하면 레지스트리에 저장 |

## 반환

검색된 주소를 선택한 출력항목 열로 구성한 텍스트 배열로 반환하며 스필됩니다(행=0이면 전체, 최대 100건). 검색어가 비었거나 출력항목이 1~27을 벗어나면 #VALUE!, 결과가 없으면 #N/A를 반환하고, 키 누락·네트워크·서비스 오류는 "ERROR: …" 텍스트로 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=SEARCHADDRESS("세종대로 110")` |  | 도로명주소 검색(네트워크·API 키 필요) |
| `=SEARCHADDRESS("세종대로 110",{1,2},1)` |  | 우편번호+도로명주소 1행(네트워크·API 키 필요) |

## 참고

- API 키는 배포되지 않습니다. 주소기반산업지원서비스( https://www.juso.go.kr )에서 발급받아 마지막 인수로 1회 입력하면 레지스트리에 저장되어 이후 생략할 수 있습니다.
- 서비스가 키를 거부하면(만료/미등록) 저장된 키를 자동 삭제하고 재발급 안내를 반환합니다.
- 출력항목: 1 우편번호, 2 도로명주소(기본), 3 지번주소, 4 영문주소 등 27개 필드.
- 검색어·api_key에 배열을 지정하면 #VALUE!를 반환합니다(api_key는 저장 전에 거부되어 잘못된 키 저장을 방지) — 여러 건은 수식을 행별로 복사해 사용합니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `SEARCHADDRESS` 이름 그대로 등록됩니다.
