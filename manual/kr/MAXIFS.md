# MAXIFS

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2016/2019

모든 조건을 만족하는 셀의 최대값을 반환합니다.

## 구문

```
=MAXIFS(최대범위, 조건범위1, 조건1, ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 최대범위 | 필수 | 최대값 대상 셀 |
| 조건범위1 | 필수 | 검사할 범위 |
| 조건1 | 필수 | 조건, 예 ">5" |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |

## 반환

모든 조건을 만족하는 셀의 숫자 값 중 최대값을 숫자 스칼라로 반환합니다. 조건 범위의 크기가 대상 범위와 다르면 #VALUE!, 만족하는 값이 없으면 0을 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=MAXIFS({1;5;3},{1;2;3},">1")` | 5 | 조건 만족 최대값 |
| `=MAXIFS({10;20},{1;2},">5")` | 0 | 불일치 시 0 |

## 참고

- 조건은 숫자, 비교 연산자(">5" 등), 와일드카드(*, ?)를 지원하며 텍스트 비교는 대소문자를 구분하지 않습니다.
- 관련 함수: MINIFS.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `MAXIFS` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.MAXIFS`으로 등록됩니다.
