# BOMTREE

**종류**: EGTools 전용 함수

모품목/자품목/소요량 목록으로 BOM 트리를 구성합니다.

## 구문

```
=BOMTREE(모품목, 자품목, 소요량, [제목행], [WBS])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 모품목 | 필수 | 모품목 열 |
| 자품목 | 필수 | 자품목 열(같은 길이) |
| 소요량 | 필수 | 소요량 열(같은 길이) |
| 제목행 | 선택 | TRUE면 제목 행 추가 |
| WBS | 선택 | TRUE면 WBS 열 추가 |

## 반환

레벨·모품목·자품목·값(WBS 선택 시 5열) 열로 전개된 BOM 트리를 2차원 배열(스필)로 반환합니다. 세 목록이 비었거나 길이가 다르면 #VALUE!를, 같은 모품목-자품목 쌍에 서로 다른 값이 있으면 "Error: ..." 텍스트를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=BOMTREE({"X";"X";"Y"},{"Y";"Z";"W"},{1;2;3})` | {0,"Top Level","X","";1,"X","Y",1;2,"Y","W",3;1,"X","Z",2} | BOM 트리 전개 |
| `=BOMTREE({"X";"X";"Y"},{"Y";"Z";"W"},{1;2;3},TRUE)` | {"level","Parent","Child","Value";0,"Top Level","X","";1,"X","Y",1;2,"Y","W",3;1,"X","Z",2} | 제목 행 포함 |

## 참고

- WBS 번호는 정렬 유지를 위해 폭 0 공백(U+200B)으로 5자리를 채웁니다.
- 전개 깊이는 64로 제한됩니다(순환 참조 가드).
- 모품목 셀이 빈 행을 만나면 그 지점에서 목록 읽기를 중단합니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `BOMTREE` 이름 그대로 등록됩니다.
