# ISVISIBLE

**종류**: EGTools 전용 함수

범위의 각 셀이 보이는지(행/열 숨김 아님) 확인합니다.

## 구문

```
=ISVISIBLE(범위)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 범위 | 필수 | 확인할 셀 범위 |

## 반환

각 셀이 보이면 TRUE, 행이나 열이 숨겨져 있으면 FALSE인 배열을 범위와 같은 크기로 반환하며 스필됩니다. 셀 수가 100,000개를 넘거나 COM 연결에 실패하면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=ISVISIBLE(A1:A5)` |  | 각 셀의 표시 여부(숨김 상태에 따라 결과 다름) |

## 참고

- 행/열 숨김을 바꾸는 것만으로는 재계산되지 않으므로 F9로 다시 계산해야 합니다.
- 매크로형 함수라 멀티스레드 재계산에서 제외됩니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `ISVISIBLE` 이름 그대로 등록됩니다.
