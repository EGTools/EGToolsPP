# DROP

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024

배열의 처음/끝에서 행·열을 제거합니다.

## 구문

```
=DROP(배열, 행수, [열수])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 대상 배열 |
| 행수 | 필수 | 제거할 행(음수=뒤에서) |
| 열수 | 선택 | 제거할 열(선택) |

## 반환

지정한 수의 행·열을 제거한 나머지 배열을 반환하며, 동적 배열을 지원하는 Excel에서는 스필됩니다. 배열이 비었거나 제거 후 남는 행·열이 없으면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=DROP({1,2,3;4,5,6;7,8,9},1)` | {4,5,6;7,8,9} | 첫 행 제거 |
| `=DROP({1,2,3;4,5,6;7,8,9},1,-1)` | {4,5;7,8} | 첫 행·끝 열 제거 |
| `=DROP({1,2},5)` | #VALUE! | 전부 제거되면 오류 |

## 참고

- 행수·열수가 음수이면 끝에서부터 제거합니다.
- 결과가 빈 배열이 되면 네이티브의 #CALC! 대신 #VALUE!를 반환합니다.
- 관련 함수: TAKE
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `DROP` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.DROP`으로 등록됩니다.
