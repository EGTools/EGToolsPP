# DROP

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024 / Microsoft 365

배열의 처음/끝에서 행·열을 제거합니다.

## 구문

```
=DROP(배열, 행수, [열수])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 대상 배열 |
| 행수 | 필수 | 제거할 행(음수=뒤에서) |
| 열수 | 선택 | 제거할 열(선택) |
