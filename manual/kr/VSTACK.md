# VSTACK

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024 / Microsoft 365

배열들을 세로로 쌓아 하나로 만듭니다.

## 구문

```
=VSTACK(배열1, ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열1 | 필수 | 결합할 배열 |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |
