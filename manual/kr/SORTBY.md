# SORTBY

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2021

다른 배열의 값으로 배열을 정렬합니다.

## 구문

```
=SORTBY(배열, 기준배열1, [정렬순서1], ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 정렬할 데이터 |
| 기준배열1 | 필수 | 정렬 키(행에 정렬) |
| 정렬순서1 | 선택 | 1 오름(기본), -1 내림 |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |
