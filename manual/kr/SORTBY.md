# SORTBY

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2021

다른 배열의 값으로 배열을 정렬합니다.

## 구문

```
=SORTBY(배열, 기준배열1, [정렬순서1], ...)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 정렬할 데이터 |
| 기준배열1 | 필수 | 정렬 키(행에 정렬) |
| 정렬순서1 | 선택 | 1 오름(기본), -1 내림 |
| … | 선택 | 위 인수(들)를 반복 지정할 수 있습니다 |

## 반환

기준 배열의 값 순서대로 행을 재배열한 배열을 반환하며 스필됩니다. array와 행 수가 같은 유효한 기준 배열이 하나도 없으면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=SORTBY({"a";"b";"c"},{3;1;2})` | {b;c;a} | 기준 배열로 정렬 |
| `=SORTBY({1;2;3},{2;2;1},1,{9;1;5},-1)` | {3;1;2} | 2차 기준 내림차순 |

## 참고

- 기준 배열은 array와 행 수가 같은 세로(열) 벡터여야 하며 행 정렬만 지원합니다(열 방향 정렬 미지원).
- 행 수가 다른 기준 배열은 조용히 무시됩니다.
- 관련 함수: SORT.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `SORTBY` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.SORTBY`으로 등록됩니다.
