# HANTONUMBER

**종류**: EGTools 전용 함수

한글(한자) 금액 표기를 숫자로 변환합니다(예: 일금 오만원 → 50000).

## 구문

```
=HANTONUMBER(텍스트, [숫자만])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 한글 금액 표기 |
| 숫자만 | 선택 | TRUE면 숫자 반환(기본), FALSE면 금/원 붙인 서식 텍스트 |

## 반환

기본(숫자만=TRUE)은 숫자(스칼라)를 반환하고, 정수부가 15자리를 넘으면 정밀도 보존을 위해 텍스트로 반환합니다. 숫자만=FALSE이면 "금1,234원" 형태의 텍스트를 반환합니다. 텍스트가 비어 있거나 아라비아 숫자·점이 2개 이상 연속이면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=HANTONUMBER("일금오만원정")` | 50000 | 한글 금액을 숫자로 |
| `=HANTONUMBER("삼억이천오백만")` | 325000000 | 억·만 단위 처리 |
| `=HANTONUMBER("일금오만원정",FALSE)` | 일금50,000원정 | 서식 텍스트 반환 |

## 참고

- 한자 표기와 이체자(一二三, 壹貳參, 拾佰仟萬 등)도 인식합니다.
- 입력의 공백과 쉼표는 무시하며, 금/일금·원/원정 접두·접미는 숫자만=FALSE일 때 그대로 복원됩니다.
- 텍스트에 배열을 지정하면 원소별로 처리해 같은 모양의 배열로 스필되며(오류 원소는 그 오류 그대로), 다른 인수에 배열을 지정하면 #VALUE!를 반환합니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `HANTONUMBER` 이름 그대로 등록됩니다.
