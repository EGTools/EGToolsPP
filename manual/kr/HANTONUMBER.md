# HANTONUMBER

**종류**: EGTools 전용 함수

한글(한자) 금액 표기를 숫자로 변환합니다(예: 일금 오만원 → 50000).

## 구문

```
=HANTONUMBER(텍스트, [숫자만])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 한글 금액 표기 |
| 숫자만 | 선택 | TRUE면 숫자 반환(기본), FALSE면 금/원 붙인 서식 텍스트 |
