# TEXTSPLIT

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024

열·행 구분 기호로 텍스트를 배열로 분할합니다.

## 구문

```
=TEXTSPLIT(텍스트, 열구분기호, [행구분기호], [빈값무시], [일치모드], [채울값])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 분할할 텍스트 |
| 열구분기호 | 필수 | 열 사이 구분자 |
| 행구분기호 | 선택 | 행 사이 구분자(선택) |
| 빈값무시 | 선택 | TRUE면 빈 값 제외 |
| 일치모드 | 선택 | 0 대소구분(기본), 1 무시 |
| 채울값 | 선택 | 들쭉날쭉 행 채움(기본 #N/A) |

## 반환

분할된 텍스트 배열을 반환하며 동적 배열에서 스필됩니다. 길이가 다른 행은 채움값(기본 #N/A)으로 채워지고, 분할 결과가 비면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=TEXTSPLIT("a,b,c",",")` | {a,b,c} | 열 분할 |
| `=TEXTSPLIT("a,b;c",",",";")` | {a,b;c,#N/A} | 행·열 분할, 부족분 채움 |
| `=TEXTSPLIT("1,,2",",",,TRUE)` | {1,2} | 빈 값 무시 |

## 참고

- 구분 기호 인수는 단일 텍스트만 지원합니다(네이티브가 허용하는 배열 형태의 다중 구분자는 미지원).
- 일치모드(match_mode)=1이면 대소문자를 무시합니다.
- 관련 함수: TEXTBEFORE, TEXTAFTER, TEXTJOIN
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `TEXTSPLIT` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.TEXTSPLIT`으로 등록됩니다.
