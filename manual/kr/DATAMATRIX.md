# DATAMATRIX

**종류**: EGTools 전용 함수

텍스트를 DataMatrix 이미지로 만들어 호출 셀에 삽입합니다.

## 구문

```
=DATAMATRIX(텍스트, [여백], [GS1])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 인코딩할 문자열 |
| 여백 | 선택 | 모듈 단위 여백(기본 0) |
| GS1 | 선택 | TRUE면 (AI)값 형식의 GS1 텍스트로 처리 |

## 반환

성공하면 빈 문자열("")을 반환하고, DataMatrix 그림이 호출 셀 크기에 맞춰 별도로 삽입됩니다. 텍스트가 비었거나 GS1 변환 또는 인코딩에 실패하면 #VALUE!, 호출 셀을 알 수 없으면 #REF!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=DATAMATRIX("LOT-2026-08")` |  | DataMatrix 그림 삽입(이미지 삽입, 환경 의존) |

## 참고

- gs1=TRUE는 GS(0x1D) 구분자로 근사하며 완전한 FNC1 인코딩은 아닙니다. 완전한 GS1이 필요하면 CODE128(GS1-128)을 사용하세요.
- 이미지는 호출 셀 안에서 정사각 비율을 유지합니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `DATAMATRIX` 이름 그대로 등록됩니다.
