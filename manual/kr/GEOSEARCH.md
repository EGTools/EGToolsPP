# GEOSEARCH

**종류**: EGTools 전용 함수

주소·장소를 검색해 GPS 좌표를 구합니다(VWorld).

## 구문

```
=GEOSEARCH(검색어, [검색대상], [EPSG], [api_key])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 검색어 | 필수 | 주소 또는 장소 키워드 |
| 검색대상 | 선택 | 1 주소(기본), 2 장소 |
| EPSG | 선택 | 좌표계 EPSG 코드(기본 4326=WGS84) |
| api_key | 선택 | vworld.kr 인증키, 1회 입력하면 레지스트리에 저장 |

## 반환

검색 결과의 x,y 좌표 배열을 반환하며 스필됩니다(결과가 여러 건이면 주소 열을 포함한 n×3). 검색어가 비었거나 검색대상/EPSG가 유효하지 않으면 #VALUE!, 결과가 없으면 #N/A를 반환하고, 키 누락·네트워크·서비스 오류는 "ERROR: …" 텍스트로 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=GEOSEARCH("서울특별시청",2)` |  | 장소 검색 좌표(네트워크·API 키 필요) |

## 참고

- API 키는 배포되지 않습니다. 공간정보 오픈플랫폼(https://www.vworld.kr)에서 발급받아 마지막 인수로 1회 입력하면 레지스트리에 저장되며, 키가 거부되면 자동 삭제 후 재발급 안내를 반환합니다.
- 주소 검색(검색대상=1)은 도로명 → 지번 순으로 자동 재시도합니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `GEOSEARCH` 이름 그대로 등록됩니다.
