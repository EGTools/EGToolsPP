# IMPORTTEXT

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 365 (2026 신규)

텍스트 파일(로컬 경로/URL)의 자료를 배열로 가져옵니다.

## 구문

```
=IMPORTTEXT(경로, [구분자], [건너뛸행], [가져올행], [인코딩], [로캘])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 경로 | 필수 | 로컬 파일 경로 또는 URL |
| 구분자 | 선택 | 구분자 텍스트(기본 탭), {1,3}처럼 오름차순 숫자면 고정폭 열 |
| 건너뛸행 | 선택 | 건너뛸 행 수 — 음수면 끝에서부터 |
| 가져올행 | 선택 | 가져올 행 수 — 음수면 끝에서부터 |
| 인코딩 | 선택 | 파일 인코딩, 기본 "utf-8" — windows-1252·euc-kr 등 |
| 로캘 | 선택 | 숫자 해석 로캘, 예 "de-DE" |
