# IMPORTTEXT

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 365 (2026 신규)

텍스트 파일(로컬 경로/URL)의 자료를 배열로 가져옵니다.

## 구문

```
=IMPORTTEXT(경로, [구분자], [건너뛸행], [가져올행], [인코딩], [로캘])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 경로 | 필수 | 로컬 파일 경로 또는 URL |
| 구분자 | 선택 | 구분자 텍스트(기본 탭), {1,3}처럼 오름차순 숫자면 고정폭 열 |
| 건너뛸행 | 선택 | 건너뛸 행 수 — 음수면 끝에서부터 |
| 가져올행 | 선택 | 가져올 행 수 — 음수면 끝에서부터 |
| 인코딩 | 선택 | 파일 인코딩, 기본 "utf-8" — windows-1252·euc-kr 등 |
| 로캘 | 선택 | 숫자 해석 로캘, 예 "de-DE" |

## 반환

텍스트 파일(로컬 경로 또는 URL)을 구분자 또는 고정폭으로 나눠 2차원 배열로 스필하여 반환하며 숫자·날짜 텍스트는 자동 변환됩니다. 경로 누락·읽기/다운로드 실패·잘못된 구분자/고정폭 지정이면 #VALUE!, skip/take 적용 후 남는 행이 없으면 #N/A를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=IMPORTTEXT("C:\data\log.txt",";",1)` |  | 파일 내용에 따름 |

## 참고

- delimiter 생략 시 탭이 기본입니다. 문자열(들)은 구분자로, 숫자 배열({1,11,21})은 고정폭 열 시작 위치(1기준 오름차순)로 해석합니다.
- encoding은 "euc-kr" 같은 문자셋 이름이나 코드페이지 번호를 지원하며 BOM이 있으면 BOM이 우선합니다.
- skip_rows/take_rows에 음수를 주면 끝에서부터 계산합니다.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `IMPORTTEXT` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.IMPORTTEXT`으로 등록됩니다.
