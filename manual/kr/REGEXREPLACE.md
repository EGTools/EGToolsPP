# REGEXREPLACE

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024 / Microsoft 365

정규식과 일치하는 텍스트를 치환합니다($1.. 역참조 지원).

## 구문

```
=REGEXREPLACE(텍스트, 패턴, 대체문자, [순번], [대소문자구분])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 원본 텍스트 |
| 패턴 | 필수 | 정규식 패턴 |
| 대체문자 | 필수 | 치환 텍스트($1, $2…) |
| 순번 | 선택 | 0 전체(기본), N = N번째 일치 |
| 대소문자구분 | 선택 | 0 구분(기본), 1 무시 |
