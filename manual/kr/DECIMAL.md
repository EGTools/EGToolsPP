# DECIMAL

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

지정한 진법의 텍스트 수를 10진수로 변환합니다.

## 구문

```
=DECIMAL(text, radix)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| text | 필수 | 변환할 텍스트 |
| radix | 필수 | 기수 2~36 |

## 반환

진법 텍스트를 변환한 10진수 숫자(스칼라)를 반환합니다. radix가 2~36 범위를 벗어나거나 text에 해당 진법에서 쓸 수 없는 문자가 있으면 #NUM! 오류를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=DECIMAL("FF",16)` | 255 | 16진수를 10진수로 |
| `=DECIMAL("111",2)` | 7 | 2진수를 10진수로 |

## 참고

- 대소문자를 구분하지 않습니다.
- 관련 함수: BASE
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `DECIMAL` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.DECIMAL`으로 등록됩니다.
