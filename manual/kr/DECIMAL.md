# DECIMAL

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

지정한 진법의 텍스트 수를 10진수로 변환합니다.

## 구문

```
=DECIMAL(text, radix)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| text | 필수 | 변환할 텍스트 |
| radix | 필수 | 기수 2~36 |
