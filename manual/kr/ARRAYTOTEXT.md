# ARRAYTOTEXT

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024 / Microsoft 365

배열을 텍스트 표현으로 반환합니다.

## 구문

```
=ARRAYTOTEXT(배열, [형식])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 대상 배열 |
| 형식 | 선택 | 0 간단(기본), 1 엄격 |

## 반환

배열 전체를 하나로 이어 붙인 단일 텍스트(스칼라)를 반환합니다. 구현 자체가 별도의 오류 값을 반환하지는 않습니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=ARRAYTOTEXT({1,2;3,4})` | 1, 2, 3, 4 | 간결 형식 연결 |
| `=ARRAYTOTEXT({"a",1;"b",2},1)` | {"a",1;"b",2} | 엄격 형식 |

## 참고

- 간결(0) 형식은 행·열 구분 없이 모든 요소를 ", "로 연결합니다.
- 엄격(1) 형식은 {a,b;c,d} 모양이며 텍스트만 큰따옴표로 감싸고 내부 따옴표는 두 번("") 표기합니다.
- 관련 함수: VALUETOTEXT
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `ARRAYTOTEXT` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.ARRAYTOTEXT`으로 등록됩니다.
