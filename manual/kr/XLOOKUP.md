# XLOOKUP

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2021

범위/배열에서 값을 찾아 두 번째 범위/배열의 해당 항목을 반환합니다.

## 구문

```
=XLOOKUP(찾을값, 찾을범위, 반환범위, [찾지못하면], [일치모드], [검색모드])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 찾을값 | 필수 | 검색할 값 |
| 찾을범위 | 필수 | 검색 대상 범위/배열 |
| 반환범위 | 필수 | 반환할 범위/배열 |
| 찾지못하면 | 선택 | 일치 없을 때 반환값 (선택) |
| 일치모드 | 선택 | 0 정확(기본), -1 작은값, 1 큰값 |
| 검색모드 | 선택 | 1 처음부터(기본), -1 끝에서부터 |

## 반환

일치한 위치의 반환범위 행(세로 검색) 또는 열(가로 검색)을 배열로 반환하며, 동적 배열 지원 Excel에서는 스필됩니다. 범위를 생략했거나 배열이 비었거나 일치 항목이 없는데 대체값도 없으면 #N/A, 일치 위치가 반환범위를 벗어나면 #REF!, 내부 오류면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=XLOOKUP("b",{"a";"b";"c"},{10;20;30})` | 20 | 정확 일치 검색 |
| `=XLOOKUP(2,{1;2;3},{10,11;20,21;30,31})` | {20,21} | 일치 행 전체 스필 |
| `=XLOOKUP(9,{1;2;3},{10;20;30},"none")` | none | 불일치 시 대체값 |

## 참고

- match_mode 2(와일드카드)와 search_mode 2/-2(이진 검색)는 지원하지 않습니다.
- 찾을범위가 1열이면 세로 검색, 그 외에는 첫 행을 대상으로 가로 검색합니다.
- 관련 함수: XMATCH, FILTER.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `XLOOKUP` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.XLOOKUP`으로 등록됩니다.
