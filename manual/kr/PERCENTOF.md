# PERCENTOF

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Microsoft 365

부분합을 전체합으로 나눈 비율을 반환합니다.

## 구문

```
=PERCENTOF(data_subset, data_all)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| data_subset | 필수 | 부분 데이터 |
| data_all | 필수 | 전체 데이터 |

## 반환

부분 데이터의 합을 전체 데이터의 합으로 나눈 비율을 스칼라 숫자로 반환합니다. 인수가 누락되면 #VALUE!, 전체 합이 0이거나 전체에 숫자가 없으면 #DIV/0!을 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=PERCENTOF({10;20},{10;20;30;40})` | 0.3 | 부분합÷전체합 비율 |
| `=PERCENTOF(50,200)` | 0.25 | 스칼라 값 비율 |

## 참고

- 숫자가 아닌 값은 합계 계산에서 무시됩니다.
- GROUPBY/PIVOTBY의 function 인수에 "PERCENTOF"를 지정하면 그룹별 구성비를 구할 수 있습니다.
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `PERCENTOF` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.PERCENTOF`으로 등록됩니다.
