# PERCENTOF

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2024 / Microsoft 365

부분합을 전체합으로 나눈 비율을 반환합니다.

## 구문

```
=PERCENTOF(data_subset, data_all)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| data_subset | 필수 | 부분 데이터 |
| data_all | 필수 | 전체 데이터 |
