# MVLOOKUP

**종류**: EGTools 전용 함수

여러 검색값의 VLOOKUP을 한 번에 실행합니다(다중 반환 열).

## 구문

```
=MVLOOKUP(검색값, 검색배열, 반환열, [일치방법], [없을때값])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 검색값 | 필수 | 검색값 열(또는 단일 값) |
| 검색배열 | 필수 | 데이터 표 — 첫 열이 키 |
| 반환열 | 필수 | 반환할 열 번호(들), 예 2 또는 {2,3} |
| 일치방법 | 선택 | FALSE 정확 일치(기본), TRUE 유사 일치(작거나 같은 최대값) |
| 없을때값 | 선택 | 일치 없을 때 값(기본 "") |
