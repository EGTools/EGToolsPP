# PDURATION

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

특정 이율로 목표 가치에 도달하는 데 필요한 기간 수를 반환합니다.

## 구문

```
=PDURATION(rate, pv, fv)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| rate | 필수 | 기간당 이율 |
| pv | 필수 | 현재 가치 |
| fv | 필수 | 미래 가치 |

## 반환

목표 금액에 도달하는 데 필요한 기간 수(스칼라 숫자)를 반환합니다. rate·pv·fv가 숫자가 아니거나 0 이하이면 #NUM! 오류를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=PDURATION(0.025,2000,2200)` | 3.859866163 | 2.5%로 2000→2200 기간 |

## 참고

- 모든 인수에 배열을 지정하면 원소별로 계산해 같은 모양의 배열로 스필됩니다 — 스칼라는 반복, 열 벡터×행 벡터는 외적으로 확장, 크기가 맞지 않는 원소는 #N/A, 오류 원소는 그 오류를 그대로 반환합니다.
- 관련 함수: RRI
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `PDURATION` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.PDURATION`으로 등록됩니다.
