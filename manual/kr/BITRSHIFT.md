# BITRSHIFT

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

수를 지정한 비트 수만큼 오른쪽으로 시프트한 값을 반환합니다.

## 구문

```
=BITRSHIFT(number, shift_amount)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| number | 필수 | 시프트할 수(0 이상) |
| shift_amount | 필수 | 오른쪽 시프트 비트 수(음수는 왼쪽) |

## 반환

오른쪽 시프트 결과를 숫자(스칼라)로 반환합니다(내림). number가 [0, 2^48-1] 범위의 정수가 아니거나, shift_amount가 정수가 아니거나 절대값이 53을 넘거나, 결과가 2^53을 넘으면 #NUM!을 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=BITRSHIFT(13,2)` | 3 | 2비트 오른쪽 시프트 |
| `=BITRSHIFT(3,-2)` | 12 | 음수는 왼쪽 시프트 |

## 참고

- shift_amount가 음수이면 왼쪽 시프트로 동작합니다.
- 관련 함수: BITLSHIFT
- 지원: Excel 2010+. 네이티브가 없는 구버전에서는 `BITRSHIFT` 그대로(드롭인), 네이티브가 있는 최신 Excel에서는 `EG.BITRSHIFT`으로 등록됩니다.
