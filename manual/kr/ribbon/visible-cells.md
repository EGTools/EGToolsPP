# 보이는 셀

**위치**: 리본 `EGTools` 탭 → `보이는 셀` 그룹

필터·행/열 숨김이 적용된 영역의 복사·붙여넣기를 다루는 기능 그룹입니다.
스플릿 버튼 2개 — **복사**(기본 동작 = 보이는 셀만 복사)와
**붙여넣기**(기본 동작 = 값만 붙여넣기) — 로 구성됩니다.

## 보이는 셀만 복사

선택 영역에서 **보이는 셀만** 골라 복사 원본으로 기억하고 클립보드에 복사합니다.

1. 복사할 범위를 선택하고 버튼을 누릅니다. 셀(범위) 선택이 아니면
   아무 동작 없이 조용히 종료됩니다.
2. 선택 영역에서 필터/숨김으로 가려진 셀을 뺀 **보이는 셀만** 골라
   통합문서·시트 이름과 영역 주소를 복사 원본으로 기억합니다.
3. 같은 영역이 Excel 클립보드에도 복사되어(움직이는 테두리 표시)
   일반 붙여넣기에 바로 사용할 수 있습니다.

## 전체 복사

선택 영역 **전체(숨김 셀 포함)** 를 복사 원본으로 **기억만** 합니다.
클립보드에는 복사하지 않으므로 화면에는 아무 변화가 없습니다.

## 값만 / 수식 / 모두 붙여넣기

기억해 둔 복사 원본을 현재 선택 영역의 **보이는 셀에만** 순서대로 붙여넣습니다.
메뉴 3개는 붙여넣는 내용만 다릅니다 — **값만 붙여넣기**(계산 결과값, 스플릿
버튼의 기본 동작), **수식 붙여넣기**, **모두 붙여넣기**(값·수식·서식 통째로).

### 동작 절차

1. 먼저 [보이는 셀만 복사](#보이는-셀만-복사) 또는 [전체 복사](#전체-복사)를
   실행해 복사 원본을 기억시킵니다.
2. 붙여넣을 대상 영역을 선택하고 메뉴를 누릅니다. 대상에서 필터/숨김으로
   가려진 셀은 건너뛰고 **보이는 셀에만** 원본 순서대로 채워집니다.
   대상으로 셀 하나만 선택하면 그 셀부터 아래·오른쪽으로 붙여넣습니다.
3. 원본이 여러 셀이면 내부적으로 **임시 통합문서**를 만들어 대상의 숨김 행/열
   위치에 맞춰 모양을 조정한 뒤 붙여넣습니다. 임시 통합문서는 저장 없이
   자동으로 닫힙니다(정리 실패 걱정 없음).
4. 이 과정에서 원본 시트의 **오토필터가 잠시 해제됐다가 조건 그대로
   복원**됩니다. 원본이 셀 하나면 이런 중간 단계 없이 대상 보이는 셀 전체에
   바로 채워집니다.

### 실행할 수 없는 경우

| 상황 | 안내 |
|---|---|
| 복사 원본이 기억돼 있지 않음 | "[보이는 셀 복사] 기능이 먼저 수행되어야 합니다" |
| 원본 통합문서/시트가 닫혔거나 이름이 바뀜 | "복사 원본 통합문서/시트를 찾을 수 없습니다. 다시 복사하세요" |

## 참고

- 원본은 통합문서·시트 이름과 주소로 기억됩니다. 원본 통합문서를 닫거나
  시트 이름을 바꾸면 다시 복사해야 합니다.
- 필터 상태에서 복사한 보이는 영역이 매우 잘게 조각나 있으면(영역 주소가
  255자를 넘는 경우) 원본 재해석에 실패할 수 있습니다. 이때도 다시 복사하라는
  안내가 표시됩니다.
