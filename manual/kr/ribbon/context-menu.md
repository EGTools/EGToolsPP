# 셀 오른쪽 클릭 메뉴

**위치**: 셀 영역 오른쪽 클릭 → 컨텍스트 메뉴

EGTools++를 로드하면 셀 오른쪽 클릭 메뉴에 항목이 추가됩니다.
일반 셀·표(리스트) 범위, 페이지 레이아웃 보기까지 같은 위치에 나타납니다.

## 날짜입력

우클릭한 셀 옆에 달력을 띄워 날짜를 골라 입력합니다. 날짜를 손으로 치는 대신
클릭 두 번으로 넣을 수 있습니다.

1. 셀을 우클릭하고 **날짜입력**을 누르면 활성 셀 오른쪽에 달력이 나타납니다
   (화면 경계를 넘으면 왼쪽으로 자리를 옮김). 현재 셀 값이 날짜면 **그
   날짜가 선택된 달**로, 아니면 오늘로 시작합니다.
2. 상단 `◀◀`/`◀`/`▶`/`▶▶` 로 연/월을 이동합니다. **날짜를 클릭하면 그 날짜가
   셀에 입력**되고 달력이 닫힙니다(회색으로 표시되는 전/다음 달 날짜도 클릭
   가능).
3. 아래 **"오늘: yyyy-mm-dd" 줄을 클릭하면 오늘 날짜로 이동**합니다.
   `Esc` 또는 창 닫기(X)로 취소하면 셀은 바뀌지 않습니다.

- 일요일·**공휴일은 빨강**, 토요일은 파랑, 오늘은 테두리로 표시됩니다.
  공휴일 칸에 마우스를 올리면 하단에 공휴일 이름이 표시됩니다.
- 공휴일은 내장 계산 기준이며, data.go.kr 키가 등록돼 있으면 **임시공휴일**도
  반영됩니다 — [달력/일정표 — 공휴일 안내](calendar.md#공휴일-안내) 참고.

## 링크열기

선택한 셀 내용에서 `http://` 또는 `https://` 로 시작하는 URL을 찾아
기본 브라우저로 엽니다.

- 셀 텍스트 안에 URL이 다른 문자와 섞여 있어도 첫 번째 URL을 찾아 엽니다.
- 여러 셀을 선택한 경우 **첫 셀(왼쪽 위)** 기준으로 동작합니다.
- 셀에 URL이 없으면 아무 동작도 하지 않습니다.

하이퍼링크 서식이 없는 일반 텍스트 URL을 클릭 두 번으로 열 수 있어,
셀 편집 모드로 들어가거나 하이퍼링크를 만들 필요가 없습니다.

---

컨텍스트 메뉴 항목은 향후 순차적으로 추가될 수 있습니다.
