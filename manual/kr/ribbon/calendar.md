# 달력/일정표

**위치**: 리본 `EGTools++` 탭 → `달력/일정표` 그룹

달력·일정표 시트를 만드는 기능 그룹입니다. 스플릿 버튼 2개 —
**달력**(기본 동작 = 월간; 메뉴: 월간·연간A·연간B)과
**일정표**(기본 동작 = 일일B; 메뉴: 주간·일일A·일일B) — 로 구성됩니다.

공통 사항:

- 날짜/연월 입력 창에는 오늘(이번 달)이 기본값으로 채워지고, 구분자는
  `-`·`/`·`.` 모두 허용됩니다. 취소하거나 해석할 수 없는 값을 입력하면
  조용히 종료됩니다.
- 새 시트는 활성 시트 **뒤에** 추가되고, 인쇄 설정(용지 방향 + 1페이지 맞춤)과
  눈금선 숨김·틀 고정이 함께 적용됩니다.

## 월간

연월(`YYYY-MM`)을 입력하면 6주(42일) 격자의 월간 달력 시트를 만듭니다.

- 각 주의 첫 열에 **주차번호**가 `W##` 형식으로 표시됩니다(수요일 기준 연간 주차).
- **공휴일**은 날짜 옆 칸에 이름이 표시되고, 그 날 블록 전체가
  연노랑 배경 + 빨간 글꼴로 강조됩니다.
- **음력 1·11·21일**인 날에는 `(MM/dd)` 음력 표기가 붙습니다.
- 앞·뒷달에 걸친 날짜는 회색 `M/D`로 표시되고(1월엔 전년 성탄절, 12월엔
  다음 해 새해첫날 공휴일도 반영), 그 달에 속하지 않는 주는 지워집니다.
- 일요일은 빨강, 토요일은 파랑. 가로 방향 1페이지 인쇄로 설정됩니다.

## 연간A / 연간B

연도(2000~2050)를 입력하면 12개월이 한 장에 들어간 연간 달력 시트를 만듭니다.

- **연간A**: 3열×4행 세로형(세로 방향 인쇄) / **연간B**: 4열×3행 가로형(가로 방향 인쇄).
  레이아웃만 다르고 내용은 같습니다.
- **공휴일** 날짜는 노란 배경 + 빨간 글꼴로 강조되고, 공휴일 이름은
  **셀 메모**로 붙습니다.
- 월 제목은 초록 배경, 일요일 빨강, 토요일 파랑으로 표시됩니다.

## 주간

날짜(`YYYY-MM-DD`)를 입력하면 그 날짜가 속한 주(일요일~토요일)의
주간 일정표 시트를 만듭니다.

- 제목 줄에 연·월, 주 시작~끝 날짜, 주차번호가 표시됩니다.
- 요일별 열에 날짜·음력(`MM/dd`)·공휴일 이름(강조)·일정 내용 칸이 배치되고,
  아래에는 **08:00~21:00, 30분 간격** 시간축의 시간 일정칸이 이어집니다.
- 일요일 빨강·토요일 파랑, 가로 방향 1페이지 인쇄로 설정됩니다.

## 일일A / 일일B

날짜(`YYYY-MM-DD`)를 입력하면 하루 일정표 시트를 만듭니다.
시트 이름은 `MMdd`(중복 시 `MMdd_1` …)로 지정됩니다.

- 구성은 **주요 업무**(체크박스 열 + 업무 내용), **시간 일정**(08~21시),
  **업무 메모**입니다. 일일A는 2단(업무·시간 일정 + 메모 열), 일일B는
  3단(업무 | 시간 | 메모) 가로형입니다.
- 체크박스 열에는 0/1 유효성 검사 + ✅/⬜ 표시 형식이 적용되어
  완료 여부를 숫자로 집계할 수 있습니다([CheckBox 적용](utilities.md#checkbox-적용)과 같은 서식).
- **미완료 업무 자동 이월**: 통합문서 안의 이전 일일 일정표 시트(가장 최근
  과거 날짜) 중 체크되지 않은(빈칸/0) 업무를 새 일정표의 주요 업무로 가져옵니다.
  일일 일정표 시트는 A1 셀의 숨은 메모(`EGCalendar:날짜`)로 식별합니다.
- 제목에 날짜·요일·음력이 표시되고, 공휴일이면 제목 아래에 이름이 표시됩니다.
- 가로 방향 1페이지 인쇄로 설정됩니다.

## 공휴일 안내

- 공휴일의 바탕은 **내장 계산**입니다 — 양·음력 공휴일과 노동절,
  **대체공휴일 규칙**(시행 연도별) 포함. [KOREANHOLIDAYS](../KOREANHOLIDAYS.md)
  함수와 같은 계산을 공유합니다.
- 여기에 **기본적으로 공휴일 API를 병합합니다**. 저장된 data.go.kr 키
  ([EGTools → API 키 관리](api-keys.md))로 특일정보를 조회해
  **임시공휴일·선거일** 등 내장 계산에 없는 항목까지 달력에 반영합니다.
  월간·연간A/B·주간·일일A/B **모든 시트**에 같은 규칙이 적용됩니다.
- 인터넷 연결이 안 되거나 키가 등록되지 않았거나 키가 만료·거부된 경우에는
  **내장 계산만으로 시트를 만들고**, 명령이 끝난 뒤 아래 안내를 **한 번**
  표시합니다(실패 사유가 함께 표시됩니다).

  > 공휴일 API를 사용할 수 없어 내장 계산으로 만들었습니다.
  > 임시공휴일·선거일은 표시되지 않습니다.

  시트 생성 자체는 중단되지 않습니다. 안내를 받았다면 키를 등록·갱신한 뒤
  다시 실행하면 임시공휴일이 반영됩니다.
- 조회 결과는 연도별로 캐시되므로 같은 연도의 달력을 여러 번 만들어도
  조회는 한 번만 일어납니다(실패는 캐시하지 않아 키를 고치면 즉시 반영).
- 음력 표기는 내장 음력표로 계산하며([TOLUNAR](../TOLUNAR.md) 함수와 동일),
  지원 범위를 벗어나는 날짜에는 표시되지 않습니다.
