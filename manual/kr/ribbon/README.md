# 리본 메뉴

EGTools++를 로드하면 리본에 **EGTools++** 탭이 추가됩니다.
기능 버튼은 성격별 **그룹**으로 묶여 있으며, 앞으로 기능이 추가되면 그룹 단위로 확장됩니다.

## 그룹: 보이는 셀

필터·숨김 상태의 복사·붙여넣기를 다룹니다(스플릿 버튼 2개: 복사 = 보이는 셀만
복사 / 붙여넣기 = 값만 붙여넣기). 상세: [보이는 셀](visible-cells.md)

| 메뉴 | 설명 |
|---|---|
| [보이는 셀만 복사](visible-cells.md#보이는-셀만-복사) | 선택 영역의 보이는 셀만 복사 원본으로 기억하고 클립보드에 복사 |
| [전체 복사](visible-cells.md#전체-복사) | 선택 영역 전체(숨김 포함)를 복사 원본으로 기억 |
| [값만 붙여넣기](visible-cells.md#값만--수식--모두-붙여넣기) | 기억한 복사 원본을 대상의 보이는 셀에만 값으로 붙여넣기 |
| [수식 붙여넣기](visible-cells.md#값만--수식--모두-붙여넣기) | 보이는 셀에만 수식으로 붙여넣기 |
| [모두 붙여넣기](visible-cells.md#값만--수식--모두-붙여넣기) | 보이는 셀에만 값·수식·서식 통째로 붙여넣기 |

## 그룹: 셀 병합/나누기

병합 셀을 다루는 기능입니다(스플릿 버튼 2개: 병합 = 서식없이 내용병합 /
나누기 = 서식없이 행 나누기). 상세: [셀 병합/나누기](merge-split.md)

| 메뉴 | 설명 |
|---|---|
| [연속값 병합](merge-split.md#연속값-병합) | 세로로 연속된 같은 값 구간을 실제 병합(여러 열은 계층형) |
| [내용감춘 병합](merge-split.md#내용감춘-병합) | 값은 그대로 두고 겉모습만 병합 — 함수·필터가 계속 동작 |
| [연속값 감춘 병합](merge-split.md#연속값-감춘-병합) | 연속된 같은 값 구간을 각각 겉모습만 병합 |
| [서식없이/서식대로 내용병합](merge-split.md#서식없이--서식대로-내용병합) | 영역을 한 셀로 병합하며 내용을 구분자·줄바꿈으로 연결(서식대로는 글자 서식 보존) |
| [서식없이/서식대로 행끼리 병합](merge-split.md#서식없이--서식대로-행끼리-병합) | 각 행을 하나의 병합 셀로 만들며 내용 연결 |
| [서식없이/서식대로 열끼리 병합](merge-split.md#서식없이--서식대로-열끼리-병합) | 각 열을 하나의 병합 셀로 만들며 내용을 줄바꿈으로 연결 |
| [나누고 채우기](merge-split.md#나누고-채우기) | 병합을 해제하고 병합돼 있던 값을 다시 채웁니다(수식은 값으로 변환) |
| [서식없이/서식대로 행 나누기](merge-split.md#서식없이--서식대로-행-나누기) | 병합 셀 텍스트를 줄바꿈으로 나눠 행마다 분배(부족하면 행 삽입) |
| [서식없이/서식대로 열 나누기](merge-split.md#서식없이--서식대로-열-나누기) | 병합 셀 텍스트를 구분자로 나눠 열마다 분배(부족하면 열 삽입) |

## 그룹: 그림/사진

이미지를 셀에 맞춰 삽입·정렬·추출합니다(스플릿 버튼 2개: 이미지 = 이미지 삽입 / 맞춤 = 선택 맞춤).
상세: [그림/사진](pictures.md)

| 메뉴 | 설명 |
|---|---|
| [이미지 삽입](pictures.md#이미지-삽입) | 이미지 파일을 골라 선택 영역 크기에 맞춰 삽입 |
| [이름에 삽입](pictures.md#이름에-삽입) | 셀 값과 같은 이름의 이미지를 폴더에서 찾아 그 셀에 삽입 |
| [양식에 삽입](pictures.md#양식에-삽입) | 양식을 복제하며 `{{}}` 위치에 폴더의 이미지를 순서대로 삽입 |
| [선택 맞춤](pictures.md#선택-맞춤) | 선택한 그림들을 각자의 좌상단 셀 크기에 맞춤 |
| [모두 맞춤](pictures.md#모두-맞춤) | 시트의 모든 그림을 셀 크기에 일괄 맞춤 |
| [추출 저장](pictures.md#추출-저장) | 시트의 모든 그림을 지정 폴더에 원본 화질 그대로 저장 |

## 그룹: 달력/일정표

달력·일정표 시트를 생성합니다(스플릿 버튼 2개: 달력 = 월간 / 일정표 = 일일B).
상세: [달력/일정표](calendar.md)

| 메뉴 | 설명 |
|---|---|
| [월간](calendar.md#월간) | 월간 달력 시트(주차번호·공휴일·음력 표시) |
| [연간A](calendar.md#연간a--연간b) | 연간 달력 세로형(3×4) |
| [연간B](calendar.md#연간a--연간b) | 연간 달력 가로형(4×3) |
| [주간](calendar.md#주간) | 주간 일정표(일~토, 08:00~21:00 시간축) |
| [일일A](calendar.md#일일a--일일b) | 일일 일정표 2단형(미완료 업무 이월) |
| [일일B](calendar.md#일일a--일일b) | 일일 일정표 3단형(미완료 업무 이월) |

상세: [양식](forms.md)

| 메뉴 | 설명 |
|---|---|
| [라벨지 만들기](forms.md#라벨지-만들기) | 양식을 자료 행마다 복제하며 `{{열이름}}`을 값으로 치환 |
| [메일머지](mailmerge.md) | 자료 행마다 양식 시트를 복제해 개별 시트/파일(xlsx/PDF)·개별 인쇄·메일 발송(파일 첨부) |

## 그룹: EGTools

수식의 함수 이름 일괄 변환, SMTP 설정, API 키 관리, 추가기능 정보를 모은
스플릿 버튼입니다(기본 = EGTools++ 정보).

| 메뉴 | 설명 |
|---|---|
| [구버전 호환 적용](apply-compat.md) | 모던/네이티브(`_xlfn.*`) 함수 토큰을 EGTools 호환 함수명으로 일괄 변환 |
| [내장 함수로 복원](restore-native.md) | EGTools 함수명을 네이티브 내장 함수로 일괄 복원 |
| [SMTP 설정](smtp-settings.md) | 메일머지 메일 발송용 SMTP 서버 등록(암호는 저장하지 않음) |
| [API 키 관리](api-keys.md) | 공공 API 키 등록/삭제(주소검색 · data.go.kr · vworld — data.go.kr 키는 공휴일·달력·사업자등록이 공유) |
| EGTools++ 정보 | 버전·배포처·기반 라이브러리를 표시하고, GitHub Release에 새 버전이 있으면 알림과 함께 배포처 링크를 제공합니다 |

새 버전 확인은 Excel 시작 후 리본이 로드될 때도 자동으로 한 번 수행되어,
새 릴리즈가 있으면 배포처 링크가 담긴 알림 창이 표시됩니다(세션당 1회).

리본 외에 셀 컨텍스트 메뉴에도 항목이 추가됩니다. 상세: [셀 오른쪽 클릭 메뉴](context-menu.md)

## 삽입 탭 CheckBox

Excel의 `삽입` 탭에도 [CheckBox 적용](utilities.md#checkbox-적용) 버튼이 추가됩니다.
네이티브 확인란이 있는 Microsoft 365에서는 표시되지 않습니다.
