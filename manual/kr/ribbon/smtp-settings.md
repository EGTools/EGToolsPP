# SMTP 설정

**위치**: 리본 `EGTools` 탭 → `EGTools` 그룹 → 스플릿 버튼 드롭다운 메뉴

[메일머지](mailmerge.md)의 **메일 발송**(옵션 4·5·6·7)에 사용할 SMTP 서버
정보를 등록하는 대화상자입니다.

## 설정 항목

| 항목 | 설명 |
|---|---|
| 발송인 이름 | 받는 사람에게 표시되는 보낸 사람 이름(생략 가능 — 생략하면 메일주소만 표시) |
| 발송인 메일주소 | 보낸 사람 주소이자 **SMTP 로그인 계정** |
| 보내는 메일서버 | SMTP 서버 주소 (예: `smtp.gmail.com`) |
| 서버 포트 | 기본 **465** |
| SSL | SSL 사용 여부(기본 켬) |

## 규칙

- 설정은 사용자 계정(레지스트리)에 저장되며 **통합문서에는 남지 않습니다**.
- **암호는 절대 저장되지 않습니다.** 메일을 발송할 때마다 입력받아 메모리에서만
  사용합니다.
- 메일머지에서 발송 옵션을 선택했는데 설정이 비어 있으면(메일주소·서버·포트 중
  하나라도 없으면) 이 대화상자가 **자동으로 열립니다**. 그래도 채워지지 않으면
  발송이 중단됩니다.

## 중요 제한 — 암시적 SSL만 지원

발송 엔진(Windows CDO)은 **암시적 SSL(implicit SSL)만 지원**합니다. 보통
**포트 465**가 여기에 해당합니다. **포트 587의 STARTTLS는 지원하지 않으므로**
587을 입력하면 발송이 실패합니다.

- Gmail: 서버 `smtp.gmail.com`, 포트 `465`, SSL 켬 —
  계정 암호 대신 **앱 비밀번호**를 발급받아 입력하세요.
- 다른 서비스도 "SSL(465)" 방식의 포트를 사용하고, 2단계 인증을 쓰는 계정이면
  앱 비밀번호가 필요할 수 있습니다.

## 참고

- 한글 등 비ASCII 제목/본문은 UTF-8로 인코딩되어 발송됩니다.
- 발송 실패 시 서버가 알려준 오류 설명이 [메일머지](mailmerge.md) 완료 요약의
  실패 목록에 그대로 표시됩니다.
