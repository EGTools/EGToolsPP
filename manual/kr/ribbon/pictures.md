# 그림/사진

**위치**: 리본 `EGTools++` 탭 → `그림/사진` 그룹

이미지를 셀에 맞춰 삽입·정렬·추출하는 기능 그룹입니다. 스플릿 버튼 2개 —
**이미지**(기본 동작 = 이미지 삽입; 메뉴: 이미지 삽입·이름에 삽입·양식에 삽입)와
**맞춤**(기본 동작 = 선택 맞춤; 메뉴: 선택 맞춤·모두 맞춤·추출 저장) — 로
구성됩니다.

## 이미지 삽입

이미지 파일 하나를 골라 현재 선택 영역 크기에 맞춰 삽입합니다.

1. 파일 선택 대화상자에서 이미지 파일을 고릅니다
   (jpg·jpeg·png·gif·bmp·tif·tiff·svg·emf·wmf 등, 취소하면 종료).
2. 선택 영역의 위치·크기에 **0.2pt 여백**을 두고 그림이 삽입됩니다
   (문서에 포함 저장, 파일 링크 아님).
3. 삽입된 그림의 **이름은 파일명**으로 설정되고, **가로세로 비율 잠금은 해제**되어
   이후 셀 맞춤 시 자유롭게 변형됩니다.

## 이름에 삽입

폴더를 골라, 시트 셀 값과 **같은 이름의 이미지 파일**을 찾아 그 셀에 삽입합니다.
명부·상품 목록처럼 이름이 입력된 표에 사진을 일괄로 붙일 때 사용합니다.

1. 폴더 선택 창에서 이미지가 든 폴더를 고릅니다(취소하면 종료).
2. 활성 시트의 사용 영역(A1부터) 모든 셀 값을 확인해, 값과 이름이 같은
   이미지 파일을 폴더에서 찾습니다.
   - 확장자는 붙여도 되고 빼도 됩니다(셀 값 `사진1` ↔ 파일 `사진1.jpg` 모두 일치).
     대소문자는 무시합니다.
   - jpg·jpeg·png·gif·bmp·tif·tiff·svg·emf·wmf 등 이미지 확장자 파일만 대상입니다.
3. 찾은 이미지를 그 셀(병합 셀이면 병합 영역 전체 크기)에 **0.3pt 여백**으로
   삽입합니다(문서에 포함 저장). 그림 이름은 확장자를 뺀 파일명으로 설정되고
   비율 잠금은 해제됩니다.
4. 완료 후 결과(삽입한 폴더 안내 / 추가된 사진 없음)를 표시합니다.

같은 값이 여러 셀에 있으면 각 셀마다 삽입됩니다.

## 양식에 삽입

양식을 복제하면서 `{{}}` 자리표시자 위치에 폴더의 이미지들을 순서대로 삽입합니다.
사진 대지(사진 보고서) 양식을 채울 때 사용합니다.

1. **양식 영역 지정** — 범위 입력 창에서 양식 영역을 지정합니다(기본값 = 현재
   선택, 취소하면 종료). 양식 안에 `{{}}`만 입력된 셀(사진 위치)이 1개 이상
   있어야 하며, 없으면 안내 후 종료됩니다.
2. **복제 방법 입력** — `1` = 양식 시트를 통째로 복제 / `2` = 양식 영역을
   아래로 복제 / `3` = 오른쪽으로 복제.
3. **폴더 선택** — 폴더 안의 이미지 파일을 **이름순**으로 정렬해 사용합니다
   (이미지가 없으면 안내 후 종료).
4. 이미지를 모두 소진할 때까지 양식을 복제하며 각 `{{}}` 셀(병합 셀이면 병합
   영역)에 **0.3pt 여백**으로 이미지를 삽입합니다. **셀 값은 파일명으로
   기록**되고 그림 이름도 파일명입니다. 이미지가 소진된 뒤 남은 `{{}}`는
   지워집니다. 진행 상황은 상태 표시줄에 표시됩니다.

- 방법 1은 시트를 복제하므로 시트 이름이 `원본이름_1`, `_2` … 로 늘어납니다.
- 방법 2/3은 행/열 전체를 복사하므로 행높이·열너비가 유지됩니다
  (복제 위치의 기존 내용은 지워집니다).

## 선택 맞춤

선택한 그림들을 각 그림의 좌상단 꼭짓점이 위치한 셀에 맞춥니다.

1. 그림(들)을 선택하고 버튼을 누르면 **여백 입력** 창이 나옵니다
   (0~10, 기본 0.3). 숫자가 아닌 값을 입력하거나 취소하면 종료됩니다.
2. 각 그림을 좌상단 셀 크기에 여백만큼 안쪽으로 맞춥니다.
   좌상단 셀이 **병합 영역**이면 병합 영역 전체 크기에 맞춥니다.
3. **90도/270도 회전**된 그림은 가로세로를 서로 바꿔 회전 상태 그대로
   셀에 맞도록 보정합니다.

그림이 선택돼 있지 않으면 "선택된 이미지가 없습니다" 안내가 표시됩니다.
그림(사진) 개체만 처리하며 도형·차트 등은 건드리지 않습니다.

## 모두 맞춤

활성 시트의 **모든 그림**을 선택 맞춤과 같은 방식으로 일괄 맞춥니다.

1. 확인 창(계속 진행 여부)에 동의하면 **여백 입력** 창이 나옵니다(0~5, 기본 0.3).
2. 시트의 모든 그림을 각자의 좌상단 셀(병합 영역이면 병합 크기)에 맞춥니다.
   진행 상태는 Excel **상태 표시줄**에 그림 이름으로 표시됩니다.
3. 완료 후 결과(정리 완료 / 이미지 없음)를 안내합니다.

## 추출 저장

활성 시트의 **모든 그림**을 지정한 폴더에 **원본 화질 그대로** 저장합니다.
시트에 붙은 사진을 파일로 되돌려 받을 때 사용합니다.

1. 시트에 그림이 없으면 안내 후 종료됩니다. 저장할 폴더를 선택합니다
   (취소하면 종료).
2. 파일 이름은 **그림 좌상단 꼭짓점이 위치한 셀의 값**입니다. 셀이 비어 있으면
   `그림이름_R행C열` 형식이 됩니다. 파일명에 쓸 수 없는 문자는 `_`로 바뀌고,
   이름이 겹치면 `_1`, `_2`… 가 붙습니다. 확장자는 문서에 저장된 원본
   형식(jpg·png 등) 그대로입니다.
3. 내부 동작: 통합문서의 **사본을 임시 폴더에 저장**해 문서 안의 원본 이미지
   데이터를 그대로 꺼냅니다. 화면 표시 화질로 다시 그리는 방식이 아니므로
   **문서에 넣을 때의 화질이 그대로 보존**되며, 원본 문서는 전혀 변경되지
   않습니다(임시 파일은 자동 삭제).
4. 완료 후 추출한 개수와 저장 폴더를 안내합니다.

- 문서가 **xlsx/xlsm 형식**이어야 합니다. 다른 형식(.xls 등)에서는
  "사진 추출에 실패했습니다" 안내가 표시될 수 있습니다.
- 대상은 그림(사진) 개체입니다. 도형·차트는 저장하지 않습니다.

## 참고

- 여백 값이 0이면 셀에 꽉 찬 그림이 되고, 클수록 셀 테두리와의 간격이 커집니다.
- 맞춤 기준은 그림의 **좌상단 꼭짓점이 걸친 셀**입니다. 원하는 셀에 맞지 않으면
  그림을 해당 셀 위로 옮긴 뒤 다시 실행하세요.
