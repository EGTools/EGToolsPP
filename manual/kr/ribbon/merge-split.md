# 셀 병합/나누기

**위치**: 리본 `EGTools++` 탭 → `셀 병합/나누기` 그룹

병합 셀을 다루는 기능 그룹입니다. 스플릿 버튼 2개 — **병합**(기본 동작 =
서식없이 내용병합)과 **나누기**(기본 동작 = 서식없이 행 나누기) — 로 구성됩니다.

- **병합 메뉴 9개**(리본 순서): 연속값 병합 · 내용감춘 병합 · 연속값 감춘 병합 ·
  서식없이/서식대로 내용병합 · 서식없이/서식대로 행끼리 병합 ·
  서식없이/서식대로 열끼리 병합
- **나누기 메뉴 5개**: 나누고 채우기 · 서식없이/서식대로 행 나누기 ·
  서식없이/서식대로 열 나누기

## 연속값 병합

선택 영역에서 세로로 같은 값이 연속되는 구간을 실제 셀 병합으로 만듭니다.
정렬된 목록에서 같은 분류가 반복되는 열을 보기 좋게 묶을 때 사용합니다.

### 동작 절차

1. 병합할 범위(정렬된 목록 권장)를 선택하고 버튼을 누릅니다.
2. 각 열에서 **같은 값이 세로로 2칸 이상 이어지는 구간**을 찾아 병합합니다.
   빈 셀 구간은 병합하지 않습니다.
3. 여러 열을 선택하면 **계층형**으로 병합됩니다 — 오른쪽 열의 구간은
   왼쪽 열(들)의 그룹 경계에서 끊어집니다. 예를 들어 A열이 부서, B열이 팀이면
   부서가 바뀌는 곳에서 팀 병합도 함께 끊깁니다.

### 참고

- 값 비교는 표시 값 기준입니다(수식이면 계산 결과 기준).
- 같은 값 구간만 병합하므로 확인 창 없이 진행해도 값이 사라지지 않습니다
  (Excel 병합 규칙상 좌상단 값만 남지만 구간의 값이 모두 같기 때문).
- 여러 영역을 선택(Ctrl+클릭)하면 영역별로 각각 처리됩니다.

## 내용감춘 병합

선택 영역(들)을 **겉모습만** 병합합니다. 각 셀의 값은 그대로 남아 있어
`SUM`·`VLOOKUP` 같은 함수와 필터·정렬이 **계속 동작**하면서, 화면에는 병합
셀처럼 좌상단 셀 값만 보입니다.

1. 병합해 보일 범위를 선택하고 메뉴를 누릅니다(여러 영역 선택 가능 —
   영역별로 각각 처리).
2. 내부적으로 현재 시트를 **임시 통합문서로 복사**해 복사본에서 실제 병합을
   만든 뒤, 그 **서식만** 원본의 같은 위치에 붙여넣습니다. 값·수식은 전혀
   변하지 않으며, 임시 통합문서는 저장 없이 자동으로 닫힙니다.

- 겉모습만 병합된 상태이므로 좌상단 이외 셀의 값은 화면에서 감춰질 뿐
  삭제되지 않습니다. 수식에서 참조하면 그대로 읽힙니다.

## 연속값 감춘 병합

[연속값 병합](#연속값-병합)과 같은 규칙(세로 2칸 이상 같은 값 구간, 여러 열은
계층형)으로 구간을 찾되, 실제 병합 대신 [내용감춘 병합](#내용감춘-병합)처럼
**겉모습만** 병합합니다. 각 셀의 값이 그대로 남으므로 병합 후에도 필터·집계가
값 기준으로 동작합니다.

- 선택 안의 기존 병합 셀은 (복사본에서) 먼저 나누고 값을 채운 뒤 구간을
  계산합니다. 원본의 값은 변하지 않습니다.

## 서식없이 / 서식대로 내용병합

선택 영역 전체를 **하나의 병합 셀**로 만들면서 내용도 이어 붙입니다.

1. 범위를 선택하고 메뉴를 누릅니다. 열이 2개 이상이면 **세로칸 구분 문자**를
   묻습니다(기본 `,`, 취소하면 종료).
2. 행 안의 셀들은 구분자로, **행 사이는 줄바꿈**으로 연결됩니다. 빈 셀은
   건너뜁니다. 수식 셀은 계산 결과 텍스트로 합쳐집니다.
3. 영역이 병합되고 연결된 텍스트가 들어갑니다. 결과 셀은 **텍스트 표시
   형식(@)** 이 됩니다.
   - **서식없이**: 셀 스타일을 표준으로 되돌리고 자동 줄 바꿈을 켭니다.
   - **서식대로**: 원본 **각 글자**의 글꼴 서식 11가지(글꼴·크기·색·굵게·
     기울임·밑줄·취소선·아래/위 첨자 등)를 기억했다가 병합된 텍스트에 글자
     단위로 다시 입힙니다.

## 서식없이 / 서식대로 행끼리 병합

선택 영역의 **각 행**을 위의 내용병합 방식으로 처리해, 행마다 하나의 병합
셀을 만듭니다. 열이 2개 이상이면 구분 문자를 **한 번만** 물어 모든 행에
재사용합니다. 진행 상황은 상태 표시줄에 표시됩니다.

## 서식없이 / 서식대로 열끼리 병합

선택 영역의 **각 열**을 하나의 병합 셀로 만듭니다. 세로로 이어지는 값들은
**줄바꿈**으로 연결되므로 구분 문자 질의가 없습니다.

## 나누고 채우기

선택 영역 안의 병합 셀을 해제하고, 병합돼 있던 값을 해제된 셀에 다시 채웁니다.
병합 해제 후에도 필터·정렬·수식 참조가 값 기준으로 동작하게 만들 때 사용합니다.

### 동작 절차

1. 값을 채울 범위를 선택하고 버튼을 누릅니다. 셀(범위) 선택이 아니면
   아무 동작 없이 조용히 종료됩니다.
2. 선택 영역의 각 병합 셀에 대해 병합을 해제하고, 병합 셀이 갖고 있던 값을
   해제된 셀에 다시 채웁니다. 값이 비어 있던 병합 셀은 그대로 비워 둡니다.
3. 여러 **열**에 걸친 병합이었다면 값은 **왼쪽 첫 열에만** 채워집니다
   (여러 행 병합은 첫 열의 모든 행에 채워짐).

### 주의

- **수식은 값으로 바뀝니다.** 병합 셀에 수식이 있었다면 계산 결과값이 채워지고
  수식은 사라집니다. 수식을 보존해야 하면 실행 전에 백업하세요.

## 서식없이 / 서식대로 행 나누기

**하나의 병합 셀**에 든 텍스트를 **줄바꿈** 기준으로 나눠, 위에서부터 행마다
하나씩 넣습니다. 내용병합의 반대 동작입니다.

1. 병합 셀(또는 셀 하나)을 선택하고 메뉴를 누릅니다.
2. 텍스트가 줄바꿈으로 나뉘어 병합이 해제된 각 행에 들어갑니다. 조각 수가
   병합돼 있던 행 수보다 많으면 부족한 만큼 **행이 삽입**됩니다.
3. 각 대상 셀은 텍스트 표시 형식(@)이 되고 행 높이가 자동 조정(AutoFit)
   됩니다. **서식대로**는 원본 글자 서식을 조각별로 보존합니다.

- 줄바꿈이 없어 나눌 조각이 1개뿐이면 안내 후 종료됩니다.

## 서식없이 / 서식대로 열 나누기

하나의 병합 셀 텍스트를 **구분 문자**로 나눠 왼쪽부터 열마다 하나씩 넣습니다.

1. 병합 셀을 선택하고 메뉴를 누르면 구분 문자를 묻습니다(기본 `,`,
   취소하거나 빈 값이면 종료).
2. 조각 수가 병합돼 있던 열 수보다 많으면 **열이 삽입**되고, 각 대상 셀은
   텍스트 표시 형식(@) + 열 너비 자동 조정이 적용됩니다. **서식대로**는
   원본 글자 서식을 조각별로 보존합니다.

## 공통 참고

### 실행할 수 없는 경우

| 상황 | 해당 기능 | 안내 |
|---|---|---|
| 셀 범위 선택이 아님 | 전체 | "셀 범위에서 작업해야 합니다" |
| 표(ListObject) 영역과 겹침 | 연속값 병합 · 연속값 감춘 병합 · 내용병합 · 행/열끼리 병합 | "표 영역에 대해서는 처리할 수 없습니다" — 표 안에서는 셀 병합이 지원되지 않습니다 |
| 한 행만 선택 | 연속값 병합 · 연속값 감춘 병합 | "오직 하나의 행은 처리할 수 없습니다" |
| 여러 영역(Ctrl+클릭) 선택 | 내용병합 | 하나의 연속 영역만 처리할 수 있습니다 |
| 100행 초과 | 내용병합 · 열끼리 병합 | "100행을 초과하는 영역은 처리할 수 없습니다" |
| 이미 병합된 셀 포함 | 내용병합(전체가 이미 한 병합 셀) · 행/열끼리 병합 | "이미 병합된 셀이 포함되어 있습니다. 나누기 후 실행하세요" |
| 하나의 병합 셀이 아님 | 행/열 나누기 | "셀 범위에서 작업해야 합니다" |

### 주의

- **"서식대로"는 글자 단위로 서식을 읽고 다시 입히므로 텍스트가 길면 오래
  걸립니다.** 진행 상황이 상태 표시줄에 표시됩니다. 글자 서식이 필요 없으면
  "서식없이"가 훨씬 빠릅니다.
- 내용병합·나누기의 결과 셀은 텍스트 표시 형식이므로 숫자·날짜로 자동 인식되지
  않습니다. 수식이 있던 셀은 계산 결과 텍스트로 바뀝니다.
