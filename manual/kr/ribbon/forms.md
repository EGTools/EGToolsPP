# 양식

**위치**: 리본 `EGTools++` 탭 → `양식` 그룹

시트에 그려 둔 양식(서식 영역)을 자료 목록으로 채워 반복 생성하는 기능 그룹입니다.
스플릿 버튼 하나(기본 동작 = 라벨지 만들기)로 구성됩니다.

| 메뉴 | 설명 |
|---|---|
| [라벨지 만들기](#라벨지-만들기) | 양식을 자료 행마다 한 시트에 반복 배치하며 `{{열이름}}`을 값으로 치환 |
| [메일머지](mailmerge.md) | 자료 행마다 양식 시트를 복제해 개별 시트/파일(xlsx/PDF)·개별 인쇄 |

## 라벨지 만들기

양식을 자료 목록의 행 수만큼 복제하면서 `{{열이름}}` 자리표시자를 각 행의 값으로
치환해, 인쇄용 라벨(명찰·주소 라벨 등) 시트를 만듭니다.

### 동작 절차

1. **양식영역 지정** — 범위 입력 창에서 양식 영역을 지정합니다
   (기본값 = 현재 선택의 연속 영역, 취소 시 종료). 값이 없는 단일 셀을
   지정하면 종료됩니다.
2. **자료 목록 지정** — 자료 목록 영역을 지정합니다. **첫 행이 열이름**이고
   둘째 행부터가 데이터입니다.
3. **가로 배치 수 입력** — 한 줄에 가로로 배치할 라벨 수(1~10, 기본 1)를
   입력합니다.
4. 새 시트(양식 시트 이름 + `_1` 형식)에 자료 행마다 양식이 복사되고
   `{{열이름}}`이 그 행의 값으로 치환됩니다. 완료 후 안내가 표시됩니다.

### 치환 규칙

| 항목 | 규칙 |
|---|---|
| 자리표시자 | `{{열이름}}`이 든 셀만 치환 대상입니다. 한 셀에 여러 개를 쓸 수 있고 앞뒤 문구와 조합할 수 있습니다(예: `주소: {{주소}}`) |
| 자리표시자 없음 | 양식에 `{{ }}` 자리표시자가 하나도 없으면 빈 양식이 자료 행 수만큼 복제만 됩니다 |
| 빈 열이름 | 목록 첫 행이 비어 있는 열은 `Empty1`, `Empty2` … 이름으로 참조할 수 있습니다 |
| 없는 열이름 | 목록에 없는 열이름을 참조하면 경고 후 작업이 중단됩니다 |
| 서식 | 양식의 서식(테두리·색 등)이 함께 복사되고, **열너비·행높이도 양식과 동일하게** 복제됩니다 |

### 참고

- 치환된 셀은 **텍스트 값**으로 입력됩니다(수식이 아님).
- 행마다 개별 시트/파일을 만들려면 [메일머지](mailmerge.md)를 사용하세요
  (라벨지 = 한 시트에 반복 배치, 메일머지 = 행마다 개별 시트/파일).
