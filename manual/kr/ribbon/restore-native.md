# 내장 함수로 복원

**위치**: 리본 `EGTools` 탭 → `EGTools` 그룹 → 스플릿 버튼 드롭다운 메뉴

EGTools 호환 함수로 변환해 사용하던 통합문서를 최신 Excel로 되가져갈 때, 활성 통합문서의
모든 수식에서 EGTools 함수명(`EG.*` 등)을 네이티브 내장 함수로 일괄 복원합니다.
복원 후에는 추가기능 없이도 해당 수식이 계산됩니다.

## 동작 절차

[구버전 호환 적용](apply-compat.md)과 동일한 안전 절차를 거칩니다:
저장 확인 → 사전 스캔(대상 함수별 개수 요약) → 자동 백업
(`원본이름_egbak_<시각>.<확장자>`) → 변환 → 결과 요약.

## 변환 규칙

| 대상 | 변환 |
|---|---|
| 일반 호환 함수 | `EG.함수` / `x함수`(xSORT/xFILTER/xLET) → `함수` (네이티브). 구버전에서 쓰던 드롭인 이름 그대로의 셀도 다시 토큰화하여 네이티브가 계산하도록 강제합니다 |
| IMAGE | **소스별 분기**: 첫 인수가 `https://` 소스면 네이티브 `IMAGE` 유지, 그 외(로컬 경로·`http://`)는 `EG.IMAGE`로 변환합니다. 참조·수식 인수는 **변환 시점에 평가한 값**을 기준으로 판단합니다(평가 실패·오류·비문자열은 안전하게 `EG.IMAGE`). 네이티브 IMAGE는 https 전용이므로, 변환 후 참조 값이 로컬 경로로 바뀌면 해당 셀은 `#VALUE!`가 됩니다 — 반대로 `EG.IMAGE`는 모든 소스에서 동작합니다 |
| GROUPBY / PIVOTBY | 함수명을 네이티브로 되돌리고, 집계자 인수의 따옴표를 제거합니다(`"SUM"` → `SUM`; 네이티브 지원 집계자 16종에 한함 — TEXTJOIN 등 EGTools 확장 집계자는 네이티브가 거부하므로 해당 수식을 건드리지 않음). 뒤따르는 선택 인수가 있어도 변환됩니다 |
| `_xlpm.*` (LET/LAMBDA 매개변수) | 구버전을 거친 수식에 남아 있는 매개변수 저장 접두를 제거합니다(`xLET(_xlpm.x, …)` → `LET(x, …)`). `_xlpm.`이 포함된 수식은 Excel이 쓰기를 거부하므로 이 제거가 없으면 해당 셀은 복원되지 않습니다. 변환 요약에 `_xlpm.*` 항목으로 집계됩니다 |
| `@` (암시적 교차) | 구버전 파일을 최신 Excel이 열 때 붙는 `@`가 **네이티브로 복원되는 함수명 바로 앞**에 있으면 함께 제거합니다(`TAKE(@xSORT(…),3)` → `TAKE(SORT(…),3)`). 제거하지 않으면 `@SORT`가 배열을 단일값으로 붕괴시켜 결과가 틀려집니다. 셀 참조나 변환 대상이 아닌 함수 앞의 `@`는 보존됩니다. 변환 요약에 `@(암시적 교차)` 항목으로 집계됩니다 |
| `_xll.*` / `_xludf.*` (추가기능 UDF 저장 접두) | 추가기능 함수가 등록되지 않은 환경에서 열었던 흔적으로 남는 접두를 제거합니다(`_xll.xSORT(…)` → `SORT(…)`). 특히 **정의된 이름**의 수식에 이 접두가 남아 이름이 변환되지 않던 문제를 해결합니다. EGTools 함수 앞의 접두만 제거하며 다른 추가기능의 함수는 건드리지 않습니다. 변환 요약에 `_xll.*` 항목으로 집계됩니다 |
| 롤아웃 미확정 함수 (IMPORTTEXT/IMPORTCSV) | 도입은 되었지만 아직 일반 배포되지 않은 함수(365 프리뷰 채널 한정)는 복원 전에 **이 Excel에 네이티브가 실제로 존재하는지 확인**하고, 확인된 경우에만 네이티브로 변환합니다. 확인되지 않으면 IMAGE와 같은 방식으로 EGTools 구현을 유지합니다(`IMPORTTEXT` → `EG.IMPORTTEXT`). 이미 일반 배포된 함수는 이 확인 없이 항상 변환됩니다 |

## 참고

- 실행하는 Excel에 해당 네이티브 함수가 없으면(구버전) 복원된 수식은 `#NAME?`이 되므로,
  이 버튼은 최신 Excel로 되돌아갈 때 사용하세요.
- 다시 구버전용으로 바꾸려면 [구버전 호환 적용](apply-compat.md)을 실행하세요.
