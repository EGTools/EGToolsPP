# 메일머지

**위치**: 리본 `EGTools++` 탭 → `양식` 그룹 → `라벨지` 스플릿 버튼의 메뉴 → **메일머지**

자료 목록의 **행마다 양식 시트를 통째로 복제**해 `{{필드명}}` 자리표시자를 그 행의
값으로 치환하고, 선택한 옵션에 따라 개별 파일 저장(xlsx/PDF)·개별 인쇄·**메일
발송**(행별 파일 첨부)을 수행합니다. 메일 발송에 쓰는 SMTP 서버 정보는
[SMTP 설정](smtp-settings.md)에서 등록합니다(암호는 저장되지 않음).

## 동작 절차

1. **옵션 입력** — 실행할 작업을 숫자(0~7, 기본 1)로 입력합니다. 1(파일저장)·
   2(인쇄)·4(메일발송)의 **비트 조합**입니다.
   `0` = 양식 시트 복제만(복제한 시트를 남김) / `1` = 파일저장 / `2` = 인쇄 /
   `3` = 파일저장 + 인쇄 / `4` = 메일발송 / `5` = 파일저장 + 메일발송 /
   `6` = 인쇄 + 메일발송 / `7` = 파일저장 + 인쇄 + 메일발송.
2. **인쇄 설정** — 인쇄가 포함된 옵션(2·3·6·7)이면 프린터 설정 대화상자가 먼저
   표시됩니다. 취소하면 작업이 중단됩니다.
3. **양식 시트 지정** — 범위 입력 창에서 양식 시트의 아무 셀이나 선택합니다.
   선택한 영역이 속한 **시트 전체**가 양식으로 사용됩니다.
4. **자료 영역 지정** — 자료 목록의 셀을 선택합니다. 선택은 연속 영역
   (CurrentRegion)으로 자동 확장되며, **첫 행이 필드명**이고 둘째 행부터가
   데이터입니다.
5. **메일 발송 준비**(발송이 포함된 옵션 4~7) — 수신자 열과 이메일 템플릿
   시트를 확인한 뒤, [SMTP 설정](smtp-settings.md)이 비어 있으면 설정
   대화상자가 자동으로 열립니다. 이어서 **SMTP 계정 암호**를 입력받습니다
   (암호는 저장되지 않으며 취소하면 작업이 중단됩니다).
6. 데이터 행마다 양식 시트가 통합문서 맨 뒤에 복제되어 `{{필드명}}`이 치환되고,
   옵션에 따라 인쇄·저장·발송이 실행됩니다. 완료 후 "완료한 항목: N"이 —
   발송을 선택했으면 "발송한 메일: N"도 함께 — 표시됩니다.

## 규칙

| 항목 | 규칙 |
|---|---|
| 자리표시자 | `{{필드명}}`은 목록 제목줄의 필드명과 **대소문자·앞뒤 공백 무시**로 대응합니다. 한 셀에 여러 개를 쓰거나 앞뒤 문구와 조합할 수 있습니다. 목록에 없는 필드명이 있으면 해당 필드명과 함께 오류를 안내하고 중단합니다 |
| 시트/파일 이름 | **첫 열 값**이 복제 시트와 저장 파일의 이름이 됩니다. 첫 열이 빈 행은 건너뛰며, 이름의 금지문자는 `_`로 바뀝니다. 같은 시트명이 이미 있으면 `_1`, `_2` … 접미사가 붙습니다 |
| 저장 위치 | 파일은 통합문서가 있는 폴더의 `Output\` 하위에 저장됩니다. **통합문서가 저장돼 있어야** 하며, 아니면 안내 후 중단됩니다(메일발송도 첨부 파일을 만들므로 동일하게 적용) |
| PDF 저장 | 목록 **첫 열의 제목이 `PDF`**(대소문자 무시)이면 xlsx 대신 PDF로 저장됩니다 |
| 열기 암호 | 목록에 `PassWord` 또는 `암호` 열이 있으면 그 행의 값이 xlsx **열기 암호**로 설정됩니다(빈 값이면 암호 없음, PDF에는 적용되지 않음) |
| 복제 시트 정리 | 옵션이 0이 아니면 복제된 시트는 인쇄·저장·발송 후 삭제됩니다. 옵션 0이면 시트가 통합문서에 남습니다 |

## 메일 발송 (옵션 4·5·6·7)

발송이 포함된 옵션을 선택하면 다음 규칙이 추가로 적용됩니다.

| 항목 | 규칙 |
|---|---|
| 수신자 열 | 자료 목록에 제목이 `eMail` 또는 `이메일`인 열(대소문자 무시)이 **필수**입니다. 없으면 안내 후 중단합니다. 수신자 셀이 **빈 행은 발송만 건너뛰며**, 시트 복제·저장·인쇄는 그대로 수행됩니다 |
| 이메일 템플릿 시트 | 통합문서에 이름이 `이메일` 또는 `Email`인 시트가 **필수**입니다. **1열 = 키, 2열 = 값**으로 입력합니다. 키: `제목`/`Subject`(**필수**), `본문`/`Body`, `참조`/`CC`, `숨은참조`/`BCC` |
| 제목/본문 치환 | 제목과 본문에도 `{{필드명}}` 치환이 적용되어 **행마다 개인화된 메일**을 보낼 수 있습니다. 목록에 없는 필드명은 원문 그대로 남습니다 |
| 첨부 파일 | 그 행에서 저장된 파일(xlsx 또는 PDF, 열기 암호 지원)이 메일에 **첨부**됩니다. 파일저장(비트 1)을 선택하지 않았으면 첨부용 파일은 발송 후 삭제됩니다 |
| 발송인/서버 | [SMTP 설정](smtp-settings.md)의 발송인 이름·메일주소·서버·포트·SSL을 사용합니다. 설정이 비어 있으면 설정 대화상자가 자동으로 열리고, 그래도 미완성이면 중단합니다 |
| 암호 | SMTP 계정 암호는 **매 실행마다 입력**받으며 어디에도 저장되지 않습니다 |
| 실패 처리 | 한 행의 발송이 실패해도 **다음 행을 계속** 진행합니다. 완료 요약에 실패한 행이 "이름 - 오류내용" 목록으로 표시됩니다 |

## 참고

- 치환된 셀은 **텍스트 값**으로 입력됩니다(수식이 아님).
- 파일 저장은 복제 시트를 단일 시트 새 통합문서로 복사해 저장한 뒤 닫는
  방식이므로, 저장된 파일에는 그 시트 하나만 들어 있습니다.
- 발송 엔진은 **암시적 SSL(보통 포트 465)만 지원**하며 587 STARTTLS는
  지원하지 않습니다. 자세한 제한은 [SMTP 설정](smtp-settings.md) 참고.
- [라벨지 만들기](forms.md#라벨지-만들기)와의 차이: 라벨지는 **한 시트에 양식을
  반복 배치**하고, 메일머지는 **행마다 개별 시트/파일**을 만듭니다.
