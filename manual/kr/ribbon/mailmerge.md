# 메일머지

**위치**: 리본 `EGTools++` 탭 → `양식` 그룹 → `라벨지` 스플릿 버튼의 메뉴 → **메일머지**

자료 목록의 **행마다 양식 시트를 통째로 복제**해 `{{필드명}}` 자리표시자를 그 행의
값으로 치환하고, 선택한 옵션에 따라 개별 파일 저장(xlsx/PDF)·개별 인쇄를 수행합니다.
메일 발송은 추후 버전에 추가될 예정이며, 그때 SMTP 설정은 암호를 제외하고 저장되는
방식이 됩니다.

## 동작 절차

1. **옵션 입력** — 실행할 작업을 숫자(0~3, 기본 1)로 입력합니다.
   `0` = 양식 시트 복제만(복제한 시트를 남김) / `1` = 파일저장 / `2` = 인쇄 /
   `3` = 파일저장 + 인쇄.
2. **인쇄 설정** — 인쇄가 포함된 옵션(2·3)이면 프린터 설정 대화상자가 먼저
   표시됩니다. 취소하면 작업이 중단됩니다.
3. **양식 시트 지정** — 범위 입력 창에서 양식 시트의 아무 셀이나 선택합니다.
   선택한 영역이 속한 **시트 전체**가 양식으로 사용됩니다.
4. **자료 영역 지정** — 자료 목록의 셀을 선택합니다. 선택은 연속 영역
   (CurrentRegion)으로 자동 확장되며, **첫 행이 필드명**이고 둘째 행부터가
   데이터입니다.
5. 데이터 행마다 양식 시트가 통합문서 맨 뒤에 복제되어 `{{필드명}}`이 치환되고,
   옵션에 따라 인쇄·저장이 실행됩니다. 완료 후 "완료한 항목: N"이 표시됩니다.

## 규칙

| 항목 | 규칙 |
|---|---|
| 자리표시자 | `{{필드명}}`은 목록 제목줄의 필드명과 **대소문자·앞뒤 공백 무시**로 대응합니다. 한 셀에 여러 개를 쓰거나 앞뒤 문구와 조합할 수 있습니다. 목록에 없는 필드명이 있으면 해당 필드명과 함께 오류를 안내하고 중단합니다 |
| 시트/파일 이름 | **첫 열 값**이 복제 시트와 저장 파일의 이름이 됩니다. 첫 열이 빈 행은 건너뛰며, 이름의 금지문자는 `_`로 바뀝니다. 같은 시트명이 이미 있으면 `_1`, `_2` … 접미사가 붙습니다 |
| 저장 위치 | 파일은 통합문서가 있는 폴더의 `Output\` 하위에 저장됩니다. **통합문서가 저장돼 있어야** 하며, 아니면 안내 후 중단됩니다 |
| PDF 저장 | 목록 **첫 열의 제목이 `PDF`**(대소문자 무시)이면 xlsx 대신 PDF로 저장됩니다 |
| 열기 암호 | 목록에 `PassWord` 또는 `암호` 열이 있으면 그 행의 값이 xlsx **열기 암호**로 설정됩니다(빈 값이면 암호 없음, PDF에는 적용되지 않음) |
| 복제 시트 정리 | 옵션이 0이 아니면 복제된 시트는 인쇄·저장 후 삭제됩니다. 옵션 0이면 시트가 통합문서에 남습니다 |

## 참고

- 치환된 셀은 **텍스트 값**으로 입력됩니다(수식이 아님).
- 파일 저장은 복제 시트를 단일 시트 새 통합문서로 복사해 저장한 뒤 닫는
  방식이므로, 저장된 파일에는 그 시트 하나만 들어 있습니다.
- [라벨지 만들기](forms.md#라벨지-만들기)와의 차이: 라벨지는 **한 시트에 양식을
  반복 배치**하고, 메일머지는 **행마다 개별 시트/파일**을 만듭니다.
