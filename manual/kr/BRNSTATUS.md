# BRNSTATUS

**종류**: EGTools 전용 함수

사업자등록번호의 현재 상태를 확인합니다(국세청, data.go.kr).

## 구문

```
=BRNSTATUS(등록번호, [api_key])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 등록번호 | 필수 | 사업자등록번호(들), 하이픈 허용 |
| api_key | 선택 | data.go.kr 인증키, 1회 입력하면 레지스트리에 저장 |

## 반환

각 사업자등록번호의 과세유형 텍스트(tax_type)를 입력과 같은 모양으로 반환합니다(배열 입력이면 스필). 입력이 비었으면 #VALUE!를 반환하고, 키 누락·네트워크·서비스 오류는 "ERROR: …" 텍스트, 조회되지 않은 번호는 "#N/A" 텍스트로 표시됩니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=BRNSTATUS("123-45-67890")` |  | 사업자등록 상태 조회(네트워크·API 키 필요) |

## 참고

- API 키는 배포되지 않습니다. data.go.kr(공공데이터포털, 국세청 사업자등록정보 상태조회)에서 발급받아 마지막 인수로 1회 입력하면 레지스트리(HKCU\Software\EGTools++\ApiKeys)에 저장되어 이후 생략할 수 있습니다.
- 서비스가 키를 거부하면(HTTP 401/403 등) 저장된 키를 자동 삭제하고 재발급 안내를 반환합니다.
- 100건 단위로 묶어 POST 요청하므로 대량 조회에 적합하며, 하이픈은 자동 제거되고 빈 입력 셀은 빈 문자열로 반환됩니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `BRNSTATUS` 이름 그대로 등록됩니다.
