# GTRS

**종류**: Google Sheets 호환 함수

GOOGLETRANSLATE의 짧은 별칭 — 구글로 텍스트를 번역합니다.

## 구문

```
=GTRS(텍스트, [원본언어], [대상언어])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 번역할 텍스트(또는 범위) |
| 원본언어 | 선택 | 원본 언어 코드, 예 "en" (기본 "auto" 자동감지) |
| 대상언어 | 선택 | 결과 언어 코드 (기본: UI 언어) |
