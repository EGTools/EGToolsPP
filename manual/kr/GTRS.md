# GTRS

**종류**: Google Sheets 호환 함수

GOOGLETRANSLATE의 짧은 별칭 — 구글로 텍스트를 번역합니다.

## 구문

```
=GTRS(텍스트, [원본언어], [대상언어])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 번역할 텍스트(또는 범위) |
| 원본언어 | 선택 | 원본 언어 코드, 예 "en" (기본 "auto" 자동감지) |
| 대상언어 | 선택 | 결과 언어 코드 (기본: UI 언어) |

## 반환

GOOGLETRANSLATE와 동일하게 번역된 텍스트를 스칼라로 반환합니다. HTTP 요청 실패 시 #VALUE!, 서비스 오류·잘못된 언어 코드·5000자 초과는 "ERROR:…" 텍스트로 반환하고, 빈 텍스트는 빈 문자열을 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=GTRS("안녕하세요","ko","en")` |  | 번역 결과에 따름 |

## 참고

- GOOGLETRANSLATE의 짧은 별칭으로 동일한 구현을 사용합니다. 상세 동작은 GOOGLETRANSLATE 문서를 참고하십시오.
- 지원: Excel 2010+. 모든 Excel 버전에서 `GTRS` 이름 그대로 등록됩니다.
