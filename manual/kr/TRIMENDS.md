# TRIMENDS

**종류**: EGTools 전용 함수

문자열 양끝의 공백만 제거합니다(중간 공백은 유지).

## 구문

```
=TRIMENDS(텍스트, [옵션])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 텍스트 | 필수 | 텍스트 또는 범위 |
| 옵션 | 선택 | 추가 제거: +1 제어문자, +2 nbsp, +4 보이지 않는 유니코드 (기본 0) |

## 반환

양끝이 정리된 텍스트(스칼라)를 반환하며, 텍스트에 배열/범위를 지정하면 요소별로 처리되어 스필됩니다. 옵션이 0~7 범위 밖이면 #VALUE!를 반환하고, 빈 셀은 빈 문자열이 됩니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=TRIMENDS("  a  b  ")` | a  b | 양끝 공백만 제거 |
| `=TRIMENDS("a",8)` | #VALUE! | 옵션 범위 초과 |

## 참고

- 옵션 0에서도 공백·탭·CR·LF는 양끝에서 항상 제거됩니다.
- TRIM과 달리 문자열 중간의 공백은 그대로 유지합니다.
- 옵션 합산: +1 제어문자, +2 NBSP, +4 보이지 않는 유니코드 공백(ZWSP·전각 공백 등).
- 지원: Excel 2010+. 모든 Excel 버전에서 `TRIMENDS` 이름 그대로 등록됩니다.
