# IMPORTHTML

**종류**: Google Sheets 호환 함수

웹 페이지에서 표(table)나 목록(list)을 추출합니다.

## 구문

```
=IMPORTHTML(주소, [종류], [번호], [로캘])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 주소 | 필수 | 웹 페이지 URL |
| 종류 | 선택 | "table"(기본) 또는 "list"(ul/ol) |
| 번호 | 선택 | 몇 번째 요소를 추출할지, 1부터 (기본 1) |
| 로캘 | 선택 | 숫자 해석 로캘, 예 "de-DE" |
