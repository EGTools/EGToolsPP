# WEBSERVICE

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2013

지정한 URL의 웹 서비스 응답을 반환합니다(HTTP GET).

## 구문

```
=WEBSERVICE(url)
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| url | 필수 | 요청할 URL |
