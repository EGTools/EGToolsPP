# RESTAPI

**종류**: EGTools 전용 함수

REST API를 호출해 응답 텍스트를 반환합니다.

## 구문

```
=RESTAPI(주소, [방법], [요청헤더], [요청본문])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 주소 | 필수 | API URL(GET 파라미터 포함) |
| 방법 | 선택 | "GET"(기본), "POST", "PUT", "PATCH", "DELETE" 등 |
| 요청헤더 | 선택 | 헤더 이름/값 2열 범위 |
| 요청본문 | 선택 | 요청 본문 텍스트 |

## 반환

응답 본문을 하나의 텍스트 스칼라로 반환합니다(UTF-8로 해석). 주소가 없거나 비었거나 HTTP 요청이 실패하면 #VALUE!를 반환합니다.

## 예제

| 수식 | 결과 | 설명 |
|---|---|---|
| `=RESTAPI("https://api.example.com/users","GET")` |  | 결과는 서버 응답에 따라 다릅니다 |

## 참고

- WinHTTP를 사용하며 네트워크 연결이 필요합니다. 응답 수신 제한 시간은 30초입니다.
- HTTP 상태 코드와 무관하게 응답 본문을 그대로 반환합니다.
- 비매크로·스레드 안전으로 등록되어 병렬 재계산이 가능합니다.
- 지원: Excel 2010+. 모든 Excel 버전에서 `RESTAPI` 이름 그대로 등록됩니다.
