# UNIQUE

**종류**: MS Excel 호환 함수 · **네이티브 도입**: Excel 2021

배열의 고유한 행(또는 열)을 반환합니다.

## 구문

```
=UNIQUE(배열, [열기준], [한번만])
```

## 인수

| 인수 | 필수 | 설명 |
|---|---|---|
| 배열 | 필수 | 데이터 |
| 열기준 | 선택 | TRUE면 고유 열 |
| 한번만 | 선택 | TRUE면 한 번만 나타난 항목 |
