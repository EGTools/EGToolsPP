# TOLUNAR

**Category**: EGTools-only function

Converts a solar (Gregorian) date to the Korean lunar date (919–2050).

## Syntax

```
=TOLUNAR(solar_date)
```

## Arguments

| Argument | Required | Description |
|---|---|---|
| solar_date | Required | date, serial, "yyyy-mm-dd" text, yyyymmdd number, or a range |
