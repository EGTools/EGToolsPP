# DAYS

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2013

2 つの日付の間の日数を返します（終了−開始）。

## 構文

```
=DAYS(終了日, 開始日)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 終了日 | 必須 | 終了日 |
| 開始日 | 必須 | 開始日 |

## 戻り値

終了日から開始日を引いた日数を数値(スカラー)で返します。各日付の時刻部分は切り捨てて計算します。引数を省略すると #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=DAYS(DATE(2026,3,1),DATE(2026,1,15))` | 45 | 2 つの日付の間の日数 |
| `=DAYS(DATE(2026,1,1),DATE(2026,1,31))` | -30 | 終了日が早ければ負数 |

## 解説

- 日付形式のテキスト("2026-01-15" など)は解釈せず、数値でない値は 0 として処理されます。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `DAYS` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.DAYS` として登録されます。
