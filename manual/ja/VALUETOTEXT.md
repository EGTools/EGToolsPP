# VALUETOTEXT

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2024

値のテキスト表現を返します。

## 構文

```
=VALUETOTEXT(値, [書式])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 値 | 必須 | 値 |
| 書式 | 省略可能 | 0 簡潔(既定)、1 厳密(文字列を引用符) |

## 戻り値

値のテキスト表現である単一のテキスト(スカラー)を返します。実装自体が個別のエラー値を返すことはありません。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=VALUETOTEXT(1.5)` | 1.5 | 数値はそのまま |
| `=VALUETOTEXT("abc",1)` | "abc" | 厳密: テキストに引用符 |
| `=VALUETOTEXT(TRUE)` | TRUE | 論理値 |

## 解説

- 厳密(1)形式では、テキスト内の二重引用符は 2 つ("")で表記されます。
- 関連関数: ARRAYTOTEXT。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `VALUETOTEXT` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.VALUETOTEXT` として登録されます。
