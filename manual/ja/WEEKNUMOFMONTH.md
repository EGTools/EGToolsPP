# WEEKNUMOFMONTH

**種類**: EGTools 専用関数

週の開始曜日・基準曜日による月内週番号を計算します。

## 構文

```
=WEEKNUMOFMONTH(日付, [週開始曜日], [基準曜日])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 日付 | 必須 | 基準日 |
| 週開始曜日 | 省略可能 | 1=日~7=土(既定 2=月) |
| 基準曜日 | 省略可能 | 所属月を決める曜日(既定 5=木) |

## 戻り値

月内の週番号(スカラー数値)を返します。日付を解釈できない場合や、週開始曜日・基準曜日が 1~7 の範囲外の場合は #VALUE! エラーを返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=WEEKNUMOFMONTH(DATE(2026,1,15))` | 3 | 1 月の第 3 週 |
| `=WEEKNUMOFMONTH(DATE(2026,2,1))` | 5 | 2/1 は 1 月の第 5 週に所属 |

## 解説

- 曜日番号は 1=日 ~ 7=土で、既定値は月曜開始・木曜基準です。
- 週の所属月・週番号は基準曜日が属する月を基準に計算します。
- 日付に配列を指定すると要素ごとに計算され、同じ形状の配列としてスピルされます(エラー要素はそのエラーをそのまま返します)。
- 関連関数: MONTHBHYWEEK。
- 対応: Excel 2010+。すべての Excel バージョンで `WEEKNUMOFMONTH` の名前のまま登録されます。
