# IMAGE

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2024

セルに URL またはファイルパスの画像を挿入します。

## 構文

```
=IMAGE(source, [alt_text], [sizing], [height], [width])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| source | 必須 | 画像の URL またはファイルパス |
| alt_text | 省略可能 | 代替(アクセシビリティ)テキスト(省略可) |
| sizing | 省略可能 | 0 比率維持, 1 塗りつぶし, 2 元のサイズ, 3 カスタム(省略可) |
| height | 省略可能 | sizing が 3 のときの高さ(px)(省略可) |
| width | 省略可能 | sizing が 3 のときの幅(px)(省略可) |

## 戻り値

常に空文字列("")をスカラーで返し、計算の終了後に呼び出しセル(結合範囲)のサイズに合わせたフローティング画像図形を挿入します。source が空の場合は #VALUE!、呼び出しセルのアドレスを確認できない場合は #REF! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=IMAGE("https://www.google.com/favicon.ico")` |  | 外部の画像に依存します |

## 解説

- 365 ネイティブのようにセルの値になるのではなく、セルの上にフローティングの画像図形(EG.Image_シート_セル)を挿入し、再計算時には同名の既存図形を置き換えます。
- alt_text・height・width 引数は互換性のために受け取りますが無視され、resize_mode が 0(既定)の場合は縦横比を維持します。
- ネイティブの IMAGE がある新しい Excel では EG.IMAGE として登録されます。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `IMAGE` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.IMAGE` として登録されます。
