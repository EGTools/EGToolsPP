# TEXTAFTER

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2024 / Microsoft 365

区切り文字の後のテキストを返します。

## 構文

```
=TEXTAFTER(テキスト, 区切り, [番号], [一致モード], [末尾一致], [見つからない時])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| テキスト | 必須 | 元のテキスト |
| 区切り | 必須 | 検索する区切り文字 |
| 番号 | 省略可能 | 何番目か、負数は末尾から(既定 1) |
| 一致モード | 省略可能 | 1 で大文字小文字を無視(既定 0) |
| 末尾一致 | 省略可能 | 1 でテキストの末尾を区切りと見なす(既定 0) |
| 見つからない時 | 省略可能 | 見つからない場合の値(既定 #N/A) |

## 戻り値

区切り文字の後ろの単一のテキスト(スカラー)を返します。順番(instance_num)が 0 の場合は #VALUE!、区切り文字が見つからない場合は未検出値(既定は #N/A)を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=TEXTAFTER("red-blue-green","-")` | blue-green | 最初の区切り文字の後ろ |
| `=TEXTAFTER("a,b,c",",",-1)` | c | 末尾から 1 番目の後ろ |
| `=TEXTAFTER("abc","x",1,0,0,"none")` | none | 未検出値を返す |

## 解説

- 末尾一致(match_end)=1 の場合は、テキストの末尾(正の順番)/先頭(負の順番)を 1 個の仮想区切り文字と見なします。
- 一致モード(match_mode)=1 の場合は大文字と小文字を区別しません。
- 関連関数: TEXTBEFORE、TEXTSPLIT。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `TEXTAFTER` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.TEXTAFTER` として登録されます。
