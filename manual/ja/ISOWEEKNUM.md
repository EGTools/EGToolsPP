# ISOWEEKNUM

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2013

日付の ISO 8601 の年間週番号を返します。

## 構文

```
=ISOWEEKNUM(日付)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 日付 | 必須 | 日付 |

## 戻り値

日付の ISO 8601 週番号(1~53)を数値で返します。引数が配列の場合は同じサイズの配列として要素ごとに計算され、動的配列対応の Excel ではスピルされます。日付が数値でない場合や負数の場合は #VALUE!、シリアル値を日付に変換できない場合は #NUM! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=ISOWEEKNUM(DATE(2026,1,1))` | 1 | 2026-01-01 は第 1 週 |
| `=ISOWEEKNUM(DATE(2023,1,1))` | 52 | 前年の最終週 |

## 解説

- 配列を入力すると要素ごとに計算し、同じサイズの配列を返します。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `ISOWEEKNUM` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.ISOWEEKNUM` として登録されます。
