# SORT

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2021

配列を並べ替えます。

## 構文

```
=SORT(配列, [並べ替え列], [並べ替え順序], [列で])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 配列 | 必須 | 並べ替えるデータ |
| 並べ替え列 | 省略可能 | 基準の列(または行)、既定 1 |
| 並べ替え順序 | 省略可能 | 1 昇順(既定)、-1 降順 |
| 列で | 省略可能 | TRUE で列を並べ替え |

## 戻り値

指定した列(または行)を基準に並べ替えた同じサイズの配列を返し、スピルします。sort_index が配列の範囲を超える場合や内部エラーの場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=SORT({3;1;2})` | {1;2;3} | 昇順の並べ替え |
| `=SORT({1,3;2,1;3,2},2)` | {2,1;3,2;1,3} | 2 列目を基準に並べ替え |
| `=SORT({5;3;9},1,-1)` | {9;5;3} | 降順の並べ替え |

## 解説

- sort_order が負の場合は降順、それ以外の値(0 を含む)は昇順として扱います(ネイティブでは 1/-1 のみ許可)。
- 同じキーは元の順序を維持します(安定ソート)。
- 関連関数: SORTBY、UNIQUE。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `SORT` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.SORT` として登録されます。 一部の旧バージョンでは予約語との競合により `xSORT` という名前で登録されます。
