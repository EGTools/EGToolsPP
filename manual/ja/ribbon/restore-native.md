# 組み込み関数に復元

**場所**: リボン `EGTools++` タブ → `EGTools` グループ → スプリットボタンのドロップダウンメニュー

EGTools 互換関数に変換して使用していたブックを最新の Excel へ持ち帰るときに、アクティブブックの
すべての数式で EGTools 関数名（`EG.*` など）をネイティブの組み込み関数へ一括復元します。
復元後は、アドインがなくても該当の数式が計算されます。

## 動作手順

[旧バージョン互換に変換](apply-compat.md)と同じ安全手順を経ます:
保存の確認 → 事前スキャン（対象関数ごとの件数を要約） → 自動バックアップ
（`元の名前_egbak_<時刻>.<拡張子>`） → 変換 → 結果の要約。

## 変換ルール

| 対象 | 変換 |
|---|---|
| 一般の互換関数 | `EG.関数` / `x関数`（xSORT/xFILTER/xLET） → `関数`（ネイティブ）。旧バージョンで使っていたドロップイン名そのままのセルも再トークン化し、ネイティブに計算させるよう強制します |
| IMAGE | **ソース別の分岐**: 第 1 引数が `https://` ソースならネイティブの `IMAGE` を維持し、それ以外（ローカルパス・`http://`）は `EG.IMAGE` に変換します。参照・数式の引数は**変換時点で評価した値**を基準に判定します（評価失敗・エラー・非文字列は安全側で `EG.IMAGE`）。ネイティブの IMAGE は https 専用のため、変換後に参照値がローカルパスへ変わるとそのセルは `#VALUE!` になります — 逆に `EG.IMAGE` はすべてのソースで動作します |
| GROUPBY / PIVOTBY | 関数名をネイティブへ戻し、集計子引数の引用符を除去します（`"SUM"` → `SUM`。ネイティブ対応の集計子 16 種に限ります — TEXTJOIN など EGTools 拡張の集計子はネイティブが拒否するため、その数式には手を付けません）。後続の省略可能な引数があっても変換されます |
| `_xlpm.*`（LET/LAMBDA のパラメーター） | 旧バージョンを経た数式に残っているパラメーター保存プレフィックスを除去します（`xLET(_xlpm.x, …)` → `LET(x, …)`）。`_xlpm.` を含む数式は Excel が書き込みを拒否するため、この除去がないとそのセルは復元されません。変換の要約では `_xlpm.*` 項目として集計されます |
| `@`（暗黙的なインターセクション） | 旧バージョンのファイルを最新の Excel が開くときに付く `@` が、**ネイティブへ復元される関数名の直前**にある場合は一緒に除去します（`TAKE(@xSORT(…),3)` → `TAKE(SORT(…),3)`）。除去しないと `@SORT` が配列を単一値に潰し、結果が誤ってしまいます。セル参照や変換対象でない関数の前の `@` は保持されます。変換の要約では `@(暗黙的なインターセクション)` 項目として集計されます |
| `_xll.*` / `_xludf.*`（アドイン UDF の保存プレフィックス） | アドイン関数が登録されていない環境で開いた痕跡として残るプレフィックスを除去します（`_xll.xSORT(…)` → `SORT(…)`）。特に**定義された名前**の数式にこのプレフィックスが残って名前が変換されなかった問題を解消します。EGTools 関数の前のプレフィックスのみを除去し、他のアドインの関数には手を付けません。変換の要約では `_xll.*` 項目として集計されます |
| ロールアウト未確定の関数（IMPORTTEXT/IMPORTCSV） | 導入はされたもののまだ一般提供されていない関数（365 プレビューチャネル限定）は、復元前に**この Excel にネイティブが実際に存在するかを確認**し、確認できた場合のみネイティブへ変換します。確認できない場合は IMAGE と同じ方式で EGTools 実装を維持します（`IMPORTTEXT` → `EG.IMPORTTEXT`）。既に一般提供済みの関数は、この確認なしで常に変換されます |

## 参考

- 実行する Excel に該当のネイティブ関数がない場合（旧バージョン）、復元された数式は `#NAME?` になるため、
  このボタンは最新の Excel へ戻るときに使用してください。
- 再び旧バージョン用に変換するには[旧バージョン互換に変換](apply-compat.md)を実行してください。
