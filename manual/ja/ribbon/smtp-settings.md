# SMTP設定

**場所**: リボン `EGTools` タブ → `EGTools` グループ → スプリットボタンのドロップダウンメニュー

[差し込み](mailmerge.md)の**メール送信**（オプション 4・5・6・7）に使用する SMTP サーバー
情報を登録するダイアログです。

## 設定項目

| 項目 | 説明 |
|---|---|
| 送信者名 | 受信者に表示される送信者の名前（省略可 — 省略するとメールアドレスのみ表示） |
| 送信者メールアドレス | 送信者のアドレスであり、**SMTP のログインアカウント** |
| 送信メールサーバー | SMTP サーバーのアドレス（例: `smtp.gmail.com`） |
| サーバーポート | 既定 **465** |
| SSL | SSL を使用するかどうか（既定はオン） |

## ルール

- 設定はユーザーアカウントに保存され、**ブックには残りません**。
- **パスワードは決して保存されません。**メールを送信するたびに入力を求め、メモリ上でのみ
  使用します。
- 差し込みで送信オプションを選択したのに設定が空の場合（メールアドレス・サーバー・ポートの
  いずれかが未入力の場合）は、このダイアログが**自動的に開きます**。それでも入力されなければ
  送信が中断されます。

## 重要な制限 — 暗黙的 SSL のみ対応

送信エンジン（Windows CDO）は**暗黙的 SSL（implicit SSL）のみ対応**します。通常は
**ポート 465** がこれに該当します。**ポート 587 の STARTTLS には対応していないため**、
587 を入力すると送信に失敗します。

- Gmail: サーバー `smtp.gmail.com`、ポート `465`、SSL オン —
  アカウントのパスワードの代わりに**アプリパスワード**を発行して入力してください。
- 他のサービスでも「SSL(465)」方式のポートを使用し、2 段階認証を使っているアカウントでは
  アプリパスワードが必要になることがあります。

## 参考

- 日本語・韓国語など非 ASCII の件名/本文は UTF-8 でエンコードされて送信されます。
- 送信に失敗した場合は、サーバーが返したエラーの説明が[差し込み](mailmerge.md)の完了時の要約の
  失敗リストにそのまま表示されます。
