# 画像/写真

**位置**: リボン `EGTools++` タブ → `画像/写真` グループ

画像をセルに合わせて挿入・整列・抽出する機能グループです。スプリットボタン 2 個 —
**画像**(既定の動作 = 画像の挿入; メニュー: 画像の挿入・名前で挿入・フォームへ挿入)と
**調整**(既定の動作 = 選択を調整; メニュー: 選択を調整・すべて調整・抽出保存) — で
構成されます。

## 画像の挿入

画像ファイルを 1 つ選び、現在の選択範囲のサイズに合わせて挿入します。

1. ファイル選択ダイアログで画像ファイルを選びます
   (jpg・jpeg・png・gif・bmp・tif・tiff・svg・emf・wmf など、キャンセルすると終了)。
2. 選択範囲の位置・サイズに **0.2pt の余白**を設けて画像が挿入されます
   (ドキュメントに埋め込み保存、ファイルへのリンクではありません)。
3. 挿入された画像の**名前はファイル名**に設定され、**縦横比の固定は解除**されるため、
   以後のセル調整時に自由に変形できます。

## 名前で挿入

フォルダーを選び、シートのセル値と**同じ名前の画像ファイル**を探してそのセルに挿入します。
名簿や商品リストのように名前が入力された表へ写真を一括で貼り付けるときに使用します。

1. フォルダー選択ダイアログで画像の入ったフォルダーを選びます(キャンセルすると終了)。
2. アクティブシートの使用範囲(A1 から)のすべてのセル値を確認し、値と名前が一致する
   画像ファイルをフォルダーから探します。
   - 拡張子は付けても省いてもかまいません(セル値 `写真1` ↔ ファイル `写真1.jpg` はどちらも一致)。
     大文字・小文字は区別しません。
   - jpg・jpeg・png・gif・bmp・tif・tiff・svg・emf・wmf などの画像拡張子のファイルのみが対象です。
3. 見つかった画像をそのセル(結合セルの場合は結合範囲全体のサイズ)に **0.3pt の余白**で
   挿入します(ドキュメントに埋め込み保存)。画像の名前は拡張子を除いたファイル名に設定され、
   縦横比の固定は解除されます。
4. 完了後に結果(挿入したフォルダーの案内 / 追加された画像はありません)を表示します。

同じ値が複数のセルにある場合は、各セルごとに挿入されます。

## フォームへ挿入

フォームを複製しながら、`{{}}` プレースホルダーの位置にフォルダーの画像を順番に挿入します。
写真台帳(写真報告書)のフォームを埋めるときに使用します。

1. **フォーム範囲の指定** — 範囲入力ダイアログでフォーム範囲を指定します(既定値 = 現在の
   選択、キャンセルすると終了)。フォーム内に `{{}}` のみが入力されたセル(写真の位置)が 1 つ以上
   必要で、ない場合は案内の後に終了します。
2. **複製方法の入力** — `1` = フォームシートを丸ごと複製 / `2` = フォーム範囲を
   下方向へ複製 / `3` = 右方向へ複製。
3. **フォルダー選択** — フォルダー内の画像ファイルを**名前順**に並べ替えて使用します
   (画像がない場合は案内の後に終了)。
4. 画像をすべて使い切るまでフォームを複製しながら、各 `{{}}` セル(結合セルの場合は結合
   範囲)に **0.3pt の余白**で画像を挿入します。**セル値にはファイル名が
   記録**され、画像の名前もファイル名です。画像を使い切った後に残った `{{}}` は
   消去されます。進行状況はステータスバーに表示されます。

- 方法 1 はシートを複製するため、シート名が `元の名前_1`、`_2` … と増えていきます。
- 方法 2/3 は行/列全体をコピーするため、行の高さ・列の幅が維持されます
  (複製位置の既存の内容は消去されます)。

## 選択を調整

選択した画像を、各画像の左上の頂点が位置するセルに合わせます。

1. 画像を選択してボタンを押すと、**余白入力**ダイアログが表示されます
   (0~10、既定 0.3)。数値でない値を入力するかキャンセルすると終了します。
2. 各画像を左上セルのサイズに、余白の分だけ内側に合わせます。
   左上セルが**結合範囲**の場合は、結合範囲全体のサイズに合わせます。
3. **90 度/270 度回転**された画像は縦横を入れ替え、回転状態のまま
   セルに収まるよう補正します。

画像が選択されていない場合は「画像が選択されていません」という案内が表示されます。
画像(写真)オブジェクトのみを処理し、図形・グラフなどには触れません。

## すべて調整

アクティブシートの**すべての画像**を、選択を調整と同じ方式で一括調整します。

1. 確認ダイアログ(続行するかどうか)に同意すると、**余白入力**ダイアログが表示されます(0~5、既定 0.3)。
2. シート内のすべての画像を、それぞれの左上セル(結合範囲の場合は結合サイズ)に合わせます。
   進行状況は Excel の**ステータスバー**に画像名で表示されます。
3. 完了後に結果(調整完了 / 画像がありません)を案内します。

## 抽出保存

アクティブシートの**すべての画像**を、指定したフォルダーに**元の画質のまま**保存します。
シートに貼り付けられた写真をファイルとして取り戻すときに使用します。

1. シートに画像がない場合は案内の後に終了します。保存先フォルダーを選択します
   (キャンセルすると終了)。
2. ファイル名は**画像の左上の頂点が位置するセルの値**です。セルが空の場合は
   `画像名_R行C列` の形式になります。ファイル名に使用できない文字は `_` に置き換えられ、
   名前が重複すると `_1`、`_2`… が付きます。拡張子はドキュメントに保存された元の
   形式(jpg・png など)のままです。
3. 内部動作: ブックの**コピーを一時フォルダーに保存**し、ドキュメント内の元の画像
   データをそのまま取り出します。画面表示の画質で描き直す方式ではないため、
   **ドキュメントに挿入した時点の画質がそのまま保持**され、元のドキュメントはまったく
   変更されません(一時ファイルは自動削除)。
4. 完了後に抽出した個数と保存フォルダーを案内します。

- ドキュメントが **xlsx/xlsm 形式**である必要があります。他の形式(.xls など)では
  「画像の抽出に失敗しました」という案内が表示されることがあります。
- 対象は画像(写真)オブジェクトです。図形・グラフは保存しません。

## 参考

- 余白の値が 0 の場合はセルいっぱいの画像になり、大きいほどセルの罫線との間隔が広くなります。
- 調整の基準は画像の**左上の頂点がかかっているセル**です。目的のセルに合わない場合は、
  画像を該当セルの上へ移動してから再度実行してください。
