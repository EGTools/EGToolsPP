# リボンメニュー

EGTools++ を読み込むと、リボンに **EGTools++** タブが追加されます。
機能ボタンは性質ごとの**グループ**にまとめられており、今後機能が追加されると
グループ単位で拡張されます。

## グループ: 表示セル

フィルター・非表示状態でのコピー・貼り付けを扱います(スプリットボタン 2 個: コピー = 表示セルのみコピー / 貼り付け = 値のみ貼り付け)。詳細: [表示セル](visible-cells.md)

| メニュー | 説明 |
|---|---|
| [表示セルのみコピー](visible-cells.md#表示セルのみコピー) | 選択範囲の表示セルのみをコピー元として記憶し、クリップボードにコピー |
| [全体コピー](visible-cells.md#全体コピー) | 選択範囲全体(非表示を含む)をコピー元として記憶 |
| [値のみ貼り付け](visible-cells.md#値のみ--数式--すべて貼り付け) | 記憶したコピー元を貼り付け先の表示セルにのみ値として貼り付け |
| [数式貼り付け](visible-cells.md#値のみ--数式--すべて貼り付け) | 表示セルにのみ数式として貼り付け |
| [すべて貼り付け](visible-cells.md#値のみ--数式--すべて貼り付け) | 表示セルにのみ値・数式・書式をまとめて貼り付け |

## グループ: セル結合/分割

結合セルを扱う機能です(スプリットボタン 2 個: 結合 = 書式なし内容結合 /
分割 = 書式なし行分割)。詳細: [セル結合/分割](merge-split.md)

| メニュー | 説明 |
|---|---|
| [連続値結合](merge-split.md#連続値結合) | 縦に連続する同じ値の区間を実際に結合(複数列は階層型) |
| [内容を残す結合](merge-split.md#内容を残す結合) | 値はそのままに見た目だけを結合 — 関数・フィルターが引き続き動作 |
| [連続値を残す結合](merge-split.md#連続値を残す結合) | 連続する同じ値の区間をそれぞれ見た目だけ結合 |
| [書式なし/書式あり内容結合](merge-split.md#書式なし--書式あり内容結合) | 範囲を 1 つのセルに結合し、内容を区切り文字・改行で連結(書式ありは文字書式を保持) |
| [書式なし/書式あり行結合](merge-split.md#書式なし--書式あり行結合) | 各行を 1 つの結合セルにし、内容を連結 |
| [書式なし/書式あり列結合](merge-split.md#書式なし--書式あり列結合) | 各列を 1 つの結合セルにし、内容を改行で連結 |
| [分割して埋める](merge-split.md#分割して埋める) | 結合を解除し、結合されていた値を再び埋めます(数式は値に変換) |
| [書式なし/書式あり行分割](merge-split.md#書式なし--書式あり行分割) | 結合セルのテキストを改行で分割し、行ごとに配分(不足すれば行を挿入) |
| [書式なし/書式あり列分割](merge-split.md#書式なし--書式あり列分割) | 結合セルのテキストを区切り文字で分割し、列ごとに配分(不足すれば列を挿入) |

## グループ: 画像/写真

画像をセルに合わせて挿入・整列・抽出します(スプリットボタン 2 個: 画像 = 画像の挿入 / 調整 = 選択を調整)。
詳細: [画像/写真](pictures.md)

| メニュー | 説明 |
|---|---|
| [画像の挿入](pictures.md#画像の挿入) | 画像ファイルを選び、選択範囲のサイズに合わせて挿入 |
| [名前で挿入](pictures.md#名前で挿入) | セルの値と同じ名前の画像をフォルダーから探し、そのセルに挿入 |
| [フォームへ挿入](pictures.md#フォームへ挿入) | フォームを複製しながら `{{}}` の位置にフォルダーの画像を順番に挿入 |
| [選択を調整](pictures.md#選択を調整) | 選択した画像をそれぞれの左上セルのサイズに調整 |
| [すべて調整](pictures.md#すべて調整) | シート内のすべての画像をセルサイズに一括調整 |
| [抽出保存](pictures.md#抽出保存) | シート内のすべての画像を指定フォルダーに元の画質のまま保存 |

## グループ: カレンダー/予定表

カレンダー・予定表シートを作成します(スプリットボタン 2 個: カレンダー = 月間 / 予定表 = 日次B)。
詳細: [カレンダー/予定表](calendar.md)

| メニュー | 説明 |
|---|---|
| [月間](calendar.md#月間) | 月間カレンダーシート(週番号・祝日・旧暦を表示) |
| [年間A](calendar.md#年間a--年間b) | 年間カレンダー縦型(3×4) |
| [年間B](calendar.md#年間a--年間b) | 年間カレンダー横型(4×3) |
| [週間](calendar.md#週間) | 週間予定表(日~土、08:00~21:00 の時間軸) |
| [日次A](calendar.md#日次a--日次b) | 日次予定表 2 段型(未完了業務の繰り越し) |
| [日次B](calendar.md#日次a--日次b) | 日次予定表 3 段型(未完了業務の繰り越し) |

## グループ: フォーム

フォームをデータ一覧で埋めて繰り返し生成します(スプリットボタン、既定 = ラベル作成)。
詳細: [フォーム](forms.md)

| メニュー | 説明 |
|---|---|
| [ラベル作成](forms.md#ラベル作成) | フォームをデータ行ごとに複製し、`{{列名}}` を値に置換 |
| [差し込み](mailmerge.md) | データ行ごとにフォームシートを複製し、個別シート/ファイル(xlsx/PDF)・個別印刷・メール送信(ファイル添付) |

## グループ: ツール

よく使う補助機能のまとめです(スプリットボタン、既定 = 全体を再計算)。詳細: [ツール](utilities.md)

| メニュー | 説明 |
|---|---|
| [スタイル削除](utilities.md#スタイル削除) | ユーザー定義のセルスタイルを一括削除(組み込み/使用中の保持を選択) |
| [名前の削除](utilities.md#名前の削除) | 参照が壊れた、または非表示の定義された名前を削除 |
| [エラー整理](utilities.md#エラー整理) | エラー値の数式を `IFERROR` で包み、表示されないように整理 |
| [空セル整理](utilities.md#空セル整理) | 長さ 0 の文字列セルを本当の空セルに整理 |
| [メモの整頓](utilities.md#メモの整頓) | シート内のすべてのメモをセルの右横へ移動 + 自動サイズ調整 |
| [罫線の色を変更](utilities.md#罫線の色を変更) | 選択範囲のすべての罫線の色を一括変更(線種は維持) |
| [形状トレース](utilities.md#形状トレース) | 背景色が塗られたセルの輪郭をなぞったフリーフォーム図形を作成 |
| [UDF 値固定](utilities.md#udf-値固定) | EGTools 関数の数式を値に変え、元の数式をメモとして保存(配布用) |
| [CheckBox 適用](utilities.md#checkbox-適用) | 0/1 の入力を ✅/⬜ で表示するセル書式を適用 |
| [全体を再計算](utilities.md#全体を再計算) | 開いているすべてのブックを強制的に全体再計算 |

## グループ: EGTools

数式内の関数名の一括変換、SMTP設定、API キー管理、アドイン情報をまとめた
スプリットボタンです(既定 = EGTools++ について)。

| メニュー | 説明 |
|---|---|
| [旧バージョン互換に変換](apply-compat.md) | モダン/ネイティブ(`_xlfn.*`)関数トークンを EGTools 互換の関数名に一括変換 |
| [組み込み関数に復元](restore-native.md) | EGTools 関数名をネイティブの組み込み関数に一括復元 |
| [SMTP設定](smtp-settings.md) | 差し込みメール送信用の SMTP サーバーを登録(パスワードは保存しません) |
| [API キー管理](api-keys.md) | 公共 API キーの登録/削除(住所検索 · data.go.kr · vworld — data.go.kr キーは祝日・カレンダー・事業者登録で共有) |
| EGTools++ について | バージョン・配布元・基盤ライブラリを表示し、GitHub Release に新しいバージョンがあれば通知とともに配布元リンクを提供します |

## セルの右クリックメニュー

リボンのほかに、セルのコンテキストメニューにも項目が追加されます。詳細: [セルの右クリックメニュー](context-menu.md)

| 項目 | 説明 |
|---|---|
| [日付入力](context-menu.md#日付入力) | セルの横にカレンダーを表示し、クリックした日付をセルに入力 |
| [リンクを開く](context-menu.md#リンクを開く) | セル内容の http/https URL を既定のブラウザーで開きます |

## 挿入タブの CheckBox

Excel の `挿入` タブにも [CheckBox 適用](utilities.md#checkbox-適用) ボタンが追加されます。
ネイティブのチェックボックスがある Microsoft 365 では表示されません。
