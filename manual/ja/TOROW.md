# TOROW

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2024

配列を 1 行として返します。

## 構文

```
=TOROW(配列, [無視], [列方向スキャン])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 配列 | 必須 | 配列 |
| 無視 | 省略可能 | 0 なし,1 空白,2 エラー,3 両方 |
| 列方向スキャン | 省略可能 | TRUE で列方向 |

## 戻り値

配列のすべての値を 1 行(1×N)に並べた配列を返し、動的配列をサポートする Excel ではスピルします。無視オプション(1=空の値、2=エラー、3=両方)で値を除外できます。配列が空の場合や、残る値がない場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=TOROW({1,2;3,4})` | {1,2,3,4} | 行優先で 1 行に |
| `=TOROW({1,2;3,4},0,TRUE)` | {1,3,2,4} | 列単位でスキャン |
| `=TOROW({1,"",2},1)` | {1,2} | 空の値を無視 |

## 解説

- 空の文字列("")も空の値と見なされ、無視オプション 1・3 で除外されます。
- すべての値が除外される場合は、ネイティブの #CALC! の代わりに #VALUE! を返します。
- 無視・列基準のオプションに配列を指定すると、その配列と同じ形状の配列を返し、各要素は要素ごとの結果の最初の値になります(ネイティブと同じ降格リフティング)。
- 関連関数: TOCOL。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `TOROW` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.TOROW` として登録されます。
