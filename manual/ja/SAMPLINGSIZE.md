# SAMPLINGSIZE

**種類**: EGTools 専用関数

ISO 2859-1 のサンプルサイズ(n)を返します。

## 構文

```
=SAMPLINGSIZE(ロット数量, AQL, [検査水準], [厳格度], [方式], [回数])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| ロット数量 | 必須 | ロット/バッチ数量 |
| AQL | 必須 | 合格品質限界、例 1.0 |
| 検査水準 | 省略可能 | G1/G2/G3/S1~S4(既定 G2) |
| 厳格度 | 省略可能 | 0 通常(既定)、1 きつい、-1 ゆるい |
| 方式 | 省略可能 | 1 1回(既定)、2 2回、3~5 多回; +10 で強制 |
| 回数 | 省略可能 | 検査回数 |

## 戻り値

ISO 2859-1 のサンプルサイズ n(スカラー数値)を返します。AQL が 0~1000 の範囲外の場合や検査水準・方式・回数が不正な場合は #VALUE!、ロット数量が 2 未満の場合や AQL が 0.01 未満の場合は #NUM!、表から該当する値が見つからない場合は #N/A エラーを返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=SAMPLINGSIZE(1000,1)` | 80 | G2・通常・1 回、AQL 1.0 |
| `=SAMPLINGSIZE(1000,1,"G2",0,2,1)` | 50 | 2 回サンプリングの 1 回目のサンプルサイズ |
| `=SAMPLINGSIZE(30,0.065)` | 30 | ロット数量で制限 |

## 解説

- 計算された n がロット数量より大きい場合はロット数量を返し、ロット数量が 1 の場合は 1 を返します。
- 方式に 10 を加えると、表の切替規則(*、++)を無視してその方式を強制します。
- 関連関数: SAMPLINGLABEL、SAMPLINGAC、SAMPLINGRE。
- 対応: Excel 2010+。すべての Excel バージョンで `SAMPLINGSIZE` の名前のまま登録されます。
