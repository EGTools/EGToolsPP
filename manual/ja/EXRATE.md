# EXRATE

**種類**: EGTools 専用関数

指定日の対ウォン基準為替レートを照会します(最大 10 日遡及)。

## 構文

```
=EXRATE([通貨], [日付])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 通貨 | 省略可能 | 3 文字コード、例 USD(既定)、EUR、JPY… |
| 日付 | 省略可能 | 照会日(既定: 今日) |

## 戻り値

韓国ウォン基準の基準為替レートを数値スカラーとして返します。未来の日付を指定すると #VALUE! を、サポートしていない通貨コードの場合や 10 日の遡及範囲内に告示レートがない場合は #N/A を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=EXRATE("USD")` |  | 結果は照会日やネットワークによって異なります |

## 解説

- smbs.biz(ソウル外国為替仲介)の基準為替レートを HTTP で照会します — ネットワーク接続が必要です。
- 指定日に告示がない場合は、最大 10 日前まで遡って照会します(休日対応)。
- CNY は CNH に自動変換されます。非マクロ・スレッドセーフとして登録されており、並列で再計算されます。
- 対応: Excel 2010+。すべての Excel バージョンで `EXRATE` の名前のまま登録されます。
