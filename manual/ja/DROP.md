# DROP

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2024

配列の先頭または末尾から行・列を削除します。

## 構文

```
=DROP(配列, 行数, [列数])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 配列 | 必須 | 配列 |
| 行数 | 必須 | 削除する行(負=末尾から) |
| 列数 | 省略可能 | 削除する列(省略可) |

## 戻り値

指定した数の行・列を取り除いた残りの配列を返し、動的配列をサポートする Excel ではスピルします。配列が空の場合や、削除後に残る行・列がない場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=DROP({1,2,3;4,5,6;7,8,9},1)` | {4,5,6;7,8,9} | 最初の行を削除 |
| `=DROP({1,2,3;4,5,6;7,8,9},1,-1)` | {4,5;7,8} | 最初の行と最後の列を削除 |
| `=DROP({1,2},5)` | #VALUE! | すべて削除するとエラー |

## 解説

- 行数・列数が負数の場合は末尾から削除します。
- 結果が空の配列になる場合は、ネイティブの #CALC! の代わりに #VALUE! を返します。
- 関連関数: TAKE。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `DROP` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.DROP` として登録されます。
