# PERCENTOF

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Microsoft 365

部分集合の合計を全データの合計で割った比率を返します。

## 構文

```
=PERCENTOF(data_subset, data_all)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| data_subset | 必須 | データの部分集合 |
| data_all | 必須 | すべてのデータ |

## 戻り値

部分データの合計を全体データの合計で割った比率をスカラーの数値として返します。引数が欠落している場合は #VALUE!、全体の合計が 0 の場合や全体に数値がない場合は #DIV/0! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=PERCENTOF({10;20},{10;20;30;40})` | 0.3 | 部分合計÷全体合計の比率 |
| `=PERCENTOF(50,200)` | 0.25 | スカラー値の比率 |

## 解説

- 数値でない値は合計の計算では無視されます。
- GROUPBY/PIVOTBY の function 引数に "PERCENTOF" を指定すると、グループごとの構成比を求められます。
- ただしエラー値は無視されず、そのエラーが結果になります(ネイティブの #NUM! ではなく元のエラーを保持)。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `PERCENTOF` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.PERCENTOF` として登録されます。
