# REGEXREPLACE

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Microsoft 365

正規表現に一致するテキストを置換します($1.. 後方参照対応)。

## 構文

```
=REGEXREPLACE(テキスト, パターン, 置換文字, [回数], [大文字小文字区別])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| テキスト | 必須 | 元のテキスト |
| パターン | 必須 | 正規表現パターン |
| 置換文字 | 必須 | 置換テキスト($1, $2…) |
| 回数 | 省略可能 | 0 すべて(既定)、N = N 番目 |
| 大文字小文字区別 | 省略可能 | 0 区別(既定)、1 無視 |

## 戻り値

置換後の単一のテキスト(スカラー)を返します。正規表現が不正な場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=REGEXREPLACE("a1b2c3","\d","-")` | a-b-c- | すべて置換 |
| `=REGEXREPLACE("a1b2c3","\d","-",2)` | a1b-c3 | 2 番目のみ置換 |
| `=REGEXREPLACE("john smith","(\w+) (\w+)","$2 $1")` | smith john | 後方参照による置換 |

## 解説

- 置換テキストで $1、$2 の後方参照をサポートします。
- 出現回数 0(既定)はすべてを、N>0 は N 番目の一致のみを置換します。
- 正規表現の構文は std::wregex の ECMAScript です。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `REGEXREPLACE` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.REGEXREPLACE` として登録されます。
