# WRAPCOLS

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2024 / Microsoft 365

ベクトルを 1 列あたり指定数で折り返して 2 次元配列にします。

## 構文

```
=WRAPCOLS(ベクトル, 折り返し数, [埋める値])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| ベクトル | 必須 | 折り返すベクトル |
| 折り返し数 | 必須 | 1 列あたりの値数 |
| 埋める値 | 省略可能 | 埋め値(既定 #N/A) |

## 戻り値

ベクトルの値を各列に折り返し数の個数ずつ縦方向に配置した 2 次元配列を返し、動的配列をサポートする Excel ではスピルします。最後の列の足りない部分は埋め込み値(既定は #N/A)で埋めます。ベクトルが空の場合や、折り返し数が 0 以下の場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=WRAPCOLS({1,2,3,4,5},2)` | {1,3,5;2,4,#N/A} | 1 列あたり 2 個ずつ配置 |
| `=WRAPCOLS({1,2,3,4,5},3,0)` | {1,4;2,5;3,0} | 埋め込み値 0 |

## 解説

- 2 次元配列の入力も行優先で平坦化して処理します。
- 関連関数: WRAPROWS。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `WRAPCOLS` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.WRAPCOLS` として登録されます。
