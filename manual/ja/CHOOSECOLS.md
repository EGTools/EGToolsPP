# CHOOSECOLS

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2024 / Microsoft 365

配列から指定した列を返します。

## 構文

```
=CHOOSECOLS(配列, 列番号1, ...)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 配列 | 必須 | 配列 |
| 列番号1 | 必須 | 返す列(負=末尾から) |
| … | 省略可能 | 上記の引数を繰り返し指定できます |

## 戻り値

選択した列で構成される配列を返し、動的配列をサポートする Excel ではスピルします。配列が空の場合、列番号が 0 または範囲外の場合、あるいは列番号を 1 つも指定しない場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=CHOOSECOLS({1,2,3;4,5,6},1,3)` | {1,3;4,6} | 1 列目と 3 列目を選択 |
| `=CHOOSECOLS({1,2,3;4,5,6},-1)` | {3;6} | 最後の列を選択 |
| `=CHOOSECOLS({1,2;3,4},5)` | #VALUE! | 範囲外の列番号 |

## 解説

- 列番号が負数の場合は後ろから数えます。
- 行を選択するには CHOOSEROWS を使用します。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `CHOOSECOLS` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.CHOOSECOLS` として登録されます。
