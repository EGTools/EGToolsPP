# IMPORTHTML

**種類**: Google スプレッドシート互換関数

Web ページから表(table)やリスト(list)を抽出します。

## 構文

```
=IMPORTHTML(URL, [種類], [番号], [ロケール])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| URL | 必須 | Web ページの URL |
| 種類 | 省略可能 | "table"(既定) または "list"(ul/ol) |
| 番号 | 省略可能 | 何番目の要素を抽出するか、1 から(既定 1) |
| ロケール | 省略可能 | 数値解釈のロケール、例 "de-DE" |

## 戻り値

Web ページの表(2 次元配列)またはリスト(N×1 配列)をスピルで返し、数値のテキストは自動変換されます。URL の欠落、search が "table"/"list" 以外、index が 1 未満の場合は #VALUE!、ダウンロードの失敗や該当 index の表/リストがない場合は #N/A を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=IMPORTHTML("https://en.wikipedia.org/wiki/Microsoft_Excel","table",1)` |  | ページの内容に依存します |

## 解説

- <script> を除去した後に MSHTML で解析するため、スクリプトが生成する動的コンテンツは取得できません。
- 表の rowspan/colspan はグリッドへ正規化され、値は左上のセルにのみ入ります。
- COM を使用するためマルチスレッド再計算からは除外され、インターネット接続が必要です。
- 対応: Excel 2010+。すべての Excel バージョンで `IMPORTHTML` の名前のまま登録されます。
