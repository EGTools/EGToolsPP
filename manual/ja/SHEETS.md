# SHEETS

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2013

ブック（または参照）のシート数を返します。

## 構文

```
=SHEETS([参照])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 参照 | 省略可能 | 参照（省略可） |

## 戻り値

参照を省略した場合はブックのシート数を、参照を指定した場合は常に 1 を数値として返します。シート数の取得に失敗した場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=SHEETS()` |  | ブックのシート数(ブックに依存) |

## 解説

- 参照を指定した場合は常に 1 を返します(3-D 参照のシート数の計算はサポートしていません)。
- マクロシート型関数として登録されます。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `SHEETS` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.SHEETS` として登録されます。
