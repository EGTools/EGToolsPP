# BRNSTATUS

**種類**: EGTools 専用関数

事業者登録番号の現在の状態を確認します(韓国国税庁、data.go.kr)。

## 構文

```
=BRNSTATUS(登録番号, [api_key])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 登録番号 | 必須 | 事業者登録番号(複数可、ハイフン可) |
| api_key | 省略可能 | data.go.kr の認証キー。1 回入力するとレジストリに保存 |

## 戻り値

各事業者登録番号の課税類型テキスト(tax_type)を入力と同じ形で返します(配列入力の場合はスピル)。入力が空の場合は #VALUE! を返し、キー未設定・ネットワーク・サービスのエラーは "ERROR: …" テキスト、照会できなかった番号は "#N/A" テキストとして表示されます。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=BRNSTATUS("123-45-67890")` |  | 事業者登録状態の照会(ネットワーク・API キーが必要) |

## 解説

- API キーは配布されません。[公共データポータルの国税庁事業者登録情報状態照会サービス](https://www.data.go.kr)で発行を受け、最後の引数として 1 回入力するか、リボンの [EGTools] → [API キー管理] で登録するとユーザーアカウントに保存され、以後は省略できます。
- data.go.kr の認証キーはアカウントごとに 1 つのため、KOREANHOLIDAYS やリボンのカレンダー/スケジュール表と同じキーを共有します。旧バージョンで事業者登録用に別途登録していたキーは、最初の使用時に自動的に統合スロットへ移行されます(ユーザーが再登録する必要はありません)。
- サービスがキーを拒否した場合(HTTP 401/403 など)、保存されたキーを自動的に削除し、再発行の案内を返します。
- 事業者登録番号が **数値として保存されたセル** もそのまま照会します — 数値は指数表記なしの整数文字列に変換し、先頭の 0 が消えて 9 桁になった値は 10 桁に復元します。ハイフン・空白など数字以外の文字は無視し、空のセルは空の文字列として返されます。
- 100 件単位でまとめて POST リクエストするため、大量照会に適しています。
- 事業者登録番号の配列の一括照会(100 件単位)は従来どおり維持されます。api_key に配列を指定すると保存前に #VALUE! を返します(誤ったキーの保存を防止)。
- 対応: Excel 2010+。すべての Excel バージョンで `BRNSTATUS` の名前のまま登録されます。
