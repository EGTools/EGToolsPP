# TEXTBEFORE

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2024 / Microsoft 365

区切り文字の前のテキストを返します。

## 構文

```
=TEXTBEFORE(テキスト, 区切り, [番号], [一致モード], [末尾一致], [見つからない時])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| テキスト | 必須 | 元のテキスト |
| 区切り | 必須 | 検索する区切り文字 |
| 番号 | 省略可能 | 何番目か、負数は末尾から(既定 1) |
| 一致モード | 省略可能 | 1 で大文字小文字を無視(既定 0) |
| 末尾一致 | 省略可能 | 1 でテキストの末尾を区切りと見なす(既定 0) |
| 見つからない時 | 省略可能 | 見つからない場合の値(既定 #N/A) |

## 戻り値

区切り文字の前の単一のテキスト(スカラー)を返します。順番(instance_num)が 0 の場合は #VALUE!、区切り文字が見つからない場合は未検出値(既定は #N/A)を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=TEXTBEFORE("red-blue-green","-")` | red | 最初の区切り文字の前 |
| `=TEXTBEFORE("a,b,c",",",-1)` | a,b | 末尾から 1 番目の前 |
| `=TEXTBEFORE("abc","x")` | #N/A | 区切り文字なし |

## 解説

- 末尾一致(match_end)=1 の場合は、テキストの末尾(正の順番)/先頭(負の順番)を 1 個の仮想区切り文字と見なします。
- 一致モード(match_mode)=1 の場合は大文字と小文字を区別しません。
- 関連関数: TEXTAFTER、TEXTSPLIT。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `TEXTBEFORE` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.TEXTBEFORE` として登録されます。
