# SAMPLINGAC

**種類**: EGTools 専用関数

ISO 2859-1 の合格判定個数(Ac)を返します。

## 構文

```
=SAMPLINGAC(ロット数量, AQL, [検査水準], [厳格度], [方式], [回数])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| ロット数量 | 必須 | ロット/バッチ数量 |
| AQL | 必須 | 合格品質限界 |
| 検査水準 | 省略可能 | 既定 G2 |
| 厳格度 | 省略可能 | 0 通常、1 きつい、-1 ゆるい |
| 方式 | 省略可能 | 1 1回、2 2回、3~5 多回 |
| 回数 | 省略可能 | 検査回数 |

## 戻り値

ISO 2859-1 の合格判定個数 Ac(スカラー数値)を返します。AQL が 0~1000 の範囲外の場合や検査水準・方式・回数が不正な場合は #VALUE!、ロット数量が 2 未満の場合や AQL が 0.01 未満の場合は #NUM!、表から該当する値が見つからない場合は #N/A エラーを返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=SAMPLINGAC(1000,1)` | 2 | G2・通常・1 回、AQL 1.0 |
| `=SAMPLINGAC(1000,1,"G2",1)` | 1 | きつい検査 |
| `=SAMPLINGAC(500,2.5)` | 3 | ロット 500、AQL 2.5 |

## 解説

- ロット数量が 1 の場合は 0 を返します。
- 関連関数: SAMPLINGSIZE、SAMPLINGRE、SAMPLINGLABEL。
- 対応: Excel 2010+。すべての Excel バージョンで `SAMPLINGAC` の名前のまま登録されます。
