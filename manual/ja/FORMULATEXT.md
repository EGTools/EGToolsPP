# FORMULATEXT

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2013

参照したセルの数式を文字列として返します。

## 構文

```
=FORMULATEXT(参照)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 参照 | 必須 | 数式を取得するセル |

## 戻り値

参照したセルの数式をテキストスカラーとして返します。参照を省略した場合、セルに数式がない場合、取得に失敗した場合は #N/A を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=FORMULATEXT(A1)` |  | A1 の内容によって異なります |

## 解説

- マクロシート型関数として登録されます。
- 関連関数: ISFORMULA。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `FORMULATEXT` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.FORMULATEXT` として登録されます。
