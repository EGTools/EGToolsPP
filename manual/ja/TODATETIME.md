# TODATETIME

**種類**: EGTools 専用関数

ハングル・漢字(年月日時分秒)を含む文字列を日時値に変換します。

## 構文

```
=TODATETIME(テキスト)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| テキスト | 必須 | 日付/時刻を含む文字列 |

## 戻り値

日付・時刻のシリアル値(スカラー数値)を返します。日付のみの場合は整数、時刻のみの場合は 1 未満の小数を返し、日付・時刻が見つからない場合は空のテキストを、解析中にエラーが発生した場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=TODATETIME("2026년 1월 15일")` | 46037 | ハングルの日付をシリアル値に |
| `=TODATETIME("오후 2시 30분")` | 0.604166667 | 午後の時刻を時刻値に |

## 解説

- 漢字(年月日時分秒)や 오전/오후(韓国語の午前/午後)・AM/PM・上午/下午 の表記も認識します。
- 月-日のみの場合は今年の年として解釈し、31 より大きい 2 桁の年は 2000 年代に補正します。
- 結果のセルに日付/時刻の表示形式を設定して使用します。
- 対応: Excel 2010+。すべての Excel バージョンで `TODATETIME` の名前のまま登録されます。
