# MINIFS

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2016/2019

すべての条件を満たすセルの最小値を返します。

## 構文

```
=MINIFS(最小範囲, 条件範囲1, 条件1, ...)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| 最小範囲 | 必須 | 最小値の対象セル |
| 条件範囲1 | 必須 | 調べる範囲 |
| 条件1 | 必須 | 条件、例 "<5" |
| … | 省略可能 | 上記の引数を繰り返し指定できます |

## 戻り値

すべての条件を満たすセルの数値のうち最小値を数値スカラーとして返します。条件範囲のサイズが対象範囲と異なる場合は #VALUE!、条件を満たす値がない場合は 0 を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=MINIFS({10;20;30},{"a";"b";"a"},"a")` | 10 | 条件を満たす最小値 |
| `=MINIFS({7;8;9},{"x";"y";"z"},"?")` | 7 | ワイルドカード条件 |

## 解説

- 条件は数値、比較演算子("<5" など)、ワイルドカード(*、?)をサポートし、テキストの比較では大文字と小文字を区別しません。
- 関連関数: MAXIFS。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `MINIFS` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.MINIFS` として登録されます。
