# STREXT

**種類**: EGTools 専用関数

文字種別(数字/英字/ハングル/日本語/漢字)または正規表現で抽出・削除します。

## 構文

```
=STREXT(テキスト, オプション, [区切り])
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| テキスト | 必須 | 対象の文字列 |
| オプション | 必須 | S=空白 A=英字 N=数字 K=ハングル J=日本語 H=漢字、先頭 "-" で削除、その他は正規表現 |
| 区切り | 省略可能 | 抽出片の連結子(既定なし) |

## 戻り値

抽出(または削除)結果である単一のテキスト(スカラー)を返します。テキスト・オプションが省略されている場合、オプションが空の場合、有効な文字クラスがない場合、または正規表現が不正な場合は #VALUE! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=STREXT("abc123한글45","N")` | 12345 | 数字のみ抽出 |
| `=STREXT("abc123한글45","K")` | 한글 | ハングルのみ抽出 |
| `=STREXT("a1b2","N","-")` | 1-2 | 区切り文字で連結 |

## 解説

- N クラスには小数点 '.' も含まれます。
- オプションが -SANKJH の組み合わせでない場合は、全体を ECMAScript 正規表現(std::wregex)として解釈します。
- オプションが '-' で始まる場合は、該当する文字を抽出する代わりに削除します。
- 対応: Excel 2010+。すべての Excel バージョンで `STREXT` の名前のまま登録されます。
