# BITRSHIFT

**種類**: MS Excel 互換関数 · **ネイティブ導入**: Excel 2013

数値を指定したビット数だけ右にシフトした結果を返します。

## 構文

```
=BITRSHIFT(number, shift_amount)
```

## 引数

| 引数 | 必須 | 説明 |
|---|---|---|
| number | 必須 | シフトする数値（0 以上） |
| shift_amount | 必須 | 右シフトのビット数（負数は左シフト） |

## 戻り値

右シフトの結果を数値(スカラー)で返します(切り捨て)。number が [0, 2^48-1] 範囲の整数でない場合、shift_amount が整数でない場合や絶対値が 53 を超える場合、または結果が 2^53 を超える場合は #NUM! を返します。

## 例

| 数式 | 結果 | 説明 |
|---|---|---|
| `=BITRSHIFT(13,2)` | 3 | 2 ビット右シフト |
| `=BITRSHIFT(3,-2)` | 12 | 負数は左シフト |

## 解説

- shift_amount が負の場合は左シフトとして動作します。
- 関連関数: BITLSHIFT。
- 対応: Excel 2010+。ネイティブ関数がない旧バージョンでは `BITRSHIFT` の名前のまま（ドロップイン）、ネイティブ関数がある新しい Excel では `EG.BITRSHIFT` として登録されます。
