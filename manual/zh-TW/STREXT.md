# STREXT

**類別**: EGTools 專用函數

依字元類型(數字/拉丁/韓文/日文/漢字)或正規表示式擷取·刪除。

## 語法

```
=STREXT(文字, 選項, [分隔符])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字 | 必要 | 來源文字 |
| 選項 | 必要 | S=空白 A=拉丁 N=數字 K=韓文 J=日文 H=漢字；以 "-" 開頭則刪除；其他視為正規表示式 |
| 分隔符 | 選用 | 擷取片段間的連接符(預設無) |

## 傳回

傳回擷取（或刪除）結果的單一文字（純量）。若缺少文字、選項引數，或選項為空、沒有有效的字元類別，或正規表示式無效，則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=STREXT("abc123한글45","N")` | 12345 | 僅擷取數字 |
| `=STREXT("abc123한글45","K")` | 한글 | 僅擷取韓文 |
| `=STREXT("a1b2","N","-")` | 1-2 | 以分隔符連接 |

## 備註

- N 類別也包含小數點 '.'。
- 若選項不是 -SANKJH 的組合，則整體會解讀為 ECMAScript 正規表示式（std::wregex）。
- 若選項以 '-' 開頭，則會刪除（而非擷取）該類字元。
- 文字指定為陣列時會逐元素處理，以相同形狀的陣列溢出傳回（錯誤元素原樣傳回）；選項·分隔符號指定為陣列時傳回 #VALUE!。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `STREXT` 原名註冊。
