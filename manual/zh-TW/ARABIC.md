# ARABIC

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

將羅馬數字轉換為阿拉伯數字。

## 語法

```
=ARABIC(text)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| text | 必要 | 羅馬數字文字 |

## 傳回

傳回羅馬數字轉換後的數字值(純量)。若含有羅馬數字符號(I·V·X·L·C·D·M)與最前面的 '-' 以外的字元，則傳回 #VALUE! 錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=ARABIC("LVII")` | 57 | 將羅馬數字轉為數字 |
| `=ARABIC("MCMXII")` | 1912 | 轉換大的羅馬數字 |
| `=ARABIC("-X")` | -10 | 支援負數表示 |

## 備註

- 忽略空格且不區分大小寫。
- 空文字傳回 0。
- 文字指定為陣列時會逐元素計算，以相同形狀的陣列溢出傳回（錯誤元素會原樣傳回該錯誤）。
- 相關函數: BASE, DECIMAL
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `ARABIC` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.ARABIC`。
