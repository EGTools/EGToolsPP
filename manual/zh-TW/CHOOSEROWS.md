# CHOOSEROWS

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2024

傳回陣列中指定的列。

## 語法

```
=CHOOSEROWS(陣列, 列號1, ...)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列 | 必要 | 陣列 |
| 列號1 | 必要 | 要傳回的列(負=從結尾) |
| … | 選用 | 上述引數可重複指定 |

## 傳回

傳回由所選列組成的陣列，在支援動態陣列的 Excel 中會溢出。若陣列為空、列號為 0 或超出範圍，或未指定任何列號，則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=CHOOSEROWS({1,2;3,4;5,6},1,-1)` | {1,2;5,6} | 第一列與最後一列 |
| `=CHOOSEROWS({1,2;3,4},3)` | #VALUE! | 列號超出範圍 |

## 備註

- 列號為負數時，從結尾往回計算。
- 若要選取欄，請使用 CHOOSECOLS。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `CHOOSEROWS` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.CHOOSEROWS`。
