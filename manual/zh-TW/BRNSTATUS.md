# BRNSTATUS

**類別**: EGTools 專用函數

查詢營業登記號碼的目前狀態(韓國國稅廳, data.go.kr)。

## 語法

```
=BRNSTATUS(登記號碼, [api_key])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 登記號碼 | 必要 | 營業登記號碼(可多個，允許連字號) |
| api_key | 選用 | data.go.kr 認證金鑰，輸入一次後存入登錄檔 |

## 傳回

以與輸入相同的形狀傳回各營業登記號碼的課稅類型文字（tax_type）（陣列輸入時會溢出）。輸入為空時傳回 #VALUE!；金鑰缺漏、網路或服務錯誤以 "ERROR: …" 文字表示，查無資料的號碼則顯示為 "#N/A" 文字。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=BRNSTATUS("123-45-67890")` |  | 營業登記狀態查詢（需要網路與 API 金鑰） |

## 備註

- 不隨附 API 金鑰。請至公共資料入口網的國稅廳營業登記資訊狀態查詢（https://www.data.go.kr ）申請，以最後一個引數輸入一次，或在功能區 [EGTools] → [管理 API 金鑰] 中註冊，即會儲存於使用者帳戶，之後可省略。
- data.go.kr 認證金鑰每個帳戶僅有一個，因此與 KOREANHOLIDAYS 及功能區行事曆/日程表共用同一金鑰。舊版中為營業登記另行註冊的金鑰，會在首次使用時自動移轉至整合位置（使用者無需重新註冊）。
- 服務拒絕金鑰時（HTTP 401/403 等），會自動刪除已儲存的金鑰並傳回重新申請的指引。
- 營業登記號碼**以數字儲存的儲存格**也能直接查詢 — 數字會轉為不含指數表示法的整數字串，因開頭 0 遺失而只剩 9 位數的值會還原為 10 位數。連字號、空格等非數字字元會被忽略，空白儲存格則傳回空字串。
- 以每 100 筆為單位批次發出 POST 要求，適合大量查詢。
- 編號陣列的批次查詢（每 100 筆一批）維持不變。api_key 指定為陣列時會在儲存前傳回 #VALUE!（防止儲存錯誤的金鑰）。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `BRNSTATUS` 原名註冊。
