# SAMPLINGSIZE

**類別**: EGTools 專用函數

依 ISO 2859-1 傳回樣本量(n)。

## 語法

```
=SAMPLINGSIZE(批量, AQL, [檢驗水準], [嚴格度], [方案], [次數])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 批量 | 必要 | 批/批次數量 |
| AQL | 必要 | 允收品質水準，如 1.0 |
| 檢驗水準 | 選用 | G1/G2/G3/S1~S4(預設 G2) |
| 嚴格度 | 選用 | 0 正常(預設)，1 加嚴，-1 減量 |
| 方案 | 選用 | 1 一次(預設)，2 二次，3~5 多次；+10 強制不轉換 |
| 次數 | 選用 | 抽樣次數 |

## 傳回

傳回 ISO 2859-1 樣本數 n(純量數字)。AQL 超出 0~1000 或檢驗水準·方式·次數錯誤時傳回 #VALUE!，LOT 數量小於 2 或 AQL 小於 0.01 時傳回 #NUM!，在表格中找不到對應值時傳回 #N/A 錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=SAMPLINGSIZE(1000,1)` | 80 | G2·正常·一次抽樣，AQL 1.0 |
| `=SAMPLINGSIZE(1000,1,"G2",0,2,1)` | 50 | 二次抽樣的第一次樣本數 |
| `=SAMPLINGSIZE(30,0.065)` | 30 | 受 LOT 數量限制 |

## 備註

- 計算出的 n 大於 LOT 數量時傳回 LOT 數量，LOT 數量為 1 時傳回 1。
- 方式加 10 可忽略表格的轉換規則(*, ++)，強制使用該方式。
- 所有引數都可指定陣列，可一次計算 LOT 清單或 AQL 表 — 逐元素計算並以相同形狀的陣列溢出傳回；純量會重複使用，欄向量×列向量按外積擴充，大小不符的元素為 #N/A。
- 相關函數: SAMPLINGLABEL, SAMPLINGAC, SAMPLINGRE
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `SAMPLINGSIZE` 原名註冊。
