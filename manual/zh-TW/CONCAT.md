# CONCAT

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2016/2019

連接值和範圍中的文字（無分隔符號）。

## 語法

```
=CONCAT(文字1, ...)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字1 | 必要 | 文字/範圍 |
| … | 選用 | 上述引數可重複指定 |

## 傳回

依序連結所有引數（含範圍與陣列）後傳回單一文字（純量）。實作本身不會傳回額外的錯誤值。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=CONCAT("A",1,"B")` | A1B | 直接連結各值 |
| `=CONCAT({1,2;3,4})` | 1234 | 陣列以列優先連結 |

## 備註

- 不使用分隔符號直接連結。若需要分隔符號，請使用 TEXTJOIN。
- 最多支援 255 個引數。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `CONCAT` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.CONCAT`。
