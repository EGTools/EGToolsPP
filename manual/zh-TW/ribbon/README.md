# 功能區選單

載入 EGTools++ 後，功能區會新增 **EGTools++** 索引標籤。
功能按鈕依性質分為 **群組**，日後新增功能時會以群組為單位擴充。

## 群組: 可見儲存格

處理篩選、隱藏狀態下的複製與貼上（分割按鈕 2 個: 複製 = 僅複製可見儲存格
/ 貼上 = 僅貼上值）。詳細: [可見儲存格](visible-cells.md)

| 選單 | 說明 |
|---|---|
| [僅複製可見儲存格](visible-cells.md#僅複製可見儲存格) | 僅將選取範圍中的可見儲存格記為複製來源並複製到剪貼簿 |
| [全部複製](visible-cells.md#全部複製) | 將整個選取範圍（含隱藏）記為複製來源 |
| [僅貼上值](visible-cells.md#僅貼上值--貼上公式--全部貼上) | 將記住的複製來源僅以值貼到目標的可見儲存格 |
| [貼上公式](visible-cells.md#僅貼上值--貼上公式--全部貼上) | 僅以公式貼到可見儲存格 |
| [全部貼上](visible-cells.md#僅貼上值--貼上公式--全部貼上) | 將值、公式、格式整批僅貼到可見儲存格 |

## 群組: 合併/取消合併儲存格

處理合併儲存格的功能（分割按鈕 2 個: 合併 = 無格式合併內容 /
取消合併 = 無格式拆分為列）。詳細: [合併/取消合併儲存格](merge-split.md)

| 選單 | 說明 |
|---|---|
| [合併連續相同值](merge-split.md#合併連續相同值) | 將垂直連續相同值的區段實際合併（多欄時為階層式） |
| [保留值的合併](merge-split.md#保留值的合併) | 值原封不動，僅合併外觀 — 函數與篩選持續運作 |
| [保留連續值的合併](merge-split.md#保留連續值的合併) | 將連續相同值的各區段僅合併外觀 |
| [無格式/保留格式合併內容](merge-split.md#無格式--保留格式合併內容) | 將區域合併為一個儲存格，並以分隔字元、換行連接內容（保留格式會保存字元格式） |
| [逐列無格式/保留格式合併](merge-split.md#逐列無格式--保留格式合併) | 將每一列變成一個合併儲存格並連接內容 |
| [逐欄無格式/保留格式合併](merge-split.md#逐欄無格式--保留格式合併) | 將每一欄變成一個合併儲存格並以換行連接內容 |
| [取消合併並填滿](merge-split.md#取消合併並填滿) | 解除合併並將原合併的值重新填入（公式轉換為值） |
| [無格式/保留格式拆分為列](merge-split.md#無格式--保留格式拆分為列) | 將合併儲存格文字以換行拆分並逐列分配（不足時插入列） |
| [無格式/保留格式拆分為欄](merge-split.md#無格式--保留格式拆分為欄) | 將合併儲存格文字以分隔字元拆分並逐欄分配（不足時插入欄） |

## 群組: 圖片

將影像配合儲存格插入、對齊、匯出（分割按鈕 2 個: 圖片 = 插入圖片 / 調整 = 調整所選）。
詳細: [圖片](pictures.md)

| 選單 | 說明 |
|---|---|
| [插入圖片](pictures.md#插入圖片) | 選擇影像檔案並配合選取範圍大小插入 |
| [依名稱插入](pictures.md#依名稱插入) | 在資料夾中尋找與儲存格值同名的影像並插入該儲存格 |
| [插入到表單](pictures.md#插入到表單) | 複製表單並將資料夾中的影像依序插入 `{{}}` 位置 |
| [調整所選](pictures.md#調整所選) | 將所選圖片各自調整為其左上角儲存格的大小 |
| [全部調整](pictures.md#全部調整) | 將工作表上的所有圖片一次調整為儲存格大小 |
| [全部匯出](pictures.md#全部匯出) | 將工作表上的所有圖片以原始畫質儲存到指定資料夾 |

## 群組: 行事曆/日程表

建立行事曆、日程表工作表（分割按鈕 2 個: 行事曆 = 月曆 / 日程表 = 日B）。
詳細: [行事曆/日程表](calendar.md)

| 選單 | 說明 |
|---|---|
| [月曆](calendar.md#月曆) | 月曆工作表（顯示週次、節假日、農曆） |
| [年曆A](calendar.md#年曆a--年曆b) | 年曆直式（3×4） |
| [年曆B](calendar.md#年曆a--年曆b) | 年曆橫式（4×3） |
| [週](calendar.md#週) | 週間日程表（週日～週六，08:00～21:00 時間軸） |
| [日A](calendar.md#日a--日b) | 每日日程表兩段式（未完成工作結轉） |
| [日B](calendar.md#日a--日b) | 每日日程表三段式（未完成工作結轉） |

## 群組: 表單

以資料清單填入表單並重複產生（分割按鈕，預設 = 製作標籤）。
詳細: [表單](forms.md)

| 選單 | 說明 |
|---|---|
| [製作標籤](forms.md#製作標籤) | 依每筆資料列複製表單，並以值取代 `{{欄名}}` |
| [郵件合併](mailmerge.md) | 依每筆資料列複製表單工作表，產生個別工作表/檔案（xlsx/PDF）、個別列印、發送郵件（附加檔案） |

## 群組: 工具

常用輔助功能集合（分割按鈕，預設 = 整理錯誤）。詳細: [工具](utilities.md)

| 選單 | 說明 |
|---|---|
| [刪除樣式](utilities.md#刪除樣式) | 批次刪除自訂儲存格樣式（可選擇保留內建/使用中的樣式） |
| [刪除名稱](utilities.md#刪除名稱) | 刪除參照損毀或隱藏的已定義名稱 |
| [整理錯誤](utilities.md#整理錯誤) | 以 `IFERROR` 包住錯誤值公式，使錯誤不再顯示 |
| [清理空文字](utilities.md#清理空文字) | 將長度為 0 的字串儲存格整理為真正的空儲存格 |
| [整理註解](utilities.md#整理註解) | 將工作表的所有註解移到儲存格右側旁 + 自動調整大小 |
| [變更框線色彩](utilities.md#變更框線色彩) | 一次變更選取範圍內所有框線的色彩（維持線條樣式） |
| [描摹形狀](utilities.md#描摹形狀) | 建立沿著填有背景色的儲存格外框描摹的手繪多邊形圖案 |
| [UDF 固定為值](utilities.md#udf-固定為值) | 將 EGTools 函數公式轉換為值，並將原公式保存在註解中（供發佈用） |
| [套用 CheckBox](utilities.md#套用-checkbox) | 套用將 0/1 輸入顯示為 ✅/⬜ 的儲存格格式 |
| [全部重算](utilities.md#全部重算) | 強制對所有開啟的活頁簿完整重算 |

## 群組: EGTools

彙集公式函數名稱批次轉換、SMTP 設定、API 金鑰管理與增益集資訊的
分割按鈕（預設 = 關於 EGTools++）。

| 選單 | 說明 |
|---|---|
| [套用舊版相容](apply-compat.md) | 將現代/原生（`_xlfn.*`）函數權杖批次轉換為 EGTools 相容函數名稱 |
| [還原為內建函數](restore-native.md) | 將 EGTools 函數名稱批次還原為原生內建函數 |
| [SMTP 設定](smtp-settings.md) | 註冊郵件合併發送郵件用的 SMTP 伺服器（不儲存密碼） |
| [管理 API 金鑰](api-keys.md) | 註冊/刪除公共 API 金鑰（地址搜尋 · data.go.kr · vworld — data.go.kr 金鑰由節假日、行事曆、商業登記查詢共用） |
| 關於 EGTools++ | 顯示版本、發佈頁與基礎程式庫；當 GitHub Release 有新版本時，會連同通知提供發佈頁連結 |

| 項目 | 說明 |
|---|---|
| [日期選擇](context-menu.md#日期選擇) | 在儲存格旁顯示行事曆，將點選的日期輸入儲存格 |
