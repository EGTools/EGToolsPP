# 表單

**位置**：功能區 `EGTools++` 索引標籤 → `表單` 群組

以資料清單填入畫在工作表上的表單（格式範圍）並反覆產生的功能群組。
由一個分割按鈕（預設動作 = 製作標籤）組成。

| 選單 | 說明 |
|---|---|
| [製作標籤](#製作標籤) | 將表單依資料列在同一工作表反覆排列，並把 `{{欄位名}}` 取代為值 |
| [郵件合併](mailmerge.md) | 依資料列複製表單工作表，產生個別工作表/檔案（xlsx/PDF）、逐一列印、寄送郵件（附加檔案） |

## 製作標籤

將表單依資料清單的列數複製，同時把 `{{欄位名}}` 佔位符取代為各列的值，
建立列印用標籤（名牌、地址標籤等）工作表。

### 操作流程

1. **指定表單範圍** — 在範圍輸入視窗中指定表單範圍
   （預設值 = 目前選取的連續範圍，取消則結束）。若指定沒有值的單一儲存格
   則結束。
2. **指定資料清單** — 指定資料清單範圍。**首列為欄位名**，
   第二列起為資料。
3. **輸入橫向排列數** — 輸入每一行要橫向排列的標籤數（1~10，預設 1）。
4. 在新工作表（表單工作表名稱 + `_1` 格式）上，每個資料列都會複製表單，
   並將 `{{欄位名}}` 取代為該列的值。完成後顯示說明。

### 取代規則

| 項目 | 規則 |
|---|---|
| 佔位符 | 只有含 `{{欄位名}}` 的儲存格才是取代對象。一個儲存格可寫多個，也可與前後文字組合（例：`地址: {{地址}}`） |
| 沒有佔位符 | 若表單中沒有任何 `{{ }}` 佔位符，則僅將空表單依資料列數複製 |
| 空欄位名 | 清單首列為空的欄可以 `Empty1`、`Empty2` … 名稱參照 |
| 不存在的欄位名 | 參照清單中沒有的欄位名時，會警告並中斷作業 |
| 格式 | 表單的格式（框線、色彩等）會一併複製，且**欄寬、列高也與表單相同**複製 |

### 備註

- 取代後的儲存格以**文字值**輸入（不是公式）。
- 若要為每列建立個別工作表/檔案，請使用[郵件合併](mailmerge.md)
  （標籤 = 在同一工作表反覆排列，郵件合併 = 每列個別工作表/檔案）。
