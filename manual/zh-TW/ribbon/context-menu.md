# 儲存格右鍵選單

**位置**: 在儲存格範圍上按滑鼠右鍵 → 內容功能表

載入 EGTools++ 後，儲存格的右鍵選單會新增項目。
無論是一般儲存格、表格（清單）範圍，還是整頁模式檢視，都會出現在相同位置。

## 日期選擇

在按滑鼠右鍵的儲存格旁顯示行事曆，點選日期即可輸入。不必手動輸入日期，
點兩下就能完成。

1. 在儲存格上按滑鼠右鍵並點選**日期選擇**，行事曆會出現在作用儲存格右側
   （若超出畫面邊界則移到左側）。若目前儲存格的值是日期，會以**該
   日期為選取狀態的月份**開啟；否則從今天開始。
2. 以上方的 `◀◀`/`◀`/`▶`/`▶▶` 移動年/月。**點選日期即會將該日期
   輸入儲存格**並關閉行事曆（以灰色顯示的上/下個月日期也可以
   點選）。
3. **點選下方的「今天: yyyy-mm-dd」列可跳到今天。**
   以 `Esc` 或關閉視窗（X）取消時，儲存格不會變更。

- 週日與**節假日為紅色**，週六為藍色，今天以框線標示。
  將滑鼠移到節假日格子上時，下方會顯示節假日名稱。
- 節假日以內建計算為準；若已註冊 data.go.kr 金鑰，**臨時節假日**也會
  一併反映 — 參見[行事曆/日程表 — 節假日說明](calendar.md#節假日說明)。

## 開啟連結

在所選儲存格內容中尋找以 `http://` 或 `https://` 開頭的 URL，
並以預設瀏覽器開啟。

- 即使儲存格文字中 URL 與其他文字混在一起，也會找出第一個 URL 開啟。
- 選取多個儲存格時，以**第一個儲存格（左上角）** 為準。
- 若儲存格內沒有 URL，則不做任何動作。

沒有超連結格式的一般文字 URL 也能點兩下開啟，
不必進入儲存格編輯模式或建立超連結。
