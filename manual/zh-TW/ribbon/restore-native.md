# 還原為內建函數

**位置**: 功能區 `EGTools` 索引標籤 → `EGTools` 群組 → 分割按鈕下拉式選單

將已轉換為 EGTools 相容函數使用的活頁簿帶回最新 Excel 時，此按鈕會將作用中活頁簿
所有公式中的 EGTools 函數名稱（`EG.*` 等）批次還原為原生內建函數。
還原後即使沒有增益集，這些公式也能計算。

## 操作流程

經過與[套用舊版相容](apply-compat.md)相同的安全流程：
儲存確認 → 事前掃描（依函數彙總對象數量）→ 自動備份
（`原檔名_egbak_<時間>.<副檔名>`）→ 轉換 → 結果摘要。

## 轉換規則

| 對象 | 轉換 |
|---|---|
| 一般相容函數 | `EG.函數` / `x函數`（xSORT/xFILTER/xLET）→ `函數`（原生）。仍保留舊版直接替換名稱原樣的儲存格也會重新符記化，強制交由原生函數計算 |
| IMAGE | **依來源分流**：第一個引數為 `https://` 來源時保留原生 `IMAGE`，其他情況（本機路徑、`http://`）轉換為 `EG.IMAGE`。參照/公式引數以**轉換當下評估的值**為準判斷（評估失敗、錯誤、非字串時安全地採用 `EG.IMAGE`）。原生 IMAGE 僅支援 https，因此轉換後若參照值變成本機路徑，該儲存格會變成 `#VALUE!` — 相對地 `EG.IMAGE` 支援所有來源 |
| GROUPBY / PIVOTBY | 將函數名稱還原為原生，並移除彙總函數引數的引號（`"SUM"` → `SUM`；僅限原生支援的 16 種彙總函數 — TEXTJOIN 等 EGTools 擴充彙總函數會被原生拒絕，因此不更動該公式）。即使後面帶有選擇性引數也會轉換 |
| `_xlpm.*`（LET/LAMBDA 參數） | 移除經舊版往返後殘留在公式中的參數儲存前綴（`xLET(_xlpm.x, …)` → `LET(x, …)`）。含 `_xlpm.` 的公式 Excel 會拒絕寫入，若不移除，該儲存格便無法還原。在轉換摘要中計入 `_xlpm.*` 項目 |
| `@`（隱含交集） | 最新 Excel 開啟舊版檔案時加上的 `@`，若位於**要還原為原生的函數名稱正前方**，會一併移除（`TAKE(@xSORT(…),3)` → `TAKE(SORT(…),3)`）。若不移除，`@SORT` 會把陣列壓縮成單一值而使結果錯誤。儲存格參照或非轉換對象函數前的 `@` 會保留。在轉換摘要中計入 `@(암시적 교차)` 項目 |
| `_xll.*` / `_xludf.*`（增益集 UDF 儲存前綴） | 移除在未註冊增益集函數的環境中開啟過所留下的前綴（`_xll.xSORT(…)` → `SORT(…)`）。特別可解決**名稱**的公式中殘留此前綴而一直無法轉換的問題。僅移除 EGTools 函數前的前綴，不會更動其他增益集的函數。在轉換摘要中計入 `_xll.*` 項目 |
| 尚未全面推出的函數（IMPORTTEXT/IMPORTCSV） | 已導入但尚未一般發佈的函數（僅限 365 預覽通道）會在還原前**確認此 Excel 是否實際存在原生版本**，僅在確認存在時才轉換為原生。無法確認時，比照 IMAGE 的方式保留 EGTools 實作（`IMPORTTEXT` → `EG.IMPORTTEXT`）。已一般發佈的函數則一律直接轉換，不做此確認 |

## 備註

- 若執行的 Excel 沒有該原生函數（舊版），還原後的公式會變成 `#NAME?`，
  因此請在回到最新 Excel 時使用此按鈕。
- 若要再次轉換為舊版用，請執行[套用舊版相容](apply-compat.md)。
