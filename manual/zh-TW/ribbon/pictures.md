# 圖片

**位置**：功能區 `EGTools` 索引標籤 → `圖片` 群組

將圖片配合儲存格插入、對齊、匯出的功能群組。由兩個分割按鈕 —
**圖片**（預設動作 = 插入圖片；選單：插入圖片、依名稱插入、插入到表單）與
**調整**（預設動作 = 調整所選；選單：調整所選、全部調整、全部匯出）—
組成。

## 插入圖片

選擇一個圖片檔，配合目前選取範圍的大小插入。

1. 在檔案選擇對話方塊中選擇圖片檔
   （jpg、jpeg、png、gif、bmp、tif、tiff、svg、emf、wmf 等；取消則結束）。
2. 圖片會依選取範圍的位置與大小、保留 **0.2pt 邊距**插入
   （內嵌儲存於文件中，不是檔案連結）。
3. 插入圖片的**名稱設為檔名**，並**取消鎖定長寬比**，
   之後配合儲存格調整時可自由變形。

## 依名稱插入

選擇資料夾，尋找與工作表儲存格值**同名的圖片檔**並插入該儲存格。
適合為已輸入名稱的名冊、商品清單等表格批次貼上照片。

1. 在資料夾選擇視窗中選擇存放圖片的資料夾（取消則結束）。
2. 檢查使用中工作表使用範圍（自 A1 起）的所有儲存格值，在資料夾中
   尋找與值同名的圖片檔。
   - 副檔名可加可不加（儲存格值 `照片1` ↔ 檔案 `照片1.jpg` 皆可對應）。
     不區分大小寫。
   - 僅以 jpg、jpeg、png、gif、bmp、tif、tiff、svg、emf、wmf 等圖片副檔名的檔案為對象。
3. 將找到的圖片以 **0.3pt 邊距**插入該儲存格（合併儲存格則為整個合併範圍的
   大小），內嵌儲存於文件中。圖片名稱設為去除副檔名的檔名，
   並取消鎖定長寬比。
4. 完成後顯示結果（已插入的資料夾說明 / 未加入任何圖片）。

若同一值出現在多個儲存格，會在每個儲存格各插入一次。

## 插入到表單

複製表單的同時，在 `{{}}` 佔位符位置依序插入資料夾中的圖片。
適合填寫照片配置表（照片報告）表單。

1. **指定表單範圍** — 在範圍輸入視窗中指定表單範圍（預設值 = 目前
   選取範圍，取消則結束）。表單內必須有 1 個以上僅輸入 `{{}}` 的儲存格
   （照片位置），若沒有則顯示說明後結束。
2. **輸入複製方式** — `1` = 整份複製表單工作表 / `2` = 將表單範圍
   向下複製 / `3` = 向右複製。
3. **選擇資料夾** — 資料夾內的圖片檔會**依名稱排序**使用
   （若沒有圖片則顯示說明後結束）。
4. 反覆複製表單直到圖片用完，並在每個 `{{}}` 儲存格（合併儲存格則為合併
   範圍）以 **0.3pt 邊距**插入圖片。**儲存格值會記錄為檔名**，
   圖片名稱也是檔名。圖片用完後剩餘的 `{{}}` 會被
   清除。進度會顯示在狀態列。

- 方式 1 會複製工作表，因此工作表名稱會以 `原名_1`、`_2` … 增加。
- 方式 2/3 會複製整列/整欄，因此列高、欄寬得以保持
  （複製位置的既有內容會被清除）。

## 調整所選

將所選圖片調整到各圖片左上角頂點所在的儲存格。

1. 選取圖片後按下按鈕，會出現**邊距輸入**視窗
   （0~10，預設 0.3）。輸入非數值或取消則結束。
2. 將每張圖片配合左上角儲存格的大小、向內縮進邊距量。
   若左上角儲存格屬於**合併範圍**，則配合整個合併範圍的大小。
3. **旋轉 90 度/270 度**的圖片會互換寬高，維持旋轉狀態
   仍能符合儲存格。

若未選取圖片，會顯示「未選取圖片」的說明。
僅處理圖片（照片）物件，不會動到圖案、圖表等。

## 全部調整

以與調整所選相同的方式，一次調整使用中工作表的**所有圖片**。

1. 在確認視窗（是否繼續）同意後，會出現**邊距輸入**視窗（0~5，預設 0.3）。
2. 將工作表的所有圖片調整到各自的左上角儲存格（合併範圍則為合併大小）。
   進度會以圖片名稱顯示在 Excel **狀態列**。
3. 完成後顯示結果（整理完成 / 沒有圖片）。

## 全部匯出

將使用中工作表的**所有圖片**以**原始畫質**儲存到指定的資料夾。
適合把貼在工作表上的照片取回為檔案。

1. 若工作表沒有圖片則顯示說明後結束。選擇要儲存的資料夾
   （取消則結束）。
2. 檔名為**圖片左上角頂點所在儲存格的值**。若儲存格為空，
   則為 `圖片名稱_R列C欄` 格式。檔名中不可使用的字元會改為 `_`，
   名稱重複時會加上 `_1`、`_2`…。副檔名維持文件中儲存的原始
   格式（jpg、png 等）。
3. 內部運作：將活頁簿的**副本儲存到暫存資料夾**，直接取出文件內的原始圖片
   資料。並非以畫面顯示畫質重新繪製，因此
   **完整保留放入文件時的畫質**，且原始文件完全不會
   被變更（暫存檔會自動刪除）。
4. 完成後顯示匯出的數量與儲存資料夾。

- 文件必須是 **xlsx/xlsm 格式**。其他格式（.xls 等）可能會
  顯示「圖片匯出失敗」的說明。
- 對象為圖片（照片）物件。不會儲存圖案、圖表。

## 備註

- 邊距值為 0 時圖片會填滿儲存格，數值越大與儲存格框線的間距越大。
- 調整基準是**圖片左上角頂點所落在的儲存格**。若沒有對到想要的儲存格，
  請將圖片移到該儲存格上方後再執行一次。
