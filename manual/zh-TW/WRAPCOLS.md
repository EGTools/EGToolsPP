# WRAPCOLS

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2024 / Microsoft 365

將向量依每欄指定數量換行成二維陣列。

## 語法

```
=WRAPCOLS(向量, 換行數, [填補值])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 向量 | 必要 | 要換行的向量 |
| 換行數 | 必要 | 每欄的值數 |
| 填補值 | 選用 | 填補值(預設 #N/A) |

## 傳回

傳回將向量的值以每欄「換行數」個直向排列而成的二維陣列，在支援動態陣列的 Excel 中會溢出。最後一欄不足的位置以填補值（預設 #N/A）填入。若向量為空，或換行數小於等於 0，則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=WRAPCOLS({1,2,3,4,5},2)` | {1,3,5;2,4,#N/A} | 每欄排 2 個 |
| `=WRAPCOLS({1,2,3,4,5},3,0)` | {1,4;2,5;3,0} | 填補值 0 |

## 備註

- 二維陣列輸入也會以列優先攤平後處理。
- 相關函數：WRAPROWS
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `WRAPCOLS` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.WRAPCOLS`。
