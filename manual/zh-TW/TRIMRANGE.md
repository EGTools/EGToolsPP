# TRIMRANGE

**類別**: MS Excel 相容函數 · **原生導入**: Microsoft 365

移除陣列邊緣的空白列/欄。

## 語法

```
=TRIMRANGE(陣列, [修剪列], [修剪欄])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列 | 必要 | 目標陣列或範圍值 |
| 修剪列 | 選用 | 0 無, 1 前端, 2 尾端, 3 全部(預設) |
| 修剪欄 | 選用 | 0 無, 1 前端, 2 尾端, 3 全部(預設) |

## 傳回

傳回移除邊緣空白列/欄後的陣列，並以溢出方式輸出。若陣列為空、修剪模式超出 0~3 範圍，或整體皆為空值，則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=TRIMRANGE({"","";"a",1;"",""})` | {"a",1} | 移除邊緣空白列與欄 |
| `=TRIMRANGE({"";1;""},1)` | {1;""} | 僅移除前端空白列 |

## 備註

- 原生 TRIMRANGE 修剪的是參照，而此實作以值為基礎，因此也可用於陣列常數與公式結果。
- 空字串("")也視為空值。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `TRIMRANGE` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.TRIMRANGE`。
