# MINIFS

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2016/2019

傳回符合所有條件的儲存格的最小值。

## 語法

```
=MINIFS(最小值範圍, 條件範圍1, 條件1, ...)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 最小值範圍 | 必要 | 求最小值的儲存格 |
| 條件範圍1 | 必要 | 要檢驗的範圍 |
| 條件1 | 必要 | 條件，如 "<5" |
| … | 選用 | 上述引數可重複指定 |

## 傳回

以數字純量傳回符合所有條件的儲存格數值中的最小值。若條件範圍的大小與目標範圍不同則傳回 #VALUE!；若沒有符合的值則傳回 0。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=MINIFS({10;20;30},{"a";"b";"a"},"a")` | 10 | 符合條件的最小值 |
| `=MINIFS({7;8;9},{"x";"y";"z"},"?")` | 7 | 萬用字元條件 |

## 備註

- 條件支援數字、比較運算子（如 "<5"）與萬用字元（*、?），文字比較不區分大小寫。
- 相關函數：MAXIFS。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `MINIFS` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.MINIFS`。
