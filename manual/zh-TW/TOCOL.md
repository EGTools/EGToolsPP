# TOCOL

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2024

將陣列以單欄傳回。

## 語法

```
=TOCOL(陣列, [忽略], [依欄掃描])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列 | 必要 | 陣列 |
| 忽略 | 選用 | 0 無,1 空白,2 錯誤,3 兩者 |
| 依欄掃描 | 選用 | 為 TRUE 時依欄 |

## 傳回

傳回將陣列所有值排成單一欄（N×1）的陣列，在支援動態陣列的 Excel 中會溢出。可用忽略選項（1=空值、2=錯誤、3=兩者）排除值。若陣列為空或沒有剩餘的值，則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=TOCOL({1,2;3,4})` | {1;2;3;4} | 以列優先排成單欄 |
| `=TOCOL({1,2;3,4},0,TRUE)` | {1;3;2;4} | 依欄掃描 |
| `=TOCOL({1,"",2},1)` | {1;2} | 忽略空值 |

## 備註

- 空字串（""）也視為空值，在忽略選項 1、3 中會被排除。
- 若所有值都被排除，會傳回 #VALUE! 而非原生的 #CALC!。
- 相關函數：TOROW
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `TOCOL` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.TOCOL`。
