# FILTER

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2021

篩選陣列，保留條件為 TRUE 的列/欄。

## 語法

```
=FILTER(陣列, 包含, [為空時])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列 | 必要 | 要篩選的資料 |
| 包含 | 必要 | 布林陣列(列或欄) |
| 為空時 | 選用 | 無相符時的值(選用) |

## 傳回

傳回僅保留條件為真之列或欄的陣列，並會溢出。若 include 的大小與 array 的列數或欄數不符則傳回 #VALUE!；若沒有保留的項目且省略 if_empty 則傳回 #N/A。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=FILTER({1;2;3;4},{1;0;1;0})` | {1;3} | 篩選列 |
| `=FILTER({1,2;3,4;5,6},{0;1;1})` | {3,4;5,6} | 多欄的列篩選 |
| `=FILTER({1;2},{0;0},"none")` | none | 無結果時的替代值 |

## 備註

- include 中的文字與空值視為 FALSE（原生函數為 #VALUE!）。
- 無結果且省略 if_empty 時，傳回 #N/A 而非 #CALC!。
- 相關函數：SORT、UNIQUE。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `FILTER` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.FILTER`。 在部分舊版 Excel 中因保留字衝突，會以 `xFILTER` 名稱註冊。
