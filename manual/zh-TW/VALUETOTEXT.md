# VALUETOTEXT

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2024

傳回值的文字表示。

## 語法

```
=VALUETOTEXT(值, [格式])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 值 | 必要 | 值 |
| 格式 | 選用 | 0 簡明(預設)，1 嚴格(文字加引號) |

## 傳回

傳回值的文字表示，為單一文字（純量）。實作本身不會傳回額外的錯誤值。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=VALUETOTEXT(1.5)` | 1.5 | 數字原樣 |
| `=VALUETOTEXT("abc",1)` | "abc" | 嚴格：文字加引號 |
| `=VALUETOTEXT(TRUE)` | TRUE | 邏輯值 |

## 備註

- 在嚴格（1）格式中，文字內的雙引號會以兩個（""）表示。
- 相關函數：ARRAYTOTEXT
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `VALUETOTEXT` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.VALUETOTEXT`。
