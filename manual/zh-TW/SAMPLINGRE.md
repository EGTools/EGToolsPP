# SAMPLINGRE

**類別**: EGTools 專用函數

依 ISO 2859-1 傳回拒收數(Re)。

## 語法

```
=SAMPLINGRE(批量, AQL, [檢驗水準], [嚴格度], [方案], [次數])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 批量 | 必要 | 批/批次數量 |
| AQL | 必要 | 允收品質水準 |
| 檢驗水準 | 選用 | 預設 G2 |
| 嚴格度 | 選用 | 0 正常，1 加嚴，-1 減量 |
| 方案 | 選用 | 1 一次，2 二次，3~5 多次 |
| 次數 | 選用 | 抽樣次數 |

## 傳回

傳回 ISO 2859-1 拒收數 Re(純量數字)。AQL 超出 0~1000 或檢驗水準·方式·次數錯誤時傳回 #VALUE!，LOT 數量小於 2 或 AQL 小於 0.01 時傳回 #NUM!，在表格中找不到對應值時傳回 #N/A 錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=SAMPLINGRE(1000,1)` | 3 | G2·正常·一次抽樣，AQL 1.0 |
| `=SAMPLINGRE(1000,1,"G2",0,2,1)` | 3 | 二次抽樣的第一次 Re |

## 備註

- 一次抽樣時 Re = Ac + 1。
- LOT 數量為 1 時傳回 1。
- 相關函數: SAMPLINGSIZE, SAMPLINGAC, SAMPLINGLABEL
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `SAMPLINGRE` 原名註冊。
