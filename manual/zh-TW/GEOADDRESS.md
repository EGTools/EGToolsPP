# GEOADDRESS

**類別**: EGTools 專用函數

傳回座標對應的地址(VWorld 逆地理編碼)。

## 語法

```
=GEOADDRESS(x, y, [地址類型], [EPSG], [api_key])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| x | 必要 | 經度或 x 座標 |
| y | 必要 | 緯度或 y 座標 |
| 地址類型 | 選用 | 1 地番(預設), 2 道路名, 3 全部 |
| EPSG | 選用 | 座標系 EPSG 代碼(預設 4326=WGS84) |
| api_key | 選用 | vworld.kr 認證金鑰，輸入一次後存入登錄檔 |

## 傳回

傳回座標對應的地址文字（地址類型=3 時以地番、道路名 2 列溢出）。地址類型超出 1~3、EPSG 無效，或 EPSG 4326 下座標超出範圍時傳回 #VALUE!；沒有地址時傳回 #N/A；金鑰缺漏、網路或服務錯誤則以 "ERROR: …" 文字傳回。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=GEOADDRESS(126.9779,37.5663)` |  | 座標的地番地址（需要網路與 API 金鑰） |

## 備註

- 不隨附 API 金鑰。請至空間資訊開放平台（https://www.vworld.kr）申請，以最後一個引數輸入一次後即儲存於使用者帳戶；金鑰被拒絕時會自動刪除並傳回重新申請的指引。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `GEOADDRESS` 原名註冊。
