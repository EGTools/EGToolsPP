# HSTACK

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2024 / Microsoft 365

將多個陣列水平堆疊為一個陣列。

## 語法

```
=HSTACK(陣列1, ...)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列1 | 必要 | 要堆疊的陣列 |
| … | 選用 | 上述引數可重複指定 |

## 傳回

傳回將引數中的各陣列水平接合而成的陣列，在支援動態陣列的 Excel 中會溢出。高度不同時，較矮陣列的空位以 #N/A 填補。若沒有任何有效的陣列引數，則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=HSTACK({1;2},{3,4;5,6})` | {1,3,4;2,5,6} | 兩個陣列水平結合 |
| `=HSTACK({1,2},{3;4;5})` | {1,2,3;#N/A,#N/A,4;#N/A,#N/A,5} | 高度不同時為 #N/A |

## 備註

- 省略的引數會被略過。
- 相關函數：VSTACK
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `HSTACK` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.HSTACK`。
