# SAMPLINGAC

**類別**: EGTools 專用函數

依 ISO 2859-1 傳回允收數(Ac)。

## 語法

```
=SAMPLINGAC(批量, AQL, [檢驗水準], [嚴格度], [方案], [次數])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 批量 | 必要 | 批/批次數量 |
| AQL | 必要 | 允收品質水準 |
| 檢驗水準 | 選用 | 預設 G2 |
| 嚴格度 | 選用 | 0 正常，1 加嚴，-1 減量 |
| 方案 | 選用 | 1 一次，2 二次，3~5 多次 |
| 次數 | 選用 | 抽樣次數 |

## 傳回

傳回 ISO 2859-1 允收數 Ac(純量數字)。AQL 超出 0~1000 或檢驗水準·方式·次數錯誤時傳回 #VALUE!，LOT 數量小於 2 或 AQL 小於 0.01 時傳回 #NUM!，在表格中找不到對應值時傳回 #N/A 錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=SAMPLINGAC(1000,1)` | 2 | G2·正常·一次抽樣，AQL 1.0 |
| `=SAMPLINGAC(1000,1,"G2",1)` | 1 | 加嚴檢驗 |
| `=SAMPLINGAC(500,2.5)` | 3 | LOT 500，AQL 2.5 |

## 備註

- LOT 數量為 1 時傳回 0。
- 相關函數: SAMPLINGSIZE, SAMPLINGRE, SAMPLINGLABEL
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `SAMPLINGAC` 原名註冊。
