# TEXTSPLIT

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2024 / Microsoft 365

使用欄和列分隔符號將文字拆分為陣列。

## 語法

```
=TEXTSPLIT(文字, 欄分隔符號, [列分隔符號], [忽略空值], [比對模式], [填補值])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字 | 必要 | 要拆分的文字 |
| 欄分隔符號 | 必要 | 欄之間的分隔符號 |
| 列分隔符號 | 選用 | 列之間的分隔符號(選用) |
| 忽略空值 | 選用 | 為 TRUE 時略過空值 |
| 比對模式 | 選用 | 0 區分大小寫(預設)，1 不區分 |
| 填補值 | 選用 | 不齊列的填補值(預設 #N/A) |

## 傳回

傳回分割後的文字陣列，在動態陣列環境中會溢出。長度不同的列會以填補值（預設 #N/A）填補；若分割結果為空則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=TEXTSPLIT("a,b,c",",")` | {a,b,c} | 分割為欄 |
| `=TEXTSPLIT("a,b;c",",",";")` | {a,b;c,#N/A} | 列與欄分割，不足處填補 |
| `=TEXTSPLIT("1,,2",",",,TRUE)` | {1,2} | 忽略空值 |

## 備註

- 分隔符號引數僅支援單一文字（不支援原生函數允許的陣列形式多重分隔符號）。
- 比對模式（match_mode）=1 時會忽略大小寫。
- 相關函數：TEXTBEFORE、TEXTAFTER、TEXTJOIN
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `TEXTSPLIT` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.TEXTSPLIT`。
