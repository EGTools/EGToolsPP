# GEOCODER

**類別**: EGTools 專用函數

傳回地址的 GPS 座標(VWorld，先道路名後地番)。

## 語法

```
=GEOCODER(關鍵字, [EPSG], [api_key])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 關鍵字 | 必要 | 地址 |
| EPSG | 選用 | 座標系 EPSG 代碼(預設 4326=WGS84) |
| api_key | 選用 | vworld.kr 認證金鑰，輸入一次後存入登錄檔 |

## 傳回

傳回 {x, y, 整理後的地址} 的 1×3 陣列，並會溢出。地址為空或 EPSG 無效時傳回 #VALUE!；找不到座標時傳回 #N/A；金鑰缺漏、網路或服務錯誤則以 "ERROR: …" 文字傳回。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=GEOCODER("세종대로 110")` |  | 地址的 GPS 座標（需要網路與 API 金鑰） |

## 備註

- 不隨附 API 金鑰。請至空間資訊開放平台（https://www.vworld.kr）申請，以最後一個引數輸入一次後即儲存於使用者帳戶；金鑰被拒絕時會自動刪除並傳回重新申請的指引。
- 先嘗試道路名地理編碼器，失敗時改以地番重試。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `GEOCODER` 原名註冊。
