# SEARCHADDRESS

**類別**: EGTools 專用函數

搜尋韓國地址(juso.go.kr)。

## 語法

```
=SEARCHADDRESS(文字, [輸出項], [列], [api_key])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字 | 必要 | 要搜尋的地址關鍵字 |
| 輸出項 | 選用 | 輸出欄 1~27，可用陣列 {1,2}: 1 郵遞區號, 2 道路名地址(預設), 3 地番地址, 4 英文地址 |
| 列 | 選用 | 輸出的列號，0/省略為全部 |
| api_key | 選用 | juso.go.kr 授權金鑰，輸入一次後存入登錄檔 |

## 傳回

以選取之輸出項欄組成的文字陣列傳回搜尋到的地址，並會溢出（列=0 時為全部，最多 100 筆）。搜尋文字為空或輸出項超出 1~27 時傳回 #VALUE!；沒有結果時傳回 #N/A；金鑰缺漏、網路或服務錯誤則以 "ERROR: …" 文字傳回。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=SEARCHADDRESS("세종대로 110")` |  | 道路名地址搜尋（需要網路與 API 金鑰） |
| `=SEARCHADDRESS("세종대로 110",{1,2},1)` |  | 郵遞區號+道路名地址第 1 列（需要網路與 API 金鑰） |

## 備註

- 不隨附 API 金鑰。請至[地址基盤產業支援服務](https://www.juso.go.kr)申請，以最後一個引數輸入一次後即儲存於使用者帳戶，之後可省略。
- 服務拒絕金鑰時（過期/未註冊），會自動刪除已儲存的金鑰並傳回重新申請的指引。
- 輸出項完整清單(1~27)如下表。預設值為 2(道路名地址)，可用 {1,2} 這樣的陣列指定多欄。

| 編號 | 欄位 | 說明 |
|---|---|---|
| 1 | zipNo | 郵遞區號 |
| 2 | roadAddr | 完整道路名地址(預設) |
| 3 | jibunAddr | 地番地址 |
| 4 | engAddr | 道路名地址(英文) |
| 5 | roadAddrPart1 | 道路名地址(不含參考項目) |
| 6 | roadAddrPart2 | 道路名地址參考項目 |
| 7 | admCd | 行政區域代碼 |
| 8 | rnMgtSn | 道路名代碼 |
| 9 | bdMgtSn | 建築物管理編號 |
| 10 | detBdNmList | 詳細建築物名清單 |
| 11 | bdNm | 建築物名 |
| 12 | bdKdcd | 是否共同住宅(1: 共同住宅, 0: 非共同住宅) |
| 13 | siNm | 市/道名 |
| 14 | sggNm | 市/郡/區名 |
| 15 | emdNm | 邑/面/洞名 |
| 16 | liNm | 法定里名 |
| 17 | rn | 道路名 |
| 18 | udrtYn | 是否地下(0: 地上, 1: 地下) |
| 19 | buldMnnm | 建築物主號 |
| 20 | buldSlno | 建築物副號 |
| 21 | mtYn | 是否山地(0: 宅地, 1: 山) |
| 22 | lnbrMnnm | 地番主號(番地) |
| 23 | lnbrSlno | 地番副號(號) |
| 24 | emdNo | 邑面洞序號 |
| 25 | hstryYn | 是否有變動紀錄 |
| 26 | relJibun | 相關地番 |
| 27 | hemdNm | 管轄居民中心 |

- 搜尋詞·api_key 指定為陣列時傳回 #VALUE!（api_key 會在儲存前被拒絕，防止儲存錯誤的金鑰）— 多筆資料請將公式逐列複製使用。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `SEARCHADDRESS` 原名註冊。
