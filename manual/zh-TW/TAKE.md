# TAKE

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2024

從陣列的開頭或結尾取得列/欄。

## 語法

```
=TAKE(陣列, 列數, [欄數])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列 | 必要 | 陣列 |
| 列數 | 必要 | 取得的列(負=從結尾) |
| 欄數 | 選用 | 取得的欄(選用) |

## 傳回

傳回從陣列開頭（正數）或結尾（負數）取得指定數量的列、欄後的陣列，在支援動態陣列的 Excel 中會溢出。若陣列為空，或要取得的列、欄數為 0，則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=TAKE({1,2,3;4,5,6;7,8,9},2)` | {1,2,3;4,5,6} | 開頭 2 列 |
| `=TAKE({1,2,3;4,5,6;7,8,9},-1,2)` | {7,8} | 最後一列的開頭 2 欄 |
| `=TAKE({1,2;3,4},0)` | #VALUE! | 0 列則為錯誤 |

## 備註

- 列數、欄數為負數時，從結尾開始取得。
- 若結果為空陣列，會傳回 #VALUE! 而非原生的 #CALC!。
- 相關函數：DROP
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `TAKE` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.TAKE`。
