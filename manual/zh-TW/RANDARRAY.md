# RANDARRAY

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2021

傳回亂數陣列。

## 語法

```
=RANDARRAY([列數], [欄數], [最小], [最大], [整數])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 列數 | 選用 | 列的數量(預設 1) |
| 欄數 | 選用 | 欄的數量(預設 1) |
| 最小 | 選用 | 最小值(預設 0) |
| 最大 | 選用 | 最大值(預設 1) |
| 整數 | 選用 | TRUE 則整數 |

## 傳回

傳回 rows×cols 大小的亂數陣列，並會溢出。若 rows 或 cols 小於等於 0，或 max 小於 min，則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=RANDARRAY(2,3,1,10,TRUE)` |  | 亂數，每次結果不同 |

## 備註

- integer=TRUE 時產生 min～max 的整數（含兩端）；否則產生大於等於 min 且小於 max 的實數。
- 相關函數：SEQUENCE。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `RANDARRAY` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.RANDARRAY`。
