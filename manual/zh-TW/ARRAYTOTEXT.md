# ARRAYTOTEXT

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2024 / Microsoft 365

傳回陣列的文字表示。

## 語法

```
=ARRAYTOTEXT(陣列, [格式])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列 | 必要 | 陣列 |
| 格式 | 選用 | 0 簡明(預設)，1 嚴格 |

## 傳回

傳回將整個陣列連結而成的單一文字（純量）。實作本身不會傳回額外的錯誤值。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=ARRAYTOTEXT({1,2;3,4})` | 1, 2, 3, 4 | 精簡格式連結 |
| `=ARRAYTOTEXT({"a",1;"b",2},1)` | {"a",1;"b",2} | 嚴格格式 |

## 備註

- 精簡（0）格式不區分列與欄，以 ", " 連結所有元素。
- 嚴格（1）格式為 {a,b;c,d} 形式，僅文字以雙引號括住，內部的引號以連續兩個（""）表示。
- 相關函數：VALUETOTEXT
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `ARRAYTOTEXT` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.ARRAYTOTEXT`。
