# IMPORTDATA

**類別**: Google Sheets 相容函數

從 URL 或本機檔案匯入 CSV/TSV 資料。

## 語法

```
=IMPORTDATA(網址或路徑, [分隔符], [地區設定], [字元集])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 網址或路徑 | 必要 | 提供資料的網址或本機檔案路徑 |
| 分隔符 | 選用 | 欄位分隔符(預設: 自動偵測 Tab/逗號) |
| 地區設定 | 選用 | 數字解析地區，如 "de-DE" |
| 字元集 | 選用 | 編碼，預設 "utf-8" — euc-kr、字碼頁編號等 |

## 傳回

將 URL 或本機檔案的 CSV/TSV 內容以二維陣列溢出傳回，數字·日期文字會自動轉換為值。缺少路徑、下載·讀取失敗、分隔符指定錯誤時傳回 #VALUE!；內容為空時傳回 #N/A。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=IMPORTDATA("https://example.com/data.csv")` |  | 視外部資料而定 |

## 備註

- 省略 delimiter 時自動偵測：第一行含 Tab 則為 Tab，否則為逗號。
- 也以向下相容方式支援在第 2 個引數給字元集名稱的舊版呼叫（IMPORTDATA(url,"euc-kr")）。
- 不採用 Google 只保留非空白行的方式，而是保留內部空白行、只移除末尾的空白行。
- url指定為陣列時傳回 #VALUE! — 多筆資料請將公式逐列複製使用。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `IMPORTDATA` 原名註冊。
