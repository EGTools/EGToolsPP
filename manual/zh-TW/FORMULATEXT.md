# FORMULATEXT

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

以文字形式傳回所參照儲存格的公式。

## 語法

```
=FORMULATEXT(參照)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 參照 | 必要 | 要傳回其公式的儲存格 |

## 傳回

以文字純量傳回所參照儲存格的公式。若省略參照、儲存格沒有公式或查詢失敗則傳回 #N/A。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=FORMULATEXT(A1)` |  | 依 A1 內容而異 |

## 備註

- 註冊為巨集表類型函數。
- 相關函數：ISFORMULA。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `FORMULATEXT` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.FORMULATEXT`。
