# TOTALPAGES

**類別**: EGTools 專用函數

依目前列印設定的總頁數(列印前請重新計算)。

## 語法

```
=TOTALPAGES([忽略起始號])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 忽略起始號 | 選用 | TRUE 忽略起始頁碼設定從 1 起 |

## 傳回

以數字純量傳回總頁數，並反映列印設定的起始頁碼(忽略起始號 為 TRUE 時從 1 起算)。若查詢頁數失敗，傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=TOTALPAGES()` |  | 結果依列印設定而異 |

## 備註

- 此為巨集型函數，使用 XLM GET.DOCUMENT(非執行緒安全)。
- 變更列印設定後需重新計算，值才會更新。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `TOTALPAGES` 原名註冊。
