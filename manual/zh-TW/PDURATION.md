# PDURATION

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

傳回投資以給定利率達到目標值所需的期數。

## 語法

```
=PDURATION(rate, pv, fv)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| rate | 必要 | 每期利率 |
| pv | 必要 | 現值 |
| fv | 必要 | 終值 |

## 傳回

傳回達到目標金額所需的期數(純量數字)。rate·pv·fv 不是數字或小於等於 0 時傳回 #NUM! 錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=PDURATION(0.025,2000,2200)` | 3.859866163 | 以 2.5% 從 2000→2200 所需期數 |

## 備註

- 相關函數: RRI
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `PDURATION` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.PDURATION`。
