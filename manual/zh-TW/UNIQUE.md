# UNIQUE

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2021

傳回陣列中唯一的列(或欄)。

## 語法

```
=UNIQUE(陣列, [依欄], [僅一次])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列 | 必要 | 資料 |
| 依欄 | 選用 | TRUE 則唯一欄 |
| 僅一次 | 選用 | TRUE 則僅出現一次的項目 |

## 傳回

傳回移除重複後的唯一列（或欄）陣列，並會溢出。若沒有保留的項目則傳回 #N/A；內部錯誤則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=UNIQUE({1;2;2;3})` | {1;2;3} | 移除重複 |
| `=UNIQUE({1;2;2;3},,TRUE)` | {1;3} | 只出現一次的值 |

## 備註

- 無結果時傳回 #N/A 而非 #CALC!。
- 相關函數：FILTER、SORT。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `UNIQUE` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.UNIQUE`。
