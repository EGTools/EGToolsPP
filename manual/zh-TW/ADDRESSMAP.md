# ADDRESSMAP

**類別**: EGTools 專用函數

將地址的地籍圖圖片插入呼叫儲存格(VWorld WMS)。

## 語法

```
=ADDRESSMAP(地址, [縮放級別], [api_key])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 地址 | 必要 | 道路名或地番地址 |
| 縮放級別 | 選用 | 1~10(預設 5)，越大越放大 |
| api_key | 選用 | vworld.kr 認證金鑰，輸入一次後存入登錄檔 |

## 傳回

成功時傳回空字串（""），並將地址一帶的地籍圖（VWorld WMS）圖片依呼叫儲存格大小另行插入。地址為空或縮放級別超出 1~10 時傳回 #VALUE!；找不到地址時傳回 #N/A；無法得知呼叫儲存格時傳回 #REF!；金鑰缺漏、網路或服務錯誤則以 "ERROR: …" 文字傳回。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=ADDRESSMAP("세종대로 110",7)` |  | 插入地籍圖圖片（需要插入圖片、網路與 API 金鑰） |

## 備註

- 不隨附 API 金鑰。請至[空間資訊開放平台](https://www.vworld.kr)申請，以最後一個引數輸入一次後即儲存於使用者帳戶；金鑰被拒絕時會自動刪除並傳回重新申請的指引。
- 先將地址轉換為座標（道路名→地番），再取得包含連續地籍圖圖層的地圖。
- 地址·api_key 指定為陣列時傳回 #VALUE!（api_key 會在儲存前被拒絕，防止儲存錯誤的金鑰）— 多筆資料請將公式逐列複製使用。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `ADDRESSMAP` 原名註冊。
