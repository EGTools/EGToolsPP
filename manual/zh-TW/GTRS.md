# GTRS

**類別**: Google Sheets 相容函數

GOOGLETRANSLATE 的簡短別名 — 使用 Google 翻譯文字。

## 語法

```
=GTRS(文字, [來源語言], [目標語言])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字 | 必要 | 要翻譯的文字(或範圍) |
| 來源語言 | 選用 | 來源語言代碼，如 "en"(預設 "auto" 自動偵測) |
| 目標語言 | 選用 | 結果語言代碼(預設: 介面語言) |

## 傳回

與 GOOGLETRANSLATE 相同，以純量傳回翻譯後的文字。HTTP 要求失敗時傳回 #VALUE!；服務錯誤·語言代碼錯誤·超過 5000 字時以 "ERROR:…" 文字傳回；空文字則傳回空字串。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=GTRS("안녕하세요","ko","en")` |  | 視翻譯結果而定 |

## 備註

- GOOGLETRANSLATE 的簡短別名，使用相同的實作。詳細行為請參考 GOOGLETRANSLATE 文件。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `GTRS` 原名註冊。
