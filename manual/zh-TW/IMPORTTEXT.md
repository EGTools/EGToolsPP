# IMPORTTEXT

**類別**: MS Excel 相容函數 · **原生導入**: Excel 365 (2026 新增)

將文字檔(本機路徑/URL)匯入為陣列。

## 語法

```
=IMPORTTEXT(路徑, [分隔符], [略過列], [擷取列], [編碼], [地區設定])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 路徑 | 必要 | 本機檔案路徑或 URL |
| 分隔符 | 選用 | 分隔文字(預設 Tab)，{1,3} 等遞增數字為固定寬度欄 |
| 略過列 | 選用 | 略過的列數 — 負數從末尾 |
| 擷取列 | 選用 | 擷取的列數 — 負數從末尾 |
| 編碼 | 選用 | 預設 "utf-8" — windows-1252、euc-kr 等 |
| 地區設定 | 選用 | 數字解析地區，如 "de-DE" |

## 傳回

將文字檔（本機路徑或 URL）以分隔符或固定寬度切分後，以二維陣列溢出傳回，數字·日期文字會自動轉換。缺少路徑、讀取/下載失敗、分隔符/固定寬度指定錯誤時傳回 #VALUE!；套用 skip/take 後沒有剩餘的列時傳回 #N/A。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=IMPORTTEXT("C:\data\log.txt",";",1)` |  | 視檔案內容而定 |

## 備註

- 省略 delimiter 時預設為 Tab。字串（可多個）解讀為分隔符，數字陣列（{1,11,21}）解讀為固定寬度的欄起始位置（以 1 為基準、遞增）。
- encoding 支援 "euc-kr" 之類的字元集名稱或字碼頁編號；有 BOM 時以 BOM 優先。
- skip_rows/take_rows 給負數時從末尾起算。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `IMPORTTEXT` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.IMPORTTEXT`。
