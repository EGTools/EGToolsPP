# SEQUENCE

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2021

產生連續數字的陣列。

## 語法

```
=SEQUENCE(列數, [欄數], [起始], [間距])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 列數 | 必要 | 列的數量 |
| 欄數 | 選用 | 欄的數量(預設 1) |
| 起始 | 選用 | 起始值(預設 1) |
| 間距 | 選用 | 增量(預設 1) |

## 傳回

傳回 rows×cols 大小的連續數字陣列（以列優先順序遞增），並會溢出。若 rows 或 cols 小於等於 0 則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=SEQUENCE(3)` | {1;2;3} | 預設 3 列數列 |
| `=SEQUENCE(2,3,0,10)` | {0,10,20;30,40,50} | 指定起始值與增量 |

## 備註

- 省略 rows 時視為 1（原生函數為必要引數）。
- 相關函數：RANDARRAY。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `SEQUENCE` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.SEQUENCE`。
