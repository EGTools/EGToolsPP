# XOR

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

傳回引數的邏輯互斥或(為 TRUE 的個數為奇數時傳回 TRUE)。

## 語法

```
=XOR(邏輯1, ...)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 邏輯1 | 必要 | 要檢驗的值或範圍 |
| … | 選用 | 上述引數可重複指定 |

## 傳回

若為 TRUE 的值個數為奇數則傳回 TRUE，偶數則傳回 FALSE（邏輯純量）。若引數中有錯誤則直接傳回第一個錯誤；若沒有任何可評估為邏輯值的值則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=XOR(TRUE,FALSE)` | TRUE | 奇數個 TRUE |
| `=XOR(TRUE,TRUE)` | FALSE | 偶數個 TRUE |
| `=XOR(1,0,1,"text")` | FALSE | 忽略文字 |

## 備註

- 會忽略文字與空值（原生函數對無法轉換的文字傳回 #VALUE!）。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `XOR` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.XOR`。
