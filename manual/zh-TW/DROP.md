# DROP

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2024

從陣列的開頭或結尾移除列/欄。

## 語法

```
=DROP(陣列, 列數, [欄數])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列 | 必要 | 陣列 |
| 列數 | 必要 | 移除的列(負=從結尾) |
| 欄數 | 選用 | 移除的欄(選用) |

## 傳回

傳回移除指定數量的列、欄後剩餘的陣列，在支援動態陣列的 Excel 中會溢出。若陣列為空，或移除後沒有剩餘的列、欄，則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=DROP({1,2,3;4,5,6;7,8,9},1)` | {4,5,6;7,8,9} | 移除第一列 |
| `=DROP({1,2,3;4,5,6;7,8,9},1,-1)` | {4,5;7,8} | 移除第一列與最後一欄 |
| `=DROP({1,2},5)` | #VALUE! | 全部移除則為錯誤 |

## 備註

- 列數、欄數為負數時，從結尾開始移除。
- 若結果為空陣列，會傳回 #VALUE! 而非原生的 #CALC!。
- 相關函數：TAKE
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `DROP` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.DROP`。
