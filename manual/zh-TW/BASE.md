# BASE

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

將數字轉換為給定基數（進位制）的文字。

## 語法

```
=BASE(number, radix, [min_length])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| number | 必要 | 要轉換的數字（≥0） |
| radix | 必要 | 基數 2-36 |
| min_length | 選用 | [選用] 結果最小長度 |

## 傳回

傳回以指定進位法表示的文字(純量)。若 number 為負數或不是數字，或 radix 超出 2~36 範圍，則傳回 #NUM! 錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=BASE(255,16)` | FF | 將 255 轉為十六進位 |
| `=BASE(15,2,8)` | 00001111 | 補 0 至最小長度 |

## 備註

- 捨去 number 的小數部分(無條件捨去)。
- 結果短於 min_length 時會在前面補 0。
- 相關函數: DECIMAL
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `BASE` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.BASE`。
