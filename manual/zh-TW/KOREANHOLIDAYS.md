# KOREANHOLIDAYS

**類別**: EGTools 專用函數

傳回韓國國定假日清單(含替代假日規則)。

## 語法

```
=KOREANHOLIDAYS([年份], [含名稱], [勞動節], [api_key])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 年份 | 選用 | 年份(預設: 今年) |
| 含名稱 | 選用 | TRUE 包含名稱(預設) |
| 勞動節 | 選用 | TRUE 包含勞動節(預設) |
| api_key | 選用 | 用於查詢臨時節假日的 data.go.kr 金鑰。輸入一次即儲存，之後可省略。指定 0 則不呼叫 API，僅用內建計算 |

## 傳回

以每列為 [日期序列值, 假日名稱] 的 2 欄陣列溢出(含名稱=FALSE 時僅有日期 1 欄)。年份超出 919~2050 範圍時傳回 #VALUE! 錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=ROWS(KOREANHOLIDAYS(2025,,,0))` | 18 | 2025 年假日的列數 — 最後一個引數 0 表示不使用 API，僅用內建計算 |
| `=INDEX(KOREANHOLIDAYS(2025,FALSE,,0),1,1)` | 45658 | 第一個假日(1 月 1 日)的序列值，僅日期(不含名稱) |
| `=KOREANHOLIDAYS(2026)` |  | 預設動作 — 以已儲存的 data.go.kr 金鑰合併臨時節假日(如 2026-06-03 全國同時地方選舉日等)。結果列數依金鑰註冊與網路狀態而異 |

## 備註

- 依實施年度反映替代假日規則(兒童節 2014~，三一節·光復節·開天節 2022~，釋迦誕辰日·聖誕節 2023~)。
- 假日名稱依增益集語言設定(韓文/英文)而定，同一天重疊的假日名稱會以逗號合併。
- 農曆假日(農曆新年·釋迦誕辰日·秋夕)以內建農曆表(918~2050 年)計算。
- api_key 引數有三種用法。**省略**時(預設動作)會以已儲存的 data.go.kr 金鑰查詢特定假日資訊 API，自動合併臨時節假日·選舉日等內建計算所沒有的項目；若沒有金鑰或查詢失敗，則僅傳回內建計算結果(公式不會因錯誤而中斷)。**指定金鑰字串**時會儲存並使用該金鑰，此時若查詢失敗，儲存格會以 `ERROR: 공휴일 API - <사유>` 的形式顯示原因(無金鑰 / 金鑰遭拒+伺服器訊息 / 伺服器連線失敗 / 回應中無項目)。**指定 0** 時不呼叫 API，僅使用內建計算(不存取網路)。
- data.go.kr(公共資料入口)認證金鑰每個帳號一組，KOREANHOLIDAYS·功能區行事曆/行程表·BRNSTATUS 共用同一金鑰。以最後一個引數傳入一次，或在功能區 [EGTools] → [管理 API 金鑰] 註冊後，即儲存於使用者帳戶，之後可省略；舊版本為營業登記號碼查詢註冊的金鑰，會在首次使用時自動移轉至整合位置。
- 查詢結果會依年度快取，重新計算時同一年度只會呼叫一次。失敗不會快取，因此修正金鑰後下次計算會立即生效。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `KOREANHOLIDAYS` 原名註冊。
