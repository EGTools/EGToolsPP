# CODE128

**類別**: EGTools 專用函數

將文字產生 CODE128 條碼圖片並插入呼叫儲存格。

## 語法

```
=CODE128(文字, [顯示文字], [GS1], [文字大小])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字 | 必要 | 要編碼的字串 |
| 顯示文字 | 選用 | TRUE 時在條碼下方顯示原文 |
| GS1 | 選用 | TRUE 時為 GS1-128(FNC1) 格式 |
| 文字大小 | 選用 | 標籤相對大小 |

## 傳回

成功時傳回空字串("")，並另行插入符合呼叫儲存格大小的 Code128 條碼圖片。若文字為空，或 GS1 轉換或編碼失敗，傳回 #VALUE!；若無法得知呼叫儲存格，傳回 #REF!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=CODE128("ABC-1234",TRUE)` |  | 插入含下方文字顯示的條碼(插入影像，視環境而定) |
| `=CODE128("(01)04012345678901(10)LOT42",FALSE,TRUE)` |  | 以 GS1-128(FNC1) 格式插入(插入影像，視環境而定) |

## 備註

- gs1=TRUE 時，會將 (AI)值 文字編碼為完全符合 FNC1 的 GS1-128(符號體系識別碼 ]C1)。
- 圖片會填滿呼叫儲存格(1D 格式)。
- 文字大小為相對值，會反映在下方文字帶的高度。
- 文字指定為陣列時傳回 #VALUE!（每個儲存格一張圖片）— 多筆資料請將公式逐列複製使用。
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `CODE128` 原名註冊。
