# WEEKNUMOFMONTH

**類別**: EGTools 專用函數

依週起始日與歸屬日計算月內週數。

## 語法

```
=WEEKNUMOFMONTH(日期, [週起始日], [歸屬日])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 日期 | 必要 | 基準日期 |
| 週起始日 | 選用 | 1=日~7=六(預設 2=一) |
| 歸屬日 | 選用 | 決定所屬月的星期(預設 5=四) |

## 傳回

傳回月內週次(純量數字)。無法解析日期，或起始星期·基準星期超出 1~7 範圍時，傳回 #VALUE! 錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=WEEKNUMOFMONTH(DATE(2026,1,15))` | 3 | 1 月第 3 週 |
| `=WEEKNUMOFMONTH(DATE(2026,2,1))` | 5 | 2/1 屬於 1 月第 5 週 |

## 備註

- 星期編號為 1=日 ~ 7=六，預設為週一開始·週四基準。
- 週的所屬月份·週次以基準星期所在的月份為準計算。
- 相關函數: MONTHBHYWEEK
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `WEEKNUMOFMONTH` 原名註冊。
