# CPK

**類別**: EGTools 專用函數

由測量值與規格界限計算製程能力指數 Cpk。

## 語法

```
=CPK(資料, [上限], [下限])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 資料 | 必要 | 測量值範圍或陣列 |
| 上限 | 選用 | USL(僅有下限時可省略) |
| 下限 | 選用 | LSL(僅有上限時可省略) |

## 傳回

以純量數字傳回製程能力指數 Cpk = min((USL-μ)/3σ, (μ-LSL)/3σ)。沒有 data 或 USL·LSL 皆未提供時傳回 #VALUE!，數字資料少於 2 個時傳回 #NUM!，標準差為 0 時傳回 #DIV/0! 錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=CPK({1;2;3;4;5},5,0)` | 0.421637021 | 規格 0~5 的 Cpk |

## 備註

- 使用樣本標準差(n-1)。
- 只提供單邊規格時，僅以該方向計算。
- 相關函數: CP
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `CPK` 原名註冊。
