# IFS

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2016/2019

依序檢查條件，傳回第一個為 TRUE 的條件對應的值。

## 語法

```
=IFS(條件1, 值1, ...)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 條件1 | 必要 | 要檢驗的條件 |
| 值1 | 必要 | 條件為 TRUE 時的結果 |
| … | 選用 | 上述引數可重複指定 |

## 傳回

原樣傳回第一個為真之條件對應的值（純量或陣列）。若沒有為真的條件則傳回 #N/A；若條件為錯誤值則直接傳回該錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=IFS(1>2,"a",2>1,"b")` | b | 第一個 TRUE 條件的值 |
| `=IFS(1>2,"a")` | #N/A | 沒有為真的條件 |

## 備註

- 條件為文字或空值時視為 FALSE（原生函數為 #VALUE!）。
- 相關函數：SWITCH。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `IFS` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.IFS`。
