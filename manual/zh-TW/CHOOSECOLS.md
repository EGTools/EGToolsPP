# CHOOSECOLS

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2024

傳回陣列中指定的欄。

## 語法

```
=CHOOSECOLS(陣列, 欄號1, ...)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 陣列 | 必要 | 陣列 |
| 欄號1 | 必要 | 要傳回的欄(負=從結尾) |
| … | 選用 | 上述引數可重複指定 |

## 傳回

傳回由所選欄組成的陣列，在支援動態陣列的 Excel 中會溢出。若陣列為空、欄號為 0 或超出範圍，或未指定任何欄號，則傳回 #VALUE!。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=CHOOSECOLS({1,2,3;4,5,6},1,3)` | {1,3;4,6} | 選取第 1、3 欄 |
| `=CHOOSECOLS({1,2,3;4,5,6},-1)` | {3;6} | 選取最後一欄 |
| `=CHOOSECOLS({1,2;3,4},5)` | #VALUE! | 欄號超出範圍 |

## 備註

- 欄號為負數時，從結尾往回計算。
- 若要選取列，請使用 CHOOSEROWS。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `CHOOSECOLS` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.CHOOSECOLS`。
