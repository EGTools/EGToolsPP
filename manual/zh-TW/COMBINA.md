# COMBINA

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2013

傳回給定數目項目的可重複組合數。

## 語法

```
=COMBINA(number, number_chosen)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| number | 必要 | 項目總數 |
| number_chosen | 必要 | 每個組合的項目數 |

## 傳回

傳回允許重複的組合數(純量數字)。引數不是數字或為負數時傳回 #NUM! 錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=COMBINA(4,3)` | 20 | 4 個中允許重複取 3 個的組合 |
| `=COMBINA(10,3)` | 220 | 10 個中允許重複取 3 個的組合 |

## 備註

- 捨去小數部分，並以 C(n+k-1, k) 計算。
- 相關函數: PERMUTATIONA
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `COMBINA` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.COMBINA`。
