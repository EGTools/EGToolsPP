# TEXTREPLACE

**類別**: EGTools 專用函數

取代文字中每個 起始鍵…結束鍵 區段。

## 語法

```
=TEXTREPLACE(文字, 起始鍵, 結束鍵, [取代文字], [保留鍵])
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| 文字 | 必要 | 來源文字 |
| 起始鍵 | 必要 | 區段起始標記 |
| 結束鍵 | 必要 | 區段結束標記 |
| 取代文字 | 選用 | 取代內容(預設空) |
| 保留鍵 | 選用 | TRUE 時保留標記僅取代內部 |

## 傳回

傳回套用取代後的單一文字（純量）。文字、起始鍵、結束鍵任一為空時，不會傳回錯誤，而是原樣傳回原始文字。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=TEXTREPLACE("a[x]b[y]c","[","]","*")` | a*b*c | 以 * 取代所有區段 |
| `=TEXTREPLACE("a<1>b","<",">","2",TRUE)` | a<2>b | 保留鍵取代 |

## 備註

- 鍵的搜尋會忽略大小寫。
- 遇到沒有結束鍵的起始鍵時，僅取代該起始鍵的位置，其餘文字保持不變。
- 相關函數：TEXTBETWEEN
- 支援: Excel 2010+。在所有 Excel 版本中一律以 `TEXTREPLACE` 原名註冊。
