# LET

**類別**: MS Excel 相容函數 · **原生導入**: Excel 2021

為值指定名稱，並在最終計算中使用這些名稱。

## 語法

```
=LET(name1, value1, calculation, ...)
```

## 引數

| 引數 | 必要 | 說明 |
|---|---|---|
| name1 | 必要 | 要定義的名稱 |
| value1 | 必要 | 此名稱的值 |
| calculation | 必要 | 使用上述名稱的最終計算式 |
| … | 選用 | 上述引數可重複指定 |

## 傳回

傳回將名稱以值取代後之最終計算式的求值結果；若結果為陣列則會溢出。若引數結構有誤或無法讀取呼叫儲存格的公式則傳回 #VALUE!；若求值失敗，會傳回取代後的公式字串而非錯誤。

## 範例

| 公式 | 結果 | 說明 |
|---|---|---|
| `=LET(x,3,x*2)` | 6 | 定義名稱後計算 |
| `=LET(x,2,y,x+1,x*y)` | 6 | 可參照前面的名稱 |

## 備註

- 這是巨集表類型函數：不像原生函數那樣繫結名稱，而是在呼叫儲存格的公式文字中將名稱以值取代後，再以 Application.Evaluate 求值。
- 名稱 "R"、"C" 是 Excel R1C1 剖析器的保留字，無法使用。
- 若求值失敗，為便於偵錯會原樣傳回取代後的公式字串。
- 支援: Excel 2010+。在沒有原生函數的舊版 Excel 中以 `LET` 原名註冊（可直接替換），在已內建原生函數的新版 Excel 中則註冊為 `EG.LET`。 在部分舊版 Excel 中因保留字衝突，會以 `xLET` 名稱註冊。
